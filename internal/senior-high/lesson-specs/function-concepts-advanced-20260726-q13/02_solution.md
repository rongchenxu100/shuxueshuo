# 解答

1. 第1步：逐项检查变量间是否唯一对应
   - A：以 \(d\) 为自变量。除容器连接处的最大直径外，同一个截面直径 \(d\) 会在上、下两个圆锥中各出现一次，对应两个不同的水面高度 \(h\)。因此 \(h\) 不是 \(d\) 的函数
   - B：以 \(t\) 为自变量。水匀速流出且排水过程单向进行，任一时刻 \(t\) 对应唯一的水量和水面位置，从而截面直径 \(d\) 唯一。因此 \(d\) 是 \(t\) 的函数
   - C：以 \(t\) 为自变量。同一排水过程中，任一时刻 \(t\) 只有一个水面位置，水面高度 \(h\) 唯一。因此 \(h\) 是 \(t\) 的函数
   - D：以 \(h\) 为自变量。容器形状固定，任一水面高度 \(h\) 确定唯一的水平截面，该截面直径 \(d\) 唯一。因此 \(d\) 是 \(h\) 的函数
   - ∴：错误的是 A

答案：A
