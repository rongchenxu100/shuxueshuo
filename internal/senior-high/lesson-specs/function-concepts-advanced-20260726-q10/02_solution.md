# 解答

1. 平方化简并确定值域
   - 由根式有意义：\(1-x≥0\)，且 \(1+x≥0\)
   - ∴：\(x≤1\)，且 \(x≥-1\)
   - ∴定义域：\(-1≤x≤1\)
   - 令：\(y=\sqrt{1-x}+\sqrt{1+x}\)
   - ∴：\(y^2=2+2\sqrt{1-x^2}\)
   - ∵：\(0≤1-x^2≤1\)
   - ∴：\(0≤\sqrt{1-x^2}≤1\)
   - ∴：\(2≤y^2≤4\)
   - 又：\(y≥0\)
   - ∴：\(\sqrt{2}≤y≤2\)，函数值域为 \([\sqrt{2},2]\)，选 C

答案：C
