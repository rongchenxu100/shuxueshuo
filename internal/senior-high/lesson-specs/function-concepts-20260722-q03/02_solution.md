# 解答

判断关系图是否表示从 M 到 N 的函数，统一检查两个条件：对任意 `x∈M`，都有且只有一个确定的 y 与之对应；实际值域是 N 的子集。

1. 图①纵坐标的取值范围为 `[0,2]⊆N`，但取 `x=3/2∈M` 时没有对应的 y，不满足条件一。
2. 图②使 M 中每个 x 有唯一的 y 与之对应，实际值域为 `[0,2]`，是 N 的子集。
3. 图③使 M 中每个 x 有唯一的 y 与之对应，实际值域为 `[0,1]`，是 N 的子集。
4. 图④纵坐标的取值范围为 `[0,2]⊆N`，但同一个 `x∈(0,2]` 对应两个不同的 y，不满足条件一。

所以图②、图③能表示集合 M 到集合 N 的函数关系，选 C。
