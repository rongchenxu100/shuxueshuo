# 解答

采用数形结合法，把各选项给出的定义区间与抛物线 \(y=f(x)\) 上的对应图像联系起来。

1. 确定取得最小值与最大值的位置
   - 配方：\(f(x)=(x-1)^2-4\)
   - ∴：区间只要包含 \(x=1\)，最小值就是 -4；要取得最大值 5，区间需包含 \(x=-2\) 或 \(x=4\)
2. 逐项检查定义区间
   - A：\([-2,4]\) 的值域为 \([-4,5]\)
   - B：\([-2,1]\) 的值域为 \([-4,5]\)
   - C：\([1,4]\) 的值域为 \([-4,5]\)
   - D：\([-1,1]\) 的最大值为 \(f(-1)=0\)，不可能得到 5，选 D

答案：D
