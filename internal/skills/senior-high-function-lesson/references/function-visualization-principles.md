# 高中函数可视化原则

- 有限离散集合的映射题可使用集合与箭头。定义域是连续区间且候选由函数公式给出时，优先绘制完整函数图像：保留坐标轴和定义域外的曲线，用浅色表示完整曲线，用主色加粗定义域内的有效片段，并用移动竖线验证“每个 x 唯一对应 y”。
- 必须区分函数的天然定义域与题目指定的输入集合。完整曲线只能画在函数天然定义域内；主色片段取天然定义域与题设集合的交集，不能为了视觉连续而画出无定义部分。
- 同一组候选函数默认共用坐标范围、轴位置和视觉比例，保证切换候选时可以直接比较。只有函数增长速度或间断点导致统一尺度明显失真时，才允许调整视窗，并在图中明确提示。
- 实际值域的计算、`R⊆B` 判断和函数定义的两个必要条件默认放在数学推导文本中。只有当区间关系本身是核心学习对象时，才增加独立的数轴或比较面板，避免图形同时承担过多任务。
- “唯一对应”和“实际值域属于 B”必须作为两个并列判据展示；若候选只在其中一个条件失败，页面必须准确标出失败条件。
- 同一函数与关系图题用候选切换，不强行加入连续滑块。
- 原题包含关系图、坐标图或几何图时，必须先在原题区域完整重建全部图形和选项编号。步骤图应复用同一份声明式图形数据，只叠加竖线、交点或强调色等教学标记；不得另画一幅结构、比例或端点不同的“示意图”替代原图。
- 原题图的验收尺寸就是它在题目卡和聚合练习页中的最终尺寸。不得依赖放大后的步骤图来弥补原题图中文字过小；轴名、刻度、点名、尺寸和选项编号应使用适配小图的独立字号与线宽。
- 定义域题按“列出全部约束 → 取交集”组织。约束较少且推导直接时，先在一个纯文字步骤中列完条件，再只为交集结果绘制数轴；不要把每个简单不等式硬拆成一张图。数轴严格区分空心、实心端点和排除点。
- 有限定义域题用值表；连续区间值域题才使用移动输入点和投影。
- 移动点必须同步展示输入值和函数值，并在图中显示横纵投影。
- 当函数图用于核对闭区间上的值域结论时，滑块范围必须严格限制在题设定义域内，并在 x 轴明确标出可取的边界值；端点应使用规格中的数学标签，避免把 `1/2` 等边界降级成小数。
- 二次函数图像用于解释区间值域时，应展示正常比例下的完整抛物线与坐标轴，并用虚线标出对称轴；再用颜色强调题设定义域内的有效部分，避免只放大某一支曲线。
- 坐标图默认展示完整坐标轴以及理解曲线所需的正负方向、刻度和边界值，不裁成只剩函数局部形状的特写。函数、横轴、滑块、对称轴和推导中的自变量符号必须统一。
- 函数图横轴必须使用题目中的自变量符号，例如 `g(t)` 的横轴标为 `t`，`f(x)` 的横轴标为 `x`；滑块、对称轴、点坐标和推导过程使用同一套符号。
- 应用题的几何背景只保留建立函数关系所需信息，不做装饰性复杂图形。
- 应用图中的变量标注应贴近对应线段且不互相遮挡。只在图和推导中保留确实使用的点名、线段名和辅助线；若某个线段无法清晰呈现，优先改用图中可见的等长线段表达，而不是在正文引用不可见对象。
- 一个步骤只强调当前结论所需对象。已经不参与推理的面板应隐藏。
- 没有独立视觉教学价值的步骤应设置 `showDiagram: false`，页面只保留居中的文字推导，不生成空白或装饰性图形区域。
- 同一函数判断题若只需逐项比较定义域和对应关系，默认使用纯文字推导。不要为了重复区间结论而绘制数轴；只有区间的交、并、补或端点变化本身是学习重点时才使用数轴。
- 所有颜色都要辅以标签、边界样式或文字，不能只靠颜色传递数学状态。
- 图例只解释图中真实存在的视觉编码，不把数学结论伪装成颜色含义。
- 控件必须揭示联动关系：滑动输入时同步显示相关函数值、长度、宽度或几何形状变化。若后续步骤只做静态代数求解，移除滑块，避免制造无意义交互。

## 原题图清晰度硬门槛

- 把题目详情页和基础练习聚合页视为两个独立交付场景。原题图必须提供 `detail` 与 `aggregate` 两档渲染参数；不得把同一套大画布字号机械缩放到两个不同尺寸的容器中。
- 若要求保持原图区域大小不变，保持外层容器宽高和页面布局不变，只调整 SVG `viewBox`、绘图区留白、字号、线宽及标签位置。不要用放大卡片、浏览器缩放或额外弹窗掩盖清晰度问题。
- 在浏览器 100% 缩放下，以 `getBoundingClientRect()` 的实际 CSS 像素验收，不以 SVG 中的声明字号验收。题目详情页的刻度和数字实际高度不得小于 `12px`，坐标轴变量不得小于 `14px`；聚合页的刻度和数字不得小于 `11px`，坐标轴变量不得小于 `13px`。
- 曲线、坐标轴和关键端点缩放后必须仍可辨认；主要曲线和坐标轴的实际线宽均不得小于 `1px`。字号放大后不得裁切曲线或减少理解题意所需的坐标范围。
- 所有轴名、端点刻度、原点、点名、尺寸和选项标记都必须做边界框碰撞检查：任意两个语义不同的标签不得相交，文字不得越出 SVG，可视范围内也不得被裁切。重点检查 `x` 与最右刻度、`y` 与最上刻度、`O` 与零附近刻度。
- 若 HTML 已在图外显示 A/B/C/D 等选项标题，原题 SVG 内不得重复标题；原题静态图也不得混入教学步骤中的移动点、坐标提示或高亮答案。
- 至少在常规桌面宽度和 `724px` 窄窗口各复测一次详情页与聚合页。多选题要逐幅检查，不能只抽查第一幅；表格、关系图和函数图都适用这套要求。
- 为可测量元素输出稳定标记，例如 `data-axis-tick`、`data-axis-label` 和 `data-axis-origin`。为详情/聚合两档字号、原图静态性和标题去重补回归测试；浏览器复测还要记录实际文字高度、越界数和标签碰撞数。

## 审校规则

- 纯代数推导默认无图。没有图时不渲染图形容器；相邻步骤使用完全相同的图且没有状态变化时，只保留一次。
- 函数图优先展示完整坐标轴和足够的整体趋势，再用颜色或线宽突出题设定义域内的有效片段，不能为了放大局部而让学生看不到坐标系和全貌。
- 坐标轴变量必须与推导一致：研究 `g(t)` 时横轴写 `t`，不能沿用通用的 `x`。对称轴、边界、端点投影等辅助线使用虚线并清楚标注。
- 原题图形按题面复原：拓扑关系、选项编号、坐标刻度、字母、尺寸和虚实线均不得省略。显示区域固定时，应调整 SVG `viewBox`、字号和线宽，而不是依赖浏览器缩放。
- 坐标轴名称应放在正向箭头外侧，并与端点刻度分居坐标轴两侧；聚合页缩放后仍不得出现 `x` 与最右刻度、`y` 与最上刻度重叠。
- 图中的字号按最终嵌入尺寸验收。表格优先使用可访问的 HTML；必须使用 SVG 时，增大字号、行高和有效绘图区，不能把小表格放在大块空白画布中。
- 立体容器用椭圆截面、实线前缘和虚线后缘表达空间关系。相连水体使用一致的填充色和透明度，图层顺序固定为水体、隐藏轮廓、可见轮廓、标注。
- 交互只保留能揭示变量联动的控件。滑块变化应同步更新公式值、图形和标签；若步骤只需判断范围或完成静态运算，则不添加滑块。
- 图形必须与当前文字推导一一对应。若文字讨论定义域交集，图中应同时呈现参与取交的区间；若本步骤只求平移后的定义域，则不要提前画下一步的根式约束。
