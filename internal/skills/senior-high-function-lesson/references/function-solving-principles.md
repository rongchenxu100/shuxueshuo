# 高中函数解题原则

## 步骤组织

- 步骤数由独立认知动作决定，不由页面模板决定。列举有限值、抽象函数特殊赋值、直接配方或一次不等式求解可以只用一步；只有结论之间存在真实依赖时才拆步。
- 选择题通常按选项拆步，并对每个选项使用相同的检查框架。不要先随意详解一个选项、再用另一套标准略过其余选项。
- 定义域、值域或函数关系判断若有两个必要条件，应在每个候选中依次检查。反例可先写完整条件结论，再补一个特殊输入作为直观证据。
- “解题要点”总结可迁移的方法，不复述本题答案。例如写“判断函数需检查唯一对应和值域包含关系”，而不是写“选 C”。
- 推导采用“必要的简短说明 + 数学式”结构：先说明所设量或所用性质，再用 `∵`、`∴` 和标准关系式推进。不要用大段自然语言替代计算，也不要堆叠没有语义说明的线段名或公式。
- `∵`、`∴`、`⇔` 按逻辑含义使用：原因、结论和等价变形不得混用。连续推导中若页面重点是结论链，可用 `∴` 领起下一行；只有双向等价确实成立且需要强调时才使用 `⇔`。

## 函数概念

- 判断 `A→B` 的函数时，必须分别检查两个条件：定义域中的每个元素都有且只有一个对应值；函数的实际值域是 `B` 的子集。一个候选可能满足唯一对应，却因函数值越界而失败。
- 检验抽象函数等式的一致性时，先明确函数定义：对定义域内任意一个自变量 \(u\)，函数值 \(f(u)\) 唯一确定。使用特殊值制造相同输入后，必须写成 \(x=a\Rightarrow f(u)=m\)、\(x=b\Rightarrow f(u)=n\) 的函数值等式；若 \(m\ne n\)，明确指出同一个 \(f(u)\) 有两个值。避免使用依赖版面位置的“左侧输入”“右侧输出”等描述。
- 判断同一函数时，统一使用“定义域和对应关系”两个条件，不使用“对应法则”。自变量字母不同不影响函数相同；比较多组函数时，将自变量统一记号，并始终用 `f(x)`、`g(x)` 指代，避免“左式、右式、两式”造成歧义。
- 关系图先做竖线检验，再核对定义域和值域集合是否完整。

## 定义域

- 根式：偶次根被开方数不小于零。
- 分式：分母不等于零；若分母含偶次根，则被开方数严格大于零。
- 零次幂：底数不等于零。
- 复合函数 `y=f(g(x))` 要先判断已知对象：若已知 `f(x)` 的定义域为集合 `A`，则要求 `g(x)∈A`；若已知 `f(g(x))` 的定义域为集合 `A`，则 `f(x)` 的定义域是 `g(x)` 在 `x∈A` 时的取值范围。变量替换时使用新的中间变量，避免让同一个 `x` 同时表示外层自变量和内层输入。
- 实际问题：代数约束之外还要满足长度、面积、数量等实际意义。
- 多个约束逐项写出，最终取交集，不把中间集合直接当答案。

## 函数值与值域

- 有限定义域优先逐个代入并列出值集。
- 抽象函数没有给出具体解析式、只给出函数关系式，并要求特殊函数值时，优先使用赋值法。围绕目标选择 `0`、`1`、相等或互为相反数等特殊值，使函数自变量合并、消去或变成目标值；尽量同时利用已知函数值，约去函数值前必须确认其不为零。
- 值域选择题按函数结构选择标准方法并逐项排除：和与积结构优先考虑基本不等式，二次式优先配方，分式先研究分母范围或分离常数，基本函数可直接使用定义域、单调性与反函数关系。页面必须写出方法依据，不能只凭图像判断。
- 使用基本不等式时先确认各项为正；若自变量可正可负，应先分类讨论。每次都写出取等条件，才能判断值域端点是否能取得。
- 形如 `y=(ax+b)/(cx+d)`（`c≠0`）的分式函数，优先用分离常数法改写为 `y=a/c+(bc-ad)/[c(cx+d)]`，找出反比例结构；再利用反比例函数性质，或从分母区间逐层执行取倒数、数乘和平移。每次明确端点次序和不等号方向的变化。
- 给定闭区间先判断单调性，再比较端点；若不单调，还要检查转折点。
- 写值域时去重，并使用与离散/连续情形匹配的集合或区间记号。
- 函数图像只用于解释输入与输出的对应，不代替严格结论。

## 实际问题建模

- 先在图中定义会参与推导的点、线段和变量，再用相似、面积或数量关系建立函数。正文只引用图中确实可见的符号。
- 对每个临时量补一个简短语义，例如“设矩形的长 `GF=x`”“上方小三角形的高 `CH=h`”；避免让学生从一串点名自行猜测含义。
- 建立函数后补齐实际定义域，再与题设不等式所得范围取交集。最终答案不能只满足代数不等式而忽略长度、面积或数量的实际约束。

## 方法选择与论证补充

- 先写支配本题的定义或定理，再使用技巧。函数判断题优先写“定义域内每个输入只有唯一确定的函数值”，不要只写“唯一对应”而不说明输入和输出。
- 使用临时函数或集合前必须先定义其含义。例如先说明 `H` 是 `h(x)` 的值域、`J` 是 `1/h(x)` 的值域，再写 `H` 与 `J` 的包含关系。
- 判别式法求值域的逻辑是：把 `y` 看作参数，将原关系整理为关于 `x` 的方程；某个 `y` 能成为函数值，当且仅当该方程在规定定义域内有实数解。二次方程情形先由 `Delta >= 0` 得候选范围，再检查定义域和退化情形。
- “对任意 `x1`，存在 `x2` 使 `P(x1)=Q(x2)`”应翻译为值域包含关系 `P(I) subseteq Q(I)`：`P(I)` 中每一个值都必须能在 `Q(I)` 中找到。正文应解释这层量词到集合语言的转换，而不是直接跳到端点不等式。
- 从值域反推定义域只在对应关系于所研究区间单调或一一对应时成立。否则同一个函数值可能对应多个输入，不能直接把值域端点当作定义域端点。
- 平移递推先展示两三个具体链条，例如 `f(9)=f(3)+6`、`f(15)=f(9)+6=f(3)+2*6`，再归纳一般步数，避免直接给最终倍数。
- 用特殊值检验抽象函数等式时，直接写实际函数值，如“同一个 `f(1)` 被推出两个不同值”，不要使用“左侧输入、右侧输出”等含混方位语言。
- 解题要点总结可迁移的方法和适用条件，不复述本题答案。常见表述包括换元法、数形结合法、列举法、分离常数、基本不等式、判别式法和量词转值域包含关系。
