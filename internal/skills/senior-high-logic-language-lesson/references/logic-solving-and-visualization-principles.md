# 常用逻辑用语求解与可视化原则

## 命题

- 先判断语句是否为陈述句，再判断能否确定真假。两项都满足才是命题。
- “是假命题”和“不是命题”不可混淆。错误的数学断言仍可能是假命题；疑问句、感叹句和含未约束自由变量的开放语句通常不是命题。
- 全称或存在量词能约束变量，使开放语句成为可判断真假的命题。
- 分类表至少包含“是否为陈述句、真假能否确定、结论”三列；如果是命题，再说明真值或反例。

## 充分条件与必要条件

- 对“若 p，则 q”，分别验证正向 `p⇒q` 与反向 `q⇒p`：
  - 仅正向成立：p 是 q 的充分不必要条件；
  - 仅反向成立：p 是 q 的必要不充分条件；
  - 双向成立：p 是 q 的充要条件；
  - 双向都不成立：p 是 q 的既不充分也不必要条件。
- 用反例否定蕴含时，反例必须满足前件且不满足后件；不能只给一个不满足前件的值。
- 对不等式或取值范围命题，令 p、q 的解集分别为 P、Q：`p⇒q` 等价于 `P⊆Q`。区间包含需检查端点开闭。
- 在数据中只保存 p、q 的谓词本身；若组件会自动渲染“p：”“q：”，不得在字段值中再次写前缀。每个映射只定义一次，避免出现“p：p：…”或“q：q：…”。
- “求一个充分不必要条件”需要候选集合真包含于原条件集合；“求一个必要不充分条件”需要原条件集合真包含于候选集合。
- 含参射线或区间先求固定条件的解集，再比较端点；最后再验证反向包含不成立，避免把充要条件误作充分不必要条件。

## 可视化

- 有限条目真假、命题/非命题、正反向蕴含：用语义表格。
- 几何判定：优先写定义、判定定理与反例，不画无助于逻辑方向的装饰图。
- 充分必要关系图只保留一组 p、q：从 p 指向 q 的箭头标“充分”，从 q 指向 p 的箭头标“必要”，勾或叉直接放在对应箭头线上；不重复绘制 p、q，也不另写“正向、反向”。
- 当 p、q 是区间或取值范围命题时，在同一关系卡片的箭头图上方先放两条对齐数轴，优先标出题目原有集合名（如 `C_{\mathbb R}A`、`B`）；只有题目没有集合名时才用 P、Q。写出包含关系（如 `B⊊C_{\mathbb R}A`），并翻译成两句命题语言：“前件集合中的元素不一定在后件集合中，所以充分不成立”和“后件集合中的每个元素都在前件集合中，所以必要成立”。数轴负责说明集合证据，箭头负责呈现“充分/必要”的结论，两层信息不可互相替代。
- 已知充分必要关系求参数时，数轴上的关系式必须同时写出集合真包含、端点不等式和最终参数范围；若端点相等会变成充要条件，要在数轴关系式和文字推导中同时排除等号。
- 区间包含和参数边界：用三条对齐数轴，分别表示 p 的解集、q 的解集和参数结论；每条轴只承担一个逻辑角色。
- 数轴端点必须用空心/实心表达是否取到，并在图注中写出包含方向。
- 补集记号中的全集写作下标，例如 `C_{\mathbb R}A`；SVG 中用真正的下标布局，不把 `R` 与 `C`、`A` 排在同一基线上。

## 量词与否定

- 否定量词命题时保持研究范围不变：`∀x∈M,p(x)` 的否定是 `∃x∈M,¬p(x)`；`∃x∈M,p(x)` 的否定是 `∀x∈M,¬p(x)`。不要把 `x∈M` 错改为 `x∉M`。
- 依次否定量词、连接词和关系符号。“至少一个成立”的否定是“全部不成立”；“且”的否定是“或”，“或”的否定是“且”。
- 常见词语否定使用教材式两行对照表展示，如“是/不是”“都是/不都是”“大于/小于或等于”“至少一个/一个也没有”。
- 聚合页、选项、答案和详情页必须保持教材原题一致；干扰项即使错误也不得擅自改写成另一道题。

## 交互选择

- “是否为命题”“真/假”等二元、多小题判断，默认逐项提供两个快速选择按钮，不要求学生重复输入固定短语。
- 每一行只能保留一个选择；提交前提示具体漏答题号，提交后逐行标记“正确”或“需要修改”。
- 只有答案本身需要数学表达式或开放性文字时才使用输入框。

## 反馈回归

- 浏览器批注先定位权威 lesson/topic source，再修正源码、补回归测试并重建；不直接改生成 HTML。
- 数学反馈同时修正结论、推理链和测试断言。
- 教材核心知识允许压缩措辞，但定义顺序、符号含义、命名关系和完整分类必须与原页一致。
- 发布前同时检查专题聚合页、模块页、实战演练和全部详情页，搜索原始 `\\text`、`\\Rightarrow`、`mathbb`、`rac12`、`x_0`、可见反斜杠和不受支持的符号序列。
- 渲染“序号 + 含公式正文”的网格行时，正文必须先包进一个独立容器，再在容器内部渲染行内公式；不得让多个公式节点直接成为网格子项。序号或徽章样式只绑定专用 class，不使用会误伤行内公式 `span` 的宽泛选择器。

## 数学字符串书写

- lesson JSON 中每个数学片段都用 `\\(...\\)` 包围；普通圆括号只表达行文括号，不能代替公式边界。
- JSON 和 JavaScript 生成器中的 TeX 反斜杠都必须双写，例如 `\\mathbb R`、`\\frac{1}{4}`、`\\Delta`。在 `.mjs` 普通字符串中禁止直接写 `\(`、`\frac`：前者会丢失反斜杠，后者的 `\f` 会成为控制字符。
- 分数统一写成带花括号的 `\\frac{分子}{分母}`，不用 `\\frac12` 等简写。
- 单选题的 A、B、C、D 四个选项必须位于同一题目行，确保聚合页能一次解析出四个按钮。
- 构建后检查聚合页与详情页中不存在 `mathbb`、`rac12`、原始 `x_0`、控制字符或可见 TeX 命令。
