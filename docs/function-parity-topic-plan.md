### 3.3 题意约定与必须保留的差别

1. **零点是否被公式覆盖。** A04、A07、A11、A15 是 $x\ge0$；A08、A09、A12 是 $x>0$。A08、A12 的正侧常数项非零，与奇函数在原点取零并不冲突，因为正侧公式不含零点。把 $>$ 识别成 $\ge$ 会制造不存在的矛盾，必须回看原图。
2. **A18 的量词。** 本文答案采用教材差商性质的常规读法：对定义域内任意 $x_1\ne x_2$ 都有差商小于零。原始转录不补造这句话；规范题意需记录这项教材约定及来源，复核不确定时返回待核对。若仅给一对点，条件不足以求出同一个解集。专题若使用显式补全量词的教学题面，另记教学规范化，不能声称原文逐字如此。
3. **A19 的零点域。** 奇性与正半轴条件保证全部非零实数属于定义域，但没有单独说明零点。$x=1$ 时，若 $0\notin D_f$ 则无定义；若 $0\in D_f$ 则 $f(0)=0$，仍不满足严格小于零。因此两种允许情况得到同一解集，代码应证明这种一致性，而不是补写 $D_f=\mathbb R$。
4. **定义域的范围优先。** A15 的“当 $x\ge0$ 时”是在已经给出的定义域内陈述规则，不扩展成所有非负实数。A03 等未单列完整域的题，保留源文及目标输入的合法性检查，不因右边是多项式就给每个未知函数补上无来源的全实数域。
5. **手写答案分开存放。** A05 的左端点、A09 的数值、A12 的零点、A20 的右端点均应由数学推导核定。学生笔迹不能覆盖印刷题干和金标。

| FP-B03 · 拆分有理式求相反输入值 | $f(x)=\frac{2024x^3+2x^2+3x+6}{x^2+3}$，$f(a)=14$，求 $f(-a)$ | 拆出常数 $2$ → 验证余项为奇 → M5 | $-10$；分母恒正；$a$ 是函数输入，不先求出 $a$ |
| FP-B04 · 对称区间上的最大值与最小值之和 | 在 $[-1,1]$ 上，$f(x)=\frac{(x+1)^2+ax^5}{x^2+1}$ 的最大值为 $M$、最小值为 $m$，$a$ 为常数，求 $M+m$ | 拆出常数 $1$ → 验证奇函数部分 → 同一对称范围上的最值配对 | $2$；对每个实数 $a$，闭区间连续性保证实际取得最值；不能假定极值点在端点，也不分别求 $M,m$ |

## 5. 六类题型的方法设计

### 5.1 方法总表

本计划规划 **5 个公共方法**；M1–M5 已随 T1–T5 交付各自受限能力，T6 继续复用 M5 并补偏移来源与最值组合合同。函数求值、联立消元、系数比较、不等式求解等继续调用既有方法或技能。

| 代号 | 名称／候选 ID | 输入 → 输出 | 使用位置 |
| --- | --- | --- | --- |
| M1 | 奇偶性定义法／`method-parity-definition`（别名“定义法”） | 显式函数、原定义域 → 奇性／偶性各自的证明或反例，及四类结论 | T1；T2、T6 的子任务 |
| M2 | 奇偶性条件求参法／`method-parity-parameter` | 含参表达式或定义域、指定奇偶性 → 必要且充分的参数集合及回验 | T2；A15、A20 的求参子任务 |
| M3 | 对称补全法／`method-parity-extension` | 已知局部解析式、完整域、奇偶性 → 可确定部分的解析式、零点与未确定部分 | T3；T4 需要显式分支时 |

常规结构的首轮计划范围为：有理系数多项式（T1 判定至四次，题给正侧规则至少覆盖本批三次式）、有理式、二次根式、绝对值及有限分段；参数优先覆盖仿射端点、至多二次的系数约束；对称关系覆盖输入反射、输出相等／和为常数，以及它们产生的有限迭代。具体次数、段数和计算预算必须在每型 S0 合同中声明并验证，不将这里的计划范围登记为当前支持范围。超出可验证范围时返回能力缺口，不能将求解失败当作“非奇非偶”或“无解”。

### 5.2 T1：判断函数的奇偶性

详细合同、复用缺口、可视化交互和分批验收见 [FP-T1 设计与实现方案](function-parity-problem-type-design.md)。显式函数判定和常见变式已实现，A01 两问已通过[原照片真实 OCR、模型与课程 API 验收](function-parity-t1-photo-acceptance.md)；原题选项任务及独立新照片留出验收仍待完成。实际范围见 [T1 修复与验证记录](function-parity-t1-generalization-acceptance.md)。

**主流程：保留原定义域 → 检查 $D=-D$ → 计算 $f(-x)$ → 分别检查奇、偶恒等式 → 给出结论。**

1. 原式限制先确定，并检查定义域非空。实数范围内无合法输入时，报告题设未定义有效函数，不用空集上的真空恒等给学生判“既奇又偶”。约分后的式子可以用于计算，但不能将约掉的孔洞补回定义域。
2. 对称检查覆盖区间开闭、有限点、多个区间与缺失点。不只比较最左、最右两个端点；不对称时给一个确切的未配对输入，足以排除奇、偶两者。
3. 在原定义域内同时验证 $f(-x)=-f(x)$ 和 $f(-x)=f(x)$，结果用两项性质表示。不能先遇到奇性就提前退出而漏掉“既奇又偶”。
4. 两式都成立时，函数在其对称定义域上恒为零；定义域可以是离散的，例如 $\{-1,1\}$，不要求一定为 $\mathbb R$。
5. 证明不成立需要合法反例或符号证据。计算器无法判定恒等不等于已证其不成立。$f(0)=0$ 只是定义于零点的奇函数的必要条件，不能当充分条件。

运算、复合可在 M1 内作为简化推导路线，引用现有知识条目并保留实际定义域；首轮不再建一套“奇偶性基本函数法”。特别是复合函数，原复合域对称且内层像在外层定义域内，才能套奇偶组合；不能用“外偶内任意必偶”等错误口诀。

代表题 A01 两问用于贯通；本型收尾必须补零函数、非对称域、约分孔洞、简单分段和根式定义域等情形。两道正例通过不代表已覆盖判断题型。

### 5.3 T2：根据奇偶性求参

详细合同、参数分类、父子任务返回、可视化及验收要求见 [FP-T2 设计与实现方案](function-parity-parameter-problem-type-design.md)。T2 R0–R3 已随 `5776ebbe` 提交，数学、临时教学及隔离正式页面已验收，R3 仅支持固定域多项式的两参数仿射联合条件。A17 与 C01–C06 六道新编代表题现已统一发布；连续参数交互控件、独立新照片不在本次发布范围内。实际范围见各批开发记录。

**R0 只开放一个实参数、关于自变量至多二次、定义域为 $\mathbb R$ 的多项式路线；各系数是参数的至多二次有理系数多项式。** 直接复用 `skill-polynomial-coefficient-comparison`，覆盖奇／偶条件、零函数、次数退化及全部／多个／无解；四次扩展放到 R2，不为 A17 改动旧待定系数法合同。

R0 即建立 T2／T3／T4 共用的题给奇偶性事实，区别于 T1 的 `determine_function_parity` 目标。沿用 `declared`／`restriction` 的域语义，“仅保证某段有意义”新增独立合法性条件。R0 保留单一方法的选法卡，只交付卡片和完整推导；域配对图在 R1、系数参数及镜像图在 R2 建设。

课程版本仍按当前全局依赖处理。按 2026-11-11 用户要求，开发期间暂缓公开课程重建；本轮根据“在专题里把题目都发布”的要求统一重建当前 authored 课程。教学／作答合同兼容时保留身份，改变时按[课程身份规则](function-parity-formula-problem-type-design.md)在原 ID 下重建、关闭进行中的作答并保留历史记录。按课程计算依赖指纹另列优化，不作为 T2 前置；不承诺共享改动对无关课程天然无影响。

M2 同时组织两类条件，按题目需要调用：

- **定义域条件。** 非空的单个区间若关于原点对称，有限端点互为相反数、两端开闭匹配；有限并集或有孔洞的域要整体配对。A15 由 $m-5=-(1-2m)$ 得 $m=-4$，还要回验非空；A20 由 $-2b=-(b+1)$ 得 $b=1$，并核对给定单调区间有效。
- **函数值条件。** 奇性要求 $f(-x)+f(x)\equiv0$，偶性要求 $f(-x)-f(x)\equiv0$，恒等作用域是实际定义域。多项式在含区间的域上可比较系数；只有有限个输入时不能直接把全部系数置零。

必要流程：**保留原参数限制 → 域非空及对称 → 在合法域内建立恒等条件 → 解条件 → 按全部原要求回验 → 返回参数集合。**

必须覆盖参数导致的次数退化、分母消失与剩余禁取值、分段边界及零点。题干未声明“二次函数”时不能擅自排除二次系数为零；零函数既奇又偶，只有题目明确要求“奇而非偶”等时才排除它。分段函数需比较镜像输入对应的分支，不是把每一段独立要求为奇／偶。

A17 是系数路线代表题；A15、A20 提供端点参数路线。参数子任务返回集合和已验证域，父任务仍须继续求 $f(m)$ 或解不等式，不提前结束。解出多个参数时按原目标保留全部分支，不能只挑一个数值示例。

### 5.4 T3：根据奇偶性求解析式及对称求值

详细合同、确定范围与自由部分、双函数分离、交互及验收要求见 [FP-T3 设计与实现方案](function-parity-formula-problem-type-design.md)。开发复用基线为 `5776ebbe`，交付提交为 `ee9747bd`；九道完整原题的真实 OCR、模型复核、课程 API 及作答状态机集成通过，现已统一发布。Review 修复及泛化范围见设计 §8.5：多条局部规则、绝对值、既奇又偶、实二次代数数，以及整组关系的全范围相容检查；模型转写兼容修复及真实调用记录见 §8.6。具体题型逻辑由代码处理，T3 交付未修改 prompt；本轮不新增独立照片验收。

T3 从 **A07 → A08** 开始：保留单方法选法卡，R0 复用 `condition_number_lines` 显示已知范围、目标范围与 $x\mapsto-x$，拖动和连续动画后续建设。补全规则用 `type-parity-formula`；A12、A13 等求值题在既有 `type-function-evaluation` 下新增 M5 分支。A15 直接调用 `borrow_domain_parameter`、`verify_borrowed_parameter`，处理剩余条件后继续原求值目标。T2 的单条局部规则相容性判定抽为共享能力，再扩展到 T3 多条规则，不各自复制重叠／零点判定。

**半边补全用 M3。** 设已知 $t\in I$ 时 $f(t)=p(t)$。对 $x\in-I$，先证明 $-x\in I$，再写 $f(-x)=p(-x)$，最后得到：偶函数 $f(x)=p(-x)$；奇函数 $f(x)=-p(-x)$。

零点和重叠部分必须单独处理：

- 已知范围含零时，直接核对题给零点值与奇偶性是否相容；不相容的题设不能生成一个“修正过”的函数。
- 奇函数且 $0\in D$ 时，$f(0)=0$；偶性本身不确定 $f(0)$。只给 $x>0$ 的偶函数公式而问全域解析式时，零点可能仍是自由值。
- $I$ 与 $-I$ 有重叠时，两条推导须在重叠处一致。若 $I\cup(-I)$ 未覆盖完整定义域，只返回已确定范围，不能声称全域唯一。
- 有跳跃仍可能为奇／偶函数。A08、A12 不允许用“图像应连续”替题目增加约束。

区间声明沿用 T2 的左端点严格小于右端点约定；明确的有限点集及合法集合运算产生的孤立点保留。允许经独立验证的非唯一结论完成相应目标：例如偶函数仅给 $x>0$ 的规则，已知 $0\in D$ 且无其他条件约束零点时，只问 $f(0)$ 可答“不能唯一确定”；问完整解析式时须给已确定分支及 $f(0)=c,\ c\in\mathbb R$ 的规则族。能力缺口或证明未决不按这种正确答案处理。

**只问函数值用短路线 M5。** A09①、A12 先把输入变到已知侧，再调用代入法；A13 直接把整个已知组合取负。只求某个表达式的值时，验证目标唯一即可，不强求函数本身唯一。

**奇偶分离复用联立与消元。** A03、A06 可只在所需输入处列方程。需要完整分离时，若 $H=f+g$，$f$ 奇、$g$ 偶，且作用域对称，则

$$
f(x)=\frac{H(x)-H(-x)}2,\qquad g(x)=\frac{H(x)+H(-x)}2.
$$

若 $H=f-g$，偶部分是 $g(x)=-\frac{H(x)+H(-x)}2$。一般 $Af+Bg=H$ 的双函数系统行列式与 $AB$ 有关，不能沿用“同一函数的两个输入”合同中的 $A^2-B^2$ 判定；$A=0$ 或 $B=0$ 时，未被约束的函数可能不唯一，所求组合仍需单独判定。复用 `method-function-equation-system` 时须新增明确的双函数绑定、退化分支和全关系回验；不另建同义消元技能。

### 5.5 T4：利用奇偶性解不等式

详细设计及交付范围见 [FP-T4 利用奇偶性解不等式：设计与实现方案](function-parity-inequality-problem-type-design.md)。三条路线、Review 修复及泛化支持已在 `976a7f82` 提交，六道原题、八个目标完成真实 OCR／模型、课程 API 与作答集成，见[照片验收记录](function-parity-t4-photo-acceptance.md)。现已整题统一发布，未验收范围不因这些原题通过而自动开放。

M4 按已有证据选择三条路线，而不是把所有题都改造成全域单调比较。

| 路线 | 适用前提与转化 | 本批样例 |
| --- | --- | --- |
| 半轴求解后反射 | 一侧有完整公式；先在这一侧求解，再按奇偶性确定另一侧的关系符号和解集 | A02；奇函数对应侧可能需要反转与零的比较，不能无条件复制解集 |
| 对称改写后按单调性比较 | 转换后的两个输入属于同一个已证明严格单调的区间 | A05、A11、A18；A20 把两输入都换到一侧 |
| 已知符号区间与分母组合 | 只有分段方向／零点／符号可用，或不能跨段比较 | A19；先排除分母零点，再组合分子分母符号 |

奇函数可将 $f(u)+f(v)<0$ 改写为 $f(u)<f(-v)$；不等号本身不会因移项后用了奇性而额外翻转，是否反序由随后调用的单调性决定。偶函数可在合法域内把输入换成绝对值，或统一换成负绝对值；必须选择一条有单调依据的支段。

统一流程：**原输入的合法条件 → 合法的对称改写 → 验证比较所需的方向／符号 → 调用原不等式子方法 → 与所有输入条件求交 → 回验原关系和端点。**

关键约束：

1. 对称区间方向传递：奇函数同向、偶函数反向；结论只覆盖那两个区间。A05、A11 另证跨零次序后才能作为整体严格递增使用。
2. A19 的 $f(2)=0$ 与正侧递增反而说明 $0<t<2$ 时 $f(t)<0$，而镜像负侧相应值为正，不能据奇性把两段合成全域递增。使用符号表即可完成，无须猜解析式。
3. A20 在正侧递减，因此 $f(x-1)\le f(2x)$ 等价于 $\lvert x-1\rvert\ge\lvert2x\rvert$；两侧非负才能进一步平方，之后调用已有二次不等式方法。
4. 只给非严格单调或存在常值段时，不作严格保序的等价去函数符号。能从显式分支求解则分流，抽象条件不足则如实说明不能唯一确定。
5. 字母角色分开：A18 的 $a$ 是待求输入变量，A20 的 $b$ 是函数定义域参数、$x$ 是不等式变量。不能将二者压成一个“参数范围”。

### 5.6 T5：非奇偶的对称性

详细设计见 [FP-T5 非奇偶的对称性：设计与实现方案](function-symmetry-problem-type-design.md)。一般反射、非零有理斜率的仿射输入、正逆向迭代、有界局部关系、有限和与独立验证已在 `10b87e95` 提交，A10 两问及 A14 的内部课包通过。T5 测试 156 项、相关旧能力 263 项通过，来源及边界见[实现记录](function-parity-t5-implementation-acceptance.md)；[真实照片验收](function-parity-t5-photo-acceptance.md)重新上传两页、4 次模型调用完成三个目标，新增照片回归 3 项通过。独立材料、账号浏览器流程和公开课程仍待验收。

图像陈述先进入已登记的共享事实 `graph_symmetry(f,axis,a)`／`graph_symmetry(f,center,a,b)`，原题直接给出的函数等式仍保留原量词与范围。M5 由代码把已绑定来源规范为带定义域前提的函数关系，不让提取模型预先推导：

| 给定性质 | 全域关系 | 必须同时验证 |
| --- | --- | --- |
| 关于 $x=a$ 对称 | $f(2a-x)=f(x)$ | $D$ 在 $x\mapsto2a-x$ 下保持不变 |
| 关于 $(a,b)$ 中心对称 | $f(2a-x)=2b-f(x)$ | 同样的域配对；若 $a\in D$，则 $f(a)=b$ |
| $f(a+t)=f(b-t)$ | 轴为 $x=(a+b)/2$ | 两种输入遍历并配对完整定义域，而非只在一小段上成立 |
| $f(a-t)+f(b+t)=c$ | 中心为 $((a+b)/2,c/2)$ | 输入范围完整、全称关系成立 |

随后按目标作合法代入、组合反射、平移迭代或有限求和。**对称性不足以确定唯一函数时，不生成一条假的精确曲线或公式。**

T3 既有相反输入求值继续使用 `type-function-evaluation`；一般对称或抽象对称有限和通过独立特征进入 `type-function-symmetry`，共用 M5 和抽出的线性证书核。点值与有限和保留 `find_value`／`finite_sum` 原目标，不能丢掉额外对称条件回退到旧求值路线。

A10 中，$f(2-x)=f(x)$ 与 $f(-x)=-f(x)$ 组合得到 $f(x+2)=-f(x)$，再次使用才得到 $f(x+4)=f(x)$。A14 同理得到 $f(x+1)=-f(x)$。两题的定义域都是 $\mathbb R$，可正反向迭代；局部关系不允许未经证明就无限外推。

局部反射 $f(R_a(x))=\varepsilon f(x)+c$ 在 $E$ 上成立时，逆边的源范围为 $R_a(E)$，值变换为 $\varepsilon f-\varepsilon c$；必须按逆边倒序组合，不能只交换两条原公式。局部带常数配对不自动成为全域图像对称。

求和证据保留索引范围、重复出现次数、每组的关系和剩余项。A10②是 13 组四项和再加 $f(53)+f(54)$；A14 可证明整数点均为零，不把这个结论扩展到非整数点。

泛化至少区分：两轴产生平移周期；奇性与非零轴产生反号平移；两个中心的组合可能产生**函数值也随之平移**的关系，而非周期。若推出 $f(x+p)=f(x)+c$ 且 $c\ne0$，不能删掉 $c$ 宣称周期。推得一个周期不等于证明最小正周期；$p=0$ 时也不能把零当周期。

### 5.7 T6：奇函数＋常数结论的应用

详细设计见 [FP-T6 奇函数＋常数结论的应用：设计与实现方案](function-shifted-odd-problem-type-design.md)。现有题源为 A16、B01–B04 共五题，覆盖辅助函数身份、正负偏移、显式含参有理式、符号输入配对和最值之和；零系数退化、带权配对与简单参数已经作为机制范围实现。各项实际能力、限制与测试状态见[实现与集成记录](function-parity-t6-implementation-acceptance.md)。五题已完成[原照片真实拍题与课程集成验收](function-parity-t6-photo-acceptance.md)：8 次整页上传、40 次模型语义调用，保留失败记录并修复来源、题意卡及最值标量完成合同；本轮 293 项回归通过，未修改 prompt 模板。独立留出、浏览器账号流程及公开发布仍待验收。

沿用 M5 与一般中心对称技能，不另建一套“加常数”求解器。首先读清哪一个函数是奇函数：

| 题面形式 | 推导出的结论 | 零点与中心 |
| --- | --- | --- |
| $f(x)=h(x)+c$，$h$ 奇 | $f(x)+f(-x)=2c$ | 若 $0\in D$，则 $f(0)=c$；中心 $(0,c)$ |
| $g(x)=f(x)+k$，$g$ 奇 | $f(x)+f(-x)=-2k$ | 若 $0\in D$，则 $f(0)=-k$；中心 $(0,-k)$ |
| $g(x)=\alpha f(x)+\beta$，$\alpha\ne0$，$g$ 奇 | $f(x)+f(-x)=-2\beta/\alpha$ | 同一域；常数偏移为 $-\beta/\alpha$ |

A16 先得到 $g(1)=11$、$g(-1)=-11$，再减去 $2$ 得 $f(-1)=-13$；也可直接使用函数值之和为 $-4$。交互必须显式区分 $g$ 与 $f$。

计划覆盖的应用为相反输入求值、零点值、对称点配对求和、最值之和及简单参数关系。$N$ 个输入按重数关于零对称时，$f=h+c$ 的总和为 $Nc$；未配对项仍要单独求值，不能只按项数相乘。没有给出 $0\in D$ 时不自动补 $f(0)$。$\alpha=0$ 的退化情形要检查一致性与信息是否足够，不能除零。

B02 的 $a,b$ 是系数参数；B03 的 $a$ 是已知函数值所对应的输入；B04 的 $a$ 是任意实常数，不得把三者都路由为“求参数”。B04 先证 $f(x)+f(-x)=2$，再证明同一对称闭区间上两个最值实际取得，得到 $M+m=2$。这要求新增含参五次有理式恒等验证与最值配对证书，不能把它当作现有有限点求和接口直接调用。

固定且已准入的显式式子复用 M1；B02／B04 的含参式走独立新增的恒等验证入口，不把构造出的含参奇函数部分重新送回旧 M1。B03 不必求出 $a$，但要验证全部原条件共同可满足：原式在 $[0,1]$ 连续，$f(0)=2<14<f(1)=2035/4$，因此存在合法输入，再由全域对称和得到 $f(-a)=-10$。显式函数值不能当作自由未知量，无法证明存在性时报告能力缺口，已证矛盾时不输出答案。

执行接入按详细设计 §4.4、§7：已使用独立版本 `function-symmetry/shifted-odd-v1`，Stage One 特征和 Stage Three 上下文先检查 T6 来源归属，避免 T5 提前接管含辅助函数的有限和；保留 T3／T5 原路线及原 `find_value`／`finite_sum` 等目标身份。M5 的 guard、结果合并、独立验证、完成与教学分派同步更新。新增数学依赖同时登记 `frozen_files`、`fingerprint`、`revisions` 三个真实版本入口；开发只做指定题源的隔离构建，全局指纹及最终统一重建约定不变。

## 6. 技能、规则与题型身份的增量

### 6.1 四项公共技能的建设合同

技能按操作与合同划分；具体“算 $f(-3)$”“判断零点”“收束答案”不各自登记一个节点。

| 代号／候选技能 | 输入与前提 | 输出及验证责任 | 首建位置 |
| --- | --- | --- | --- |
| S1 `skill-domain-symmetry`：检查定义域的对称性 | T1 固定域与 T2 R1 含参域各有独立输入合同；T5 支持固定有理中心下的完整域及局部配对范围 | `check_domain_symmetry` 返回固定域配对／反例；`solve_domain_symmetry_conditions` 返回含参域分类；T5 的 `check_general_symmetry_domain` 验证一般反射及对应输入合法性，均保留开闭和孔洞 | T1、T2 R1、T5 已建 |
| S2 `skill-function-symmetry-transform`：利用对称关系变换输入与函数值 | 已证明／题给的 $f(2a-u)=\varepsilon f(u)+c$（$\varepsilon=\pm1$）、域闭合证据和完整输入 | 合法替换后的函数调用、等式或分支表达式；记录所有外层负号／常数及来源，不自行证明全域对称性 | T3 首建已知关系的应用，T2、T5、T6 按需复用；T1 的显式公式代入使用代入法 `method-function-evaluation` |
| S3 `skill-parity-monotonicity-transfer`：对称区间的单调性传递 | 奇／偶性质、区间 $I$ 上已知严格方向、$I$ 与 $-I$ 均合法 | 输出 $-I$ 上的方向和有序双点推导；不输出跨零的整体单调结论 | T4 |
| S4 `skill-function-shift-iteration`：函数平移关系的迭代 | 已证 $f(x+p)=\varepsilon f(x)+c$、整数迭代次数、可沿轨道使用的作用域 | 迭代关系与可用周期／非周期诊断；正反向合法，不能凭一次等式外推所有整数 | T5 已建；当前消费由反射生成的关系 |

S1 不再新增同义公共节点，但“复用节点”不等于无需区分执行能力。T1 已支持固定的有理及实二次代数数端点；T2 R1 已建设受限含参端点和参数类覆盖证书，不能将含参表达式直接传入固定域入口。

S2 统一奇、偶、轴对称、中心对称与奇函数加常数。轴对称对应 $\varepsilon=1,c=0$；中心对称对应 $\varepsilon=-1,c=2b$。不允许把任意 $\varepsilon=1,c\ne0$ 的反射关系当作轴对称：反射两次会要求 $2c=0$，必须先检查一致性。

S4 在已证明可迭代的域内，分别返回

$$
\varepsilon=1:\quad f(x+np)=f(x)+nc;
\qquad
\varepsilon=-1:\quad f(x+np)=(-1)^n f(x)+\frac{1-(-1)^n}{2}c.
$$

首轮只覆盖这些加性／反号平移关系，不据此声称支持任意函数递推。非零 $p$、$\varepsilon=1,c=0$ 给周期 $\lvert p\rvert$；$\varepsilon=-1$ 给周期 $2\lvert p\rvert$；其他情况保留准确结论。有限域仅允许验证过的有限轨道，不擅自扩成周期函数。

### 6.3 候选题型与判断规则

六个题型候选身份为：`type-function-parity`、`type-parity-parameter`、`type-parity-formula`、`type-parity-inequality`、`type-function-symmetry`、`type-shifted-odd-application`。类型是任务视角，不新造六套底层目标语义；求值、求解析式、求参数、不等式与求和仍按实际目标绑定。与既有 `type-function-formula`、`type-function-evaluation` 的重叠通过明确特征与选法合同处理，不能让标签竞争导致走错目标。

首轮只预留两项有复用价值的判断：

- **奇偶性应用的选法判断**：已知半边规则需补全；两个函数需联立；只问相反点／组合值可直接变换。选择 M3、M5 或已扩展的构造方程组法。
- **奇偶不等式的步骤判断**：能否放到同一严格单调区间；是否只需半轴求解后反射；是否必须按符号分段。选择公共子方法，不把整条判断塞进 prompt。

T1、T2 和 T3 沿用当前共享流程，单一路线也保留「选择解题方法」卡；是否简化另列共享交互改进，不随本次题型开发改动。已有定义域、不等式和分段选法规则继续使用；数学上适用但尚未实现的方法不能作为学生答错的选项。P0 仅登记 `planned` 题型，不提前启用空方法或占位执行器。

### 7.2 文案、子方法和恢复

选法线索直接使用学生熟悉的描述，例如：

- “把 $x$ 换成 $-x$，看函数值是否相等或互为相反数。”
- “只知道一侧的公式，先把另一侧的输入换到已知的一侧。”
- “已知两个相反输入的函数值关系，只求这几个值就够了。”
- “先用奇偶性把两个输入放到同一侧，再看增减方向。”
- “图像关于这条直线／这个点对称，先找成对的输入。”
- “加上或减去一个常数后是奇函数，先找原函数的成对值之和。”

副文字可给一个短例子，但不提前泄露当前题的最终答案。小问标题标清“求负半轴解析式”“比较两个输入”“处理零点”等实际任务，避免多个步骤都叫“使用奇偶性”。

T3 沿用 T1／T2 的单方法选法卡；原式用源 AST，化简只出现在后续推导中；学生文案使用“不恒成立”，相反输入不用“左右”描述；干扰项按数学含义去重。选项须写出函数对象与范围，完整推导只保留简洁数学式及必要条件，具体执行约束见 T3 设计 §6.4。

父方法只给子目标、输入和返回用途，完整调用已有定义域、单调性、不等式流程，不复制选项和步骤。简单多项式的全实数定义域可 `fold`；首次出现的域对称、零点、跨段比较默认展开；重复使用同一已验证结果可折叠引用。

子方法调用分[简单调用与转化为问题后辨别调用](topic-and-photo-learning-development-workflow.md#532-子方法的两种调用方式2026-11-13)两种。2026-11-13 起，T2 原式路线（有理式、分段、根式，如 C03–C05）在「检查定义域」步按简单调用借用 `method-domain-intersection`（能力 `solve_parity_parameter_domain`，保留约分前的原限制）：学生只看到一张「求定义域」只读卡，不判断转化成了什么问题；题给固定 $D$（C06、domain 模式）不调用；含参域的对称分类仍由 `skill-domain-symmetry` 处理。

同一数学状态驱动当前卡、完成卡、图形和 AI 回放；公式排版后不通过反复销毁重建卡片更新图像，保持高度与滚动位置稳定。刷新恢复、前问依赖失效及返回父任务均按共同题页契约处理。

## 8. 题意表示、执行与验证要求

### 8.1 保存题给事实与推导来源

沿用 `graph_lesson` 三阶段和共同题页，不另起一套只为奇偶性运行的解题链。T2 已交付 `parity(f,property)` 及绑定后的 `function_parity` 事实，T3 直接消费；`binding.parity_fact` 为校验错误码。下表概括需承载的语义，其余尚未实现的字段在各型 S0 设计中核查后定稿。

| 语义 | 必须保留的内容 | 不允许的替代 |
| --- | --- | --- |
| 奇偶性 | 函数身份、奇／偶要求、完整定义域或题给范围、来源 | 只存一个“odd”标签却丢掉域；把 $g=f+2$ 的奇性绑定到 $f$ |
| 局部解析式 | 完整公式、分支条件与开闭、该条件在原定义域内的作用域 | 把 $x>0$ 写成 $x\ge0$；把局部公式当全域定义 |
| 一般对称性 | 轴／中心坐标，或原全称函数关系、域的配对条件 | 根据两个偶然相等的函数值推整图对称 |
| 单调与符号 | 原区间、严格性、零点、全称量词或规范化依据、题给／推导标记 | 正侧方向自动扩成全域方向；从一对点比较制造全称事实 |
| 多函数与线性组合 | $f,g,h$ 各自身份、奇偶性、原等式完整符号与系数 | 以同一个占位函数合并；把 $f-g$ 读成 $f+g$ |
| 参数与目标 | 参数约束、求解变量、原目标和各问的 `target_ref` | A15 输出 $m$ 就结束；A20 混淆 $b$ 与 $x$ |
| 迭代／有限求和 | 原索引范围、重数、平移关系适用域、剩余项 | 省略未配对项；把递推当周期；把可用周期写成最小正周期 |
| 结果状态 | 唯一结果、结果族、条件不足、题设矛盾、能力缺口分别表示 | 无法计算等同“无解”；函数不唯一等同目标值不唯一 |

对源文提供的奇偶性／对称性保存原事实，可由代码规范化成统一的反射关系。所有规范化都保留来源；推导出的 $f(0)$、参数值、整体单调性、周期只能作为带证据的中间结果，不能回填成题给事实。

### 8.3 独立验证与目标依赖

- M1 分别验证域对称与两条恒等式；M2 证明参数条件必要且充分；M3 验证公式在返回范围内与原局部规则、奇偶性一致，并检查范围是否完整。
- M4 从原式重建合法输入，核对每次等价改写、方向、分支覆盖和端点；数值采样可找反例，不能代替完整解集证明。
- M5 检查关系代入、反射／平移组合和求和覆盖；T6 最值组合还需核对共同范围、反射闭合及最值实际取得。未知函数无需唯一，但目标必须对所有满足条件的函数给出同一结果，否则返回条件不足。
- 多问先按目标独立执行。后问可以在自己的路线内从原题重证所需结论；若显式复用前问产物，须绑定前问的验证、版本与依赖，失败或更新后令后问失效，不能直接读学生输入的前问答案。
- 金标只用于测试，不进入生产求解或生产验证器。执行器的最终答案与同一个硬编码答案比较，不能作为独立数学验证。

## 9. 泛化覆盖与分批实施

### 9.1 常见情况覆盖矩阵

原题决定优先级，合同范围决定开放后必须覆盖的分支。下表的补充机制样例是**拟建的开发／回归材料**，不计入已收集的 24 道原题，不冒称独立留出照片。

| 题型 | 原题已有覆盖 | 首轮需补的常见分支／反例 | 不得越过的结论边界 |
| --- | --- | --- | --- |
| T1 | 分式奇函数、绝对值与二次式之和为偶 | 零函数与非零常数；$x^2+x$ 非奇非偶；$[-2,2)$ 的开闭不对称；约分前孔洞；根式产生离散域；简单分段；有定义域前提的运算与复合 | 找到几个对称点不等于全域成立；对称域不等于函数为奇或偶 |
| T2 | 偶性比较系数；A15、A20 的对称端点 | 求奇与求偶两方向；零／多个／无参数解；退化为零函数；参数孔洞；分段镜像条件；有限域与区间域的差别 | 只满足端点对称不等于函数值条件成立；不能对有限域直接比较全部系数 |
| T3 | 奇／偶补全、正侧含零／不含零、求值、两函数加减组合 | 从负侧推正侧；有限对称区间；分段已知侧；偶函数未给零点值；已知两侧冲突；补全仍不能覆盖全域；零系数消元退化 | 不添连续性、不补未定零点、不以函数不唯一否定可唯一求值 |
| T4 | 奇函数和式、偶函数同侧比较、增减两方向、差商、严格／非严格目标、抽象分式符号 | 镜像区间开闭变化；复合输入为二次式；常值／非严格单调；已知单调区间小于定义域；零点不在域；分母符号与端点 | 对称两段方向不提供跨段次序；没有同一严格区间时不能等价去掉函数符号 |
| T5 | 奇性＋非零对称轴、反号平移、有限求和 | 独立的一般轴／中心题；两轴；两中心且中心纵坐标不同；零平移；局部对称；反向迭代；不完整求和组 | 一般轴不是 $y$ 轴；一般中心不是原点；值平移不是周期；周期不必最小 |
| T6 | A16／B01 的辅助函数；B02 的含参配对和；B03 的符号输入；B04 的最值之和 | 偏移为零；$g=\alpha f+\beta$ 与零系数退化；零点可取／不可取；多项配对与未配对项；最值范围不对称或没有实际最值 | 不把 $f$ 本身标奇；不混淆系数与输入；配对按重数；最值之和要求同一对称范围及实际取得 |

优先冻结以下可明确校验的边界样例：

| 样例 | 应有结论／用途 |
| --- | --- |
| $f(x)=\dfrac{x^2-1}{x-1}$ | 原域为 $\mathbb R\setminus\{1\}$，不对称，非奇非偶；约分不能补点 |
| $f(x)=\sqrt{1-x^2}+\sqrt{x^2-1}$ | 原域 $\{-1,1\}$，恒为零，既奇又偶；不能假设函数域一定是区间 |
| $f(x)=ax^2+bx$，分别要求奇／偶 | 奇性要求 $a=0$，偶性要求 $b=0$；$a=b=0$ 两者皆满足，除非额外排除零函数 |
| $f(x)=\dfrac{x-a}{x-a}$，要求偶函数 | 对称域要求 $a=0$；此时在非零实数域上恒为 $1$，是偶函数；原孔洞随参数保留 |
| $D=\mathbb R$，偶函数，仅给 $x>0$ 时 $f(x)=x^2+1$ | $x\ne0$ 处确定为 $x^2+1$，$f(0)$ 可任意；不能返回唯一的全域公式 |
| $D=\mathbb R$，奇函数，声称 $x\ge0$ 时 $f(x)=x^2+1$ | 条件在零点矛盾；区别于 A08、A12 的开半轴，不静默删掉等号 |
| 对所有实数 $x$，$f(2-x)+f(x)=6$，且 $f(0)=1$ | 中心 $(1,3)$，$f(2)=5$；不需要也不能宣称原函数奇／偶 |
| 由两个中心得到 $f(x+2)=f(x)+4$ | 保留函数值平移；不能判周期 $2$。可用显式线性函数构造一致性对照 |
| $f=h+3$，$h$ 奇，求 $f(-2)+f(0)+f(2)$ | 若零点在域中，结果 $9$；配对两项共 $6$，另加零点值 $3$ |

只有全域闭合、有限轨道覆盖、消元唯一性等前提可验证时才开放对应分支。指数、对数、三角函数的一般恒等式证明、任意抽象函数方程及最小正周期求解不因本批通过而自动纳入范围；如后续建设，应另选代表题扩展相应合同。
