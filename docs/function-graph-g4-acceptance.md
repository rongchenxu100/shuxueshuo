## 学生流程与原图

从第 97 页照片裁出题干原图与四幅选项；解析区不进入题图。原图在每张相关卡片内直接显示，未加载时不能提交。题干原图单独占一行，四个选项随后成组排列；作答时点图片选择，独立“放大”按钮查看细节。完成态保留原图、点对应和数学推导。

1. 关于 y 轴对称：`y=f(x) → y=f(-x)`，`(u,v) → (-u,v)`。
2. 向右平移 2 个单位：`y=f(-x) → y=f(-(x-2))=f(2-x)`，`(-u,v) → (2-u,v)`。
3. 总结：`(u,v) → (2-u,v)`；原图所示部分从左往右上升，变换后的对应部分从左往右下降。
4. 横轴交点：`f(0)=0`，`2-x=0 ⇒ x=2`，故 `(0,0) → (2,0)`。
5. 同时核对交点与方向，选择原图 C。

没有给 f 拟合解析式，也没有画一条替代原图的 S 形曲线。原图事实只描述照片中展示的部分，不推出全定义域或全局单调性。

| 选项 | 展示部分从左往右 | 横轴交点 | 核对 |
| --- | --- | --- | --- |
| A | 上升 | `(2,0)` | 方向不符 |
| B | 上升 | `(-2,0)` | 方向、交点均不符 |
| C | 下降 | `(2,0)` | 两项符合 |
| D | 下降 | `(-2,0)` | 交点不符 |

## 首轮合同与边界

`select_function_graph.source_graph` 保存未知函数名、原图可核对的方向及横轴交点。所求为 `f(±x+b)`，b 为固定有理数；所有选项同样记录这两项事实。交点只接收明确标记或原点，估计坐标、不明方向和图内不确定信息不能进入求解。缩放、有限定义域、额外条件、一般曲线等价暂不准入；多个选项在这两项特征下无法区分时停止，不按标签挑答案。

点映射与方向由确定性计算得到，独立核验重新检查 `a*x_new+b=x_old` 及全部原选项。上述特征服务于本批的大致选图，不能用来证明一般曲线精确等价。

公开题面增加 `statement_figure_regions`，必须逐目标绑定题干原图。复核通过后安装高保真裁片，题干原图哈希与原选项哈希共同参与身份；同文同选项但原图不同的题不能合并。交互合同增加 `show_source_graph`，复用原图组件，未新增猜测曲线的 graph 类型。
