# 函数的概念 Q23（2）：独立的定义域求参问题

## 独立题面与来源

已知函数 $f(x)=\dfrac{\sqrt{x^2-3x-m}}{\sqrt{x-1}}$ 的定义域为 $(1,+\infty)$，求实数 $m$ 的取值范围。

本题从设计稿第 23 题的第二问独立出来，仅使用公共函数定义与第二问的已知定义域，不继承第一问的 $m=10$。公共 ID 为 `function-concepts-q23b`，专题入口为 `/topics/function-concepts/q23b/`。原题为第 83 页例 6 变式 2；题源保存两段原图裁片与拼接记录，不将组合后的独立题图冒称为原始上传图片。

## 数学路径

沿用 `type-function-domain` → `method-domain-parameter` → `method-separation`，复用既有配方、二次函数区间值域和恒成立转范围能力。

1. 按原式保留三条限制：$x^2-3x-m\ge0$、$x-1\ge0$、$\sqrt{x-1}\ne0$。两个根式及分母分别有原式位置和知识来源。
2. 分母的两条限制合为 $x>1$，恰好等于题给定义域。$x\le1$ 时分母无意义或为零，原式不可能合法；因此原目标等价于分子条件在每个 $x>1$ 上成立。
3. 分离参数：$m\le x^2-3x=(x-\frac32)^2-\frac94$ 对所有 $x>1$ 成立。
4. 顶点 $x=\frac32$ 位于该范围内，最小值为 $-\frac94$，故 $m\le-\frac94$。
5. 等号可以取：此时分子在 $x=\frac32$ 为零，分母不为零；对其他 $x>1$ 原式也有意义，域外仍被分母排除。

最终参数集合为 $(-\infty,-\frac94]$。不能仅验证题给范围内成立而丢掉域外排除，也不能把分子的根式非负误改成严格正。

## 通用能力与验收范围

新增输入族为 $\sqrt{P(x,m)}/\sqrt{L(x)}$：$L$ 为固定非恒定仿射式，题给定义域恰为 $L>0$ 的开半轴；$P$ 为固定至多二次多项式加非零常数倍参数。左右半轴、顶点在域内／域外／边界、一次与常数退化及参数系数正负均按契约处理，不按题号或本题数字分支。

独立核验应从原式重建域内条件和域外排除证据，使用半轴上的下确界与取得情况判定全部参数范围；不得信任方法的候选答案或把题给范围直接当成原函数已有定义域。
