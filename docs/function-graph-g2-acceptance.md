## 本次实现

1. 找零点 −1、3；按三个区间分别确认保留或翻折，每确认一次补上一段曲线。
2. 合成图像时核对分段式、覆盖区间、曲线方向和边界。完成态保留整幅图和数学推导。这是引导式构图，不是自由手绘评分。
3. 第二问在函数图像中加入 `y=3`，依次确认交点、直线上方的区间、端点取舍。
4. 最终曲线和数轴共用精确解集 `(-∞,1−√7]∪[0,2]∪[1+√7,∞)`。严格 `>` 的变式只移除四个交点，模型与渲染都保持开闭一致。

新增方法 `method-absolute-piecewise-graph`、`method-piecewise-graph-inequality` 与技能 `skill-absolute-sign-split`。复用已有 `skill-quadratic-sign` 的公共知识关联，使用精确多项式不等式求解，不另做图片猜测评分。两问各自从同一原式构造并核验模型，课包按顺序衔接；本批尚未引入跨目标缓存模型的依赖传递协议。

目标合同增加 `draw_function_graph` 和 `solve_graph_inequality`。受控范围是固定有理系数的 `|p(x)|`，p 至多二次，定义域为实数或一个显式区间。内部模型验证分段恒等、整段非负、互不重叠、覆盖完整原域，以及精确交点和不等式解集；核验器不调用构造函数冒充独立核验。

`piecewise_curve` 同时接入 schema、后端校验和前端绘图。每段只接收数值系数、区间与开闭，使用二次 Bézier 路径精确显示曲线，不执行表达式代码。公共交互增加 `guided_plot`，明确记录 pieces、intervals、direction、boundaries 四项检查。一般分段定义式仍归 FR-T3；绝对值外的额外变换、纯示意图与自由手绘评分不在本批。
