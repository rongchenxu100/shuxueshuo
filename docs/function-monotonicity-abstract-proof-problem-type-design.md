## 1. 题型身份、方法与首轮范围

### 1.1 任务边界

沿用现有题型 `type-monotonicity-abstract-proof`，学生名称“证明抽象函数的单调性”，归属 `function-monotonicity` 专题及 3.2.1 单调性与最大（小）值。节点当前保持 `planned`；此次设计不改变运行准入或生成课程。

| 容易混淆的任务 | 本型判断 |
| --- | --- |
| 给函数关系与符号条件，判断并证明函数的单调性 | 属于 T5；未知的方向须由证明得出 |
| 给具体解析式，用任意两点作差证明增减 | 属于 T1 的 M1 路线；共用定义法，但输入与变形能力不同 |
| 已知函数递增／递减，比较两个函数值或解不等式 | 属于 T3；其单调性是可用依据，T5 中则是待求结论 |
| 给二元函数关系，要求求解析式 | 属于已有求解析式任务；有相同的合法代入动作，整题目标不同 |
| 给递推关系，求区间最值或参数 | 例如 B15，仍属 T2 拓展，不能因“没有完整解析式”归入 T5 |

本批函数为实值函数，首轮限一个未知函数、一条二元全称等式、一条全称严格符号条件，目标为整个题给定义域上的单调性。开放下面两族及其严格负号变式：

| 批次 | 函数域与关系 | 符号条件 | 完整支持分支 |
| --- | --- | --- | --- |
| R0 加法关系 | $D_f=\mathbb R$，任意 $u,v\in\mathbb R$ 有 $f(u+v)=f(u)+f(v)$ | 任意 $t>0$，$f(t)>0$ 或 $f(t)<0$ | 分别证明严格递增／严格递减；代表题 C01 |
| R1 乘法输入关系 | $D_f=(0,+\infty)$，任意 $u,v>0$ 有 $f(uv)=f(u)+f(v)$ | 任意 $t>1$，$f(t)>0$ 或 $f(t)<0$ | 分别证明严格递增／严格递减；代表题 C02 |

结构识别允许变量改名、等式两端交换、加数交换，以及有明确恒等变形证据的移项写法。函数身份、定义域、量词及严格性必须保持；不能只匹配一段文字。既然开放同一严格符号合同，负号分支应随本族实现，不等收集到一题递减原题才补。

多个未知函数、附加未处理的限制、一般函数方程、局部关系域、任意阈值或有限目标区间、仅有单点正负、非严格符号升级为严格单调，不在首轮准入范围。范围外不等于函数不单调；应返回未覆盖的证明义务，不能猜一个答案。

### 2.2 C01：正差把两个函数值连接起来

任取 $x_1,x_2\in\mathbb R$ 且 $x_1<x_2$，记 $h=x_2-x_1$，则 $h>0$。在原二元关系中令 $u=x_1,v=h$，两个输入均为实数，且 $u+v=x_2$，所以

$$f(x_2)=f(x_1)+f(x_2-x_1).$$

同减 $f(x_1)$，得到

$$f(x_2)-f(x_1)=f(x_2-x_1)>0.$$

严格正号来自“对任意 $t>0$，$f(t)>0$”，因为已经证明 $x_2-x_1>0$。因此对任意这样的两点，都有 $f(x_1)<f(x_2)$，故 $f$ 在 $\mathbb R$ 上严格递增。

这个证明允许 $x_1,x_2$ 为负数或异号。只要求差为正，不能把任取范围缩成 $0<x_1<x_2$ 后宣称证明了整个实数域。也无需先求 $f(0)$、证明奇函数或求出解析式。

### 2.3 C02：用商满足乘法关系

任取 $0<x_1<x_2$，记 $r=x_2/x_1$。由 $x_1>0$ 可合法相除，得到 $r>1$，因而 $r>0$。在原关系中令 $u=x_1,v=r$；两者在原关系的正数域内，且 $uv=x_2$，所以

$$f(x_2)=f(x_1)+f\!\left(\frac{x_2}{x_1}\right).$$

移项并用 $r>1$ 时的题给正值条件，有

$$f(x_2)-f(x_1)=f\!\left(\frac{x_2}{x_1}\right)>0.$$

任意正数 $x_1<x_2$ 都满足 $f(x_1)<f(x_2)$，故 $f$ 在 $(0,+\infty)$ 上严格递增。

证明不能只取 $1<x_1<x_2$；目标还包含 $(0,1]$ 及跨过 1 的两点。题给“大于 1 时函数值为正”作用于 **商**，不是要求原来的两个输入都大于 1。同时，$r>0$ 只保证代入合法，$r>1$ 才能调用正值条件，这两个检查不可混为一个。

### 2.4 两题的统一证明及方向变式

| 环节 | C01 加法关系 | C02 乘法输入关系 |
| --- | --- | --- |
| 任意两点 | $x_1<x_2$，$x_1,x_2\in\mathbb R$ | $0<x_1<x_2$ |
| 待判断的差 | $\Delta=f(x_2)-f(x_1)$ | $\Delta=f(x_2)-f(x_1)$ |
| 让原关系产生 $f(x_2)$ 和 $f(x_1)$ | $u=x_1,\ v=x_2-x_1$ | $u=x_1,\ v=x_2/x_1$ |
| 代入与移项 | $\Delta=f(x_2-x_1)$ | $\Delta=f(x_2/x_1)$ |
| 能套用的符号范围 | $x_2-x_1>0$ | $x_2/x_1>1$ |
| 原题正号 | $\Delta>0\Rightarrow$ 严格递增 | $\Delta>0\Rightarrow$ 严格递增 |
| 同结构负号变式 | $f(t)<0\Rightarrow\Delta<0\Rightarrow$ 严格递减 | $f(t)<0\Rightarrow\Delta<0\Rightarrow$ 严格递减 |

教材解析取 $x_1>x_2$ 并考察 $f(x_1)-f(x_2)$；本设计与 T1 统一使用 $x_1<x_2$ 和 $f(x_2)-f(x_1)$，两者等价。内部必须记录实际取点顺序和被减式，不能靠变量下标或箭头样式猜方向。交换 $u,v$ 后仍满足同一等式的代入也应识别为等价方案。

## 4. 题意协议、来源与证明结果

### 4.1 保留“判断”而不是提前填“递增”

当前 `FunctionMonotonicityGoal` 要求具体 `expression` 和 `direction`，不足以准确表达这两道无解析式、方向待求的题。拟增加语义目标 `determine_monotonicity_on_interval`：函数引用、待考察区间及其来源，不含预先求出的方向。该名称在编码时登记到共享记法和提取协议，不能先当现成枚举调用。

对明确要求“证明递增／递减”的变式，保留 `prove_monotonicity_on_interval` 的证明任务语义，增加可绑定函数关系的受控合同；原具体函数目标继续兼容。不得把题型总名“证明抽象函数的单调性”误当成原题已经指定递增。判断目标没有产生证明时，不能用猜测补上方向。

| 信息 | 规范化内容与来源要求 |
| --- | --- |
| 函数声明 | 同一个实值函数的稳定引用、完整定义域；与考察区间分别保存 |
| 二元关系 | 原等式 AST、$u,v$ 的独立绑定、各自范围、全称性质、源文本位置 |
| 符号条件 | 独立绑定的 $t$、范围 $(0,+\infty)$ 或 $(1,+\infty)$、$f(t)$ 与 0 的比较、严格性和来源 |
| 原目标 | “在定义域上判断单调性”；完整域来自声明，不从答案或模型常识补写 |
| 证明局部上下文 | 新鲜的任意 $x_1,x_2$，共同范围及 $x_1<x_2$；属于方法引入，不能写回原题已知 |
| 中间量 | $h=x_2-x_1$ 或 $r=x_2/x_1$ 的局部定义；附生成它的证明步骤 |

符号条件是“对某范围内每一个输入都成立”，不是只有 $f(x)>0$ 的游离字符串，更不是函数在该范围递增。优先沿用现有绑定／引用机制表达“受限全称变量 + 比较式”，补齐共用协议；不把当前记法不支持的裸蕴含式塞进 `facts`，也不改成恒成立求参数目标。

原关系变量、符号规则变量和证明变量即便同名，也属于不同绑定。代入前可改为 $u,v,t$ 避免捕获，显示原文仍保留原字母。原关系、符号条件、域、目标或严格性任一改变，原证明及课程缓存不可被认作同一题意。

### 4.3 证明产物与独立验证

结果最少包含函数和目标引用、完整考察域、任意双点作用域、差的方向、同时代入映射、代入合法性、每个恒等步骤、严格符号证据、量词收束和最终方向。以下是**语义上的证据链**，字段名以正式合同为准：

```text
原函数关系 + 原符号条件 + 完整定义域
  → 任取 x₁,x₂∈I，x₁<x₂
  → 构造 h=x₂−x₁ 或 r=x₂/x₁
  → 检查代入合法、正差/商落入符号条件的适用范围
  → 对整条函数关系同时代入
  → Δ=f(x₂)−f(x₁)=f(h) 或 f(r)
  → Δ>0 / Δ<0
  → 对任意有序双点成立
  → f 在 I 上严格递增 / 严格递减
```

独立验证器从冻结原题重建可用假设，检查有限证明步骤，不再次调用求解器拿同一结论比对，也不信任 `passed` 标记：

1. 检查 $I$ 与原目标、完整定义域相符；任意两点覆盖整个 $I$，没有额外缩成正数子域或 $(1,+\infty)$。
2. 检查二元关系确实全称、函数引用一致，代入映射替换所有对应位置；两个新输入和关系中的复合输入均合法。
3. 检查每个代数恒等步骤。商约去 $x_1$ 前须有 $x_1\ne0$；未知函数值只能按题给关系改写，不能由普通化简器自行消去。
4. 从双点约束证明 $h>0$ 或 $r>1$，再合法实例化题给符号规则，得严格符号。只有非严格符号不够。
5. 检查被减式、差号与最终方向一致；解除局部的任取假设，得覆盖所有双点的结论。不能只留下两个具体点的比较。
6. 结果明确区分证成、结论被证否、条件冲突、缺少所需依据和能力未覆盖。证明搜索失败不自动变成“不单调”。

少量数值可用于辅助验错或展示，但无法验证任意函数的全称结论。删去符号条件后，$f\equiv0$ 满足两种函数关系却不严格单调，可用作不能强判严格性的反例；它不表示原条件已经证明每个函数都不单调。

## 5. 方法执行与技能合同

### 5.1 M1 的抽象关系分支

| 步骤 | 数学任务 | 子调用与返回 |
| --- | --- | --- |
| 1 确认目标与可用条件 | 核对函数、完整域、关系和符号条件；方向仍待求 | 产生结构描述及未解决目标 |
| 2 任取两个有序输入 | 建立 $x_1,x_2\in I$、$x_1<x_2$ 的任意上下文 | 返回有作用域的双点证据 |
| 3 比较两个函数值 | 建立 $f(x_2)-f(x_1)$ 的符号子目标 | 正式调用 `method-difference-comparison`，保留父目标与局部上下文 |
| 4 按定义收束 | 子方法返回任意双点的严格次序，回到原函数和原区间 | 判断题返回已证方向；指定方向证明题还须核对是否完成原要求 |
| 5 原题回验 | 重查域、关系、符号来源与证明依赖 | 独立验证通过才发布结论 |

现有 T1 的“分析具体函数 → 划分单调区间”分支保持其任务语义；T5 两族的目标域都是连通区间，直接证明全域方向，无需生成虚假的顶点或再让学生选择已给定义域。

### 5.2 作差比较法的抽象关系分支

输入为“两个函数值、既有函数关系及任意有序双点上下文”，不要求先给出已经成立的单调结论。

1. 固定 $\Delta=f(x_2)-f(x_1)$，保留被减式与减式的身份。
2. 让原关系中的一个输入为 $x_1$，组合输入为 $x_2$：加法解出 $v=x_2-x_1$，乘法解出 $v=x_2/x_1$。通过受限结构推导候选，不按题号选择。
3. 调用 `skill-equality-transform`：先检验映射合法，再同时代入原等式。返回代入后的完整等式与各处来源，之后移项。
4. 调用已有化简能力确认输入相加／相乘确实得到 $x_2$；保留商的非零依据，不展开或拟合 $f$。
5. 用双点次序和 `skill-inequality-transform` 证明新输入落入符号规则的区间，再实例化符号规则，取得 $\Delta$ 的严格正负。
6. 返回 $f(x_2)>f(x_1)$ 或 $f(x_2)<f(x_1)$ 及任意性证据。M1 负责“因此函数在整个 $I$ 上单调”的父目标收束。

“合法代入”的**定义域条件**须在代入前通过；“能否使用正值条件”则是独立义务，可在教学判号步展开。二者不能因结果看起来正确而省略。

### 5.3 技能为何足够、如何扩展

| 操作 | 技能输入 | 可验证输出 | 不承担的职责 |
| --- | --- | --- | --- |
| 合法代入与移项 | 原全称等式、带绑定的替换映射、代入域证据 | 实例化等式、移项后的差式及逐步引用 | 不决定整题是否单调，不求唯一解析式 |
| 代数化简 | $x_1+(x_2-x_1)$ 或 $x_1(x_2/x_1)$，原限制 | 结果为 $x_2$ 的恒等证据 | 不凭函数名称推断线性、对数或单调性 |
| 符号推导 | $x_1<x_2$，必要时 $x_1>0$；全称符号规则 | $h>0$／$r>1$，以及相应 $f(h)$／$f(r)$ 的符号 | 不把单点正值推广到全部正输入 |

恒等关系的实例化是一个推导，不要求由这个实例反推出整条原关系；本题也不要求证明唯一解析式。知识条目中的“双向等价”与“由全称得到特例”要区分，避免把求解析式流程中的候选回代要求机械套在每一步上。

## 6. 学生选法、交互与图形

### 6.1 方法入口

本批只有一条经过设计的整题路线，默认直接进入定义法，不提供“图像法”“求解析式”等不能执行的并列按钮。可以用简短的方法提示承接：

| 题目线索 | 给学生的说明 | 方法 |
| --- | --- | --- |
| 没有给出解析式，但给出了函数值之间的关系 | “在定义域内任取两个数，看看输入变大时，函数值之差是正还是负。” | 定义法 |

如果需要一张选法练习，必须使用公共选法组件，并只列实际可用路线；不为此新增与 T1 重名的定义法规则。单调性方向仍留给最后的证明收束。

### 6.2 代表课 C01：构造正差

| 卡片／小问 | 进行中题干与题板 | 学生要确认什么 | 完成态与典型反馈 |
| --- | --- | --- | --- |
| 任取两点，建立比较 | “要判断整个实数域上的单调性，怎样取两个输入？” | 选择“任取 $x_1,x_2\in\mathbb R$，且 $x_1<x_2$”；不是只取 $0<x_1<x_2$ 或具体 1、2 | 显示任意双点范围和待判断的 $f(x_2)-f(x_1)$；反馈“正差不要求两个输入都为正” |
| 用函数关系构造差式 · 选择代入 | 题板保留 $f(u+v)=f(u)+f(v)$，要求 $u=x_1,\ u+v=x_2$；问“$v$ 应取什么？” | 从带对象的选项中选 $v=x_2-x_1$ | 之后显示代入映射及实数域合法性；本问标题不提前出现正确的 $v$ |
| 用函数关系构造差式 · 写出差 | 承接已确认映射；问“移项后，$f(x_2)-f(x_1)$ 等于什么？” | 选择完整等式 $f(x_2)-f(x_1)=f(x_2-x_1)$ | 展示先代入、再移项的两行推导；“$f(x_1-x_2)$”反馈指出差的方向变了 |
| 利用题给条件判断差的正负 | 已知栏只给 $x_1<x_2$、已确认差式及正值条件 | 一条选项同时给出 $x_2-x_1>0\Rightarrow f(x_2)-f(x_1)>0$ | 完成态标明严格正号来自哪条题给条件；不额外再问一次“是否大于零” |
| 回到单调性的定义 | 已有任意双点和差严格为正 | 选择“$f$ 在 $\mathbb R$ 上严格递增” | 最终一行结论；完整证明可展开，保留“任意”的范围 |

两小问属于同一张“用函数关系构造差式”大卡，步进标题分别为“选择代入”“写出差”，不用两个同名“推导”标题。符号化简如 $x_1+x_2-x_1=x_2$ 作为推导显示，不再增加一张机械计算卡。

### 6.3 扩展课 C02：从正差迁移到商

| 卡片／小问 | 学生要做的判断 | 重点与反馈 |
| --- | --- | --- |
| 任取两个正输入 | 任取 $0<x_1<x_2$ | 不能只取两个大于 1 的输入；定义域还包含 $(0,1]$ |
| 用函数关系构造差式 · 选择代入 | 在 $u=x_1,\ uv=x_2$ 下选择 $v=x_2/x_1$ | 干扰项 $v=x_2-x_1$ 不满足乘积要求；这一步不以“构造比值”作标题泄露选择 |
| 用函数关系构造差式 · 检查代入 | 确认 $x_1>0$ 且 $x_2/x_1>0$，可在原关系中代入 | 本问只核对定义域；$v>1$ 留作正值规则的关键判断 |
| 用函数关系构造差式 · 写出差 | 得到 $f(x_2)-f(x_1)=f(x_2/x_1)$ | 干扰项包括 $f(x_2)/f(x_1)$；反馈“题给的是输入相乘对应函数值相加” |
| 利用题给条件判断差的正负 | 确认 $x_1>0,\ x_2>x_1\Rightarrow x_2/x_1>1$，从而差为正 | 干扰项“商大于 0 就能使用正值条件”不足；商大于 1 的条件必须保留 |
| 回到单调性的定义 | 得到整个 $(0,+\infty)$ 上严格递增 | 不能把结果域写成 $(1,+\infty)$ 或 $\mathbb R$ |

学生选项必须指明对象，例如 $v=\frac{x_2}{x_1}$、$f(x_2)-f(x_1)>0$、$f\text{ 在 }I\text{ 上严格递增}$；避免裸商、裸正负号或只有“递增”。数学上等价的交换代入不应成为错误选项。首轮用已有选择／匹配交互，不默认宣称支持任意手写证明自动批改。

### 6.4 图形与作答状态

- 用**输入数轴和关系板**帮助理解：C01 确认正差后在 $x_1$ 到 $x_2$ 的间隔标 $h=x_2-x_1$；C02 确认商后显示 $x_1\times r=x_2$，需要时在单独的 $r$ 数轴标 $1<r$。
- 数轴只表达已建立的输入次序，无数值刻度的点距不代表实际取值。C01 不固定两个点都在 0 的同一侧；C02 不把两个原输入固定在 1 的同一侧。
- 构造代入尚未作答时，图和题板显示“$x_1+\square=x_2$”或“$x_1\times\square=x_2$”，不预先填出差／商；判号尚未确认时，不展示待答的正确符号或单调箭头。
- 不给未知函数画 $y=x$ 或 $y=\log x$ 的精确曲线。即使某些附加理论能刻画函数族，也不是本题待证结论的先验依据。需要函数值示意时，确认大小关系后再画不带数值纵坐标的次序关系。
- 图有助于当前判断时才挂图；代入／移项使用公式板即可。完成图与所属小问的结论板紧邻，沿用稳定尺寸、公式渲染和小问滚动行为。

| 内容 | 默认展示 | 范围 |

## 9. 必要验证矩阵与验收口径

| 维度 | 必要用例 | 要防止的错误 |
| --- | --- | --- |
| 两族数学 | C01/C02，各自严格负号变式 | 只会给递增；误用 $f(uv)=f(u)f(v)$ |
| 任意性与域覆盖 | C01 的负数／异号两点；C02 的 $(0,1]$ 内及跨 1 两点作为辅助检查，另验完整全称证书 | 用两次采样当证明；只证明子域 |
| 差的方向 | $x_1<x_2$ 与教材反向命名；交换被减式 | 符号正确但最终增减相反 |
| 代入合法性 | 比值除数非零且为正、关系域与符号域分别检查 | 先约分丢限制；仅 $r>0$ 就调用 $r>1$ 的条件 |
| 结构及绑定 | 改函数名、改变量名、等式交换、交换两个合法代入量；不同函数或作用域则拒绝 | 按字面／题号识别；同名变量捕获 |
| 条件不足 | 删除符号规则、只给单点正值、只给非严格号、关系只在局部或只对某点成立 | 擅自补全全称；失败后输出“不单调” |
| 来源与目标 | 题干要求判断、指定方向证明；邻题图、印刷解析、严格号变化 | 把待证递增当已知；解析进入 facts；误走配图流程 |
| 证书篡改 | 改域、差方向、替换映射、正负号或源引用 | 求解与验证共享错误、信任外部 `passed` |
| 共享能力回归 | T1 多项式定义证明、既有求解析式合法赋值、T3 题给单调性比较 | 新合同破坏旧准入、出现循环证明或全站版本失效 |
| 交互与记录 | 两题代入／符号卡的完成、错误不推进、回退、刷新与回放、服务端判定 | 提前露答案、丢父子上下文、旧答案继续驱动新映射 |

单元测试按这些数学边界参数化组织；不为文案逐字写测试，不反复跑无关全站套件。图像和排版用少量必要页面检查；实际课程生成、记录恢复和照片链路分别验收。

照片验收须保存真实原图、选题框、实际发给模型的图、提取／复核调用、原始失败、数学与课程结果及时间。教材解析与邻题同页，需至少检查一次选题边界，确认没有引入答案；旧响应回放只用于回归，不能算新的模型识别。接口上传／人工框、浏览器上传裁剪、课程快照恢复和学生作答保存分项记录，不互相代替。
