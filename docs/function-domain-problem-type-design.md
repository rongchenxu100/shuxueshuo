## 2. 题型整体范围与首批范围

### 2.1 T2 的整体范围

| 子任务 | 方法安排 | 推进位置 |
| --- | --- | --- |

抽象函数输入范围的对应属于 T3；函数值、值域属于另外的题型。同一个表达式可以对应不同任务，不能仅凭出现根号或分母就判为定义域题。

### 2.2 首批实现范围

首批围绕第 15 题及第 8 节的基础边界例建设：实数范围、单个自变量、固定有理数系数，涉及仿射表达式的平方根、仿射分母或平方根分母、加减乘除的受限组合，以及明确给定的固定区间。整数、有限小数和分数系数按精确数处理。正式边界由 `stage_one/function_domain.py` 的 `fixed-affine-function-domain/v1` 契约检查，按结构判定，不按题号或固定数字匹配。

显式 `input_domain` 只记录题设另给的范围，不能填入推算出的自然定义域或答案；缺省为实数。当前公开提取准入仍会拒绝恒为零的分母、常量负数开平方等语义无效候选；它们不属于已验收的公开输入。已验证的空集结果包括原式条件互斥和题设范围与合法输入不相交。

参数讨论、零次幂、绝对值条件、二次条件、根号内分式、抽象函数和情境建模在后续批次扩充。首批遇到未实现结构时记录明确缺口，不能忽略该部分继续输出定义域。约分前限制贯穿原式保存设计，相关求解用例随扩题验收。

“M1 的方法适用范围”与“本批程序已实现的范围”分别维护；方法名称不代表其所有子情形已经可以运行。

## 3. 代表题与完整数学路径

### 3.1 题目

求函数

$$
f(x)=\frac{\sqrt{x-1}}{x-2}
$$

的定义域。

题源身份沿用 3.1 设计稿“第 15 题”，正式公共题目 ID 为 `function-concepts-q15`。原图及裁片、提取与复核录制已登记，见[首题验收记录](function-domain-q15-acceptance.md#真实图片与调用证据)。题号用于题源追溯，不作为求解入口。

### 3.2 数学步骤

| 步骤 | 依据与操作 | 产物 |
| --- | --- | --- |
| 1. 识别输入限制 | 实数平方根要求被开方数非负；除法要求分母非零 | $x-1\ge0$，$x-2\ne0$，并保留各自在原式中的位置 |
| 2. 求解各条件 | 整理一次条件，保持等价性 | $x\ge1$，$x\ne2$ |
| 3. 求交集 | 原式各部分需要同时有意义 | $[1,+\infty)\cap(\mathbb R\setminus\{2\})$ |
| 4. 表示并核验 | 保留 1，排除 2，将去点范围写成区间并集 | $D=[1,2)\cup(2,+\infty)$ |

完整性依据：原式在实数 $x$ 处有意义，当且仅当 $x-1\ge0$ 且 $x-2\ne0$，当且仅当 $x\in D$。既说明集合内每个输入都允许，也说明集合外没有遗漏的允许输入。有限试值与端点演示只作辅助，不代替这一等价关系。

$x=1$ 时分子为 0、分母为 $-1$，允许取到；$x=2$ 时分母为 0，必须排除。最终答案允许集合描述等价写法，不能只接受某一个字符串。

## 4. 方法与技能契约

### 4.1 M1：列条件求交集法

| 项目 | 设计 |
| --- | --- |
| 目标 | 求具体表达式全部允许的实数输入 |
| 输入 | 保留结构的原表达式、自变量、实数语义、题设另给的输入范围及其来源 |
| 适用性 | 表达式明确；相关参数已固定或由上层完成分支；本次调用中的条件类型可完整处理 |
| 组织步骤 | 调用 S3 提取条件 → 调用适用能力求解 → 与题设范围取交集 → 表示结果并验证原目标 |
| 输出 | 完整结果集合、原始条件及来源、各条件的解集与等价整理依据、交集过程、完整性验证结果 |
| 未完成处理 | 提取不完整、求解未知或验证失败时保留缺口，不将部分条件的交集当作完整定义域 |

本题中的 $x-2\ne0\iff x\ne2$ 是基础等价整理；无需为这一操作新增公共技能。复杂方程、不等式在后续按任务调用匹配的技能或子方法，调用结果仍要与其他原式限制合并。

题设另给输入范围时，M1 必须把它纳入交集。化简表达式不得删除原始限制；计算得到空集时，应明确说明“没有使该表达式有意义的实数输入”。

### 4.2 S3：提取表达式有意义的条件

| 项目 | 设计 |
| --- | --- |
| 输入 | 原表达式的结构、自变量与相关语义上下文；题设范围作为独立来源保留 |
| 输出 | 各部分同时有意义所需的条件清单；每条包含原式位置、限制原因和知识依据 |
| 首题输出 | 根号内 $x-1$ 对应 $x-1\ge0$；分母 $x-2$ 对应 $x-2\ne0$ |
| 职责边界 | 不解条件，不求交集，不生成最终定义域；遇到未知结构不能静默跳过 |
| 原式保护 | 提取依据是原式结构；即使后续约分或化简，仍保留条件与原式的对应关系 |

规则逐步扩充并单独验收。首批包含平方根和除法；例如 $1/\sqrt{x-2}$ 同时要求 $x-2\ge0$ 与 $\sqrt{x-2}\ne0$，可经有依据的整理得到 $x-2>0$，不能只套普通根式的非负条件。

S3 到教学投影已使用以下来源字段；条件、求解结果与交互从同一数学产物投影。

| 已实现字段 | 含义与约束 |
| --- | --- |
| `condition_id` | 本次产物中的稳定条件标识；求解结果、反馈和数轴引用同一条件 |
| `source_ref` + `ast_path` | 前者指向候选中的原函数定义，后者定位原表达式 AST 内的被开方数或分母；两者一起构成位置引用 |
| `expression_ast` / `condition` | 原位置的表达式结构及提取出的原始数学条件；后续正规化与求解证据保留对应关系 |
| `kind` / `basis_refs` | `radicand_nonnegative` 或 `denominator_nonzero`，以及可解析的知识依据，如 `square-root-expression#meaning` |

每条条件的 `source_ref` 与 `ast_path` 必须能在同版本原式中解析，`basis_refs` 必须能在正式内容中解析；缺失时不能以页面硬编码位置或知识名称补齐。首题的两条路径分别为 `[1,2]`、`[2]`，来源同为 `/root/definitions/0`。重复根式具有不同路径，不能按表达式文本去重。条件即使在最终交集中不再缩小范围，也保留原始条件、来源与依据。

### 4.3 复用与粒度

| 内容 | 处理方式 |
| --- | --- |
| 不等式变形与推导 `skill-inequality-transform` | 复用已有身份，如将 $x-1\ge0$ 整理为 $x\ge1$；乘除负数必须改变不等号方向 |
| 一次条件和不等于条件的求解 | 核实并复用已有计算能力，为定义域场景补齐输入、证据和教学适配 |
| 求交集、区间表示、端点核验 | M1 内的基础步骤；底层集合运算可以共用，不因此另建教学技能节点 |
| 代数化简、等式变形及更复杂求解 | 只有实际路线需要独立操作时才关联，不为凑齐节点预先挂上 |

## 5. 知识依据与判断职责

### 5.1 知识依据

| 知识 | 首题作用 | 当前安排 |
| --- | --- | --- |
| 函数的概念 `function-concept` | 定义域是全部允许输入 | 复用 |
| 区间的概念 `interval-notation` | 表达范围及端点开闭 | 复用 |
| 集合的交集与并集 `set-intersection-union` | 同时满足取交集；表示最终结果时可能用区间并集 | 复用 |
| 分式节点的分母非零依据 `rational-expression#meaning` | 解释除法中的分母限制；分子为零可以允许 | 复用相关条目，不把含根式的整个式子误称为整式之比 |
| 不等式的性质 `inequality-properties` | 一次条件的等价变形 | 通过复用技能关联 |
| 二次根式有意义的条件 `square-root-expression#meaning` | 实数平方根的被开方数非负，0 允许作为被开方数 | 已正式登记并通过集合归属、图谱与导出引用检查 |

“多个条件取交集”与“答案写成两个区间的并集”应区分清楚：前者是同时满足各条件，后者是同一个结果集合的表示。

二次根式已登记为知识节点 `square-root-expression`，名称“二次根式”，归入 `junior-knowledge`。`meaning` 条目明确“在实数范围内，$\sqrt{u}$ 有意义当且仅当 $u\ge0$，允许 $u=0$”，并说明平方根作分母时须进一步排除零。公共条目入口为 `/knowledge/square-root-expression/#meaning`；S3 已引用此正式条目。

题型节点现有的 `quantifiers`、`quadratic-inequality` 保留为求参及二次条件扩题的知识关联。首题的识别、M1／S3 执行契约与教学投影只依赖实际使用的依据，不把整个题型的 `knowledge` 列表自动转成首题强制依赖，也不要求学生先完成量词或二次不等式内容。

### 5.2 判断放在哪一层

| 判断 | 归属 |
| --- | --- |
| 当前目标是不是求具体函数的定义域 | 题型识别，结合目标语义与表达式角色 |
| 本批是否能完整处理这个表达式 | 方法适用性与执行范围检查 |
| 根号、分母各自要求什么条件 | S3 内部规则，引用知识依据 |
| 如何求解当前条件 | 方法内部按条件类型调用能力；需要复杂分支时再扩展 |
| 结果是否保留全部限制、端点是否归属正确 | 方法验证与相应步骤检查 |
| 学生选项或填写结果是否正确 | 教学交互判定，依据已经验证的数学产物 |

首题只有 M1 一条入口路线，暂不新增独立的公共选法规则节点。上述判断不自动各建一个规则节点；后续存在清晰、独立、可复用的选法或选步骤分支时，再按公共图谱类型登记。

## 6. 学生教学与交互

静态专题与拍题共用教学运行时及同一 D1 投影。读题只检查容易混淆且会改变解题方向的含义；公式作为已知信息展示，不要求学生逐句复述或辨认已经给出的表达式。

### 6.1 D1：明确“定义域”要求什么

本轮确认将 D1 统一为一个 `choice`，不再用多个作答槽确认题面信息。

| 项目 | 约定 |
| --- | --- |
| 已知信息 | 展示原函数公式；若题目显式给定输入范围，同时展示该范围。两者均不占作答槽，也不从求解答案反填题设范围 |
| 提问 | 题目要求“定义域”，也就是要确定什么？ |
| 正确选项 | 自变量 $x$ 的取值范围 |
| 干扰选项 | 函数值 $f(x)$ 的取值范围 |
| 干扰项依据 | 对应把定义域与值域混淆的真实误解，不添加与解题无关的凑数选项 |
| 答对后解释 | 定义域是自变量所有允许取值组成的集合；本题要找使原式有意义的 $x$，若有题设范围还须同时满足它。此时不提前给出各条件或最终集合 |
| 答错后反馈 | 提醒区分输入 $x$ 与输出 $f(x)$；函数值的取值范围是值域，引导重新理解本题目标 |

变量和函数名称来自题意，改用其他变量或函数名时同步投影，不把 `x`、`f` 固定为所有定义域题的显示内容。两种入口都验收：D1 只有这一道含义判断，公式和显式题设范围可见但不可作答，正确后再进入后续步骤。

### 6.2 四个数学教学单元

以下四个单元由验证后的 Stage3 seeds 生成。本次只调整 D1 读题交互，数学路线不变；完整教学仍为 **D1 读题、D2 判型、D3 方法确认，加上四个数学教学单元，共 7 步**。布局、刷新和模式切换的浏览器检查见验收记录，不能用数据层测试替代。

| 阶段 | 学生要完成的任务 | 正确依据与反馈重点 | 图形安排 |
| --- | --- | --- | --- |
| 找限制位置 | 指出原式中需要检查的部分 | 根号与分母；不能只发现其中一个 | 由 S3 的 `condition_id`、`source_ref`、`ast_path` 与原 `expression_ast` 生成区域高亮 |
| 列条件 | 写出或选择各部分有意义的条件 | $x-1\ge0$、$x-2\ne0$；解释为何前者可以等于 0 | 原式位置与对应条件关联显示 |
| 解条件 | 整理各个输入范围 | $x\ge1$、$x\ne2$；用变式检验负系数时的方向 | 两条数轴分别显示各条件的解集 |
| 求交集与核验 | 保留共同范围、设置端点并填写定义域 | 1 保留、2 排除；答案为 $[1,2)\cup(2,+\infty)$ | 合并数轴，1 实心、2 空心，保留向右无限延伸与两段范围 |

“找限制位置”是 S3 产物的一种教学呈现，不是独立技能。投影通过 §4.2 的位置字段绑定原式区域、条件卡与反馈，再通过条件标识关联求解结果和数轴；不得在 UI 中重新猜测或另写一套限制提取逻辑。验收需覆盖更换数字、变量名及同类结构出现多次时的位置绑定，证明高亮跟随数学产物；位置引用失效时报告投影缺口。

主要错因与反馈：

- 只写 $x\ge1$：提示回看分母，补上不能为零的条件。
- 写成 $x>1$：引导检查 $x=1$ 时是否确实有意义，说明分子为零不等于分母为零。
- 合并条件时选并集：回到“同一个输入必须同时满足两项限制”。
- 写成 $[1,2]$ 或遗漏右侧范围：分别检查禁取点和大于 2 的允许输入，随后回到完整条件证明。
- 区间开闭错误：根据对应条件核验端点，数轴与文字答案保持一致。

学生反馈与可接受答案必须来自验证后的数学数据，不能在题目页硬编码一套与求解结果无关的正确选项。进入“自己做”时不预先揭示最终答案；“看 AI 解题”、提示和回放沿用共同运行时，分别记录进度。

## 8. 验收范围与边界例

### 8.1 首批数学边界清单

下列是首批数学验收口径，已纳入定向开发／回归；独立留出变式与实际运行记录见验收文档。数学测试通过不自动覆盖最终浏览器行为。

| 检查点 | 输入示例 | 预期 |
| --- | --- | --- |
| 代表题、分子可以为零 | $\dfrac{\sqrt{x-1}}{x-2}$ | $[1,2)\cup(2,+\infty)$ |
| 数值变化 | $\dfrac{\sqrt{x-3}}{x-5}$ | $[3,5)\cup(5,+\infty)$ |
| 禁取点与根式端点重合 | $\dfrac{\sqrt{x-2}}{x-2}$ | $(2,+\infty)$ |
| 禁取点在根式范围之外 | $\dfrac{\sqrt{x-1}}{x+1}$ | $[1,+\infty)$；条件清单仍含 $x+1\ne0$，来源指向原式分母，依据含 `rational-expression#meaning` |
| 根式内为负系数一次式 | $\dfrac{\sqrt{3-x}}{x-2}$ | $(-\infty,2)\cup(2,3]$ |
| 根式在分母 | $\dfrac{1}{\sqrt{x-2}}$ | $(2,+\infty)$，端点严格排除 |
| 条件冲突 | $\sqrt{x-2}+\sqrt{1-x}$ | 无允许的实数输入，解集为空 |
| 题设限制与单点结果 | 代表题另限 $x\in[0,1]$ | $\{1\}$ |
| 等价答案表示 | 代表题填写 $\{x\in\mathbb R\mid x\ge1,\ x\ne2\}$ | 与区间答案等价 |

“禁取点在根式范围之外”的测试必须同时断言最终集合和条件证据：原始条件清单保留 $x-1\ge0$ 与 $x+1\ne0$；分母条件有原式位置、知识依据及排除 $-1$ 的求解关系；最终交集仍为 $[1,+\infty)$。只比较最终集合会漏掉“错误地忽略分母但碰巧答案相同”的实现，不能作为通过依据。

另测语义与能力边界：同一表达式改问函数值或值域时不误用 M1；原式关键结构缺失时不猜补；二次条件、未知参数、根号内分式等本批未覆盖结构应明确报告缺口。后续扩题必须覆盖约分前禁取值，以及“根号内分式非负”不能简化成“分子非负且分母非零”的反例。
