更新：2026-11-12。开发基线：`976a7f82`，T1–T4 已提交。状态：**T5 数学执行、来源绑定、选法、隔离课包及评分回放已实现，A10 两问和 A14 已通过真实 OCR／模型、课程 API 及作答状态机集成验收；独立新材料、账号浏览器流程及公开课程验收待完成。工作区未提交。** 实际范围与验证见[实现记录](function-parity-t5-implementation-acceptance.md)、[照片验收](function-parity-t5-photo-acceptance.md)及 §9。

本文细化[函数奇偶性建设计划](function-parity-topic-plan.md)中的 T5，承接 [T3 对称求值](function-parity-formula-problem-type-design.md)首建的 M5／S2，遵循[专题与拍题学共用开发流程](topic-and-photo-learning-development-workflow.md)。

这里的“非奇偶”指**不局限于原点和 $y$ 轴的一般对称关系**，不是要求原函数一定非奇非偶。主线为：读出轴或中心对应的输入配对，合法地组合两次对称，得到带符号与常数的平移关系，再求指定值或有限和。

## 1. 身份、范围与完成标准

### 1.1 共用方法，不另建周期专用求解器

| 项目 | 约定 |
| --- | --- |
| 专题／分组 | `function-parity`／FP-T5 非奇偶的对称性 |
| 候选题型 | 新增 `type-function-symmetry`；T3 已有的 `type-function-evaluation` 对称求值分支保留，按 §3.2 分流 |
| 方法 | M5 `method-function-symmetry`，学生名称“对称关系法”；在 T3 已开放子范围上扩展 |
| 技能 | 扩展 S1 `skill-domain-symmetry` 的一般中心横坐标、S2 `skill-function-symmetry-transform` 的一般反射；首建 S4 `skill-function-shift-iteration` |
| 复用 | 代入法、构造方程组法、消元、等式变形、有限求和、精确集合及系数计算 |
| 知识依据 | `function-graph-symmetry#axis`、`#center`、`#paired-arguments`、`#translation`；`function-parity#zero` |

知识层仍保持三个节点。周期及反号平移可作为“一般图像对称性”的内部条目，不为每种组合建立独立公共方法。

本型原题为 **A10、A14 两题、三个原目标**。独立的一般轴、一般中心以及两中心题在原两图中缺失，实施时必须补机制样例与独立新材料，不能只完成“奇函数＋一条轴”后宣称覆盖全部 T5。

### 1.2 结构范围与有界执行

| 子范围 | 计划覆盖 | 边界 |
| --- | --- | --- |
| 读出位置 | 关于 $x=a$ 的轴对称、关于 $(a,b)$ 的中心对称；输入和固定的全称函数关系 | 必须核对关系量词及覆盖范围；局部关系只作局部配对 |
| 关系组合 | 一个函数、至多两条独立生成反射；两轴、两中心、轴与中心、奇偶与一般对称的组合；R3 覆盖带常数的局部反射配对等式 | 局部配对不自动成为图像对称性质；同一关系的等价写法可去重；三条以上独立生成关系先报告能力缺口，不丢弃多余条件 |
| 值与目标 | 有理输入处的点值、有限有理线性组合、连续整数索引上的仿射输入求和 | 一般非线性函数值方程、无限级数、最小正周期、任意函数解析式不在首批范围 |
| 常数 | 固定有理轴、中心、平移量与偏移量；符号坐标可作结构推导展示 | 数值执行前须确定；一般含参轴／中心分类另列范围，不从个别点猜参数 |
| 定义域 | 至多 8 个有理端点区间、16 个有理孤立点／删点，可含无穷端点 | 只允许已证明合法的反射或迭代；一般无限周期点集不在首批集合表示范围 |
| 迭代 | 正、零、负整数次数；恒等平移、反号平移、带常数的值平移；零位移退化 | 值平移不自动等于周期；局部关系不能外推为全域周期 |

共用源预算：AST 至多 256 节点、深度 24、有理数至多 128 位。普通点值任务至多 32 个不同函数值未知量、32 条数值线性条件；关系化简与目标证明长度有界，超限返回能力缺口。

有限求和沿用既有总项数上限 4096、索引绝对值上限 10000，新增证据可以压缩相同轨道。题面紧凑求和不受“展开后 32 个调用”的错误拦截；至多 32 个独立基础值，其余项须由合法迭代推回这些基础值，不能无限扩充未知量。直接手写点值组合仍使用普通点值预算。

局部关系首批允许至多 32 次显式变换，每次验证作用域；全域关系可用整数迭代公式及整条轨道合法性证书压缩。不能把展示上的省略号当成数学证明。预算集中登记并进入准入、验证与评分版本。

## 2. 题源与数学金标

题源沿用[总计划台账](function-parity-topic-plan.md#3-逐题台账)和[原图清单](../internal/senior-high/source-images/function-parity-planning-20261110/manifest.json)。下列答案独立核对，不使用手写答案作为执行输入。

| 原题 | 印刷条件及目标 | 金标与关键关系 |
| --- | --- | --- |
| A10① | $\mathbb R$ 上奇函数，关于 $x=1$ 对称，$f(1)=1$；求 $\sum_{k=1}^{4}f(k)$ | $0$；整数点值依次为 $1,0,-1,0$ |
| A10② | 同一条件；求 $\sum_{k=1}^{54}f(k)$ | $1$；13 组四项加 $f(53)+f(54)=1+0$ |
| A14 | $\mathbb R$ 上奇函数，关于 $x=\frac12$ 对称；求 $\sum_{k=1}^{5}f(k)$ | $0$；所有整数点值为零，不能推广为函数恒零 |

### 2.1 A10：先反号平移，再求和

由轴对称 $f(2-x)=f(x)$，在其中换入 $-x$，再用奇性，得到

$$
f(x+2)=f(-x)=-f(x),\qquad f(x+4)=f(x).
$$

$f(0)=0$，故 $f(2)=f(4)=0$；由 $f(1)=1$ 得 $f(3)=-1$。于是四项和为零，54 项由 13 组和两项余项构成。这里 $4$ 是已证明的一个正周期，未证明它是最小正周期。

### 2.2 A14：只确定整数点

$f(1-x)=f(x)$ 与奇性组合为 $f(x+1)=-f(x)$；从 $f(0)=0$ 迭代得每个整数点均为零。函数本身仍可不为零，例如 $\sin(\pi x)$ 满足这些条件；这个反例仅用于数学核查，不表示生产执行需要新增三角函数求解器。

### 2.3 补充机制题，不计入原题数量

| 机制样例 | 精确结论 | 用途 |
| --- | --- | --- |
| $\mathbb R$ 上关于 $x=2$ 对称，$f(1)=3$ | $f(3)=3$；不能从轴对称确定 $f(2)$ | 独立的一般轴 |
| $\mathbb R$ 上关于 $(1,2)$ 中心对称，$f(0)=5$ | $f(2)=-1$，$f(1)=2$ | 非原点中心及固定点 |
| $\mathbb R$ 上关于 $x=0$ 和 $x=3$ 对称 | $f(x+6)=f(x)$ | 两轴组合；不声称最小周期 |
| $\mathbb R$ 上关于 $(0,0)$、$(1,2)$ 中心对称 | $f(x+2)=f(x)+4$，$f(6)=12$ | 两中心产生函数值漂移，$2$ 不是该函数的周期 |
| 只在 $x\in[0,1]$ 给 $f(2-x)=f(x)$，完整域为 $\mathbb R$ | 可以配对 $[0,2]$ 内相应点；不能证明全域关于 $x=1$ 对称 | 局部关系与全域性质分开 |

### 3.2 特征、题型与共用 M5 的分流

1. **T3 合同保持稳定。** 只有既有奇偶事实、相反输入关系和数值目标的旧题，仍产生 `symmetry_evaluation`，归属 `type-function-evaluation`，消费 `symmetry_value_goal`。已有双函数分离、T2 参数借用、求值状态和证书继续回归。
2. **T5 独立描述。** 原文给出一般图像对称事实、超出 T3 合同的单函数反射／平移等式（包括没有奇偶前提的原点配对与局部带常数配对），或要求利用抽象对称事实完成 `finite_sum` 时，由新描述器生成 `symmetry_relation` 及 `symmetry_relation_goal`，归属 `type-function-symmetry`。显式函数求和且没有此类事实的旧题继续走原代入路线。新描述必须消费全部适用的原条件；超出两生成关系、预算或当前批次的来源保留失败原因，不丢条件回退到 T3。
3. **先判来源归属，再判支持程度。** `features.py` 命中 T3 描述后会提前结束该目标的特征提取；现已把 T5 所有权判断放在这个分支之前，[stage_three/context.py::build_context](../server/shuxueshuo_server/graph_lesson/stage_three/context.py) 的分支顺序同步调整。一般对称的显式陈述即使轴／中心坐标为零，也由 T5 来源合同处理；仅用 `parity` 表达的既有 `find_value` 旧题仍归 T3。对一个目标不同时发布两个可执行的对称特征，避免新增题型与既有求值题型竞争。
4. **共用方法，分开适配。** M5 的 execution、admission、capability、presentation 与冻结回验按结构版本选择 T3 或 T5 分支。T5 在轨道化简后调用共享线性核，并从原关系独立重建矩阵；T3 的奇偶专用相容检查、`verify` 和来源绑定不能直接充当 T5 验证器。
5. **保留原目标种类。** 点值／手写有限线性组合使用 `find_value`；紧凑求和使用既有 `finite_sum`，包括逐项来源与索引块。答案分别保留 `scalar_value`／`finite_sum` 结果身份，证明不唯一时按既有 `insufficient_information` 状态交付证据。派生轴、中心及周期不是替换原求值／求和目标的理由。A10①的四项组合采用 `find_value`，A10②的 54 项采用 `finite_sum` 索引块；两个目标独立进入识别、执行和导出，课程必须包含两个 `target_ref`。

## 4. 对称关系与结果合同

### 4.1 原题事实：图像陈述与函数等式分开转录

沿用 `root.facts` 的受控数学字符串，不让模型输出 AST 或推导后的反射记录。以下共享记法已登记到 [math_expression_catalog](../internal/llm-prompts/problem-math-notation-expressions.json)、编译器及原文绑定器，供提取、复核和修复共同使用；真实模型转录效果仍须单独验收。

| 原题陈述 | 候选事实／目标 | 代码职责 |
| --- | --- | --- |
| $f$ 的图像关于直线 $x=a$ 对称 | `graph_symmetry(f,axis,a)` | 绑定原坐标 AST、全图声明与函数身份，再生成反射；不是唯一对称轴声明 |
| $f$ 的图像关于点 $(a,b)$ 中心对称 | `graph_symmetry(f,center,a,b)` | 绑定两个原坐标 AST；由代码生成值关系，不要求模型算 $2a$、$2b$ |
| $f$ 是奇／偶函数 | 继续使用 `parity(f,odd)`／`parity(f,even)` | 复用现有 `function_parity` 事实，不从图像声明反向补造一条奇偶事实 |
| 完整定义域为 $D$ | 继续使用 `Dom(f)=D` | 与对应函数绑定；声明域不是关系量词的局部范围 |
| 对任意 $t\in E$，$f(qt+a)=f(b-qt)$ 或两个函数值之和为 $c$，$q\in\mathbb Q\setminus\{0\}$ | 原样转录已有 `∀t∈E:…` 数学等式 | 保留量词、变量和 $E$；代码读取仿射输入、计算中点并精确转换输入范围，不能让模型改填一个全域轴／中心声明 |
| 求 $\sum_{k=1}^{54} f(k)$ | `{"kind":"finite_sum","terms":[{"expression":"f(k)","index":"k","lower":1,"upper":54}]}` | 复用 `FiniteSumGoal`，索引仅在此块内绑定；不填周期、分组大小或答案 |

`graph_symmetry` 的首批记法仅表示明确的**全图**轴／中心陈述，坐标为原题表达式而非答案。带局部限制的题给等式保留量词表示；若原文只说某一段图像对称、无法分清是该段自身对称还是与另一段配对，保留歧义并要求复核，不扩写成全图性质。否定句、疑问中的待判断性质以及另一函数或兄弟小问的性质都不能注册为本目标的已知事实。

编译／绑定后的来源记录由代码生成，至少包括：

| 字段 | 含义及约束 |
| --- | --- |
| `function_ref`、`source_ref`、`source_span` | 函数的作用域身份、候选位置及原文片段；新事实须能在没有 `parity` 或显式函数体时登记函数身份 |
| `source_kind` | `graph_statement`、`quantified_relation` 或 `parity`；保留来源区别，派生公式不能覆盖原题 |
| `symmetry_kind`、`coordinate_asts` | 图像来源的 `axis`／`center` 与原坐标；等式来源保留 `relation_ast` 和量词变量，由代码另存归一化参数 |
| `scope_kind` | 图像／奇偶全域声明为 `whole_domain`；题给量词等式为 `relation_scope`，保留原 `scope_ast` 及变量代换证据 |
| `domain_source_refs`、`domain_ast` | 完整域的来源；缺省时保持未明示，不把局部 $E$ 或缺省域填成 $\mathbb R$。需要的合法性必须从来源及闭合性质推出，无法证明则报能力缺口 |

例如 A10 的来源为 `Dom(f)=ℝ`、`parity(f,odd)`、`graph_symmetry(f,axis,1)`、`f(1)=1`；`f(x+2)=-f(x)` 和周期 $4$ 均为后续代码证据，不进入提取事实。原文绑定须覆盖中文轴／中心措辞、坐标、否定和小问归属；改变轴坐标、中心纵坐标、量词范围或函数身份时拒绝原证据。两个等价来源可以共享归一化结果，但各自原文引用都保留。

来源绑定支持“关于两条直线／两个点对称”和“对称轴／对称中心为”的并列陈述，以及中文量词、公式中的 `∀`、共用量词和逐条重复量词。每个等式先绑定实际拥有它的量词，再比较变量与范围；后一句范围不匹配时不能借用前一句。否定与疑问的判断保留完整陈述上下文，含引号及逗号后的“不成立”“对吗？”，不能只读取等式紧邻的几个字。

量词原式中的每个分母和被开方数，须在原 $E$ 上先通过有意义检查；被约去或乘以零的部分也不能跳过。原范围已排除奇点时可以正常处理，否则拒绝准入，不能自动缩小量词范围。两个输入归一化后的斜率必须是互为相反数的非零有理数；允许负数和分数，保留像范围的开闭端点及孔洞。非仿射输入、零斜率及不等幅斜率返回能力缺口。

### 4.2 统一反射记录

从 §4.1 的已绑定事实派生反射记录，保存函数身份、来源、全称变量及关系作用域 $E$，并规范为

$$
R_a(x)=2a-x,\qquad f(R_a(x))=\varepsilon f(x)+c,\quad \varepsilon\in\{1,-1\}.
$$

| 对称性质 | 参数 | 域要求 |
| --- | --- | --- |
| 关于 $x=a$ 的轴对称 | $\varepsilon=1,c=0$ | 全域声明须 $R_a(D)=D$ |
| 关于 $(a,b)$ 的中心对称 | $\varepsilon=-1,c=2b$ | 同样核对反射闭合；$a\in D$ 时才有 $f(a)=b$ |
| 偶／奇 | 分别为 $(a,\varepsilon,c)=(0,1,0),(0,-1,0)$ | 复用原奇偶事实及其来源 |

若两次反射都可用，恒有 $(\varepsilon+1)c=0$。因此非空全域上的 $\varepsilon=1,c\ne0$ 是矛盾，不能当作一种轴对称；局部关系若不允许第二次作用，不能据此误判矛盾。

局部 $\varepsilon=1,c\ne0$ 的等式只登记为带值偏移的配对关系，R3 按有方向的边处理，不赋予轴对称名称。正向边的源范围为 $E$、像范围为 $R_a(E)$，须证明两者均在 $D$ 内；不能静默截去原量词中导致输入无定义的部分。区间记法沿用 T2–T4 的左端点严格小于右端点约定，有限集保留集合语义。

固定点检查为 $(1-\varepsilon)f(a)=c$。轴对称不会确定轴上函数值；中心对称会确定中心处函数值，但中心横坐标可以不在域中，例如 $f(x)=1/(x-1)+2$ 在 $\mathbb R\setminus\{1\}$ 上关于 $(1,2)$ 对称。

由 $f(a+t)=f(b-t)$ 识别轴 $x=(a+b)/2$，或由 $f(a-t)+f(b+t)=c$ 识别中心 $((a+b)/2,c/2)$，必须证明允许的 $t$ 覆盖完整定义域的相应输入。只有几个点或一段关系时，产出局部配对，不能赋予全域对称标记。

### 4.3 派生关系、目标与诊断

每条派生边记录父来源、使用方向 `forward/inverse`、源范围、像范围及常数计算证据。平移另记录 $f(x+p)=\eta f(x)+d$、顺序明确的父边和域闭合证据；反向使用不改写原事实的 $c$。点值目标记录每个出现位置与系数；求和目标另记录索引起止、输入表达式、重数、分组与余项。

结果区分：某条轴／中心成立、一个可用正周期、指定值／和唯一确定、目标不唯一、题设矛盾以及执行能力缺口。“没找到足够关系”本身不能证明数学上不唯一；未知全函数也不妨碍某个目标唯一。

所有题给关系都参与一致性检查；不得选择一条方便关系后忽略冲突值。原输入非法是目标无定义，不是目标值自由。

## 5. 数学执行与独立验证

### 5.1 有序组合两次反射

先用源范围为 $E_a$ 的正向边 $R_a$，再用源范围为 $E_b$ 的正向边 $R_b$，组合的源范围为 $F=E_a\cap R_a^{-1}(E_b)$，像范围为 $F+2(b-a)$。在该范围内有

$$
R_b(R_a(x))=x+2(b-a),\qquad
f(x+2(b-a))=\varepsilon_b\varepsilon_a f(x)+\varepsilon_b c_a+c_b.
$$

代码保存父边顺序和方向，不能只保留两个轴／中心的无序集合。$F$ 为空只表示这个组合没有可用输入，不能由此推出全域恒等式或非空范围上的矛盾。

对原边 $e:x\mapsto R_a(x)$、$f(R_a(x))=\varepsilon f(x)+c$（$x\in E$），代数逆边是

$$
e^{-1}:y\mapsto R_a(y),\qquad
f(R_a(y))=\varepsilon f(y)-\varepsilon c,\quad y\in R_a(E).
$$

因此正向组合 $e_b\circ e_a$ 的逆须按 $e_b^{-1}$、$e_a^{-1}$ 的顺序使用，其平移参数为 $(-p,\eta,-\eta d)$，源范围为 $F+p$。只有每条原边的常数满足 $(\varepsilon+1)c=0$，且逆用所需输入也属于原边源范围时，才能把原边本身当作逆边。全域轴／中心满足这些条件；局部关系不能只交换两条原公式。

回归反例：在 $x\in(0,1)$ 上有 $f(-x)=f(x)+1$，在 $x\in(-1,0)$ 上有 $f(2-x)=f(x)+2$，完整域为 $\mathbb R$。两步把 $\frac12$ 送至 $\frac52$，值增加 $3$；若 $f(\frac52)=3$，逆用得到 $f(\frac12)=0$。直接交换原公式会错误保留 $+3$。这些局部条件相容，例如在 $(0,1)$、$(-1,0)$、$(2,3)$ 分别取常值 $0,1,3$，其余点取 $0$；不能以全域反射的自反要求判它矛盾。

| 组合 | $p$、$\eta$、$d$ | 可得结论 |
| --- | --- | --- |
| 两轴 $a,b$ | $2(b-a),1,0$ | $p\ne0$ 且全域闭合时，$\lvert p\rvert$ 为周期 |
| 原点中心，再关于 $a$ 的轴 | $2a,-1,0$ | 反号平移；再作用一次得到 $4\lvert a\rvert$ 的周期，要求 $a\ne0$ |
| 中心 $(a,A)$，再中心 $(b,B)$ | $2(b-a),1,2(B-A)$ | $A=B$ 时可有上述周期；$A\ne B$ 时该步是值漂移 |
| 一般轴与中心 | 按有序公式计算，$\eta=-1$ | 即使 $d\ne0$，再作用两次的偏移相消 |

$p=0$ 单独处理：$\eta=1,d=0$ 是恒等关系，不产生正周期；$\eta=1,d\ne0$ 在非空作用域上矛盾；$\eta=-1$ 则强制相应范围上 $f=d/2$，还需与其余条件相容。不能除以 $p$ 或把零称为周期。

### 5.2 S4：正反向迭代与域

若已证明 $f(x+p)=\eta f(x)+d$ 可以沿所需轨道正反使用，则对整数 $n$：

$$
\begin{aligned}
\eta=1:\quad &f(x+np)=f(x)+nd,\\
\eta=-1:\quad &f(x+np)=(-1)^n f(x)+\frac{1-(-1)^n}{2}\,d.
\end{aligned}
$$

正向平移源范围为 $F$ 时，逆一步为 $f(x-p)=\eta f(x)-\eta d$，其源范围为 $F+p$（等价于检查 $x-p\in F$）。不能机械地调换输入而保留常数符号或源范围。$n=0$ 返回原值，仍须原输入合法；局部多步迭代每一步均检查相应有方向边。

全域周期需同时满足 $D+p=D$ 和对应函数值恒等式。两条全域反射的域闭合可组合成平移闭合；局部关系则逐步检查中间输入落在所用正向或逆向边的源范围，不能一律检查原 $E$。非空有界域不可能在非零平移下保持不变，因此“完整有界域＋两条不同的全域对称轴”须发现矛盾，不能画一段曲线后忽略域。

具备上述全域证据且 $p\ne0$ 时，$\eta=1,d=0$ 给周期 $\lvert p\rvert$；$\eta=-1$ 给周期 $2\lvert p\rvert$；$\eta=1,d\ne0$ 不给步长 $\lvert p\rvert$ 的周期。最后一种情况不等于已经证明不存在任何其他周期。

“最小正周期”是独立目标，本批不开放。常值函数也有任意正周期而无最小正周期，不能因为找到一个周期就添加“最小”二字。

### 5.3 点值轨道、一致性与唯一性

至多两条反射生成的输入变换按“平移 $x\mapsto x+np$”或“反射后平移 $x\mapsto2a-x+np$”归一化，保留函数值的符号与常数。全域时用精确有理算术判断目标点是否在同一轨道；局部时这只提供候选输入变换，实际可达性仍需有方向路径及每一步范围证据，不能靠同余判断跳过不可用的中间步骤，也不能只按最终输入合并不同值偏移的路径。

在每个相关轨道上，将已知点值、固定点和返回同一输入的关系写成线性条件，再复用 T3 的目标线性组合证书：先验证方程组相容，再验证目标在已知条件的行空间中。循环得到 $z=z+d$ 且 $d\ne0$ 时矛盾；循环得到 $z=-z+d$ 时确定 $z=d/2$。

全局存在性不能仅由有限目标点的矩阵相容代替。对一／两反射的有界合同，需要检查生成关系、域闭合以及轨道稳定变换的相容性，给出其余轨道可自由选初值并扩展的构造。若不能验证这种扩展，返回能力缺口；不声称已证明所有原事实存在共同模型。

目标不唯一时，至少提供两个满足全部事实的可扩展轨道赋值，使目标不同；不能只找两个违反别处对称条件的点值表。局部关系不具备全域轨道闭合，只按已验证路径执行，非唯一结论同样需全来源模型证据。

### 5.4 有限和、余项和重复项

把每个合法项规范为 $\alpha_k z_{j(k)}+\beta_k$，保留其来源位置和重数，再求系数总和。若按周期分组，验证索引组不重叠、无遗漏、边界正确，余项仍有合法求值证据。

不能看到 $f(x+p)=-f(x)$ 就把任意相邻两项配对；两项的实际输入必须相差 $p$。带常数反号关系 $f(x+p)=-f(x)+d$ 的配对和为 $d$，不是零；值漂移关系的多组和还会累计偏移。

对 $u_k=u_0+sk$，用有理比例与整数同余判断实际周期分组；不写死“四项一组”或输入是 $k$。可分组则压缩证书，否则在项数与独立基础值预算内直接建立合法线性组合。缺少基础值但总系数恰好消去时，和仍可唯一确定。

### 5.5 独立验证器

验证器从原关系重新计算反射、正逆方向、源范围／像范围、组合次序、迭代符号与偏移，验证轨道归一化和每条点值线性证明，不调用生产求值入口。全域结论须验证域闭合与关系覆盖；点值结论须检查所有实际使用的中间输入。逆边必须从原来源按 $-\varepsilon c$ 及 $R_a(E)$ 重建，不信任证书自行声称的逆关系。

求和验证检查每个索引恰好出现应有次数、分组关系成立、余项存在、常数累计正确。交换反射顺序、修改偏移、漏一项、把局部标成全域、把周期标成最小或删掉冲突事实，均须被拒绝。
