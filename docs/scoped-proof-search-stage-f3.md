## 默认入口与历史边界

`RuntimeOrchestrator`、基本不等式 authoring 求解及 Lesson 构建入口默认使用 `scoped-facts/v2`。原始 `RuntimeContext` 的构造默认值仍为 v1，供直接内核调用及历史测试使用；运行编排器显式设置实际协议。显式 v1 保留原条件绑定及历史 checkpoint 语义，但新证明构造也使用分层调度，不回退旧搜索。

生产 `proof_kernel.py` 删除单体 `_Search`。历史实现保存在 `server/tools/proof_search_legacy.py`，仅供阶段 A/D 基线和历史规则节点篡改测试使用。`HistoricalRequests` 是工具侧的显式离线注入器，生产包没有对它的导入。历史证书回放仍由 checker 完成，不依赖搜索策略版本，也不需要该归档工具。

F1/F2 冷回放脚本的禁止搜索探针改为当前 `ScheduledRealSearch`；原始归档内容、外部授权 fixture、规则 hash 均不修改。

## 回归发现与修复

新策略版本为 `layered-search/v2` / `layered-method-search/v2`，未增加 ProofLimits、总算术额度或每候选的分支配额。检索视图只分配 attempts/reductions，不再把剩余 nodes 平分给每次扩容；证书仍受原全局及每候选节点上限约束。

- 预算内成功子目标缓存：绑定规则、完整局部上下文、已提交 manifest 和策略指纹；复用时重新检查每个节点，并保留共享事实读取依赖。候选失败不退款，已验证子结论可在相同授权下复用。独立调用的会话只存活于其显式预算内。
- 节点计数按实际依赖去重：计数键包含规则、Scope、符号、预算 profile、该节点实际引用的前提、子节点键与证书；新增无关前提不再重复收费。见证/exists/all 保留完整上下文键。节点检查、证书完整 context_hash 与 sources 比较仍逐次执行；此项只改变工作量计数，不缓存授权或免除 replay。
- 检索闭包：小视图保留当前标量顺序/正性基础和已提交的完整传递路径，避免把 F≥G、G≥k 拆散后重复证明定义域。共享片段作为 S1 候选，先尝试简单正性规则；多份同结论证书按可达节点数稳定排序。
- 当前前提优先：已被 Method 验证并纳入当前上下文的关系，使用 `given` 节点；不反复内联其此前完整推导。原生产证明仍由外层证据链重放。
- 结构正性：`positive_components` 对由已知正表达式构成的和、积、商递归提出 `sign` 证明。允许 `a-b>0` 这样的复合式作为叶子，每个分母仍须非零。策略不按题号或答案分支。
- 同端点界传递：`endpoint_transport` 从已有同方向、同端点的界出发，验证两边表达式的等价关系，再使用既有 `equality_bound_transport` 规则。错误方向、缺少必要等式、遗漏余项均拒绝。
- 非零积因子：已知乘积等于非零有理数时，直接构造 equal_sign / factor_nonzero 证明，避免先猜测因子正负。覆盖变量改名、负常数、等式反向及零常数拒绝。
- 完全数值化的显式换入优先：代入映射跟随变量依赖闭包，接受 `b=4-a, a=2-sqrt(3)` 等自然链；循环映射仍拒绝。只有沿无环变量依赖能够完全数值化的关系进入早期 ground_substitution，证书逐层记录代入；普通含参数代入仍放在兜底层，避免把 M07 新变量重新展开成原变量后进行昂贵搜索。独立符号与不含它的式子不能构成无条件恒等式，避免对此启动无意义恒等归约。等式求解与已知关系传递先于一般差式符号搜索。
- 当前应用保留提交配对：M11 先验证提交推导中的候选，再考虑 Runtime 展开式。旧应用记录仍按其确切已记录候选重放，不根据新排序改写证书。

测试中只有专门针对旧 checker 节点格式的篡改用例显式生成历史证书。普通内核测试和冻结题目继续使用新搜索。阶段 C 的合成教学 bridge 测试显式保留 v1，因为它注入的是 C 阶段内部事实库，并非 v2 自动授权路径；真实 v2 教学由 E/F3 和题库页面测试覆盖。

本轮修订保持 checker 规则和限额不变：

1. 历史片段中缺少的 `given`，只有在它也是可用已验证片段的结论时才递归构造证明；不能导入为假设。导入的每个节点仍重新检查，具名 polynomial/substitution 前提仍须准确映射。缺少当前前提时拒绝，源片段和递归读取均保留依赖。
2. `nonnegative_components` 以已知弱正性及偶次幂提出组合证明，用既有 sign checker 检查，避免先猜严格正性。负系数、严格大于零和缺分母定义域的情况有拒绝测试。
3. 比例检查对零分子及相同分母先处理；前提的符号集合在正负两种比例下都有交集时，不做无法检出矛盾的代数计算。实际相反条件仍拒绝。该优化不主张一般相容性判定，M13 仍必须独立验证见证。
4. M11 最小值路径中，同一配对的模板预筛共用一个私有运算预算，只跳过次数、项数等明确的结构规模超限。该预算耗尽时结束本配对，外层可继续尝试下一配对；最大值路径及正性证明消耗调用方预算，耗尽立即上报。不退还已消耗预算，不放宽证书回放。
5. M13 取等引用先探测已知取等关系能否直接归约；能直接证明时不展开完整式的平方，否则保留平方辅助及符号验证。探测本身不授予证明权限。
