# 函数的概念 Q12：根式分母的定义域求参

## 原题与复用路径

## 数学与证据要求

记 $P(x)=mx^2-6mx+m+8$。原式同时要求 $P(x)\ge0$ 和 $\sqrt{P(x)}\ne0$，等价于 $P(x)>0$。两条原始条件分别绑定二次根式与分母知识依据，不能只留下合成条件而丢掉来源。

| 情形 | 结果与理由 |
| --- | --- |
| $m=0$ | $P(x)=8>0$，原函数为 $1/\sqrt8$，保留 $0$ |
| $m<0$ | 开口向下，不可能对所有实数严格为正 |
| $m>0$ | $\Delta=32m(m-1)<0$，得 $0<m<1$ |
| 合并 | $\{0\}\cup(0,1)=[0,1)$ |
| $m=1$ | $P(x)=(x-3)^2$，$x=3$ 时分母为零，因此不能取 $1$ |

严格性须贯穿根式条件、恒成立转化、判别式、参数区间、原式核验、端点说明及交互；禁止把根式分母误当普通根式。分子为零或可约分时仍保留原分母限制。

## 方法范围与常规分支

M6 在同一契约内支持普通根式 $\sqrt P$ 与根式分母 $N/\sqrt P$，其中 $P$ 原本为关于自变量的含参二次多项式，系数关于一个参数至多一次；$N$ 为预算内、处处有意义的多项式。零分子、负分子、含参数分子和可约形式都保留原分母限制；额外除法、根式或变量底数零次幂等隐藏限制明确拒绝。

严格分支要求 $A>0,\Delta<0$，或 $A=B=0,C>0$；普通根式保持对应的非严格条件。覆盖固定正／负首项、退化一次式、正／零／负常数、常量或恒零判别式、重根、无理端点及空集，并独立从原式核验完整参数范围。错误开闭端点和篡改严格性的证据不能通过。
