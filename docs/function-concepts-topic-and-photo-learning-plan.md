# 函数的概念：专题与拍题学同步建设计划

专题现有 Q15、Q01、Q22、Q04、Q12、Q23b、Q20 七题。T2 具体定义域与 T1 同一函数判定为受限开放；Q22 真实照片、T2 剩余目标、Q19 和独立留出题仍有验收缺口，不能将七题收录等同于整型完成。数学内容见[章节设计](function-concepts-and-representation-knowledge-graph-discussion.md)，开发要求见[共用流程](topic-and-photo-learning-development-workflow.md)。

## 1. 范围与完成口径

专题名称采用用户确认的**“函数的概念”**，归属第三章“函数的概念与性质”。**第一轮只实施 3.1“函数的概念及其表示”中已经整理的题目及相关能力**；单调性、最值、奇偶性等性质模块以后逐节补题源和设计，沿用同一流程。

现有设计包含：8 个知识点，5 类题型，14 个方法候选，5 个复用方法，1 个技能候选，14 个复用技能，以及 30 道大题。大题可包含多个目标，验收按目标与路线计数，不以 30 个页面代表所有能力完成。

| 范围 | 本轮处理 |
| --- | --- |
| K1–K8 知识内容及目录关系 | 章节启动阶段登记已审核内容，作为空专题的知识基础；练习覆盖单独标记 |
| T1–T5 题型 | 章节启动阶段登记知识关联、任务定义和可读特征，状态为待建设；具体识别、方法及执行随代表题实现 |
| M1–M14 方法候选、S3 及判断规则 | M1 已登记为 `method-domain-intersection`，M6 为 `method-domain-parameter`，M8 为 `method-function-equality`，S3 为 `skill-expression-defined`；其余候选随当前题型扩题逐步实现，不一次性实施 |

## 2. 第一轮的目标架构

开发以题型为单位推进；单题内部按“规范题意 → 结构特征 → T1–T5 判型 → 适用方法 → 技能／子方法／判断 → 完整验证 → 教学投影”执行。

- 专题题目使用预先构建、审核和版本化的课程，共用拍题学的教学运行时。
- 拍题通过原图复核后进入同一数学和教学链路，按真实进度显示。
- 专题外层保留知识介绍、知识图谱入口、题型／方法分组、题序与进度。
- 每个题型先完成一题的两种入口及交互验收，将它加入专题；再用本型剩余题扩展能力并精选入专题。登记节点、代表题通过、本型已整理题集通过及拍题支持范围分别记状态。
- 章节启动阶段专题题目数为 0，展示知识内容、题型分组和待建设状态；不会为了填满页面预先加入尚未通过的题。

## 3. 图谱与能力登记清单

### 3.1 题型与入口方法

| 题型 | 任务 | 方法候选 |
| --- | --- | --- |
| T1 | 判断是否为相同函数 | M8 同一函数判定法 |
| T2 | 具体函数定义域、定义域求参、情境建模及定义域 | M1 列条件求交集法；M6 定义域求参法；M11 几何数量关系建模法 |
| T3 | 抽象函数定义域及混合限制 | M2 自变量对应法 |
| T4 | 函数求值、复合输入、逆向输入及函数值组合 | M9 代入法；M10 配对求和法 |
| T5 | 完整值域 | M3 二次函数区间值域法；M4 方程有实根法；M5 分式分离求值域法；M7 整数平移与区间合并法；M12 换元求值域法；M13 基本函数范围传递法；M14 枚举法 |

第 9、13 题分别含定义域和值域目标。第 24(2) 是最值目标，复用已有基本不等式方法，不归为 T5 完整值域。

本表是后续开发的候选关系清单。章节启动阶段先完成知识和题型节点；方法、技能、选法／步骤判断规则在对应代表题与扩题时登记。已有公共方法和技能可直接引用其真实身份。

当前 T2 有两条可执行入口：“已给具体解析式求定义域”受限分支进入 M1；“已知定义域恰为指定集合，反求参数”进入 M6。M6 的全实数域输入族支持已准入的 $\sqrt P$ 与 $N/\sqrt P$，保留根号非负与分母非零的原始来源，再复用判别式法处理非严格／严格恒成立；半轴输入族支持 $\sqrt P/\sqrt L$，其中 $L$ 为固定非恒定仿射式、$P$ 为固定至多二次多项式加参数的一次常量偏移，题给域必须恰为 $\{L>0\}$。后一族保留三条原始条件及域外分母非法证据，再复用分离参数法与既有区间值域能力。M11 建模与 T3–T5 题型入口仍待实现。精确范围见 [T2 设计 §9.6](function-domain-problem-type-design.md#96-q12根式分母与严格恒成立)和 [§9.7](function-domain-problem-type-design.md#97-q23b半轴定义域与分离参数)；Q15 首批范围不因后续扩充而改变。

T1 的首批可执行入口现为 M8「同一函数判定法」：限一个实自变量、固定有理数系数的至多二次多项式、仿射绝对值、仿射式平方的平方根及仿射根式的平方，保留原式、显式范围与各项作用域。M8 分别复用 M1 求域，再验证全域对应关系或有效反例；只对已准入结构发布完整结果。详细边界见 [T1 设计 §2.1](function-equality-problem-type-design.md#21-第一批q20-的结构范围)，Q19 所需扩展不在本次通过范围内。

### 3.2 依赖与复用要求

- S3 只提取有意义条件及来源，M1 再组织求解和求交集；不能把求定义域全过程塞进 S3。
- M8 调用 M1 后比较对应关系；M10、M14 复用 M9。
- M3 复用完整二次区间值域能力；M12 负责换元及覆盖证明；M13 负责已知范围经过基本函数后的传递；M5 负责分式限制与输出可达性。
- M6 调用判别式法或分离参数法时，适配的是经过证明的子目标；原目标“定义域恰为 D”仍由 M6 验证。
- M11 的表达式和定义域必须经过验证，才交给第 24(2) 的最值路线。

五个正式方法引用：`quadratic-inequality-solve`、`method-rational-inequality`、`method-discriminant`、`method-separation`、`method-amgm-direct`。14 个技能的全局 ID 沿用[设计稿第 4.2 节](function-concepts-and-representation-knowledge-graph-discussion.md#42-直接复用的正式技能)，登记时核对 `kind`、能力注册和输出，不按 `method-` 前缀推断类型。

这些方法／技能已经有图谱节点，不代表当前拍题执行路径全部可调用。每个批次明确“直接可用、需扩展绑定、需补实现、暂不可用”。新增全局 ID 在实施时核对冲突并记录，保持内容条目引用一致。

## 4. 按题型逐一建设

### 4.1 主顺序

**章节启动 → T2 具体定义域 → T1 同一函数 → T3 抽象定义域 → T4 函数值 → T5 完整值域。** 开发顺序与题型编号、教材展示顺序分别管理。

**本轮排期调整：按用户指定优先实现 T1 代表题 Q20，已完成并加入专题；Q19 仍为下一扩题候选。** 具体方案见 [T1 判断是否为相同函数：开发设计](function-equality-problem-type-design.md)。T2 尚未实施的目标和 Q22 真实拍题验收缺口继续保留，当前七题收录不等于 T2 或 T1 整型完成。

T1 的 Q20 首批已打通 `abs` 提取、显示与数学验证；比较目标、选项作用域／公共基准引用、显式单点域及选择极性进入同一 IR。原题多选使用独立精确集合评分；M1 按选项上下文取证，学生侧默认 `light` 选域清单（后台证书可记 `fold`），不投影 M1 逐步卡。Q20 原照片已归档并完成本轮拍题验收；课包 **15** 确认步；Q19 与独立留出新题仍遵守原图归档后才能开启真实拍题验收的要求。

T1 教学采用“逐项判真 → 原题多选收束”：每项先 `checklist` 自选两边定义域，同域时再在同一证据卡判断对应关系是否等价，然后单独一张卡收口「相同／不同」；全部通过后才开放终答。收束前进度区只显示完成状态，终答通过后展示完整结论板；后台数学完成或 AI 回放不能代替学生逐项完成，选项也不作为互斥 `case_path` 或伪造小问。交互与结论板细则见 [T1 设计 §6](function-equality-problem-type-design.md#6-学生教学与交互设计)。

### 4.2 T2 内部扩充顺序

第 15 题的数学、交互、课程和真实拍题验收通过并加入专题后：

1. **M1 的其余情形**：先以第 1 题作为第一道扩题验收门，补零次幂及约分前限制，验证约分后仍保留 $x\ne1$ 和零次幂所需的 $x\ne-4$；数学、交互与真实拍题验收通过后，再推进 9 定义域、14、21、23(1) 等。后续补二次条件、绝对值分母和分式条件，核对各子方法的能力注册。具体依赖与断言见 [T2 设计第 9 节](function-domain-problem-type-design.md#9-实施顺序与进度)。
2. **M6 定义域求参**：4、12、22、23(2)。在本题型内复用判别式法、分离参数法及其区间值域技能，不要求先建完 T5。处理参数退化、严格性及“定义域恰为 D”的完整验证。
3. **M11 建模与关联最值问**：24(1)(2)。核实图文，补建模能力和已验证前问产物的依赖调度；复用基本不等式法。24(2) 是最值问，不归入 T5；前问通过不能标整题完成。
4. 全部完整题目和新增路径验收后，从中选取基础、易错、方法变化和综合应用题展示；其余题继续保留为能力与回归样例。

新增一条方法路径时，先从当前剩余题中选一题把新路径完整打通，再覆盖使用这条路径的其余题。题型为主组织方式，内部按方法依赖安排，不回到跨题型的全局方法排期。

### 4.3 T5 内部扩充顺序

具体批次以 [T5 开发设计](function-range-problem-type-design.md) 为准：R0 先完成第 3 题和 30(4) 的 M3；R1 扩充 5、8、11、16、30(1)(5) 的 M13／M12；R2 完成 7、9 值域、10、17、30(2) 的 M5；R3 以第 6 题建设 M4，第 7 题的 M4 备选路线单独验收；R4 完成第 13 题值域的完整覆盖传递；R5 以 30(3) 接入 M14 → M9；R6 以第 18 题完成 M7。每批只要求自身新增能力及依赖通过，不等待后续方法全部实现。

方法和技能属于公共能力，按实际契约复用；不要求重新实现 T2、T4 中已有能力。第 9、13 题的值域路线可由原题自行推导输入范围；若消费其他目标的输出，使用已验证产物和版本依赖协议。

### 4.4 能力题集与专题精选题

- 完整题源中的每个目标都进入所属题型的能力台账，记录方法、分支、技能、判断、数学／交互／拍题验收；未入选专题的题仍参与回归。
