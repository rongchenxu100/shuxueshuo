# M07 换元：阶段 5B

M07 `substitute_expressions` 接收原题极值目标、`definitions`（新符号到原变量表达式的映射）、`steps[].math`（域与条件推导）和 `expression`（换元后的完整目标）。本阶段支持单个原变量的有理系数可逆一次式和平方；不接受覆盖原符号、循环定义、跨定义或同一原变量的重复定义。不实现一般非线性方程搜索。

定义是经过域检查的保守符号扩展，不是从题设推出的等式。新符号记录在成功的 `Substitution` 事务结果中，带 Scope/原目标身份；下游通过准确 StepResultRef 显式消费，不能靠名称获得其他调用的新变量。失败事务不注册符号、不提交结果。生产默认 Family 不开放。

原始 AST 的定义域、全部提交条件、原目标与换元目标的等价关系均由证明内核验证并保存证书。声明 `u=x²` 不授权 `u>0`；非负和额外正性都须验证。代码从已识别的一次式/平方结构产生反解：一次式唯一逆，平方同时保留正负根；两个平方组合四个分支。完整原条件仍保留，不把这些反解宣称为符合原条件的全部解。

M11 增加可选 `substitution` 精确结果输入，与 expression/elimination/previous_bound 互斥，重放 M07 后才使用其符号和事实。所得界仍属于原目标；连续调用继承换元依赖。M13 重放全部依赖，要求显式给出所有原变量的取值，再按已验证定义计算新变量并验证原条件、原始分母、累计取等条件和原目标值；不搜索取值。多个见证逐个验证，不声称穷尽。

### 换元与条件消元的教学边界（2026-09-26）

M07 只负责定义替换与恒等整理；目标等式在仅有换元定义和已验证定义域的上下文中核对，不能借题设等式消去新变量。需要条件消元时，Planner 显式调用 M08，并以准确 StepResultRef 绑定 M07 的 substitution 输出和同一原目标。M08 重放换元证据后校验新变量下的消元，输出保留完整换元依赖；M11 消费 elimination，M13 沿依赖还原并验证原变量。

q12 的实际执行链为 M07 → M08 → M11 → M13；M07 的“整体换元”止于条件 `5uv+v²=1` 和目标 `u+v`，M08 独立产生“条件消元”步骤。图中先突出 `u=(1-v²)/(5v)`，再对照 `u+v → (1/v+4v)/5`；定义域及计算细节留在正文。删除此前 M07 内部的教学拆分逻辑，不再由展示层推断额外 Method。q25 无需消元，仍为 M07 → M11 → M13、五个学生步骤。完整分母与平方继续共用表达式到新变量的形状映射。

### 契约补强与最终验收（2026-09-27）

2026-09-27 契约补强：M08 的还原公式右侧只能包含剩余的新变量；未提供换元依赖时，只能包含原目标中的剩余变量。换元定义（如 `p=r²`）不能冒充消元结果。M07 生成完整证据后，在返回、提交事务之前以独立预算重放域证书和关系证书，重放失败由 M07 当场拒绝。学生投影中的换元定义与目标统一经过数学显示格式化，兼容内核的 `^` 幂记法。

幂记法由通用数学显示函数统一处理：仅完整的平方、立方转换为上标，其他 `**` 幂转为 `^` 保留；换元调用处不再改写幂运算符，避免 `u^10`、负指数或变量指数失去乘方含义。
