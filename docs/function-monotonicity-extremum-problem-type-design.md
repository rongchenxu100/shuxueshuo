## 1. 题型身份、方法与建设范围

公共题型沿用 `type-monotonicity-extremum`，学生名称为“利用单调性求最值”，属于 `function-monotonicity` 专题。现有节点仍为 `planned`；本次只细化设计，不激活节点。

### 1.1 按原目标区分任务

| 任务 | 需要完成什么 | 不能替代成什么 |
| --- | --- | --- |
| 直接求最值 | 在准确的输入范围上，给出最大／最小值及取得位置，或说明所求最值不存在 | 只给单调区间，或把上、下界直接叫作最值 |
| 量词比较求参 | 保留“任意谁、存在谁、各自范围、比较关系”，求使命题成立的完整参数集合 | 把两个变量当成同一个变量；把值域包含只改成两个最值比较 |
| 指定点是最值点 | 验证指定点合法，以该点实际函数值为界，检查全域条件并求参数 | 从端点取得最值反推整个函数单调；额外要求最值点唯一 |
| 递推与前缀区间 | 用递推关系控制整个 $(-\infty,m]$，求最大允许的 $m$ | 只检验 $f(m)$；把倍增关系当成周期关系 |

B08、B14 虽然要求参数，条件是“某点的值为最值”，仍归 T2。T4 的输入则是“函数在某区间单调”。B15 研究递推后的全区间下界，不归入 T5 的抽象函数单调性证明。

### 1.2 三种方法及职责

M 编号沿用专题总计划，不在 T2 内重新编号。

| 编号／候选公共 ID | 学生名称 | 输入 → 输出 | 组织的主要子能力 |
| --- | --- | --- | --- |
| M4／`method-monotonicity-extremum` | 单调性求最值法 | 函数、有效输入范围、所求方向 → 最值及取得证据，或不存在及边界依据 | 定义域；T1 单调性；一次／二次／对勾范围；求值和候选比较 |
| M7／`method-quantified-range-comparison` | 量词比较求参法 | 两个独立变量的有序量词、范围、关系及原参数限制 → 像集关系或最值条件 → 参数集合 | 既有量词转换技能；M4 或完整值域方法；参数不等式 |
| M8／`method-extremum-condition-parameter` | 指定最值求参法 | 原函数、指定点及最大／最小条件 → 各段恒成立子问题 → 参数集合 | 原分段式求值；区间最值／分离参数等公共方法；对勾或基本不等式 |

M4 与已有 `method-interval-extremum` 不重复：后者面向一个量词的恒成立／存在求参，M4 面向原函数的最值，并负责组织单调性证据。M7、M8 遇到适用的单量词子问题时借用前者，不复制它的流程。

**C1“递推分区间最值”先作为拓展组合路线。** 完成倍增递推、负向延拓与无穷区间覆盖合同后再决定是否登记独立方法；不因 B15 单独一题先增加公共方法空壳。

### 1.3 分批准入

| 批次 | 题目／主线 | 明确支持的结构 | 开放前必须补齐 |
| --- | --- | --- | --- |
| R0 基础 | A16 → A14；M4 | 固定有理系数的二次／一次式；可分离的线性分式；二次式与仿射根式之和，且各项在同一有效区间上的方向足以确定和的方向 | 运算技能、M4 最值收束、取得性、直接最值答案协议 |
| R1 量词基础 | A07 → A18 → B16；M7 | 两层独立的 $\forall\exists$；等号对应认证区间像集包含；严格／非严格比较对应两侧实际存在的最值；固定区间，参数限制已确定相关斜率方向 | 嵌套量词绑定；A18 的 $Ax^3+C$ 段证据；分段候选汇总 |
| R2 量词分类 | B11 → B10；M7 | 含参一次函数正／负／零分类；一端随参数移动的闭区间上固定二次函数的最值 | 参数分支覆盖、非空域、端点竞争、精确二次无理数参数边界 |
| R3 指定最值 | B08 → B14；M8 | 两段函数、固定分界；含参顶点位置与指定点最值条件；另一段为一次式或正半轴对勾式 | 全域恒成立、顶点域内／域外分支、未取得边界、参数必要性与充分性 |
| R4 递推拓展 | B15；C1 | 正向倍增递推与一个基准区间上的二次式；本题的负向无限延拓和前缀下界 | 整数块覆盖、首个失效位置、前缀验证、递推源语义 |

R0 复用 T1 的有理端点、无穷端点与表达式预算，新增结构单独声明预算。线性分式必须保留原分母禁取点；分离后的余项为零时按常值处理，不能消除原孔点。系数允许取零的运算，须在本批覆盖常值和退化分支。

R1 不声称支持任意嵌套量词、相互依赖的量词域或任意三次多项式。R2 需要的 $2+\sqrt7$ 等是**精确参数边界**，不等于已开放 T1 任意无理输入端点。R3 按上述表达式族完成全部参数分支，不以某道题的正确答案反推准入条件。

一般两个非常数函数的乘积、一般商、任意高次多项式、三角／指数／对数最值均不纳入本批。规则不足时保留“当前依据不能判断”，不据此断言函数不单调，也不返回一个未验证的最值。

### 2.2 基础代表题 A14、A16

**A14：和的方向先证清楚，再选最值点。**

1. 原式要求 $1-2x\ge0$，所以 $D=(-\infty,\frac12]$。
2. $\sqrt{1-2x}$ 在 $D$ 上严格递减。
3. 学生将二次项配成 $2(x-\frac54)^2+\frac{15}8$。对称轴 $x=\frac54$ 在 $D$ 右侧，二次式在整个 $D$ 上严格递减。
4. 两项在**同一区间、同一个自变量**上都递减，因此原函数递减。
5. 右端点 $\frac12$ 在定义域内，故最小值为 $f(\frac12)=0+\frac12-\frac52+5=3$。

这里只问最小值，不要求学生再求完整值域或最大值。独立核验可用：当 $x\le\frac12$ 时，$\sqrt{1-2x}\ge0$，且 $2x^2-5x+2=(2x-1)(x-2)\ge0$，故 $f(x)\ge3$；等号由 $x=\frac12$ 取得。

**A16：分式分离是已有技能，运算判断不另建一套求值域流程。**

$[-2,2]$ 上 $x+3\in[1,5]$，原式有意义；分离为 $2-5/(x+3)$。输入增加时，$x+3$ 增加，取倒数后递减，乘 $-5$ 后递增，再加 $2$ 保持递增。所以最大值在 $x=2$ 取得，等于 $1$。

已有 `method-fraction-split-range` 可作为完整备选路线，得到 $[-3,1]$ 后取最大值；仅在该路线的最值答案接线也通过时开放。主路线不先做一遍单调性、再强制重做完整值域。原式独立检查可用 $1-f(x)=(2-x)/(x+3)\ge0$，等号在 $x=2$ 成立。

### 2.3 量词路线的关键金标

| 题目 | 参数条件的推导 |
| --- | --- |
| A07 | $G=[1-a,1+a]$、$F=[-1,3]$；$G\subseteq F$ 等价于 $1-a\ge-1$、$1+a\le3$，再与 $a>0$ 求交 |
| A18 | 左段 $[-1,0)$ 的像集为 $(2,3]$，右段 $[0,1]$ 为 $[2,3]$。两侧实际最大值比较：$3\le5-k$，与 $k>0$ 合并。$0$ 处向上跳跃，不要求整个 $f$ 递减 |
| B10 | $f([-2,-1])=[-\frac32,0]$。$a\ge1$ 时，$\max g=\max\{-6,a^2-4a-3\}$；$1\le a\le3$ 时为 $-6$，$a>3$ 时为后者。要求严格大于 $0$，得 $a>2+\sqrt7$ |
| B11 | $F=[-1,3]$。$a>0$ 时 $G=[-a-1,2a-1]$，包含给出 $a\ge2$；$a<0$ 时 $G=[2a-1,-a-1]$，给出 $a\le-4$；$a=0$ 时 $G=\{-1\}$，不能覆盖 $F$ |
| B16 | $m<0$，故 $\max_{x_1\in[1,3]}(mx_1+1)=m+1$；二次式在 $x_2=3$ 取最大值 $0$。严格关系要求 $m+1<0$；$m=-1$ 时 $x_1=1$ 找不到严格更大的见证 |

B10 的端点竞争分界是 $a=3$，由 $g(a)-g(1)=(a-1)(a-3)$ 得到；不能只讨论顶点 $2$ 在不在区间中，就断言最大值一定是 $g(a)$。

### 2.4 指定最值与递推拓展

**B08：** $f(0)=a^2$。左段若 $a<0$，顶点 $x=a$ 合法且函数值 $0<a^2$，立即排除；若 $a\ge0$，左段最小值就是 $a^2$。右段在 $x=1$ 取最小值 $a+2$，要求 $a+2\ge a^2$，得 $-1\le a\le2$。合并为 $[0,2]$。$a=2$ 时 $x=0,1$ 都取到最小值，仍符合原题。

**B14：** 指定点使用右段，$f(1)=\frac12$；右段全部不超过它。左段分两类：

- $a<1$：顶点 $x=a$ 合法，最大值为 $a+\frac52$，要求它不超过 $\frac12$，得 $a\le-2$。
- $a\ge1$：左段在 $x<1$ 上递增，只有上界 $-(1-a)^2+a+\frac52$，不在左段取得。要求该上界 $\le\frac12$，得 $a\ge\frac{3+\sqrt{13}}2$。正边界应保留：左段各值仍小于 $\frac12$，而右段的 $x=1$ 真正取得全局最大值。

**B15：** 唯一写成 $x=t+2n$，$t\in(0,2]$，$n\in\mathbb Z$，得到 $f(x)=2^n t(t-2)$。基准式在 $t=1$ 取得最小值 $-1$，在合法端点 $t=2$ 取得最大值 $0$。所有 $n\le1$ 的块覆盖 $(-\infty,4]$，各块最小值 $-2^n\ge-2>-3$。在下一块 $(4,6]$，$f(x)=4(x-4)(x-6)$；从左到右首次达到 $-3$ 的位置为 $x=\frac92$，其后紧邻区间内出现小于 $-3$ 的值。因此完整可行集为 $m\le\frac92$，题目所求最大值是 $\frac92$。虽然 $f(6)=0$，$m=6$ 仍不合格，因为前缀包含 $f(5)=-4$。

### 4.1 保存原任务，不在识别阶段代解

| 任务 | 沿用／扩展原则 | 必须保存的来源 |
| --- | --- | --- |
| A14、A16 | 沿用具体函数 `find_range` 搭配 `answer_request: {kind: extremum, quantity: minimum/maximum}` 的公共请求；兼容既有最值表达式目标，不另造同义目标 | 原函数定义、所求最小／最大、题给输入限制及原式有意义条件 |
| A07 等五题 | 保留求参数集合的原目标；扩展嵌套量词的特征、匹配、执行绑定，不把父目标改成“求某函数值域” | 按顺序绑定的两个量词、各自变量与域、函数调用输入、关系符号、原参数限制 |
| B08、B14 | 指定最值作为已知条件，求参作为目标；优先沿用既有最值事实语义，缺少的结构在 S2 统一补合同 | 指定点、最大／最小类型、全定义域、分段条件及该点归属 |
| B15 | 保留递推关系、基准区间、全称前缀条件与“求 $m$ 的最大值” | $f(x+2)=2f(x)$ 的两个作用位置、$(0,2]$ 的开闭、$(-\infty,m]$、$\ge-3$ |

原式自然域、明确声明的完整定义域、目标研究的子区间按既有语义区分。若“完整定义域”与原式冲突，应报冲突，不能悄悄求交后继续。函数名和变量名均从题源绑定；换元用不冲突的新名字，不固定成 $f,x,u,v$。

嵌套量词不能压成一个 `quantifier` 字段，也不能把绑定变量变成自由参数。A07 中全称变量属于 $g$，B11 中属于 $f$；由此决定包含方向。B16 可以等价改写比较两边，但变量角色和严格性必须随之保留。参数区间为空时，存在量词没有见证；B10 的 $a\ge1$ 是必查条件。

题意身份与复核同时覆盖这些区别，尤其是根号范围、$<$／$\le$、$x<1$／$x\le1$、原题有无 $a>0$。新增语义同步进入提取、复核、修复共用规则及冻结记录；不能只改 prompt 或只在求解阶段猜回缺失条件。

### 4.2 三种产物分别建模

| 产物 | 最少包含的语义 | 不允许的替换 |
| --- | --- | --- |
| 单调性证据 | 原表达式、变量、准确区间、增减方向及严格性、常值状态、各输入前提、使用的规则和验证来源 | 一个没有域或来源的方向箭头 |
| 最值／边界证据 | 求最大还是最小；值或无界；是否取得；取得点及其原域证明；候选覆盖和全域界证明 | 只有某个端点代入值；用浮点图像最高点作证 |
| 完整像集证据 | 精确集合及空隙、开闭、每个边界的可达性、完整覆盖依据 | 只有最小值和最大值，或把不连通像集填成区间 |

M4 原则上只返回目标需要的最值证据；等号量词的 M7 必须索取完整像集。一个实际取到的点足以证明最值存在；若输出声称“全部取得点”，则必须证明点集完整。常值分支可能整段都取得，不能硬列成两个端点。

不同输入位置给出同一边界值时，只要其中一个合法位置取得，该边界就可达。例如 B15 的 $t(t-2)$ 在 $(0,2]$ 上，虽然 $t=0$ 被排除，$t=2$ 仍使 $0$ 取得。端点取得性由原域与见证核验，不只转抄符号库给出的区间括号。

### 4.3 原题独立验证

1. **M4：** 从原式和原域检查全域 $f(x)\le M$ 或 $f(x)\ge m$，并代入合法见证点。未取得的边界应有可逼近依据；无界与有限但未取得分别返回。局部候选不足以证明全局完成。
2. **M7：** 从原量词重新绑定角色，核对包含／比较等价关系、每侧证据与最终参数集合；分别证明集合内充分成立与集合外不能成立。两函数在同一参数分支下计算，不能混用不同参数类别的范围。
3. **M8：** 先从原分段式取得 $f(c)$，验证 $c$ 合法，再验证所有分支的全域不等式；所有参数分类互斥且覆盖，最终与题设限制求交。
4. **C1：** 验证递推的整数延拓、基准块唯一归属、左侧所有块的统一界，以及越过候选 $m$ 后必有一个反例输入。有限采样或验证 $f(m)$ 不能完成。

独立验证不能只重复调用同一个求解函数比较答案。符号化简、原式代入、定义／因式分解证据和参数条件可按合同交叉核验；未知返回能力缺口。图像负责解释，不能代替这些证明。

## 5. 三种方法及拓展路线的执行设计

### 5.1 M4 单调性求最值法

**主问题：研究哪一段 → 这段怎样增减 → 最值可能在哪里 → 能否取到 → 最终是多少。**

调用关系固定为：**M4 组织整题**；基本函数／复合层走 T1 **M2**；和／差／乘常数／加常数／倒数走 **`skill-monotonicity-operations`（运算增减性判断）**，可由 M2 或 M4 直接调用。不把和差运算塞进 M2 的表达式族，也不为运算另建第二套方法。

| 步骤 | 执行与复用 | 学生需要判断什么 |
| --- | --- | --- |
| 确定有效范围 | 调用或复核定义域子方法；保留根号零端点、分母禁取值、原分段边界 | A14 判断 $x\le\frac12$；A16 的合法闭区间可直接展示 |
| 建立增减依据 | 各项／各层复用 T1 M2；和差与常数倍／倒数调用运算技能；二次先配方，分式先分离 | 说明各项在当前区间的方向、所用运算为什么保持／改变方向 |
| 找候选位置 | 根据认证的方向、原分界、内点转折与端点取舍组织候选 | 增函数向右取较大值、减函数向右取较小值；右端是否存在且包含 |
| 求值并汇总 | 借用求值、一次／二次／对勾区间技能；多段分别求所需界再比较 | 选择真正控制全局最值的候选；相等候选保留取得信息 |
| 回验原目标 | 原式界证明＋取等见证；最值不存在时保留界信息 | 写出最值和取得点，而不是只给箭头或区间 |

A18 分段最大值可逐段取得后汇总，不需要先证明整函数单调，也不应强制调用“跨段单调性检查”。只有当前路线确实要合并为一个单调区间时，才调用 T1 的跨段技能。

开放区间、无穷端点、孤立合法点分别处理。最值点不在域内时不得借闭端点值充数；孤立点可以成为最值点，但不是一个严格增减区间。输入为空与“非空域上没有最大值”是不同结果。

### 5.2 M7 量词比较求参法

**主问题：由图像读出两边值域（或所需最值）→ 讨论覆盖／比较 → 参数条件是什么。**

内部可将全称一侧记为 $U=F(D_{\forall})$、存在一侧记为 $V=G(D_{\exists})$；**学生可见文案不用「像集」，优先用当前题的函数名与「值域」**，禁止用「左边／右边」指代两个函数。不单独开「分清随便取／配合」交互卡；不在交互卡上追问端点／转折点候选。两域非空，函数在各自域上有定义。

| 原命题 | 可用的等价条件 | 前提 |
| --- | --- | --- |
| $\forall u\in U,\exists v\in V:u=v$ | $U\subseteq V$（学生侧：$F$ 的值域 $\subseteq$ $G$ 的值域） | 完整值域，不允许用区间包络代替 |
| $\forall u\in U,\exists v\in V:u\le v$ | $\max U\le\max V$ | 两侧最大值都存在且取得 |
| $\forall u\in U,\exists v\in V:u<v$ | $\max U<\max V$ | 两侧最大值都存在且取得 |
| $\forall u\in U,\exists v\in V:u\ge v$／$u>v$ | $\min U\ge\min V$／$\min U>\min V$ | 两侧最小值都存在且取得 |

最后两类比较通过交换序向复用，不能把 $>$ 照抄进最大值公式。等号的包含方向始终由量词角色确定。$x_2$ 可以依赖 $x_1$；某题能给一个统一见证，不代表可以普遍交换原量词顺序。

执行顺序：

1. 后台绑定两个域与有序量词，保留原参数条件（学生侧不单独做角色卡）。题面未命名时呈现层引入 \(g/f\) 等别名（见[交互步骤卡片设计规范](interactive-step-card-design-spec.md) §9）。
2. 由图像读出两边值域或所需最值。**等号**：直接读值域（二次先「配成顶点式」，只保留代数不挂函数图；读值域卡再给 ↑／↓ 图；参数影响斜率／顶点时先分类再汇总）。**不等号**：非空域（如需）后先出一张简洁化归卡，把原命题选成 \(\max/\min\) 比较，再读所需最值（不先求完整值域）。**禁止**再出「检查最值候选／边界与转折点」交互卡。
3. 两边结果出来后讨论覆盖／比较（问法绑函数名；已知栏用值域或分情况汇总，不复述函数式）。单分支建立条件时可挂约 2 条值域数轴；多分支求参不重复挂轴。
4. **求参阶段不再计算值域**。单分支：建立参数条件 → 解参数条件。多分支：每支一卡，选项为「判断 \(\Rightarrow\) 参数集」，已知栏不剧透判断／不等式。
5. 分支结果取并集，再与原参数限制求交，回验原量词。

卡片版式、小问锚点、完成图与选项去重等 UX 细则以[交互步骤卡片设计规范](interactive-step-card-design-spec.md) §9 为准。

R1–R2 的不等号快路径要求相关最值确实存在。没有最值时，只有实现并核验完整像集／取得性政策才继续；否则明确不准入，不能机械地把 `max` 换成 `sup`。例如 $U=[0,1),V=[0,1]$ 时“任意 $u$ 存在 $v>u$”成立，尽管上界相等；$U=[0,1],V=[0,1)$ 时“任意 $u$ 存在 $v\ge u$”不成立。

等号路径首批以认证的区间／单点像集为准；推广到并集时须真正计算集合包含。例如 $U=\{0,1,2\}$、$V=\{0,2\}$ 的最小和最大值相同，但覆盖不成立。范围外输入不能落入端点比较的快捷路径。

### 5.3 M8 指定最值求参法

**主问题：指定值是多少 → 它是最大／最小意味着什么 → 每一段要满足什么 → 哪些参数同时合格。**

1. 核对指定输入 $c$ 在原定义域内，按真正包含它的分支计算 $f(c)$。这是已知条件的具体化，不把整段边界都改成闭端点。
2. 若 $f(c)$ 是最大值，建立 $\forall x\in D,f(x)\le f(c)$；最小值建立 $\ge$。取等见证由合法点 $c$ 提供，之后仍检查全域界。
3. 按原分段条件划分子问题；各段都是恒成立，所求参数必须**同时**满足。段内涉及参数的分类结果则取并集，两层集合操作不能混淆。
4. 逐段复用共享恒成立子问题入口（`quantified_subproblem`：判断转化＋plane 选法），再 `submethod` 展开所选方法（`presentation: expanded`）。能分离时优先分离参数（B08 两段皆然；二次残差在端点残差恒为 $0$ 时可放开端点以保证除数变号）；不能分离的二次段仍借区间最值。父方法只收回各段 $a$ 再求交，**不自建选法／求参平行卡**，也不用「左／右侧」称谓。细则见[交互步骤卡片设计规范](interactive-step-card-design-spec.md) §9.5「调用子方法时要注意什么」。若使用基本不等式，验证正数条件与取等点，不能只写一个未必能达到的下界。
5. 汇总参数集合，检验分支交界、答案端点、原指定点与可能的其他取等点，完成原目标。

B08 两段正路均为分离参数：左段二次残差在放开 $x=0$ 后分离；右段对勾式走同一子方法。选法坐标对分式认格时，可在内部清恒正分母，学生板书仍可用原式。已有基本不等式可作为适用备选，不要求学生连续完成两条证明。

B14 顶点在域内与不在域内的分界是 $a=1$。上界没在左段取得，不妨碍它等于指定最大值；原题没有“唯一最大值点”或“严格大于其他值”的要求。M8 不调用 M3 来强制证明整个分段函数单调；左段若不能分离则借区间最值，仍先走共享恒成立入口。右段一次式不含 $a$，标为无参段：不套恒成立求参入口，一步快速验证即可，成立则该段贡献 $\mathbb R$。

### 5.4 C1 递推分区间最值

拓展按“基准块 → 整数延拓 → 左侧统一界 → 首个失效块 → 前缀目标”组织。已有配方、二次区间最值、参数条件求解与精确集合运算继续复用；新增的是块覆盖与递推证明。

首个设计对象只要求处理 B15 所属的正倍数递推结构；一般负倍数、零倍数、任意函数方程及无依据的周期化均不开放。正式实现前须确定可泛化的正步长、正倍数和基准二次式合同，至少以不同步长／倍数／阈值的留出样例核验，不写死“第 3 块”或 $9/2$。

本题有无穷多个左侧块，不能用循环枚举到某个负数当作覆盖完成。复用有限平移组件只负责可显示的相邻几块；后台必须有针对所有 $n\le1$ 的统一证明。界面不要求学生逐块点击。

## 6. 新增技能、知识引用与选法判断

### 6.1 唯一新增公共技能：运算增减性判断

候选 ID：`skill-monotonicity-operations`；学生名称 **运算增减性判断**（与 T1「复合增减性判断」对称）。

**它解决的问题：** 已经知道各部分在当前区间怎样变化，经过加减、取倒数、乘常数或加常数之后，整个式子怎样变化。它与「复合增减性判断」共用基础证据，但负责显式运算组合，不负责求最值或组织整道题。

**输入：** 同一自变量、同一区间上各输入函数的方向及严格性、原域和必要符号证据、指定运算。**输出：** 输出表达式的方向和规则依据，或“仅凭这些条件不能判断”；不自行改动输入区间。

| 运算 | 首批规则和必要前提 | 本型使用 |
| --- | --- | --- |
| 和 | 各项均非减（或均非增），且至少一项严格，才能据此保证和严格递增（或递减）；仅有非严格证据时保留非严格性，全常值则返回常值 | A14：两项同为严格递减 |
| 差 | 化为加相反函数；一增一减作差可判向，同增／同减的差仅凭方向一般不能判定 | B10：$x$ 增、$1/x$ 在负半轴减，故 $x-1/x$ 增 |
| 乘常数、加常数 | 正常数倍同向，负常数倍反向，零倍为常值；加常数不改方向。原式有意义条件继续保留 | A16：倒数后乘 $-5$ 再加 $2$ |
| 倒数／常数除以函数 | 输入范围必须在同一非零符号侧；正、负两侧分别反序。常数分子再按符号处理 | A16 的正输入；B10 的负输入 |
| 两个非常数函数的乘积、一般商 | 当前题源不要求，首批不开放；将来须补符号、零点和方向合同，不能套“同增就增” | 暂无必需题；A16 先分离，不能算作已实现一般商规则 |

反例必须可解释：“只知道两项递增”不足以判断它们的差；“一增一减相加”不足以判断 $x+1/x$。后者在 B08 应用对勾技能或基本不等式，不让运算技能猜一个全局方向。

倒数若已由 `skill-composite-monotonicity` 完成一次有前提的传递，新技能引用该结果，不再要求学生重复答一次。开方继续复用复合技能；A14 的新学习点是“两个递减函数相加”。

| --- | --- | --- |
| 给出函数，求最大值或最小值 | 根据同一区间内的增减，选择最值位置，再检查能否取到 | M4；适用且已验收的完整值域路线可作为备选 |
| 一边随便取，另一边都能配上 | 题面常见「对任意 $x_1$，存在 $x_2$，使 $f(x_1)\le g(x_2)$」。先分清谁随便取、谁负责配合，再比较两边取值范围（或最值），求参数 | M7 |
| 指定某一点已经是最大或最小 | 例如 $f(0)$ 是最小值：先算出这个值，再要求定义域里其他点都不比它更小；最大值则其他点都不比它更大。不必要求只在这一点取到 | M8 |

进入子问题继续复用 `rule-function-monotonicity-method`、`rule-function-range-method`、`rule-interval-skill` 以及适用的恒成立选法。只显示数学适用的选项；未展开的有效备选说明状态、不判错。A16 不为凑选项强制提供定义法。

### 7.2 子方法默认密度与调用约定

所有子调用仍完整执行和验证；`fold/light/full`／`expanded` 控制学生侧展开程度。**调用子方法的目的是复用其卡片与流程**，不是在父方法里复制一套平行教学。

| 父方法／借用能力 | 默认档 | 升级到完整步骤的条件 |
| --- | --- | --- |
| M4 的平凡域或已验证题给域 | `fold` | 原域冲突、分母孔点或端点易误判时改为 `light/full` |
| M4 的根式／分母定义域 | `light` | 学生判断错误或本题以域判断为主要难点时，展开已有定义域子方法 |
| M4 的二次配方、方向与新增运算 | `full`（代表课） | 后续同类题可 `light`，但保留顶点式、区间与方向依据；不再用含糊的“判断基本函数”作标题 |
| M7 的一次、二次范围或 M4 | `light` | 参数改变顶点／端点、分段跳跃等关键情况展开；简单端点代入只读，不把两边都嵌套成完整 T1 教程 |
| M7 的量词翻译、包含方向、严格性 | 主线交互 | 不能折叠掉本题真正学习的量词判断 |
| M8 的指定点求值 | `light` | 分界点归属错误时展开已有分段求值流程 |
| M8 的恒成立子问题 | 共享入口 + `expanded` 子方法 | 判断转化＋plane 必出；子方法步骤走原方法卡片；父侧不重复求参 |
| C1 的各块二次求值 | `light/fold` | 基准块配方可完整展开一次，后续块复用认证结果 |

调用约定（M8 及同类宿主）：

1. **入口单一**：恒成立子问题一律 `quantified_subproblem`（判断转化 → plane），与定义域求参、分段值域求参合同一致；禁止宿主自建「选择解法」choice。
2. **展开真方法**：plane 选定后 `submethod` 调 `method-separation`／`method-interval-extremum` 等，`presentation: expanded`，学生看到的是子方法自己的移项、分离、值域、求参卡。
3. **父侧只收束**：子方法返回参数集合后，父侧取交／回到原题；不再出「第 N 段：求参」或把顶点分类插在子方法前当主线。
4. **命名用数学对象**：`subproblem_context` 与标题写表达式和定义域，不写「左／右／第几段」。
5. **嵌套可重复交互**：子方法帧继承宿主 `case_path`，多段各自的 plane／子步骤不因 `repeat: first` 变成只读。
6. **选法认格**：对勾等分式在 plane 认格时可内部清恒号分母；展示语句仍可用原关系。分离除数在闭端点为 0 但残差恒成立时，可放开该端点再借分离。

作答记录与图谱高亮绑定真实父子步骤和所选路线；子方法改教学合同后，所有调用方重建课包即同步，不在宿主里抄步骤。

### 7.3 视觉与防泄露约定

与 [T1 §7.3](function-monotonicity-problem-type-design.md) 同一套方向语义，不另造箭头组件。

- **方向箭头：** 严格递增用 ↑，严格递减用 ↓，常值用水平标记；箭头绑定具体函数与区间。文字“增／减”可并存，但不能只有文字、没有方向图形。选法卡、结论行、数轴分区和完成态回放共用同一套语义。
- 沿用 T1 的图形组件：当前研究区间着色，边界／对称轴画分割线，图下标区间；未确认前不提前涂答案区间或点亮合成箭头。无穷端不得画成可取的实心终点。
- 二次先让学生配成顶点式，再按该证据显示对称轴和顶点。标题明确为“判断二次函数的增减”“比较二次函数在区间两端的值”。
- **运算链必须逐步可视化：** “输入函数及当前区间 → 操作名＋公式 → 输出方向”，如“取倒数：$v=1/u$”。当前待答方向为 `?`，已确认方向保留；A16 按层展开，禁止口诀卡一次给出整条链。加法／减法展示两个输入箭头**汇合**到结果（`↓ + ↓ ⇒ ?`），不能误画成函数复合的内外层。
- 在学生选择最值位置前，只显示区间、候选点及已知方向；确认后再标最值与取等点。值域数轴的包含关系、参数答案也按步骤解锁。
- 分段函数图像只画对应分支的合法范围，单侧逼近值和分界点原值分别处理。B14 的参数分类用对应分支的示意，不靠拖动参数采样判断答案。
- 复用现有数学排版和稳定布局；公式渲染、学习记录保存、尺寸观察不能反复重建卡片引起抖动。专题与拍题使用同一投影，不维护两套图。

## 9. 必要验证矩阵与验收口径

本次只写设计，不运行产品回归。实施时对新增合同、边界和受影响共用能力做必要单元测试；首次能力开放再按既有纳题流程完成实拍与交互验收，不要求每个文案变更跑全仓或重复调用模型。

| 维度 | 最少覆盖 | 必须拦住的错误 |
| --- | --- | --- |
| 原题主路径 | §2 的 10 题逐批入账；A16 备选路线单独记录 | 开发题通过就宣称同型所有题通过；漏掉拓展仍报全完成 |
| 运算与符号 | 同向和、差、正负零倍数、正／负侧倒数；跨零拒绝；方向不足返回未知 | $x+1/x$ 被判全域同向；把负半轴倒数判成增函数；约分删除原孔点 |
| 最值与原域 | 闭／开端点、无穷端、常值开区间、单点、断域、分段跳跃 | 非法点取等；有下界却说有最小值；A18 被迫整体递减 |
| 同值多个位置 | $t(t-2)$ 在 $(0,2]$ 的值域为 $[-1,0]$；A18 在 $-1,0$ 都达到 $3$ | 一个开端点覆盖另一个合法见证的取得标记 |
| 量词与包含 | A07／B11 的相反函数角色；B16 交换书写两边；改名但保留绑定；像集有空隙的反例 | 固定包含方向、变量合并、交换量词或只比最值就认定集合包含 |
| 严格性和非空域 | B10 的 $a=1$ 与 $a=2+\sqrt7$；B16 的 $m=-1$；无最值的两组像集反例 | 存在域为空仍成立；严格关系放入等号；未达上界被当最大值 |
| 参数分类 | B11 的正／负／零；B10 的 $a=1,2,3$ 及相邻段；B08 的 $a=0,2$；B14 的 $a=1,-2,\frac{3+\sqrt{13}}2$ | 漏负参数、漏退化、只比顶点不比端点、误要求最值唯一 |
| 指定点与开边界 | B14 的 $f(1)$ 必须取右段；正参数答案边界保留 | 将左段补成闭区间、上界未取得就排除参数等号 |
| 递推前缀 | B15 的负整数块、块连接点、$m=\frac92$、紧邻右侧与 $m=6$ | 有限枚举替代无穷覆盖，只查 $f(m)$，把递推倍率误作周期 |
| 验证器反证 | 主动篡改取得标记、量词角色、候选覆盖、参数端点 | 求解与验证共用同一错误结果仍自报通过 |
| 方向／运算可视化 | A14 汇合卡、A16 逐步链、M4／M7 完成态均带 ↑／↓；运算卡待答位为 `?` | 仅有文字口诀无箭头链路；未作答前点亮合成箭头或最值点；把和式画成复合层 |
| 共同教学与兼容 | 核心作答与回放、父子返回、图形开闭；受影响 T1／值域／恒成立调用 | 答案正确但必答卡无法完成；新改动破坏旧题评分或无图拍题流程 |

留出题不复用以上 10 道作为“新题”：M4 改系数、符号和开闭；M7 至少包含方向改写、斜率零和不存在见证；M8 改指定点与分界归属；C1 改递推步长／倍数／阈值。另补独立照片来评价真实提取，排版截图和注入规范题意只算离线验证。

拍题台账分别记录提取、复核、判型、求解、验证、教学生成及耗时，明确是否真实模型调用。仍把带配图题目处理慢作为已有问题记录，不因 T2 数学或静态页验收通过而声称它已解决。
