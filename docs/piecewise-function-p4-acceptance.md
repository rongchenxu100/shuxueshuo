## 数学与交互

两题直接展示“分段值域求参法”，不恢复 J1 统一选法表。先求不含参数一段的值域，再用对齐的输出数轴比较已得值域与题目目标。数轴变量明确为 y，参数答案在作答前隐藏；完成态保留数学条件，“补齐”路线增加缺值数轴。

- **变式1：不越界。** 固定段 `x²−2 (x≤1)` 已有值域 `[-2,+∞)`。将另一段条件转为对所有 x>1 成立的 `ax²−x+2≥−2`，分离得 `a≥(x−4)/x²`；令 `t=1/x∈(0,1)`，配方为 `−4(t−1/8)²+1/16`。最大值在 x=8 取得，故 `a≥1/16`。端点代回原含参段为 `(x−8)²/16−2≥−2`。
- **变式2：补齐。** 固定段 `x+1 (x>1)` 的值域为 `(2,+∞)`，缺少 `(−∞,2]`。先检查 a=0，再讨论开口；a≤0 中仅 a<0 可行。顶点 `1/a<0<1` 在原段域内，含参段的完整值域为 `(−∞,−1/a]`，接上固定段需 `−1/a≥2`。结合 a<0 得 `−1/2≤a<0`；a=−1/2 时在 x=−2 取得2，a=0 时整体值域仅为 `[-2,+∞)`。

每个动作单独成卡，展示当前公式、输入域或参数条件；“完整推导”是代入、配方、不等式变形和集合关系，非操作说明。两题分别11步、11步回放（包含题型与直接方法卡；第一题还含原选项匹配）。公式渲染检查覆盖卡片、选项、推导和输出数轴标签。
