## 1. 题型身份、方法与建设范围

### 1.1 任务边界

沿用公共题型 `type-monotonicity-parameter`，学生名称“已知函数的单调性求参”，专题为 `function-monotonicity`。节点已激活，8 道静态课共用本方法执行与交互合同。

典型任务：给出含参数的函数 $f_a$，要求它在指定区间 $I$ 上严格递增或严格递减，求参数的全部取值。核心问题是：**每一段怎样增减，跨过分界点后次序是否仍成立，以及整个指定区间是否都有定义。**

| 容易混淆的任务 | 本型的判断 |
| --- | --- |
| 已知单调性，求函数系数中的 $a$ | 属于 T4，例如 $x^2-ax+5$ 在给定区间递增 |
| 已知 $f$ 递减，解 $f(m^2+2)>f(2m+5)$ | 属于 T3；$m$ 是输入表达式里的求解变量，不是函数系数 |
| 已知 $f(0)$ 是最小值，求参数 | 属于 T2 的指定最值求参；不能仅凭“求参数”归入 T4 |
| 差商或差积对任意不同两点恒正／恒负 | 先按等价定义识别严格增减要求，再进入 T4 |
| “在 $I$ 上递增” | $I$ 被一个递增区间覆盖，不要求 $I$ 恰好是最大递增区间 |
| “单调递增区间恰为 $I$” | 增加区间相等和最大性要求；不混入首轮准入 |
| “在 $I$ 上有定义” | 要求 $I\subseteq D_{f_a}$，不是 $D_{f_a}=I$ |

支持一个实参数、一个实自变量；系数为参数的一次以下有理多项式，目标区间与分界点固定，有限端点为有理数。支持一次／二次函数、固定有序显式分支、独立或分段中的 $c(a)/x+d(a)$、$sx+c(a)/x+d(a)$（$s$ 为非零常数），以及一次／二次式的平方根。计算产生的代数数端点保留精确值。

目标区间须非空且包含不止一个点。分段时先与目标区间相交：空分支不参加判断，单点分支只检查定义和值，不能按“常值段不递增”误删。其余结构必须落入已完成的子方法合同；不因表达式长得相似就开放。

参数只出现在区间外分支时，仍保留“求这个参数”的原目标：若区间内函数已满足要求，单调性不再限制参数；若不满足则无解。两者都继续与原题的参数条件求交。分支书写顺序不影响单点和相邻区间的排序。

倒数项在 $x=0$ 的分界点处不直接代入分母。先检查倒数项系数是否必须为零，再比较消去倒数项后的有限边界值；普通 $c/x+d$ 在 $c=0$ 时是常值区间，仍会被严格单调条件排除。核验时先代入具体参数，再计算相应单侧极限。

非严格单调、多个参数、随参数移动的区间或分界点、任意有理式、高次函数、任意外层复合以及函数方程证明单调性不在首轮范围。不得把 $\le$ 自动识别成严格递减，也不能以导数严格正／负替代本型的全部判定。

本次增量的定向回归如下；这些是合成变式的数学与交互测试，不代表新照片验收。平移分母 $a/(x+1)$、目标区间内未定义的分母、含参的对勾一次项系数仍明确报告未覆盖。

| 覆盖点 | 变式与要求 | 独立金标 |
| --- | --- | --- |
| 独立反比例 | $a/x$ 在 $(0,+\infty)$ 严格递增 | $a<0$ |
| 独立对勾及等号端点 | $x+a/x$ 在 $[1,+\infty)$ 严格递增 | $a\le1$ |
| 单点分支 | $ax$（$x<1$）、$2$（$x\ge1$）在 $[0,1]$ 严格递增 | $0<a\le2$ |
| 参数仅在区间外 | $x$（$x<1$）、$ax$（$x\ge1$）在 $[0,\frac12]$ 严格递增 | $a\in\mathbb R$；附加 $a>0$ 时仍须保留 $a>0$ |
| 零点接缝 | $x$（$x\le0$）、$x+a/x$（$x>0$）在 $\mathbb R$ 严格递增 | $a=0$ |
| 根式汇总保留原条件 | $\sqrt{ax^2-x+2}$，$a>0$，在 $[1,2]$ 严格递减 | 内层及最终均为 $0<a\le\frac14$ |
| 固定轴在端点 | $a(x-1)^2$ 在 $[1,2]$ 严格递增 | $a>0$；正系数卡只保留一个正确选项 |

### 2.2 二次函数：区间包含与次数退化

| 题目 | 必要且充分的条件 | 等号为什么可取 |
| --- | --- | --- |
| A05 | 开口向上，对称轴 $x=\frac m2$；$[1,2]$ 必须在轴的右侧，故 $\frac m2\le1$ | 轴恰在左端点时，区间内任意不同两点仍保持严格递增 |
| A09 | 开口向上，对称轴 $x=a-1$；$(-\infty,4]$ 必须在轴的左侧，故 $a-1\ge4$ | 轴恰在右端点时，整个区间仍严格递减 |
| A11 | $a<0$ 时轴 $1/a<0$，给定区间在右侧，递减；$a=0$ 时为 $-2x+3$，也递减；$a>0$ 时充分向右必递增，排除 | 原题只说“函数”，没有 $a\ne0$；不得先除以 $a$ 丢掉一次函数 |

可用任意两点作独立校核。A05 对 $1\le x_1<x_2\le2$，有

$$f(x_2)-f(x_1)=(x_2-x_1)(x_1+x_2-m),\qquad x_1+x_2>2.$$

所以 $m=2$ 仍严格递增；$m>2$ 时可在左端附近找到反例。A09 对 $x_1<x_2\le4$ 有 $x_1+x_2<8$，轴取等号同样成立。A11 的差式为 $(x_2-x_1)[a(x_1+x_2)-2]$；$a\le0$ 时恒负，$a>0$ 时足够大的输入使其为正。

“严格单调”不等于“每个参数条件都用严格不等号”，也不等于“导数在含端点的整个区间内处处严格非零”。

### 2.3 分段函数：段内条件与跨段条件同时成立

下表先按从左到右排列分支，保留原分界点归属。“边界趋近值”是该段函数值靠近边界时趋向的数，不一定是该段实际取得的值。

| 题目 | 左段严格性 | 右段严格性 | 跨段次序 | 合并 |
| --- | --- | --- | --- | --- |
| A06，整体递增 | $2a+4>0$ | 二次轴 $\frac a2\le1$，即 $a\le2$ | 左段趋近 $2a-1$ 但不取；右段实际 $f(1)=1-\frac a2$。须 $2a-1\le1-\frac a2$ | $a>-2,\ a\le2,\ a\le\frac45$，得 $(-2,\frac45]$ |
| A08，整体递减 | $-a<0$，即 $a>0$ | 右段轴 $\frac a2\le2$，即 $a\le4$ | 左段实际 $f(2)=1-2a$；右段趋近 $a-4$ 但不取。须 $1-2a\ge a-4$ | $(0,\frac53]$ |
| A17，整体递减 | $3a-1<0$ | $a/x$ 在 $[1,+\infty)$ 递减须 $a>0$ | 左段趋近 $7a-1$ 但不取；右段实际 $f(1)=a$。须 $7a-1\ge a$ | $[\frac16,\frac13)$ |

等号允许的原因要落到两个实际输入上。例如 A06 在 $a=\frac45$ 时，任何左段输入的函数值都严格小于左边界趋近值，该值等于 $f(1)$；因此跨段仍严格递增。相反，$a=-2$ 使整条左段成为常值，必须排除。

不能只检查两段方向，也不能强制两段连续。一般跨段严格递增要求左段的任一函数值小于右段的任一函数值；比较有限上、下确界时，两边相等且不同时取得仍可能成立。递减同理。取得性、分支范围与边界所属必须进入证据，不能把这三题的非严格边界号写成无条件通用规则。

### 2.4 A10：相反方向相加不能省略右段判断

左段 $\frac ax$ 在 $(0,1]$ 递增，首先得到 $a<0$。右段写成 $x+\frac{-a}{x}-2$；这里 $x$ 递增，而 $\frac{-a}{x}$ 递减，单凭两项方向不能判断它们的和。

| 检查 | 推导 | 条件 |
| --- | --- | --- |
| 左段反比例函数 | 系数为负，正半轴上严格递增 | $a<0$ |
| 右段对勾函数 | 在 $a<0$ 下转折点为 $\sqrt{-a}$；整个 $(1,+\infty)$ 要落在递增侧 | $\sqrt{-a}\le1\iff a\ge-1$ |
| 跨段次序 | $f(1)=a$；右段趋近 $-1-a$ 但不取 | $a\le-1-a\iff a\le-\frac12$ |

合并得到 **$[-1,-\frac12]$**。只检查左段和接缝会漏掉下界 $-1$。

右段还可独立用差式证明。设 $1<x_1<x_2$，则

$$r(x_2)-r(x_1)=(x_2-x_1)\left(1+\frac a{x_1x_2}\right).$$

在 $a<0$ 下，$a\ge-1$ 时括号恒正，因为 $x_1x_2>1$；$a<-1$ 时可取 $1<x_1<x_2<\sqrt{-a}$，得到括号为负。该证明说明 $a=-1$ 可以取，也证明更小的参数全部不行，不是仅试一个数。

主教学路线使用已有“对勾函数”的单调性知识；若开放定义法备选，必须补足受限有理式作差、分母符号和双点范围合同。当前 `skill-reciprocal-range` 是求最值与值域的技能，不能把它直接当成含参单调性求解器。

### 2.5 A13：单调条件与定义条件必须相交

令 $q(x)=ax^2+2x-5a+5$，$I=(-\infty,-2]$。可行参数同时满足：

1. 对每个 $x\in I$ 都有 $q(x)\ge0$，整个原区间上能开方。
2. 在这一合法范围内，$\sqrt{u}$ 严格递增，所以 $f$ 递减等价于 $q$ 递减。

| 检查 | 推导 | 结果 |
| --- | --- | --- |
| 内层方向的必要条件 | $a\le0$ 不能使 $q$ 在左半无限区间严格递减；$a>0$ 时须轴 $-\frac1a\ge-2$ | $a\ge\frac12$ |
| 该候选范围内的定义条件 | $q$ 已在 $I$ 递减，最小值在 $x=-2$ 取得，$q(-2)=1-a$ | $a\le1$ |
| 原函数回验 | 对候选范围内所有参数，$q\ge0$ 且严格递减；开方保序 | $a\in[\frac12,1]$ |

可以先记录合法性待证，再推导“任何可行参数必满足 $a\ge\frac12$”，最后完成定义条件；不能在合法性未通过时标记原函数已在整段有定义。$a=\frac12$ 的轴落在端点仍允许，$a=1$ 的端点被开方数为零也允许。

独立校核内层差式：

$$q(x_2)-q(x_1)=(x_2-x_1)[a(x_1+x_2)+2],\qquad x_1<x_2\le-2.$$

由于 $x_1+x_2<-4$，严格递减的充要条件为 $a\ge\frac12$。定义条件单独求解时，完整参数集合为 $[\frac{5-\sqrt5}{10},1]$；它与 $[\frac12,+\infty)$ 相交也得到同一结果。这条独立路线用于验证，学生主线不必为已排除的参数重复做全部定义域分类。

不能把 $I$ 改成“$I$ 与自然定义域的交集”后判断，也不能要求自然定义域恰等于 $I$。例如 $a=\frac12$ 时根式在整个实数域都合法，仍满足本题在 $I$ 上递减的要求。

## 4. 题意协议、结果与验证

### 4.1 参数角色与原条件

沿用已有题意协议，补足下列语义；字段名称在编码时按现有 schema 落地，不另造第二套题意系统。

| 信息 | 必须保留的内容 |
| --- | --- |
| 函数与变量 | 函数身份、自变量绑定、唯一参数绑定、参数初始范围；不按 $x/a/m$ 字母猜角色 |
| 原表达式 | 原始 AST、原分支及其范围；分母与根式限制不能在约分或参数代入后丢失 |
| 指定区间 | 精确端点、开闭、来源；区分“在此区间”与“区间恰为” |
| 单调要求 | 递增／递减、严格性；题设文字或差商／差积的来源 |
| 双点条件 | 量词、$x_1\ne x_2$、两个输入的共同范围、差式与分母的原始顺序 |
| 原目标 | 求函数参数的完整集合；保留与原始条件对应的可验证目标 |

A08、A13 中差商分子分母同时反向不改变符号，只反向一处会改变方向。A17 的乘积条件在 $x_1\ne x_2$ 下与差商同号。证明中可不失一般性设 $x_1<x_2$，但不能把它新增成原题漏给的条件；省略“不同两点”也不能凭模板自行补齐。

阶段①只转录来源事实并遵循通用字段约定；`required_monotonicity` 表示参数须满足的要求，`function_monotonicity` 表示题给已知事实。共享 prompt 不列题型编号、变式清单、支持范围或解题步骤，不为独立反比例／对勾、单点分支、区间外参数追加说明。结构识别、区间裁剪、单点与接缝检查、原参数约束求交及差商／差积方向核验均由代码处理并用单元测试覆盖。明确声明“二次函数”的条件应按原文保留，其系数非零约束应由代码推导；A11 没有该限制，不能补造。

### 4.2 条件化结果

M1／M2／M3 扩展结果须区分固定函数的方向证据与含参条件。含参结果至少包含：

- 参数分类范围、分类依据与完整覆盖证明；退化点单独保留。
- 每类中的有效函数表达式、原输入区间、完整定义条件。
- 段内严格增减的充要条件、复合规则前提，以及跨段次序和取得性。
- 条件的数学来源及父子调用绑定；每类取交后的集合、各类取并后的最终集合。
- 对保留类的成立证明，对排除类的不成立理由；最终验证状态与未解决义务。

原有数值结果合同不静默改义。未通过参数条件的单调证据不能回流为无条件事实；同一函数在不同参数类、不同区间上的证据不能混用。参数约束发生变化时，要重新验证依赖它的转折点、范围和符号。

### 4.3 完整性与原题验证

最终提交必须同时证明充分性和必要性：保留参数都使原函数在原区间有定义且满足严格次序；任一被排除的参数类别都有定义失败、段内方向失败、常值或跨段失败的依据。

验证器从原表达式、原分支和原目标独立检查，不仅比较执行器给出的区间字符串。有限参数采样、几张函数图和若干边界代入只能辅助诊断，不能证明连续参数区间全部成立。反例可参数化给出，例如 A10 在 $a<-1$ 时选择 $1<x_1<x_2<\sqrt{-a}$。

每个借用子方法的参数身份、函数变量、区间、比较号与返回集合都要校验。失败、能力未覆盖、条件缺失和数学空集分开；缺少一条跨段或定义证据时，不能返回“已完成”。

### 5.1 共同主流程

| 步骤 | 输入与动作 | 输出 |
| --- | --- | --- |
| ①读清要求 | 绑定参数、原区间和严格方向；有差式时引用等价定义 | 原题增减要求及来源 |
| ②记录必须有定义的条件 | 保留各分支实际适用范围内的分母、根式限制 | 完整合法性义务；可暂待后续子调用解决 |
| ③按参数与结构分情况 | 零系数、开口／斜率／倒数系数符号、轴或转折点与区间关系 | 完整且互不遗漏的参数类别 |
| ④判断段内增减 | 调用 M2，必要时调用 M1；复合函数带入外层合法范围 | 带当前参数前提的严格增减条件 |

| ⑦回到原题 | 核验端点、退化点、保留类和排除类 | 可交付答案与可教学的证明 |

有的题只需一条参数不等式，不能为了统一模板强行拆出七张学生卡。数学步骤齐全，展示按认知任务合并。

### 5.2 各结构路线

**二次函数路线。** 先判断二次系数是否可能为零；非零类别中复用配方／对称轴性质，把“整个指定区间在增／减一侧”转成参数条件。首轮固定区间不引入动区间端点竞争。一次退化按斜率处理，非零长度区间上的常值函数不满足严格要求。

**显式分段路线。** M3 接收原分支及其与目标区间的交集，逐段调用 M2，再用 `skill-piecewise-order-join` 返回跨段条件。跨段检查在段内方向条件下进行，边界趋近值、实际取值和开闭分别绑定。A17 的 $x=0$ 落在一次分支，不能把右分支 $a/x$ 的分母限制扩散到整个实数域。

**对勾路线。** A10 先由左段取得 $a<0$，再在此前提下调用右段的对勾单调性质。首轮该子路线的参数前提保证 $k=-a>0$；转折点与正区间的比较必须返回条件。若父方法不能证明该前提，应先分类或报告未覆盖，不能直接套正系数对勾结论。

**根式路线。** 将 A13 拆成“内层严格递减条件”和“原区间上被开方数恒非负”两个真实义务。开方在 $[0,+\infty)$ 严格保序，非负证明足以提供外层适用范围，不强迫额外求一遍完整像集。

### 5.3 A13 的借用合同与教学收束

本批优先沿用现有正式调用：向恒成立子系统提交 $\forall x\in(-\infty,-2],\,q(x)\ge0$，让它基于真实结构选取区间最值等已支持方法，返回完整参数集。父 M6 再与 $a\ge\frac12$ 求交，不假设借用器自动继承该候选条件。

教学投影可折叠与父候选集不相交的已验证分类，并依据已有子证据展示“在当前候选范围内，最小值在 $-2$，故 $1-a\ge0$”。这种折叠只改变展示，不改变子问题或验证范围。若以后增加带候选参数约束的借用接口，必须显式传入、记录并验证约束，不能通过题号特判省去分类。

## 9. 必要验证矩阵与验收口径

本节是后续编码的测试要求。本次设计只校核题目数学、引用和文档格式，不运行整站测试。

| 维度 | 必要用例 | 必须挡住的问题 |
| --- | --- | --- |
| 8 题精确结果 | §2 全部集合；A06/A08/A17 开闭端点 | 大致方向正确但参数边界遗漏 |
| 次数与常值 | A11 的 $a=0$；A06 的 $a=-2$；A17 的 $a=\frac13$ | 统一排除零系数；把常值段判严格单调 |
| 指定区间语义 | A05 的轴可在左端之外；“在区间”与“恰为区间”对照 | 把包含关系误作相等，只得一个参数 |
| 差商／差积 | 同时换序、仅换分子、缺不同两点条件、有限共同区间 | 错判方向、虚构量词或丢失作用域 |
| 严格性 | $<0$ 与 $\le0$ 对照；单点分支与常值区间分开 | 把非严格性质升级为严格；误删单点分支 |
| 跨段比较 | 同向但跳反、等边界但一侧不取得、允许正确方向跳跃 | 只查段内；强制连续；等号一律删除 |
| 分支内合法性 | A17 的 $x=0$；根式／分母仅在所属分支检查 | 把局部分母孔点错误扩散至整个区间 |
| A10 右段 | $a=-1$、$a=-\frac12$、$a<-1$ 整类；变换接缝常数的留出题 | 丢失右段条件；以相反方向的和直接判断 |
| A13 定义条件 | $a=\frac12,1$；$a>1$；整段非负与仅端点非负对照 | 把区间缩小；遗漏根式合法性；把包含改相等 |
| 参数分类完备 | 每个临界点单独验证；分类覆盖初始参数域；分类内符号证书 | 用几次参数采样代替必要充分性 |
| 子调用与回验 | 篡改参数名、原区间、严格号、接缝取得性或最终端点 | 验证只复述执行结论；父约束静默进入子题 |
| 旧能力与边界 | 受影响的 T1 数值增减、T2 参数范围／恒成立调用；多参数等范围外题 | 共享改动破坏旧课；能力缺口伪装成空集 |
| 教学与记录 | 代表课完成／回退／回放，子方法返回与不重复提问 | 未作答先露答案；卡片与参数类别错配；旧记录全站失效 |

测试按数学边界参数化组织，不为文案逐字增加测试，也不重复运行无关整站套件。实现完成后补相关课程生成／回放检查及代表真实拍题；两者分别记录，不把单元测试通过写成拍题通过。

留出按结构分组：二次函数轴位置、零系数退化、分段接缝、对勾转折、根式全域合法性分别留题。改变一个决定答案的条件，例如开口、区间位置、接缝常数、根号内常数或严格性，并另留非同页照片检查抽取。用于调试的题移入回归集，再补留出，不能换题号冒充新题。
