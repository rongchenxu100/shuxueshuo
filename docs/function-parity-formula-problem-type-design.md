### 1.3 分批开放的结构范围

下表是实现目标。执行准入按表达式、域、关系和可验证证据判断，不按题号或答案判断。

| 子范围 | 计划覆盖 | 限制与退化 |
| --- | --- | --- |
| 局部规则补全 | 奇／偶／既奇又偶；已知侧可以为正侧、负侧、有限区间、有限点集或其并集 | 保留开闭、孔洞和零点；局部规则可有重叠但必须相容；排他性质“奇而非偶”等先另列能力缺口，不静默忽略 |
| 多项式／有理式 | 有理系数，原多项式或原分子、分母至多四次 | 至少支持 A12 的三次幂；保留约分前分母和原规则作用范围 |
| 绝对值／根式 | 固定一次或二次式的绝对值；二次式平方根及 T1 已验收的有界组合 | 反射只替换输入，不凭平方等式丢掉符号；一般嵌套根式及任意根式和消元暂不开放 |
| 有限分段 | 至多 6 个原局部分支，分支属于上述结构 | 反射后统一细分，核对重叠、原点及端点；不按“首个分支优先”遮盖矛盾 |
| 对称求值 | 一个或两个未知函数；数值输入上的有限线性组合、题给值关系与局部规则求值 | 保留重复项；变量分别绑定到函数、形参、参数、目标；非线性未知函数值关系暂不开放 |
| 奇偶分离 | $Af(x)+Bg(x)=H(x)$，$A,B$ 为固定有理数，两个函数各自给出奇／偶性质 | 主路线为一奇一偶；同奇／同偶及零系数须检查一致性与目标唯一性，不能除零或强求两函数唯一 |
| 参数前置 | M2 已验收的完整有限候选集，初始至多 8 个候选 | 每个候选实例化后重新检查规则和目标；无限参数族先保留并报告所需后续能力，不挑一个值继续 |
| 目标形式 | 指定范围的解析式、全域规则或规则族、具体函数值／有限线性组合 | 一般迭代求和归 T5；任意复合未知函数、一般函数方程、指数／对数／三角补全另列范围 |

固定集合沿用 T1 的目标范围：至多 8 个区间、16 个孤立点／删点，有限端点为有理数或可精确比较的实二次代数数；反射、合并与恒等比较共用至多 48 个切点、97 个单元的预算。反射可能使分支数量增加，输出受公共细分预算约束，不把“6 个原分支”误当作输出也只能有 6 段。

沿用 T2 的区间约定：原题以区间记法声明的范围须满足左端点严格小于右端点，含参时先列此约束；不把退化区间读成单点或空集。明确写出的有限集合，以及合法集合运算／自然域推导得到的孤立点，仍按集合语义保留。无穷只能作为开端点。

源 AST 每个规则至多 256 节点、深度 24，有理数至多 128 位；内部正规式沿用 T1 的次数预算。点值路线初始最多 32 个函数调用出现位置、32 条线性条件、32 个不同的函数值未知量。数值输入支持有理数及以有理数、平方根表示的实二次代数数，结果必须精确表示。完整函数域须关于原点对称；每条全称关系可以仅覆盖一个局部范围，但必须标明范围，并与其他关系及反射后的关系在公共细分上一起核验，不能只在目标输入处联立。

这些预算在共享合同中集中登记；准入、生产、验证及评分读取同一版本。执行范围以依赖已通过验收的子集为准，中间结果超限返回能力缺口，不返回“非奇非偶”“无解”或伪造唯一公式。

### 2.1 三条路线的最短推导

A07：$x<0\Rightarrow -x>0$，所以 $f(-x)=(-x)(1-x)=x^2-x$。偶性给 $f(x)=f(-x)$，得到原目标范围内的公式。

A08：$x<0$ 时，$f(-x)=x^2+3x-1$，奇性再给

$$
f(x)=-f(-x)=-(x^2+3x-1)=-x^2-3x+1.
$$

因为题给公式仅用于 $x>0$，它在 $0$ 处的代入值不构成原题约束。$f(0)=0$ 与两侧跳跃可以同时成立。

A12：$f(0)=0$，$f(-1)=-f(1)=-(1+2+1)=-4$。A13 则把整个已知等式取负：

$$
f(1)+f(-2)=-\bigl(f(-1)+f(2)\bigr)=-3.
$$

A03 在关系适用的 $2,-2$ 处得 $f(2)+g(2)=3$、$-f(2)+g(2)=7$，故 $f(2)=-2$。A06 令 $H(x)=x^3+x^2-1$，由 $H(-2)=-f(2)-g(2)=-5$，直接得到目标 $5$。其短路线与完整联立路线都是正确路线，不能把较长但适用的解法判错。

## 4. 题意、结果与共享技能合同

### 4.1 保留题给信息

沿用 `find_function_formula`、`find_value` 等原目标语义；专题分组不新造一个笼统的“奇偶性答案”。题给奇偶性直接使用 T2 已交付的 `parity(f,property)`，编译产物为绑定函数引用的 `function_parity` AST；`binding.parity_fact` 是无效输入的错误码，不是待新增的字段。普通 `odd`／`even` 允许零函数，`both` 同时要求两种性质；T3 尚未支持的排他性质明确分流。题给事实与 T1 判定得出的证明仍分别保存来源。

完整定义域及输入限制继续沿用 `declared`／`restriction` 的角色；仅保证某段有意义时沿用独立的 `defined_on(f,D)`／`function_defined_on` 条件，不把它解释为完整定义域。下表规定 T3 必须保留的信息；派生规则族、覆盖和目标唯一性的结果合同仍需在 T3 实现。

| 对象 | 必须保存 |
| --- | --- |
| 函数与性质 | 稳定函数引用、形参绑定、奇／偶对象及来源；题给性质与 T1 证明结果分别标记 |
| 完整域 | 明确给定的域、推导出的域或尚未具体化的原域；域角色、非空及反射闭合依据；区间声明严格满足左端点小于右端点，有限集合另行保留 |
| 局部规则 | 未化简规则 AST、局部条件、端点开闭、量词范围、原分母／根式限制及来源 |
| 函数关系 | 所有函数身份、系数和完整正负号，关系适用范围及其量词；有限点等式与全称关系区分 |
| 目标 | 完整表达式、每次函数调用、要求的规则范围、原问编号及父目标引用 |
| 参数与其他条件 | 原参数限制、题给值和其他性质；逐项处理或交回父方法，不静默丢弃 |

若源文只说“$x>0$ 时”，该规则按原函数域内的条件解释；已有完整域时取 $I=D\cap(0,+\infty)$。只有源文明确对全部正实数规定函数值，才据此得到全部正半轴的成员资格。不能由局部多项式的自然域推断未知函数的完整域。

未给具体完整域时可以保留抽象对称域 $D$。如 A04，按 $D$ 内的正、负、零三种情况可得到原域内的统一公式，结果仍带原域身份；不凭该公式添加 $D=\mathbb R$。若需要计算一个具体值，则另外核验该输入、反射输入及所用关系的适用性。

A03 的校核采用题干关系适用于所求输入 $2$ 及其相反数这一教材语义。实施时须记录适用依据和规范化来源，不把它扩大成“两函数均定义在 $\mathbb R$”。若抽取给出明确的排除点，原目标求值不能覆盖该冲突；适用范围确实不明时进入待核对，不凭目标出现某个输入就覆盖显式域限制。

题意摘要必须显示“谁是奇／偶函数、已知哪段规则、在哪个范围、具体求什么”。A12 的 $>$、A15 的有限完整域、A06 的减号均进入规范身份和版本；派生的负侧公式、零点值和参数不能回写为 OCR 已知事实。

### 4.2 S2 对称变换

共享 S2 使用带范围证据的关系

$$
f(2a-u)=\varepsilon f(u)+c,\qquad \varepsilon\in\{-1,1\}.
$$

T3 首批只绑定 $a=0,c=0$，分别表示奇、偶；一般中心／轴与偏移后续由 T5、T6 开放。输入包含函数身份、原关系来源、允许作用域、实际替换输入及合法性证据，输出完整改写式与所用范围。

必须整体替换绑定形参，而非字符串替换；原参数、函数名、其他函数的形参和自由变量不受影响。关系用于一段时只推出该段的结果，不能由一个点的 $f(-u)=\pm f(u)$ 升格为全域奇偶性。S2 负责应用已知关系，不反过来把本次变换当作性质来源。

### 4.3 结果类型

拟议结果按目标区分为 `ParityExtensionResult` 和 `SymmetryValueResult`，共享来源、版本和依赖记录。

| 内容 | 合同 |
| --- | --- |
| 确定规则 | 分支式、精确分支范围、原式限制、生成来源及相容性证据 |
| 零点 | 不属于域／已知值／由奇性推出零／仍自由／与原条件冲突；不能仅用一个布尔值 |
| 范围 | 原完整域、已确定部分 $K$、目标范围 $J$、尚未确定部分；抽象域保留谓词和覆盖证明 |
| 自由部分 | 未知零点常数或未覆盖的对称输入对上的自由规则，以及仍需满足的奇偶约束 |
| 点值目标 | 精确值、合法调用、变换轨迹、代入证据或线性组合证书；不要求所有未知量分别唯一 |
| 子任务与完成 | 原目标、父目标、已处理条件、剩余义务、验证状态；补全子结果可交 T4，不能代替 T4 答案 |

数学状态须区分：

- **目标已唯一确定：** $J$ 被确定规则覆盖，或所求值对所有符合题设的函数相同。
- **规则族／条件不足：** 可以描述剩余自由部分，但不能声称有唯一全域公式；如果原目标只涉及已确定部分，仍可完成该原目标。
- **题设矛盾：** 域不对称、已知零点冲突、重叠规则不一致等有证据地排除了所有函数。
- **目标无定义：** 原要求的输入明确不属于函数域，与“属于域但值未知”分开。
- **能力缺口／来源待核对：** 超预算、证明未决或源信息不清；不转成数学空解。

**允许经证明的非唯一结论完成相应原目标。** 已知 $0\in D$ 且偶函数仅给 $x>0$ 的规则时，若只问 $f(0)$，可将“$f(0)$ 不能唯一确定”作为正确答案；若问完整解析式，须回答已确定分支与 $f(0)=c,\ c\in\mathbb R$ 的规则族，不能只写“不能确定”而漏掉可确定部分。须独立验证自由取值与全部题设相容及扩展存在性。原目标只涉及已确定部分时正常给出唯一结果；零点不在域、题设矛盾、能力缺口和证明未决均不按这种正确答案处理。

## 5. 数学执行与独立验证

### 5.1 对称补全与存在性

对完整对称域 $D$，设有效局部规则为 $f(t)=p_i(t)$，$t\in I_i\subseteq D$。奇性取 $s=-1$，偶性取 $s=1$。对任意 $x\in-I_i$：

$$
-x\in I_i,\qquad f(-x)=p_i(-x),\qquad f(x)=s\,p_i(-x).
$$

题给点值先编为单点规则，与区间规则一起反射、检查重叠和计算覆盖。重叠、零点和自由部分的条件组织从 T2 R1 的单规则实现抽为共享相容性模块：T2 在参数分类后调用，T3 对多条固定域规则调用。共享的是判定规则与证书合同，各自保留域表示适配；不能令 T2 与 T3 对同一组原条件作出不同的矛盾判断。执行次序如下：

1. 绑定原域、规则及目标；先检查每条原区间声明的左端点严格小于右端点，再确认整个域非空、关于原点对称。含参区间将此条件交给 T2，非法区间不读成单点／空集；明确的有限集合及合法集合运算得到的孤立点不受此限制。抽象域可引用题给奇偶性的域前提；具体域必须实际核对。
2. 验证规则在声明的 $I_i$ 上处处有意义。规则明确覆盖某点而分母为零时是冲突，不悄悄缩小 $I_i$ 来修复题目；只有原文已有排除条件才保留为孔洞。
3. 保存原分支并生成反射分支，区间端点交换且开闭随端点移动；原式限制同时反射。
4. 调用共享相容性能力，对所有原／原、原／反射、反射／反射的非空交集验证同值；临界点、孤立点单独核对。原规则与镜像规则均携带来源，证明相容后才可合并表示。
5. 在同一共享合同下处理零点：若 $0\in D$，奇性补 $f(0)=0$ 并与已有值比较；偶性不新增零点值。给出“既奇又偶”时则整个域都必须取零，并检验全部原条件。
6. 计算已确定范围 $K$。普通奇／偶情形为全部 $I_i\cup(-I_i)$（包含单点规则及其反射）加奇函数的合法零点；随后检查原目标要求的 $J\subseteq K$。

已知信息只包括这些局部规则、性质和已核验点值时，相容性足以构造扩展：在未确定的每一对输入 $\{x,-x\}$ 上选一个值，另一侧按 $s$ 确定；合法零点按性质处理。因而可以证明哪些自由部分仍存在，不能把“没有继续算”当作非唯一的证明。额外条件也须处理完，才可使用这一存在性结论。

例：偶函数定义在 $\mathbb R$ 上，仅给 $x>0$ 时 $f(x)=x+1$。可得非零处 $f(x)=\lvert x\rvert+1$，零点为任意实数 $c$；$f(-2)=3$ 已确定，但全域没有唯一公式。相同题设换成奇函数时，负侧为 $x-1$，零点为 $0$，全域规则唯一且允许跳跃。

### 5.2 公式拼接与等价答案

先输出带范围的分段规则，再按已证明等价关系化简成绝对值等紧凑写法。分支式相同不代表可以跨孔洞合并定义域；数值侧限相同也不赋予缺失端点取值。

A09②可将负侧与零点合并成 $-2x^2-x$、$x\le0$，因为该式在零点恰为 $0$。A08、A12 的负侧公式若代入零点分别为 $1,-1$，必须保留独立的 $f(0)=0$，不能合并。

评分比较实际要求范围内的函数对应关系，并单独验证范围覆盖和原式合法性。分段式与绝对值式可以等价；一个表达式在更大自然域上有意义不代表学生主动扩大了原函数域，但答案若明确给出错误的完整域则不能接受。只答未知侧时不要求学生重写已知侧；问全域时不能漏零点或自由部分。

### 5.3 对称求值与目标唯一性

M5 先尝试直接变换原目标。能把整组求值映射到题给组合时，直接记录等式推导；需要数值代入时，将合法调用交给公共代入法。没有必要先生成整个分段函数。

需要联立时，以“函数身份＋精确输入”建立未知量，奇偶关系将相反输入配对；重复出现仍保留其系数。把全部相关题给线性关系、已核验局部值和零点约束写为精确系统

$$
Az=b,\qquad T=c^\mathsf{T}z+d.
$$

先证明系统一致；存在 $\lambda$ 使 $\lambda^\mathsf{T}A=c^\mathsf{T}$ 时，目标唯一且

$$
T=\lambda^\mathsf{T}b+d.
$$

验证器检查该线性组合证书，不要求每个 $z_i$ 都可单独求出。无条件的反号消去、偶性等值消去也形成同类可核验等式链，不必为了简单题在学生端展示矩阵。

若目标不唯一，给出满足原约束的两个赋值且目标不同，并证明它们可扩展为满足全部题设的函数。只给两个局部数值而忽略全域恒等关系，不能证明条件不足。奇偶关系之外还有未处理性质时，应先处理或声明缺口。

若经完整参数求解得到多个候选，对每个候选检查题设、目标合法性及目标值；只有全部有效候选的目标一致才收束为单个数值。参数非唯一不自动使目标非唯一；无限解族超出本批合同也不等于数学条件不足。

### 5.4 两函数奇偶分离

设 $f(-x)=s_f f(x)$、$g(-x)=s_g g(x)$，且 $Af(x)+Bg(x)=H(x)$ 在已验证的对称公共域 $E$ 上成立。代入 $-x$ 得

$$
\begin{cases}
Af(x)+Bg(x)=H(x),\\
A s_f f(x)+B s_g g(x)=H(-x).
\end{cases}
$$

系数行列式为 $AB(s_g-s_f)$。$f$ 奇、$g$ 偶时它为 $2AB$（按上列行序），与旧单函数合同中的 $A^2-B^2$ 不同。当 $AB\ne0$、$f$ 奇且 $g$ 偶时，

$$
f(x)=\frac{H(x)-H(-x)}{2A},\qquad
g(x)=\frac{H(x)+H(-x)}{2B}\qquad(x\in E).
$$

两条公式只确定 $E$ 内的规则；$D_f,D_g$ 超出公共关系域的部分不能被自动填上。$H$ 的分母限制属于原关系的适用条件，不据此擅自删去两个函数各自声明域里的点。即使某个系数为零，也要保留原函数调用的合法性，不能把 $0f(u)$ 化为零来掩盖 $u$ 不属于域。某个目标只需 $u,-u$ 的关系时可以在这两个合法输入处联立，避免要求恢复全部函数。

退化分类必须完整：

| 条件 | 必须处理 |
| --- | --- |
| $A=0,B\ne0$ | 检查 $H/B$ 与 $g$ 的性质在 $E$ 上相容；$f$ 仍受自身性质及其他原条件约束，不置零 |
| $B=0,A\ne0$ | 对称处理；未被约束的偶函数零点也不能随意设为零 |
| $A=B=0$ | 在原关系域核验 $H\equiv0$；成立时这条关系不约束函数，不成立时矛盾 |
| $s_f=s_g$ | 检查 $H(-x)=s_f H(x)$；组合可能唯一，两个函数通常不唯一，再按目标证书判断 |
| 固定输入 $x=0$ | 若属于域，加入每个奇函数的零点条件；不能只根据行列式为零就判目标不唯一 |
| 关系域未证明反射闭合 | 不写第二条全称方程；可核验局部目标所需的适用范围，否则保留未知或分流 |

例如两个奇函数满足 $f+g=x$，$f(2)+g(2)=2$ 唯一，$f(2)$ 本身不唯一。若改为 $f+g=1$ 且域为 $\mathbb R$，则题设矛盾。通用秩判断与全域相容性检查都需要，不只实现 $A=B=1$ 的非退化公式。

### 5.5 独立验证器

验证器从冻结原题重建函数、域、性质、局部规则、线性关系及原目标，不调用生产补全器／目标求解器后自比答案。可共用精确 AST、集合和代数运算，但独立核验：

- S2 每次输入替换的函数身份、范围、完整负号及来源；题给性质不迁移给别的函数。
- 原规则在其声明范围上的合法性与保持性、镜像规则、所有重叠、零点和端点；用全域恒等证书或有限域全枚举，不用图形采样代替。
- $K$ 的来源、目标覆盖、未确定部分的自由度和扩展存在性；删除一段或补回孔洞必须失败。
- 数值目标的每次调用和精确代入，线性系统的一致性、目标组合证书；非唯一时核验反例赋值及函数扩展。
- 双函数的真实系数矩阵、各自性质、原关系和有效范围；验证 $A=0$、同性质和 $x=0$ 等退化情形。
- 全部原条件与原目标的处理状态。子任务结束不等于整题结束；不从学生前问答案直接借用公式或参数。

已确定公式可在 T1 支持的固定结构内调用其判定验证，但这只是充分性的一部分；还需证明原局部规则、覆盖和目标唯一性。金标只用于测试，不成为生产答案来源。

| “只知道一侧公式，要求另一侧” | M3 | “把要研究的输入换到已知的一侧，再用奇偶性换回来。” |
| “只求几个函数值或它们的和” | M5，按需借用代入法 | “先找相反输入之间的关系；能直接得到所求组合，就不用补出整个函数。” |
| “两个函数混在一条等式里” | 扩展的构造方程组法，或 M5 的目标短路线 | “分别代入一对相反数，看看相加或相减能消去哪一个函数值。” |

**沿用 T1／T2，单一路线也保留「选择解题方法」卡。** 选法线索复用总计划中的“奇偶性应用的选法判断”。A03、A06 可以提供确实适用且已接通的 M5 短路线与联立路线；适用但尚未展开的替代路线不能作为错误干扰项。选法卡与后续关键判断的教学密度分开处理，不因保留选法卡而重复展开所有子步骤。

| 主线阶段 | 学生关键判断 | 子方法默认密度 |
| --- | --- | --- |
| 读题与范围 | 明确要补哪一段／求哪个组合；公式与题给性质直接展示 | 平凡域确认 `fold`；孔洞、参数或范围不清时 `light/full` |
| 输入映射 | $x$ 在目标侧时，$-x$ 落在哪里 | M3 主交互；已知范围的重复使用 `fold` |
| 代入规则 | 把完整 $-x$ 放入每个绑定位置 | 第一次 `light`，易混复合输入可 `full`；后续简单数值代入 `fold` |
| 奇偶回写 | $f(x)$ 等于 $f(-x)$ 还是 $-f(-x)$ | M3 主交互；乘开外层负号保留板书 |
| 拼接与零点 | 目标是否含零、零点是否已知、范围是否覆盖 | 存在新零点／重叠／未覆盖范围时展开，否则 `fold` |
| 对称组合或联立 | 整组取负、找消去项或选择需用的另一输入 | A13 直接一个关键判断；双函数首题联立 `full`，简单加减 `light` |
| 返回原目标 | 把值代回原组合，或回到参数／不等式父任务 | `fold`，保留完整验证证据 |

折叠的是展示，数学合法性、全部条件和独立验证不省略。避免多个小问都叫“使用奇偶性”；采用“把输入换到已知侧”“处理外层负号”“检查零点”“求所需组合”等实际任务名称。

### 6.2 可视化

**R0 即复用课程数轴，随步骤显示已知范围、目标范围及 $x\mapsto-x$。** 复用 `condition_number_lines` 渲染合同，从 T2 配对数轴构造中抽出不依赖参数标签的部分。已知范围 $I$、目标范围 $J$ 与反射范围 $-J$ 使用同一尺度，明确标出开闭端点、零点及 $-x$ 是否属于 $I$ 的依据；待学生确认的关系按当前步骤状态逐步揭示。R0 交付卡片、完整推导及范围配对展示，拖动、连续动画和函数曲线揭示留到后续批次。

后续 M3 再增加与数轴对应的函数图和点探查。选定目标输入 $x$ 时，同时显示 $-x$ 及其落在已知范围的依据；偶性对应 $(t,p(t))\mapsto(-t,p(t))$，奇性对应 $(t,p(t))\mapsto(-t,-p(t))$。区间标签、分割线、空实端点和当前分支都直接标在图内。

已知曲线与待补曲线分层显示，学生确认相应关系后再揭示新分支；代数板分别标明 $f(-x)=p(-x)$ 与奇性回写的 $f(x)=-p(-x)$。A08 在 $x<0$ 且趋近 $0$ 时函数值趋近 $1$，在 $x>0$ 且趋近 $0$ 时趋近 $-1$；A12 对应为 $-1$ 与 $1$。实际 $f(0)$ 均为 $0$，图像不得跨跳跃连线；学生文案按输入符号说明，不用页面位置代指输入关系。

“零点属于域但值未知”用问号和文字说明，不用空心点冒充“零点不在域”。空心端点只表示确实不取到的点；已知值才画对应实心点。原域有孔洞时不因化简而补实，未确定区间不画出一条暗示唯一公式的曲线。

M5 的抽象求值题用输入配对及等式卡。A13 只标已知组合 $3$ 与待求组合，不给 $f(1),f(2)$ 任意指定数值，也不配一条假定曲线。双函数分离时可展示 $H(x)$、$H(-x)$ 的加减；只有各分支已确定且范围明确时才绘制对应曲线。

图形、板书、完成卡、后退与 AI 回放使用同一验证状态。更新图层和数值时不反复销毁公式卡，避免排版抖动；颜色配合线型和文字，键盘与点击均能完成核心作答，窄屏保持范围与公式邻近。

### 6.3 多问与父任务

A09 两问分别保存完成状态；第一问得到一个值不替代第二问的范围公式。A05①、A11① 在 T3 内实现、验收并记录子目标完成状态，公开课程等 T4 完成两道题的全部原目标后统一发布；不先发布删除第②问的原题页。后问可从原题独立重证补全，也可按版本引用前问已验证产物；不能依赖学生刚填入但未验证的表达式。

A15 的借用卡明确“先确定定义域中的参数”。父方法从冻结原题选择本次处理的 `source_refs`，调用 `borrow_domain_parameter(context, parameter_ref, source_refs)`，再以原 `context` 调用 `verify_borrowed_parameter(context, output)`。使用其 `parameter_set`、`instantiated_domain`、`processed_source_refs` 和 `remaining_source_refs`；必须保留 `parent_target_pending=True` 及原父目标引用，不能把子任务结果直接标为整题完成。

A15 的已验证返回为 $m=-4$、$D=[-9,9]$。T3 随后检查目标输入 $-4$ 与反射输入 $4$、局部规则的实际范围及剩余条件，再求 $f(m)=-8$。接口仅在单元素有限解集时提供 `instantiated_domain`；多个有限候选由父方法逐个实例化、回验并比较目标结果，不取首个值继续。修改原域、局部范围或参数条件后，子证书及父目标依赖均须重新核验。

### 6.4 教学展示的硬约束

1. **原式板书使用源 AST。** 保留未约分的分子、分母、根式和分段条件；约分或其他化简只作为有依据的后续推导显示，不能用化简式覆盖原式。
2. **学生文案说「不恒成立」。** 不用 `\not\equiv` 等陌生符号替代解释；需要否定时给合法输入处的确切反例或说明违反的条件。
3. **干扰项按数学含义去重。** 数值、公式及其实际作用范围、规则族或联合条件与正确答案等价时不能作为错误选项；不能只比较显示字符串。不能可靠构造不同答案时减少选项，不填同值干扰项。
4. **相反输入不称为「左右」。** 明确说「互为相反数的输入」「$x$ 与 $-x$」或「一个端点与它的相反数」，避免学生把正负或映射关系误当成卡片布局位置；趋近零点时明确 $x<0$ 或 $x>0$。
5. **选项写明对象与范围。** 例如「$x<0$ 时 $f(x)=x^2-x$」，不能只放一个多项式；区分 $f(-x)$ 与 $f(x)$、原目标与参数子目标。非唯一答案写明哪个值自由、哪些分支已确定。
6. **完整推导只保留简洁数学式。** 保留范围、等式、必要不等式与零点依据；教学解释放在当前问题、提示或反馈中，不把长段说明重复写进完整推导。简洁不能省略决定答案有效性的条件。

## 8. 必要测试与真实验收

### 8.1 数学与表示覆盖

原题金标见 §2；下表是机制回归材料，不新增原题，也不计作独立留出。

| 机制 | 例子与预期 | 核查点 |
| --- | --- | --- |
| 负侧已知 | 偶函数域为 $\mathbb R$，$x\le0$ 时 $f=x^2-x$，求正侧：$x^2+x$ | 不把代码写死为“已知正侧” |
| 奇函数跳跃 | 域为 $\mathbb R$，$x>0$ 时 $f=x+1$：负侧 $x-1$，零点 $0$ | 无连续性假设 |
| 偶函数自由零点 | 同一正侧规则，改为偶：非零处 $\lvert x\rvert+1$、$f(0)=c$；$f(-2)=3$ | 目标可确定而全域规则不唯一 |
| 零点冲突 | 奇函数域为 $\mathbb R$，$x\ge0$ 时 $f=x+1$ | 矛盾；不能删零点或改为 $>$ |
| 域不含零 | 奇函数域 $\mathbb R\setminus\{0\}$，正侧规则 $1/x$ | 负侧 $1/x$；$f(0)$ 无定义，不补零 |
| 范围未覆盖 | 偶函数域 $[-3,3]$，$[1,2]$ 上规则为 $x^2$ | $[-2,-1]$ 同式；$f(-2)=4$，$f(3)$ 未定，$f(4)$ 无定义 |
| 有限域 | 偶函数域 $\{-2,-1,1,2\}$，仅给 $f(1)=3$ | $f(-1)=3$，$\pm2$ 成对自由；不拟合多项式 |
| 重叠检查 | 奇函数域 $[-2,2]$，$[-1,2]$ 上给 $x^2$ | 零点虽满足，$\pm1$ 冲突；不能只查零点 |
| 相容重叠 | 上例改为偶函数 | 全域 $x^2$，一致重叠可规范化，不当成多值 |
| 约分孔洞 | 偶函数域 $\mathbb R\setminus\{-1,1\}$，非负侧给 $(x^2-1)/(x-1)$ | 原域内可写 $\lvert x\rvert+1$；$\pm1$ 仍排除 |
| 局部规则非法 | 上例改为完整域 $\mathbb R$，并明确所有 $x\ge0$ 都适用原分式 | $x=1$ 处冲突，不能自行去掉该点 |
| 根式反射 | 偶函数域 $(-\infty,-1]\cup[1,+\infty)$，$x\ge1$ 时为 $\sqrt{x-1}$ | 全域 $\sqrt{\lvert x\rvert-1}$，两个端点均取得 |
| 奇根式 | 奇函数域 $\mathbb R$，$x>0$ 时为 $\sqrt{x}$ | 负侧 $-\sqrt{-x}$、零点 $0$；不能写 $\sqrt{x}$ |
| 退化域 | 奇函数域 $\{0\}$ | 唯一值 $0$；偶函数同域未给值则自由 |
| 双函数加减 | $f$ 奇、$g$ 偶，$f-g=x^3+x^2-1$ | $f=x^3,\ g=1-x^2$；不能丢 $g$ 前负号 |
| 零系数 | $\mathbb R$ 上 $f$ 奇、$g$ 偶，$0f+g=x^2$ | $g$ 已定；$f(0)=0$，$f(1)$ 未定 |
| 同性质退化 | 两奇函数满足 $f+g=x$ | $f(2)+g(2)=2$；单个 $f(2)$ 未定 |
| 零行与矛盾 | $0f+0g=0$／$0f+0g=1$，关系域非空 | 前者无新增约束，后者矛盾 |
| 重复项 | 奇函数，$f(2)=5$，求 $f(2)+f(-2)+f(2)$ | $5$，同输入两次出现不能去重 |
| 只知组合 | A13 及变式要求单独求 $f(1)$ | 原目标 $-3$ 唯一；单值不唯一且能构造满足条件的函数 |
| 关系域小于函数域 | $\mathbb R$ 上奇 $f$、偶 $g$，仅在 $x\ne0$ 给 $f+g=1/x$ | 非零处 $f=1/x,g=0$；$f(0)=0$，$g(0)$ 自由，不删原域的零点 |
| 参数子任务 | A15；另有多个参数候选的组合目标 | 原目标继续求值；不同候选分别回验，不取首个结果 |

| Review 问题 | 修复后的约束 |
| --- | --- |

| 根式化简后遗漏原定义条件 | 从未化简的源 AST 收集每个被开方数和分母，求解、验证都检查原范围；相消、乘积化简不能消去限制 |
| 多条恒等式仅分别检查，或只在目标点检查 | 按全部关系范围及反射范围细分，同时检查整组线性关系；目标点恰好不冲突也不能掩盖其他输入处的矛盾 |
| 不同偶函数在零点被合并成同一个未知量 | 每个函数有独立的零点未知量；如偶函数 $f,g$ 满足 $f-g=2$ 可以成立 |
| 合法有理式约分后无法通过运行确认 | 在已验证的原范围上比较恒等关系，保留原域孔洞；不再用展开式的字面相等判定 |
| 数学已支持的根式关系在教学卡报错 | 源 AST 展示支持平方根和绝对值，同时保留原式和适用范围 |

新增机制支持与验收入口：

- **多条局部规则：** 补全路线至多 6 条，使用现有局部关系与 `∀x∈I:f(x)=…` 记法，不新增题型专用提取指令。检查已知规则的交叠、镜像交叠和端点相容，再分段反射、合并；每条相关规则分别生成教学卡。点值路线也消费带范围的全称关系。
- **绝对值：** 固定一次、二次多项式的绝对值及受控算术组合。恒等比较按绝对值内部表达式的符号划分，不能因 $x>0$ 就将 $|x-1|$ 换成 $x-1$；干扰项按当前范围内的数学含义去重。
- **既奇又偶：** 消费已有 `parity(f,both)` 事实，要求所有已知值为零，并确定未给出规则部分的值也为零；值目标与完整解析式均可完成。
- **实二次代数数：** 有限端点、点值输入和关系实例化保持精确，覆盖 $f(-\sqrt2)$、$[-\sqrt2,\sqrt2]$ 等情况；题面范围兼容根号、分式、集合差的 TeX 写法。
- **自由零点：** 偶函数只给严格正侧规则且未给零点值时，完整结论写明 $f(0)=c$（$c\in\mathbb R$，不能唯一确定），不擅自赋值。
