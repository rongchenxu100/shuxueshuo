## 学生流程

1. 读题明确“按要求平移，再选择图像”；预连线选法卡突出题给的平移方向和距离。
2. 向左平移 2 个单位：由 `y=|-x²+1|+2` 得到 `y=|-(x+2)²+1|+2`。确认后显示移动前的虚线和移动后的实线。
3. 向下平移 3 个单位：从上一步的图像继续，得到 `y=|-(x+2)²+1|-1`。干扰项分别对应上下方向相反、把竖直平移放到绝对值里面。
4. 总结三个点：`(-1,2)→(-3,-1)`、`(0,3)→(-2,0)`、`(1,2)→(-1,-1)`。完整推导展示坐标变换和公式，不用操作说明替代数学过程。
5. 对照四幅原图选择 C。作答时点击图片即选择；放大使用独立按钮，沿用 G1 已有交互。

两次平移共用坐标窗口；后一小步从前一步的完成图开始。坐标标签避开横轴刻度。完成态保留前后图和三个点的对应。

## 实现边界与验证

目标合同在 `select_function_graph` 上增加有序 `transformations`，保留移动前的 `expression`。原文锚定同时核对方向、距离与顺序；漏掉额外平移、翻折等操作时不匹配。G3 选项只接收受控转折点、对称性和方向事实，不接收可执行表达式代码。

首轮支持固定有理系数、具有两个不同有理零点的 `|p(x)|+c`，定义域为全体实数；一次水平、一次竖直平移可任选顺序，也允许只有其中一步。有限区间、重根/无实根、无理零点以及其他变换未在此路线开放。有限端点随变换移动的既有 G1 能力仍保留，不将它冒充本批的区间支持。

精确构造与独立核验分别检查逐步多项式恒等、竖直常数、三个点的移动及全部原选项。核验器不调用构造函数。教学图沿用经过校验的多项式系数、区间和开闭合同，以二次 Bézier 精确显示，不从采样点判选项。
