# 学生讲解模式：我来讲解

该模式是 Q12 的独立本地实验，页面为 `/1/q12/explain/` 和 `/1/q12/explain/page/`，不作为正式拍题课程的默认入口。运行和当前协议见[会话上下文](student-explanation-context-design.md)。

## 体验与职责

学生选择或表达下一步操作，模型生成局部推导、后继状态和下一批候选。页面展示操作、关键变化和详细推导，支持追问、撤回与分支。参考解法仅供模型理解，不直接计作学生已表达或已掌握的证据。

代码检查结构、身份、版本、幂等和状态提交；当前数学推理由模型负责，结果标记为 `llm_generated`，不显示“已验算”。独立符号验证、语音与正式产品接入属于后续扩展。

## 验证要求

检查单次操作边界、非法响应拒收、重复提交、撤回与分支隔离、未来答案不提前进入状态、页面数学排版和错误提示。实验验证与正式静态练习、图谱求解、真实供应商及生产环境分开报告。
