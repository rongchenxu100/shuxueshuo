## 1. 方法总览、范围要求与开发批次

本型的任务是从条件恢复未知函数的规则，必要时再计算题目所求数值或求不等式解集。它与“已知完整规则后代入求值”不同，也不把“知道若干函数值”理解成已经知道全函数。

### 1.1 学生选法：五种方法

**本批题按五种教学方法组织：待定系数法、换元法、配凑法、构造方程组法、赋值法。** 这是本批教学分类，不宣称求解析式只有这五种解法。原稿的 A0—A3、B、C、D 是开发批次，不能用批次名称代替方法说明。

| 方法 | 什么条件提示用它 | 核心动作 | 本批推荐采用的题目 |
| --- | --- | --- | --- |
| 待定系数法 | 明确给出 f 是一次函数、二次函数等已知类型 | 设满足类型限制的一般式，代入条件，比较系数并保留全部候选；按原目标继续求值或解不等式 | B04、B04-v、W01、W10、W12，共 5 道 |
| 换元法 | 给出 `f(g(x))=h(x)`，容易由整体输入 t=g(x) 表示原变量 | 令 t=g(x)，确定 t 的范围，合法逆代，把右式全部改写成 t 的式子 | B05-v1、B05-v2、W09、W11，共 4 道 |
| 配凑法 | 给出 `f(g(x))=h(x)`，右式容易直接整理成 g(x) 的组合 | 将右式配成 `H(g(x))`，由整体输入的覆盖范围得到 `f(t)=H(t)` | B05、B05-v3 的解析式目标、W02、W04，共 4 道 |
| 构造方程组法 | 同一关系中出现 `f(x)` 与 `f(−x)`、`f(1/x)`、`f(c−x)` 等 | 作合法的输入替换，得到新的关联方程，联立消去另一个函数值 | B06、B06-v、W03、W05、W06、W07、W14，共 7 道 |
| 赋值法 | 条件对两个变量恒成立，可选择特殊值消去变量或形成同类项 | 合法取 x=0、y=0、x=y 等，推出候选后回验完整原关系 | B07、B07-v，共 2 道 |

上表按推荐主方法归类，合计 22 道，不能理解为每题只有一种合法方法。逐题的可选方法见 §2.2。例如 B05、W02、W04 也可以换元；B05-v2、W09、W11 也可以配凑。B05-v3 的 f(0) 目标可直接令原变量 x=1 求值，不必先求全解析式；这一步与后问采用配凑法分别记录。W10 的主方法是待定系数，恢复二次函数后调用既有二次不等式能力，完成原题所求的解集。

**图谱层也按五个独立方法节点建设**，不再沿用原稿“四个方法族、五种教学解法”的组织方式。换元法用 `method-function-substitution`，配凑法用 `method-function-matching`；两者可以共享范围、恒等验证和结果协议，但各有选法依据、执行轨迹与教学步骤。A0 首批只开放换元法，其余方法随对应批次逐项建设。完整新增范围为 **5 个方法节点、1 个技能节点、1 个选法判断节点**，详见 §3.2—§3.4；这些是设计增量，不是 P0 已登记或已可执行的能力。

### 1.2 不统一把“求定义域”作为第一道解题步骤

**所有方法都必须检查输入和操作是否合法，但不要求所有题都先独立求一次 f 的定义域。** 共同的开头是读清已知条件与目标、确认范围约束，再根据题目选择方法。范围是否成为显式教学步骤、出现在哪里，由当前推导需要决定。

这里须区分三个对象：原关系中的变量 x 可以取哪些值；整体输入 t=g(x) 可以取哪些值；题目是否另外给出了 f 的完整定义域。对 `f(g(x))=h(x)`，前两个分别是 D 与 g(D)，通常不相同；g(D) 只是该关系直接约束的 f 的输入范围，也未必等于 f 的全定义域。

| 方法 | 推荐的第一项核心推导 | 范围检查放在哪里 |
| --- | --- | --- |
| 待定系数法 | 由已知类型设 `f(x)=kx+b`、k≠0，或二次一般式 | 在读题中保留题给域与类型条件；本批 R 上的多项式题不另设“求定义域”关卡。若题给限域或复合合法性有额外要求，代入前须检查 |
| 换元法 | 识别整体输入并令 t=g(x) | 根式／分式的原限制先明确；t 的范围与换元同步确定，尤其在平方、选逆分支前检查符号。简单仿射输入遍历 R 可合并说明 |
| 配凑法 | 找到 g(x) 与右式的恒等结构 | 代数变形前保留原式限制；g(D) 的完整覆盖可在配凑后、写最终规则前证明，不强迫一开始就完成值域计算 |
| 构造方程组法 | 找到能互换两个函数输入的替换 | 作替换前核对它把合法输入映到合法输入。例如 x≠0 时才可把 x 换成 1/x；原域为 R 时换成 −x 无须另做求域题 |
| 赋值法 | 找到能消去变量的赋值 | 每次赋值前确认所取值在条件作用域内。题给任意实数 x、y 时，可直接令 x=0；不能在非零域条件下照搬令 x=0 |

例如 B05-v2 中先明确原变量 x≥0，再令 t=√x+1，得到 t≥1；这两个范围都要在教学中显式区分。W01 已给一次函数，应直接设 `f(x)=kx+b`、k≠0，而不是插入一道没有新判断的“求定义域”。B05-v3 中先保留 x≠0，配出 `(x−1/x)²+2` 后再证明 `x−1/x` 遍历 R，同样是完整解法。

系统始终携带并验证范围，但已经给出或没有新判断的范围可以只展示条件标签、合并说明或折叠。需要学生作出的关键判断——如根式换元后的半轴、分式输入的禁取值、非法赋值——才安排相应交互；不生成所有方法共用的固定“先求定义域”答题关卡。

A0 是首个实施批次。A1、A2、A3、B、C、D 的机器预算和语法范围已在各自验收记录中冻结。D 限制 AST 最多 192 个节点、深度 16、6 个不同函数调用、固定有理系数及全实数对作用域；额外条件与限域不进入首批赋值执行。A2 保留原分母的全部禁取点并映射到新变量，包含约分消去的禁取点；当前限定最多 4 个有理禁取点。上表记录建设顺序和必须满足的数学要求。A0 不接受额外人为限域、参数系数、嵌套根式、多未知函数或多条相互约束的函数恒等式；识别保留这些原条件，并报告范围缺口，不能删掉它们凑成首批结构。

A0 的 a=0 不进入可逆换元执行。该输入不能除以 a，也不能误报出一条全半轴解析式：若右侧非恒定，关系矛盾；若右侧恒定，仅约束 f(b) 的一个值。首批至少返回明确的适用性拒绝／信息不足诊断；一般退化函数约束的完整求解不作为 A0 开放能力。

## 2. 原题、金标与来源

### 2.1 首题 B05-v2

题源为[图 4 原页](../internal/senior-high/source-images/function-representations-planning-20261030/source-image-04.png)中“变式 2”。原题：

> 已知 f(√x+1)=2x+1，则 f(x)=____。

规范输入必须保留 `f(√x+1)`，不能误写成 `f(√(x+1))`；原题没有给出 f 的全域，也没有声明 f 是二次函数。题面右侧没有 √x 项，属于 A0 中 v=0 的分支。

推荐教学解法：由根式得原变量 x≥0；令 t=√x+1，得 t≥1、x=(t−1)²。于是

$$
f(t)=2(t-1)^2+1=2t^2-4t+3,\qquad t\ge1.
$$

任取 t≥1，取 x=(t−1)²≥0，有 √x+1=t，说明覆盖整个 `[1,+∞)`。把候选代回题给关系恒得 2x+1。最后可将绑定变量 t 改名为 x，写成 **f(x)=2x²−4x+3，x≥1**，并说明题给关系确定的是这个范围上的规则。

不能因候选式为多项式就把它的自然域 R 当成题目已经确定的 f 的定义域。若后续题明确声明 f 在 R 上定义，同一关系仍不足以确定 x<1 上的规则；这种“全域请求信息不足”与“范围内规则恢复成功”应分别表达。

允许配凑路线：`2x+1=2(√x+1)²−4(√x+1)+3`，仍须给出整体输入范围和覆盖依据。A0 首先实现换元路线；尚未实现的配凑路线只能显示为暂未开放，不能被标成数学错误。

### 3.3 新增技能与已有技能的分工

本批只新增“多项式恒等式比较系数”这一项技能。已有“化简”可以展开并合并同类项，但“恒等成立，所以同次幂系数相等”有独立的前提、输出和数学依据，不能只用化简步骤冒充。

| 方法 | 复用／扩展的已有技能 | 本型需要补齐的支持 |
| --- | --- | --- |
| 待定系数法 | `skill-simplify`、`skill-equality-transform`、`method-elimination`、`skill-solve-quadratic`，加新增比较系数技能 | 将候选函数代入原恒等式；比较系数生成方程后，另行解方程并保留类型约束和全部分支 |
| 换元法 | `method-substitution`、`skill-expression-defined`、`skill-equality-transform`、`skill-simplify` | 整体输入可出现在未知函数调用中；保留原变量域、整体输入范围及逆代条件。求范围按真实任务调用已有能力 |
| 配凑法 | `method-complete-square`、`skill-simplify`、`skill-equality-transform` | 用配方与恒等整理得到 `h(x)=H(g(x))`，方法负责识别整体输入并证明覆盖。已有配方技能已含 `x²+1/x²=(x−1/x)²+2` 的例子 |
| 构造方程组法 | `method-elimination`、`skill-equality-transform`、`skill-simplify` | 将关联函数值作为待消去的量；扩展消元的输入绑定和方程组证据，保留行列式为零等分支 |
| 赋值法 | `skill-equality-transform`、`skill-simplify`，必要时调用消元 | 给等式推导补充“对全称关系作合法代入”的操作及依据；区分原关系推出特例与特例推出原关系，最终由方法回验完整关系 |

比较系数技能的输入为已整理的多项式恒等关系、所比较的变量、系数中的参数及恒等作用域；首批支持关于该变量次数不超过二、在 R 上恒等的情形。输出为所有同次幂的系数等式，缺项按零处理，并附带恒等条件和依据引用。它不负责选择函数类型、解出系数、恢复函数或验证整题，这些由外层方法及其他技能完成。

例如 W01 先由一次函数类型设 `f(x)=kx+b，k≠0`，代入得到 `k²x+(k+1)b=4x+6`。新技能输出 `k²=4`、`(k+1)b=6`；后续才解出两组系数并回验。仅在一个或几个取值点成立的等式不能按这份全称契约直接比较系数；B 批同时补齐多项式恒等系数判定的知识依据和反例。

上表的“复用／扩展”要求检查实际输入输出及绑定。C 已为 `method-elimination` 补充关联函数值消元、为 `skill-equality-transform` 补充恒等关系的合法全称代入；D 已补齐二元关系赋值、必要常数与函数值求解及完整原式核验，均有实际公共调用与数学验证记录。选择 `x=0`、`y=x` 等有用代入属于赋值方法的决策，不另外造五个与方法同名的技能；范围检查、回代验证也不因每条路线都使用就各建一份节点。

### 3.4 一个选法判断节点，五个可重叠的方法分支

已新增 `rule-function-formula-method`，沿用现有 `kind=judgment_rule`、`subtype=method_selection`。输入为未知函数的题给类型、原恒等关系、量词／作用域和原目标；输出为每种方法的适用依据、可执行状态及推荐。以下五种方法均已在 A0—A3、B、C、D 的声明范围内开放：

| 题面结构与准入检查 | 对应方法 |
| --- | --- |
| 题给一次／二次函数类型，可设受控一般式，代入后的系数约束在声明范围内 | 待定系数法 |
| `f(g(x))=h(x)` 的整体输入属于已支持的逆代结构，范围与逆代限制可核验 | 换元法 |
| `f(g(x))=h(x)` 可由受控恒等整理凑为 `H(g(x))`，对应输入覆盖属于已支持结构 | 配凑法 |
| 出现 `f(x)` 与 `f(φ(x))`，替换在原作用域内合法，φ²=id，关联方程属于声明范围 | 构造方程组法 |
| 全称二元关系可作已支持的合法赋值，消去变量或形成可解的关联关系 | 赋值法 |

各分支分别检查，不用“命中第一条就停止”的互斥分流。B05-v2 的换元与配凑都可以是正确选法；推荐换元不使配凑变错。数学上适用但尚未实现的路线注明暂未开放；无法确认适用性的输入保留未知，不能把能力缺口判成学生数学错误。候选匹配只做受控结构与前提检查，不读取题号、金标或提前恢复出的答案；全式回验和完备性证明留在执行阶段。

这是一个公共选法节点，不是每题强制出现五个选项，也不是新增一套题型识别节点。每题按已核验的适用性和开放状态投影；方法内部的范围、除数非零、特殊值是否合法等判断仍属于局部步骤，不各自新增公共判断节点，更不增加统一的“先求定义域”关卡。

### 3.5 学生可视化：从题目线索看到方法与第一步

选法判断节点提供一张“看结构，选方法”的导图。默认展示四类线索与五种方法；“已知复合函数的解析式”同时连向换元和配凑，不画成五个互斥的是／否分支。每条路线只放三层信息：**题目里看见什么 → 可尝试的方法 → 第一步怎么做**，方法详情和完整解答随后展开。

| 可视线索 | 方法 | 第一动作标签 |
| --- | --- | --- |
| 给了函数类型：一次／二次函数 | 待定系数法 | 按类型设一般式，代入后比较系数 |
| 给了整体输入 `f(g(x))=h(x)`，反解方便 | 换元法 | 令 t=g(x)，反解后代入右式 |
| 同一整体输入，右式容易配形 | 配凑法 | 把右式凑成 H(g(x)) |
| 出现关联函数值：f(x) 与 f(−x)、f(1/x)、f(c−x) | 构造方程组法 | 替换输入，得到第二个方程并联立 |
| 对任意 x、y 成立的二元关系 | 赋值法 | 试 x=0、y=0、x=y 等合法代入 |

两种教学使用方式共用同一判断结果：

- **学习总览／例题讲解**：可切换代表例题，突出题干中的依据、对应连接及适用方法，同时展示具体第一动作；方法旁以“先试”“也可选”区分推荐与其他正确路线。B05-v2 同时突出换元与配凑、推荐换元；B05 仍突出这两条路线、推荐配凑，让学生理解方法重叠与推荐理由。此处是教学示例，切换题目不计分。
- **当前题自己做**：先显示通用线索、预先连接的方法和原题，学生直接点选方法；无需另选线索或自己连线。提交前不自动突出本题正确路线、推荐方法或具体推导结果。提交后保留完整关系图，突出本题所选分支，再进入所选方法。范围及最终解析式仍受原步骤的答案显示约束。

正式接入时，图上的连线和状态从 §3.4 选法契约投影，关联原题的 `source_ref` 与方法 ID；示例预览中的人工对应表不能进入生产判型或评分。未关联的其他路线保持中性，不因没有突出就标成错误；数学适用但当前不可执行的方法注明“暂未开放”，未知状态单独说明。所有已验证适用的方法均可选择，推荐标签不参与对错评分。

桌面横向排列线索和方法，整体输入的两条连接并列可见；窄屏保留分支对应并允许标签自然换行，不整体缩小文字。颜色同时配合文字状态与连接表达，不能只靠颜色辨别。范围提醒为“范围随方法核对”，各方法步骤再解释必要条件，不把定义域画成所有路线的必经解题关卡。

早期设计预览覆盖总览、五道代表例题切换、同题多方法和推荐变化。本轮已把 §3.5.1 的线索—方法连线接入正式题页与拍题的共同判断投影；当前适用性核验声明 A0/A1/A2 输入族，不把设计预览的人工示例表当作生产判型依据。

#### 3.5.1 实际判断卡：线索卡片、方法卡片与自动连线

FR-T1 的当前题判断卡采用**行列对齐的线索卡片与方法卡片，加自动连线箭头**。表格布局帮助比较，箭头表达“这条依据支持这种方法”。已有含参二次不等式选法平面用两个明确维度定位（主元是否取全实数、参数是否有给定范围）；本型的结构线索可重叠，同一线索也可能支持两个方法，采用关系连接展示。

## 4. 题意、目标与结果契约

### 4.1 原始条件与未知函数

S2 同步扩展提取 schema、记法 schema／compiler、原文规则、公共题目身份与阶段一特征。下表描述完整设计语义；A0 已实现 `find_function_formula` 的 `function`、`variable`、`relation` 及可选 `relation_domain`、`declared_domain`、`requested_domain`、`function_type`。类型字段会保留，但 A0 不接受题给一次／二次类型约束；数值、多关系与候选集合等仍待后续批次。

| 对象 | 必须保留的信息 | 禁止的提前推导 |
| --- | --- | --- |
| 未知函数声明 | 函数身份、一元实函数、题给一次／二次类型、题给全定义域（若有） | 从结果形状反推函数类型；替未知函数编具体表达式 |
| 恒等关系 | 完整左右式、绑定变量、量词及关系有效输入域、原文引用 | 在提取阶段计算 `g(D)`、系数解或恢复式 |
| 原输入合法性 | 显式量词域与原式的自然限制分开记录；用户批准的修订单独引用 | 未经用户修订就静默缩小显式域；忽略常量乘法中的非法输入 |
| 求解析式目标 | 建议 `find_function_formula`，指定未知函数、原目标引用和请求范围（若原文给出） | 改写为求值域，或把求解析式伪造成已知函数的定义 |
| 所求数值目标 | 沿用／扩展 `find_value`，保留具体调用；关联其可见未知函数条件 | 因只问 f(1) 而丢掉一次函数类型与复合恒等关系 |
| 所求不等式解集目标 | 沿用不等式目标语义，保留 W10 的 `f(x)>0`、二次类型、差分和初值条件 | 提取时提前求出二次式；只返回中间解析式便将原目标标为完成 |

自然合法域是可由原式证明的约束；显式量词若包含非法点，须保留冲突。题给“恒成立”但未写全量词时，依据共同规则补全的内容须有来源标记，与直接转录区分。各小问只消费本作用域和祖先条件。

同一函数不同字母与绑定变量的规范化沿用公共身份机制，函数参数改名不改变数学身份；更改根式作用范围、显式域、量词或类型必须改变身份。题源号、答案、手写批注不进入生产路由条件。

### 4.2 恢复结果不是普通裸表达式

建议结果类型为 `function_formula_result`，至少包含：

- `function_ref`、规范绑定变量、原目标 `target_ref`；表达式使用受控 AST，不使用可执行字符串。
- `source_domain`：原恒等式变量的有效范围；`determined_domain`：已证明由条件确定规则的函数输入集合；`declared_domain`：题给 f 的全域或空缺标记。三者不得合成一个 domain 字段。
- `candidates`：全部已验证函数规则；每项包含表达式、适用域、类型约束和证据引用。B 批有限多解按无序集合比较，不因式子顺序改变评分。
- `coverage`：范围、覆盖和同输入单值性证据；`identity_verification`：在原合法域上的全称回验；`completeness`：无漏解或唯一性证明。
- 数学结论：在确定范围上唯一、有限多个候选、无满足函数、题设不足以确定请求范围。能力未知／预算超限／验证失败属于执行状态，不伪装成“无解”。

原题只问解析式而未给全域时，B05-v2 的课程提交要求是“式子＋确定范围”；可写 f(x) 或 f(t)，变量作绑定改名处理。若原文明确要求 R 上的完整解析式而关系仅覆盖半轴，应说明域外不确定，不能将成功的半轴规则包装成全域唯一函数。

只求数值的 B04 保持标量目标；候选恢复是该路线的内部证据。全部候选在所求输入处都有定义且值相同，才给唯一值；候选值不同则按原目标语义报告不唯一。B05-v3 的 f(0) 可直接合法赋值求出，解析式另行恢复；两目标可独立重推，不强制创建跨问依赖。

W10 保持不等式解集目标：先由系数条件与 f(0)=0 唯一恢复 `f(x)=−3x²/2+7x/2`，回验差分和初值，再调用现有二次不等式能力得到 `(0,7/3)`。教学与终答评分都以原解集为准；0 和 7/3 不取到，只求出解析式不算完成原题。

## 5. 方法契约与独立验证

### 5.1 A0 换元恢复

已实现的方法 ID 为 `method-function-substitution` 和 `method-function-matching`，分别代表**换元法求解析式**和**配凑法求解析式**；两者共用范围和结果协议，各有独立执行与验证，不共用方法身份。A0 输入为通过结构准入的未知函数与恒等式，输出带确定范围的单一规则；有限候选集合等完整结果形态在后续批次扩展。

对 `f(a√x+b)=ux+v√x+w`，a≠0：

1. 由原 AST 证明 x≥0；保留限制来源，禁止先约掉 √x。
2. 令 t=a√x+b，得到 `J=[b,+∞)`（a>0）或 `J=(-∞,b]`（a<0）。
3. 得 √x=(t−b)/a，并要求 `(t−b)/a≥0`；进而 x=((t−b)/a)²。这里的符号条件不能在平方后消失。
4. 在 J 上推出 `F(t)=u((t−b)/a)²+v(t−b)/a+w`。
5. 任取 t∈J，以 x=((t−b)/a)² 为见证，证明输入重新映射为 t，完成覆盖；由每个 t 都有原输入，恢复规则在 J 上唯一。
6. 在原域回验 `F(a√x+b)=ux+v√x+w`，输出函数式、确定范围及结论强度。

首批数学预算建议：单函数、单变量、单关系、固定有理系数，AST 节点≤128、深度≤16、系数分子分母位长≤64；原式中根式为 √x，右式可无展开但须在预算内规范化到 ux+v√x+w。具体预算在实现中与项目共享上限取更严格值，准入、执行和验证一致，预算外返回缺口。

独立验证器从**原约束 AST**读取 a、b、u、v、w 和域，不信任执行器提供的逆函数／像集：使用 s≥0、x=s²，将 `candidate(a·s+b)−(u·s²+v·s+w)` 做多项式恒等零验证；独立根据 a 的符号重建 J，并验证每个 t∈J 的非负 s=(t−b)/a 见证。这样同时校验恒等、范围与覆盖，不以几个采样点代替证明。

### 5.2 后续方法

| 方法候选 | 子能力与分支 | 独立收束 |
| --- | --- | --- |
| 换元法的仿射／分式路线（A1、A2） | 令整体输入为 t，合法逆代并记录原式限制；复用换元、等式变形与范围能力 | 验证原式恒等、输入像集与可达性；分式化简不能丢失原禁取点 |
| 配凑法，拟 `method-function-matching`（A3；同时补齐前批题的配凑路线） | 将右式表示为整体输入的多项式／已准入表达式，不必先从 t 解出 x；非单射时须证明同一输入的输出一致 | 同样验证恒等、像集准确和每个像值可达；不能任选一个逆分支。与换元法共用范围及验证能力，方法身份和教学步骤独立 |
| 待定系数法，拟 `method-function-coefficients` | 一次设 kx+b、k≠0；二次设 ax²+bx+c、a≠0。有限分支全部解出，单独处理退化 | 从原关系重新比较系数并检验类型；参数方程组解集完整性必须证明。不能强行把无穷候选写成有限集合 |
| 构造方程组法，拟 `method-function-equation-system` | φ(x)=−x、c−x 或 1/x，原域须在 φ 下封闭，φ²=id；系数矩阵行列式为 A²−B² | 非零行列式可验证 `f(x)=(A H(x)−B H(φ(x)))/(A²−B²)`。退化时先核验一致性及固定点，不把欠定或矛盾一律当零解 |
| 赋值法，拟 `method-function-assignment` | 受控枚举 x=0、y=0、x=y、x=−y 等合法代换，保留推导和常数来源 | 将候选代回原二元关系，做全称多项式恒等校验；每步是必要条件，最终回验给充分性 |

构造方程组的 φ 固定点须满足原式。W14 的指数表达式仅作为可合法代换的已知右侧原子，允许恒等线性组合验证；不由此打开一般指数函数求解。A3 中 `x−c/x` 的覆盖须有证明：对任意 t，方程 x²−tx−c=0 有非零实根（c>0），配凑才能给出 R 上的完整规则。

现有 `method-matching` 是定和／定积配凑技能，`method-variable-swap` 是量词更换主元方法，均不能仅凭名称用于本型。`method-function-evaluation`、`method-substitution`、`method-elimination` 和公共代数技能按真实输入输出复用；首次需要的缺失操作先补公共绑定，不按题号加旁路。

## 6. 教学投影与双入口交互

首题课程围绕以下关键决策编排，D1—D3 的读题／判型／选法按共用流程适度合并；最终卡数由交互契约决定，不预设一项等于一张卡。下表是 B05-v2 的换元路线，不作为其他方法的固定步骤模板；范围判断按 §1.2 安排，不统一增加“先求定义域”关卡。

| 教学环节 | 学生回答 | 图形／反馈与证据 |
| --- | --- | --- |
| 识别整体输入 | f 的输入是 √x+1 | 原式局部高亮；选成 x 或 √(x+1) 时指明括号位置 |
| 选择思路 | 将整体输入换成 t | 适用方法可选择；配凑未实现时注明暂未开放 |
| 变换输入范围 | x≥0，所以 t≥1 | 双数轴／对照表区分原变量与函数输入；提交前不揭示目标范围 |
| 逆代 | √x=t−1、x=(t−1)² | 要求 t−1≥0；只写平方结果不能自动视作范围验证通过 |
| 改写函数规则 | `f(t)=2(t−1)²+1` | 允许保持配方式或展开式，评分按域上恒等处理 |
| 核对覆盖与回代 | 每个 t≥1 都能由合法 x 达到，代回满足原关系 | 解释构造见证，符号恒等验证留在证据中；不要求学生手算冗长展开 |
| 原题收束 | `f(x)=2x²−4x+3，x≥1` | 表达式与范围分别评分；仅答式子不能完成整题 |

自己做模式不提前展示推荐答案、目标域或最后解析式；看 AI 解题由同一证据逐步回放，进度独立。一个公式的不同等价形式、绑定变量改名和同一集合的等价写法应接受；遗漏 x≥1、写成 x≥0、全实域外推、根式括号错误必须给具体反馈。

常规代数化简可 `fold`，原输入合法性和整体范围用 `light`，首次选法及不易发现的覆盖依据用 `full`。每层子调用返回原目标有独立证据；不得让后台求解完成直接替学生通过关键决策。

专题与拍题共同使用新结果投影、前后端评分和版本绑定。B05-v2 已使用正式题身份 `function-representations-b05-v2-r4` 和页面 `/topics/function-representations/variant02/`，编入“求函数的解析式”的换元法小组，计入专题题量与学习记录。实验预览身份 `function-representations-formula-a0`、页面 `/lab/graph-walk/function-representations-formula-a0/` 继续独立保留；两者复用实际运行证据，预览不提交正式记录。当前四个推导判断为选择题，尚不接受自由键入的等价公式；上文自由表达式评分要求保留为后续建设项。
