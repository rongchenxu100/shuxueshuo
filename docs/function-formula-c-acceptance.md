## 声明范围

- 原题求未知函数解析式，给出一条 `a f(x)+b f(φ(x))=H(x)` 恒等关系。两个调用属于同一个未知函数；a、b 为固定非零有理数。不能删除额外条件或用右式次数猜函数类型。
- φ 支持 `c−x` 与 `k/x`，c 为有理数，k 为非零有理数；确定性核验 `φ(φ(x))=x`。前者的关系作用域为实数，后者为非零实数；替换后仍在同一作用域内。原题有其他限域或额外禁取点时报告不支持，不能忽略。
- H 支持次数 −2 至 2 的有界 Laurent 多项式，最多两个固定正有理底数的指数项。指数是一次式或倒数一次式；底数不超过 100，不支持嵌套指数、指数项乘积或一般指数方程。反射输入族不接受变量分母。W14 的 `10^x` 只参与代换和等式化简。
- AST 最多 128 个节点、深度 16，有理数分子／分母最多 64 位；中间表达式最多 96 个操作，右式规范化多项式最多 24 项。原分母在约分前检查，不补回原来无定义的输入。
- `a²−b²≠0` 时得到唯一的解析式，并代回原恒等关系核验；对合变换的固定点也受同一证明覆盖。独立验证重新读取原关系、替换和范围，不调用恢复答案的算法或以抽样代值证明恒等。
- `a²−b²=0` 时不相除：第二方程与第一方程恒等一致则诊断信息不足；找到精确反例则诊断无解；暂不能证明则报告一致性未证。本批没有为无限函数族生成完整交互课程。
- 明确要求更大范围、而题给关系只能确定非零输入上的解析式时，输出信息不足及已确定范围，不编造 f(0)。

## 公共能力与学生交互

本批不新增技能或判断节点。为 `skill-equality-transform` 补充恒等关系的合法全称代入及原式回验，为 `method-elimination` 补充关联函数值的联立消元与退化诊断，化简调用 `skill-simplify`。三项公共能力都有实际执行证据；题型和选法不按题号或最终答案硬编码。

共用读题、题型判断和预连线选法卡，线索“出现关联函数值”连接构造方程组法。学生直接点选方法，完成后保留节点与连线；“已知复合函数的解析式”等其他线索保持原名称。没有增加统一的“先求定义域”步骤。

方法内五步依次为：让两个函数值交换位置 → 写出第二个方程 → 联立消去另一个函数值 → 把解析式代回原关系 → 写出完整答案。第一步完成后保留两列互换表；第二步要求等号右边也同步替换；消元显示两个编号方程及所乘系数；最后保留原题非零条件。未确认时不提前填入卡片的待求结果。错答评分、完成卡和 AI 回放使用共同课程编译器。
