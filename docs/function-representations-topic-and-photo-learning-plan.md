### 3.2 四组题型

为避免与上一章 T1—T5 混淆，本文使用 **FR-T1—FR-T4**。它们是本专题分组编号，不能按题号或分组名硬编码求解。

| 分组 | 任务与判型线索 | 方法候选及复用 |
| --- | --- | --- |
| FR-T1 求函数的解析式 | 未知函数满足类型约束、复合输入或恒等关系，目标为解析式或由其确定的值 | 待定系数法、换元／配凑法、构造方程组法、赋值法；结果求值复用代入法 |

### 3.3 候选方法与职责

下列名称用于设计，不一次性登记全局 ID；每个方法在对应代表题阶段核对同名能力、`kind`、输入输出和执行注册后决定复用或新增。

| 候选／已有方法 | 组织的关键步骤 | 必须验证的事实 |
| --- | --- | --- |
| 待定系数法 | 按已知函数类型设一般式 → 代入关系 → 比较系数 → 解出全部候选 → 回验 | 类型是题给条件；一次首项不为零、二次首项不为零；候选满足原关系且无漏解 |
| 换元／配凑求解析式 | 整体输入 `t=g(x)` → 求其准确范围 → 逆代或将右侧写成 t 的式子 → 恢复记号 | 可确定范围、单值性、原式限制及恒等关系。配凑作为同一任务的另一条路线，不另造泛化不足的技能 |
| 构造方程组法 | 选输入变换 → 写出合法的新关系 → 联立消元 → 回验 | 变换后的输入仍在条件作用域内；已声明的退化系数分支不遗漏；消元不是整题方法的全部 |
| 赋值法 | 利用对所有 x、y 成立 → 选择消去变量的赋值 → 求必要常数 → 推得候选式 → 原式全域回验 | 赋值点合法；特殊值只用于推导，最终仍验证任意变量的原恒等式 |
| 图像变换法 | 确认原图与域 → 点坐标变换或分段翻折 → 保留关键点、空实点 → 对应选项／作图结果 | 复合变换次序、水平输入范围、绝对值内外位置 |
| `method-function-evaluation` 代入法 | 给定数值由内到外，每层按当前输入选段 | 下一层根据中间值选段，不能沿用原始 x 的段；原式须有定义 |
| 分段讨论法 | 按段求解或求范围 → 与本段域取交 → 合并，返回原任务 | 原像任务合并输入集合，值域任务合并输出集合；上下文不可混用 |
| 分段建模法 | 读清计费语义 → 确定分界 → 累计前段费用 → 写模型和实际域 → 核验 | 超出部分计费与整段统一计费不同；无漏费、重计，单位正确 |
| 逐层求原像法 | 令 t=f(x) → 解外层 t 条件 → 限定合法中间值 → 解内层 x 条件 → 合并回验 | 每层都保留段域；不强制完整展开 `f(f(x))`，也不把两个逐段不等式误作同时成立 |

已核查的复用注意点：

- `method-substitution` 的真实类型为 **skill**，可提供换元步骤；不能直接冒称已具备“恢复未知函数解析式”的完整方法。
- `method-elimination` 的真实类型为 **skill**；外层构造函数关系方程组仍须组织并验证作用域。
- `method-matching` 的内容是“配凑定和或定积结构”，不能因名称相似便用于所有函数输入配凑。
- `method-variable-swap` 是量词语境的“更换主元法”，不等同于将 x 替换成 −x 或 1/x 来构造联立关系。
- `method-quadratic-interval-range`、`method-direct-range`、`method-separation`、二次／分式不等式与集合能力按实际契约复用。含参数的区间范围、像集并等于指定集合仍需上层验证。
- `skill-simplify`、`skill-equality-transform`、`skill-expression-defined`、`skill-solve-quadratic` 及已有区间、集合能力随实际步骤调用。不为“选段”“回代验根”“由内到外”预建重复技能节点。

### 4.1 FR-T1 内部顺序

1. **换元与配凑**：例 5 变式 2 → 例 5 → 变式 1 → 变式 3，结合小条 W02、W04、W09、W11 扩充。代表题得到 `f(t)=2t²−4t+3`，条件仅确定 `t≥1` 上的规则；先以此冻结函数恢复结果协议，再扩展仿射、分式及不要求显式反解的配凑。
2. **待定系数**：例 4 → 例 4 变式 → W01、W12。例 4 有两个候选一次函数，但 `f(1)` 相同；不能只保留一个候选。已知二次类型的差分题需保留二次系数非零条件。W10 不参与正式扩题。
3. **构造方程组**：例 6 → 例 6 变式 → W03、W05、W06、W14。先限定 `−x`、`c−x`、`1/x` 等已有题源中的二次作用回到原输入的变换；检查域的封闭性与系数退化。W14 的 `10^x` 作为实数输入上的已知表达式参与代换，不由此宣称指数函数求范围或一般指数方程可解。W07 待题面修订确认。
4. **赋值**：例 7 → 例 7 变式。先覆盖给定二元多项式恒等关系，选择合法赋值并完成候选全域回验；不扩大到任意函数方程。

每一小批以“数学正确 → 教学可操作 → 原图拍题 → 独立新题”收口；方法选法卡根据“已知类型、单个复合输入、成对关联函数值、二元恒等关系”等线索组织。允许多条已验证方法，不把可用换元的题强制判成只能配凑。

### 4.2 FR-T2 图像与数学同时建设

- 例 9 先支持解析式和选项图像之间的结构核对，不能只记住答案字母 A。选项顺序改变后仍依图像事实判断。
- 变式 1 的二次绝对值图像先代数确定零点、顶点、翻折区间，再绘制；求不等式时明确与水平线的交点及端点取舍。题干关系符号在正式入库前单独复核，不根据解析中的括号猜定。
- 变式 2 先写出平移后的解析式并检查关键点，避免只背“左加右减”后错误处理整体绝对值。
- 变式 3 的原函数只有示意图，不能编一个 S 形解析式替代。使用点关系 `(u,v)→(2−u,v)`、零点位置和方向变化核对选项；图形证据不足时保留识别缺口。
- `f(\lvert x\rvert)` 虽无本批独立例题，若图像变换方法声明覆盖“绝对值内外两类”，则须补边界样例和留出材料；否则首批仅开放 `\lvert f(x)\rvert`，知识介绍不等于执行范围。

| 子任务 | 代表来源 | 关键组织 |
| --- | --- | --- |
| 正向／嵌套求值 | 例 10 | 原输入选段 → 得中间值 → 重新选段；复用代入法 |
| 已知函数值求输入 | 例 10 变式 1 | 各段解方程 → 取交本段输入范围 → 求并集；无解段也保留证据 |
| 分段不等式 | 例 10 变式 2 | 先求 `f(1)` → 各段解与该阈值的比较 → 交段域 → 合并 |
| 分段函数值域 | 例 11 | 各段在其限制域上求完整像集 → 求并集，检查端点是否能由别的段补入 |
| 已知整体值域求参数 | 例 11 变式 1、2 | 区分“固定段已经覆盖全目标，只需不越界”与“固定段只覆盖部分，参数段须补足” |
| 情境建模与逆向求值 | 例 12 | 按超出部分累计费用 → 验证分段模型 → 用费用反求用量并验段 |

例 11 两个参数变式不能套同一个“最小值不低于下界”的模板。变式 1 的固定段已覆盖 `[-2,+∞)`，参数段只需落在其中；变式 2 的固定段仅覆盖 `(2,+∞)`，另段必须补足 `(-∞,2]`。必须检查参数二次项为零、开口方向、顶点位置、边界是否取得。

例 12 首先保留教材给出的阈值 180、350 和单位价格，不当成当前真实电价资料。应得到三段累计模型；费用 199 元对应 320 千瓦时。后问若直接消费前问模型，须使用已验证的同版本模型。

### 4.4 FR-T4 复合问题的教学路线

统一采用 `t=f(x)` 的中间层表达，避免先展开成很多段而掩盖主线：

1. 将原目标变为关于 `f(t)` 的方程或不等式，记录 t 作为 f 输入时的合法范围。
2. 按外层各段求 t 的候选集合，与内层 `f(x)` 的实际可达范围结合；也可将不可达候选在内层原像为空时排除，证据必须明确。
3. 把每个 t 候选或区间转回 `f(x)` 条件，再按内层各段求 x 的原像。
4. 各段结果与本段输入范围取交，最后求并并回验原复合目标。

前端应呈现 `x → t=f(x) → f(t)` 三层关系，可用水平参考线或目标带辅助。层间跳转必须携带验证证据；“求到 t”不算原题完成。给定具体 x 的例 10 是正向代入，留在 FR-T3，不因同样出现 `f(f(·))` 就误判为逆向复合任务。

## 5. 专题与拍题共同的教学要求

| 场景 | 学生真正需要作出的判断 | 共同视觉／反馈 |
| --- | --- | --- |
| 求解析式选法 | 函数类型已知吗？当前输入整体是什么？关联输入能否互换？是否有合法赋值可消元？ | 条件标签与选法卡；不用人为二维坐标装饰本任务 |
| 换元／配凑 | t 的范围是什么？右边如何完全用 t 表示？ | 原变量—整体输入—函数输出对照；域丢失时指出具体缺失 |
| 待定系数 | 哪些系数受类型约束？是否还有另一个候选？ | 关系展开与系数对照；最后回验全部候选 |
| 方程组／赋值 | 为何这样替换合法？新关系是哪一条？ | 对应输入颜色联动、两条关系或变量消去过程 |
| 图像变换 | 点怎么移动？保留哪一侧？边界是否仍取到？ | 原图与目标图叠加、关键点联动、空实点和域同步 |
| 分段常规 | 当前输入属于哪段？解出来的值是否仍属于本段？ | 输入数轴与分段公式联动；错误分支反馈关联条件 |
| 分段值域／求参 | 各段输出如何合并？整体是否还有缺口或超出？ | 分别显示输入区间和输出区间，输出集合叠加 |
| 阶梯计费 | 每一段计的是总量还是超出量？之前费用是多少？ | 累计费用表、阈值点和折线 |
| 复合逆向 | 当前求的是中间值还是原输入？ | 两层目标集合与原像，逐层完成而非跳到终答 |

沿用已有 `fold / light / full` 子方法交互原则：普通化简可以折叠，关键域与选段用轻交互，首次出现的选法或参数分类完整展开。不把每个代数操作变成必答卡，也不把关键的段域判断藏入后台。

“自己做”和“看 AI 解题”分别保存进度；方法选择、错误反馈、目标完成、刷新恢复和终答揭示两端一致。原题单选、多选、未注明选择模式沿用共用规则，后者默认精确选择全部符合项，不根据已算答案个数反写题面。

初期作图任务可用结构选择、关键点和区间输入验证；不要求学生自由手绘。若以后加拖点／画线交互，须定义服务端可验证的判定协议，不能只用前端截图或像素距离评分。

## 6. 数学边界与验收要求

### 6.1 必查边界

| 能力 | 验收断言 |
| --- | --- |
| 函数恢复 | `f(g(x))=h(x)` 只直接约束 `g(D)` 上的 f；若题给 f 的定义域更大，未覆盖部分不能凭空确定 |
| 换元单值性 | 当不同 x 得同一个 g(x) 时，h(x) 必须相同；不能以任取一个逆分支得到“答案” |
| 配凑 | 恒等关系与输入覆盖都验证；`x−1/x` 的像为 R 需要覆盖依据，不能因形式像多项式便默认全实域 |
| 待定系数 | 保留全部系数解、类型限制及原关系；无解、一个候选、多个候选分别处理 |
| 联立关系 | 替换作用域合法；分母零点排除；行列式为零时区分矛盾与信息不足，不能直接除零 |
| 赋值 | 特殊值合法且推导后回验全域；不能把试值一致当作恒等证明 |
| 图像变换 | 水平变换同时变域；负号所在位置、变换次序、绝对值内外、空实端点都验证 |
| 图像解不等式 | 临界值由精确信息确定；严格／非严格关系决定是否取交点；示意图采样不是完整证明 |
| 分段定义 | 每段原式在其声称范围内合法；缺口明确保留；重叠处输出冲突时不能假装有效函数 |
| 分段原像 | 每个分支结果与分支域取交后才求并；无解、多解、断点解、重复候选都处理 |
| 分段像集 | 每段考虑端点与顶点，最终按集合并合并；某段的开端点可能由另一段取到 |
| 值域求参 | “不越界”与“覆盖目标”是两项条件；首项为零、开口方向及极值点位置不能遗漏 |
| 复合求值／原像 | 各层分别合法；中间值重新选段；外层候选不可达时剔除；最终回到原输入 x |
| 阶梯建模 | 分段阈值和累计费用正确；实数或整数用量按题设决定，未声明不能擅设整数；逆解验段 |
| 结果等价 | 表达式连同域比较；函数候选按无序集合比较；区间并、单点和空集的评分语义一致 |

### 6.2 每个批次的五层验收

1. **内容与题意**：原图、题干／选项、条件作用域、目标与答案分离；保存完整原页和必要选题裁片；独立校核数学金标。

3. **教学双入口**：同一证据投影到专题和拍题；真实浏览器验证自己做、AI、错误输入、子方法返回、图形、终答门槛、刷新恢复及窄屏。
