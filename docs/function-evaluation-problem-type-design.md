### 1.1 分两批开放

**A 批：Q28a—Q28d，数值与表达式求值。** 四道题按原小问顺序独立开发、验收与纳题。限实数、一元显式函数、固定有理数系数；原函数体为至多二次多项式，或分子至多二次、分母为仿射式的分式。输入允许有理数、仿射式、非零仿射式的倒数加常数，以及至多两层已登记函数的复合。表达式可包含有限项加减与有理系数乘法，具体项数、AST 大小、深度和展开次数在 S0 固定共享预算。

允许的函数体包括常量和系数为零的退化情形；分母为零常量时是无效函数声明，不得作为普通函数求值。显式定义域可为有理端点区间、有限有理点集合或去掉有限个有理点的上述集合；自然定义域由原式决定。题面明确声称的定义域若含原式无意义的点，应报告条件冲突，不能悄悄删点改题。复合产生的二次分母须能精确求出合法范围，不能只支持代表题恰好无实零点的情况。

**B 批：Q29b，定值判断与配对求和。** 仅取原 Q29(2)，完整保留已知函数定义及两个所求。扩充 M9 内的有限函数值之和及倒数配对 `t ↔ 1/t`，不新增方法。学生按“代入试算 → 观察规律 → 验证定值 → 配对计数 → 计算剩余项 → 合计”推进。输入项由明确的有限列表、闭区间整数索引及其倒数生成，长度和索引规模受统一预算约束。必须证明配对和在实际参与输入上恒定，并验证每个出现项恰计一次；不能仅凭数值样本猜规律，也不能用“求和到 101”的题号／数字分支。

### 1.2 本轮边界

- 求给定输入的输出属于 T4；求所有输入产生的完整输出集合属于 T5。出现 `g(f(x))` 不足以判断目标，必须读题目所求。

## 2. 题源与数学金标

### 2.1 Q28：第 86—87 页例 10

共同题干：$f(x)=3x^2-1$，$g(x)=\dfrac1{x+2}$。

| 小问 | 原请求 | 数学金标与必要条件 |
| --- | --- | --- |
| (1) | 求 $f(1)$、$g(1)$ | $f(1)=2$，$g(1)=\frac13$；输入 1 分别合法 |
| (2) | 求 $f(g(0))$、$g(f(0))$ | $g(0)=\frac12$，故 $f(g(0))=-\frac14$；$f(0)=-1$，故 $g(f(0))=1$ |
| (3) | 求 $f(x-1)$、$g(1/x-1)$ | $f(x-1)=3x^2-6x+2$，$x\in\mathbb R$；$g(1/x-1)=\frac{x}{x+1}$，$x\ne0,-1$ |
| (4) | 求 $f(g(x))$ | $\frac3{(x+2)^2}-1$，$x\ne-2$ |
| (5)，暂缓 | 已知 $g(f(x))=1$，求 $x$ | $g(f(x))=\frac1{3x^2+1}$；分母恒正，令其等于 1 得 $3x^2=0$；全部合法解为 $\{0\}$ |

Q28(3) 第二个表达式化简后在 $x=0$ 看似可用，但原输入 `1/x-1` 在该点无意义，必须保留 $x\ne0$。另由交给 $g$ 的输入不等于 $-2$ 得 $x\ne-1$。两个限制来自不同位置，证据和教学反馈不能合并丢失来源。

原 Q28 五问共享两个函数定义，没有“后问须使用前问答案”的数学依赖。本轮只独立收录前四问，每道题都带上完整的 $f$、$g$ 定义；第五问仅保留原题金标作为后续参考。Q28b 内层与外层计算的顺序依赖属于同一目标内的调用证据，不能建成对 Q28a 结果的依赖。

Q28a、Q28b、Q28c 各保留两个目标，Q28d 保留一个目标；不再把每个输出拆成一道题。并列目标保留在同一真实作用域，用稳定 `target_ref` 区分；原图中的 (1)—(4) 标签可保留为真实小问，不能为并列输出再伪造 children。a—d 是本系统的来源标识，不冒称教材已有这些题号。

### 2.2 Q29b：第 87 页例 10 变式的第 (2) 问

共同题干：$f(x)=\dfrac{x+2}{x+1}$。

原第 (1) 问求 $f(2)+f(\frac12)=3$，不作为本轮独立题或前置结果。Q29b 的完整请求为：判断 $f(x)+f(1/x)$ 是否为定值，并求

$$
f(1)+f(2)+\cdots+f(101)+f(\tfrac12)+f(\tfrac13)+\cdots+f(\tfrac1{101})
$$

合法条件为 $x\ne0,-1$；在此范围上

$$
f(x)+f(1/x)=\frac{x+2}{x+1}+\frac{1+2x}{1+x}=3
$$

总和共 201 项。$n=2,\ldots,101$ 与 $1/n$ 形成 100 对，$f(1)=\frac32$ 只出现一次，因此

$$
S=100\times3+\frac32=\frac{603}{2}
$$

“定值为 3”须附其成立范围，且为整个有效范围的恒等证明，几个数值样本不能替代。Q29b 保留定值判断和总和两个目标；只完成其中一个不能标为该独立题完成。若教学用 $f(2)+f(1/2)$ 观察规律，应在 Q29b 内重新代入计算，作为引导步骤，不要求先完成原第 (1) 问，也不增加一个原题没有的终答目标。

### 4.2 输入替换与合法性

对函数 $f(u)=F(u)$ 和输入 $a(x)$，合法条件为：$a(x)$ 本身有意义，且其值属于 $D_f$。先保存这些条件和来源，再得到 $F(a(x))$；函数体未使用 $u$ 时也不能忽略前一项。

代入只替换绑定自变量节点，不能做字符串替换。调用 $f(x-1)$ 时所有绑定位置同时替换；函数内绑定变量、外层自由变量、题给参数和求和索引有不同身份。必要的内部改名保持数学等价且可追溯，不能捕获自由变量。

多函数可见上下文以稳定引用及目标作用域传入；不得把 `f` 与 `g` 的定义拼成同一函数，也不得删去真实约束来适配旧的单函数准入器。重复调用形成独立调用位置和证据引用，共享缓存仅能复用同输入、同范围、同版本的已验证产物。

数值输入一旦在某层非法，该调用及依赖目标停止并如实解释。表达式输入则返回完整合法范围；约分、通分或常量化简都不扩大原范围。诸如 $x/x$ 在化简前仍排除 0。

### 4.3 验证与完整性

数值结果以精确有理数／受支持代数数比较；表达式结果在声明合法范围内验证恒等，另外独立重建原调用合法范围。只验证结果式在若干点相等，不能证明表达式答案完整。

逆向求输入的结果协议与全解验证暂缓建设，不列入本轮测试矩阵。正向求值所需的合法范围仍须完整求解，不能以暂缓逆向任务为由省略分母禁取点或输入限制。

每个目标都有独立结果类型、完成证据和归属。拆分题完成以自身全部目标为准：Q28a—c 各两个、Q28d 一个、Q29b 两个，共 9 个；不等待 Q28(5)，也不计入 Q29(1)。这不等于原 Q28 五问或原 Q29 两问整题通过；用户上传完整原题时仍按全部实际目标统计进度。

## 5. 方法、技能与判断

### 5.1 M9 代入法

全局 ID 采用 `method-function-evaluation`。它组织完整求值任务，不等同于已有换元节点 `method-substitution`（现有注册为 `kind=skill`，不按历史 ID 前缀判断节点类型）。学生文案明确对照：**代入**是将完整输入替换已知对应规则中的自变量位置，例如把 $x-1$ 整体放入 $3u^2-1$；**换元**是另设新变量并转换关系、范围及回代。本型未实际设新变量时只称代入。

| 项目 | 契约 |
| --- | --- |
| 输入 | 来源明确的函数定义、指定数值／表达式／复合输入、原范围、目标模式及可见作用域 |
| 前置 | 函数引用可解析、非递归，结构与共享预算通过；参数已固定，目标不含未声明符号 |
| 正向路线 | 明确完整输入 → 按内到外确定合法性 → 替换全部绑定位置 → 有条件化简／计算 → 返回输出与有效范围 |
| 组合与求和路线 | 代入计算 → 观察候选规律 → 在合法范围上验证 → 配对并核对出现次数 → 计算剩余项 → 合计 |
| 输出 | 数值、表达式及合法范围、定值真假与证明或有限总和；附逐层输入、对应定义、替换位置、条件来源、配对计数及验证 |
| 子调用 | 主要复用 S3、代数化简；等式变形与二次求根仅按实际合法条件或验证需要调用，简单数值代入由 M9 内部完成 |

M9 本轮只开放正向求值、定值判断与有限求和。原式输入及分母合法性在化简前保留，条件求解沿用已有能力；涉及根式端点时使用精确比较。Q28(5) 的逆向路线及其二次／一次／恒等方程分支留待后续独立实施，不加入本轮完成门。

### 5.2 M9 内部的发现规律与配对求和

本轮不注册 `method-function-pair-sum`，不创建 M10 节点或 M10 → M9 借还流程。M10 编号暂留空，其他方法编号不重排；未来出现多类需要独立选择配对策略的任务，再评估是否抽成方法。首轮配对变换为 $\phi(t)=1/t$，它在非零输入上是对合；配对依据来自函数与项结构，不能预先默认和为 3。

| 阶段 | 输入、产物及必须验证的条件 |
| --- | --- |
| 代入并发现规律 | 先计算示例值，观察实际输入中的倒数关系，提出两项和恒定的候选；此时尚未得到证明 |
| 验证配对恒等式 | 在当前 M9 任务中代入一般输入 $t$、$\phi(t)$，保留两项和 $\phi$ 的合法条件；复用代数化简，证明和为精确常量 $K$ |
| 核查使用范围 | 每个参与项均满足恒等式条件；定值证明只在部分域成立时，不得套给域外项 |
| 建立项对应 | 以“出现项”为单位建立互不重叠的二元对、自配对单项及剩余项；重复输入仍按出现次数计入 |
| 验证计数 | 对合关系、索引映射、上下界和覆盖证明一致；所有原项恰计一次，不能只给一个无依据的对数 |
| 计算剩余项 | 自配对处的单次出现仅计算一次；剩余合法项沿用 M9 的代入计算步骤，不能丢弃或自动补上不存在的配对项 |
| 合计与返回 | 对数乘 $K$ 加各剩余项；输出总和、配对恒等式、合法范围及完整覆盖证据 |

首轮覆盖 $t=1$、$t=-1$ 的可能自配对（只在具体函数有定义时使用）、无固定点、多个相同输入、额外零散项、只有剩余项和合法空索引块。非法项如 Q29 的 $f(-1)$ 使原和无定义，不能跳过后继续给总和。

有穷项数较小且满足 M9 预算时，可以直接逐项代入相加；发现并验证配对关系后可以合并计算，两者均属于 M9 内部组织。配对和不恒定时不能套用配对常量；可在预算内直接求和，否则报告该执行路径尚未支持，不把原和判为无意义。未知恒等关系不得伪装成“不恒定”，数学否定需要两个合法输入给出不同输出，或有已验证的非常量证明。

单独的“是否为定值”目标由 M9 完成组合表达式求值，再在完整有效范围上核验恒等或非常量证据：肯定时返回常量及恒等证明，否定时返回有效反例或等价证书。有效范围只有一个输入时按该点实际值判定；范围为空时不能凭空声称一个唯一常量。M9 的求和目标消费其中已验证的恒定产物组织配对；定值目标得到否定结论可以完成，但不能据此继续套用恒定配对公式。两个目标分别保存状态，跨目标复用时绑定已验证产物和版本。

### 5.3 节点增量、技能复用与方法选择

| 正式节点／条目 | 本型用途 |
| --- | --- |
| `function-concept#definition`、`#elements` | 函数输入输出、完整输入与对应规则，两个条目已登记 |
| `rational-expression#meaning` | 原分母与复合输入分母非零，来源分别保留 |
| `skill-expression-defined` | 提取原输入和原函数体各部分有意义的条件，不负责替代整个 M9 |
| `skill-simplify` | 代入后的展开、通分、约分及配对恒等式，保留有效条件 |
| `skill-equality-transform` | 恒等验证或合法条件整理中的等价变形，按需调用并明确乘除条件 |
| `skill-solve-quadratic`、`quadratic-equation` | 复合分母等合法条件确需二次求根时复用；不据此增加逆向求输入任务 |

**本轮只新增 M9 方法节点，不新增技能节点。** 整体代入、嵌套顺序、发现规律、配对计数及剩余项处理是 M9 的步骤；规律的数学验证复用代数化简与等式依据，不另建“发现规律”“验证规律”技能。只有实际建立新变量、转换范围及回代关系才调用已有换元法；不能把 M9 的绑定替换改名成“换元”。

图谱节点复用不等于执行代码已经全部具备。仍需接通多函数调用、原式合法性、结果类型、独立验证及教学投影；已有技能遇到多函数或复合输入的执行缺口，应在原职责下补齐并测试，不复制一个 T4 专用技能。定义域条件的求解与求交按需复用已有不等式变形、集合运算或定义域方法，简单数值计算不强行生成技能卡。

本轮指定单值、表达式、定值判断及有限求和均以 M9 进入，再按目标与实际结构推进内部步骤。本轮只有一个方法，不注册 `rule-function-evaluation-method`，不为“代入还是配对”制造选法卡。可在步骤中让学生识别输入、调用顺序或配对关系，这些是数学判断，不是新的图谱选法节点。

未来 T5 的 M14 借用 M9 时先展示当前子目标；只有一条已核验的直接路径时用确认，结束后返回父目标。Q29 的配对和剩余项计算始终留在当前 M9 目标内，不产生借出／归还交互；完成一对函数值或一个未配对项不得提前完成总和。

## 6. 教学、交互与学习记录

两入口共用 `graph-walk` 课程投影、图谱工具栏、自己做／AI 模式及服务端评分。以下是教学阶段，不预设执行步数或点击数：

| 场景 | 学生任务 | 证据与呈现 |
| --- | --- | --- |
| Q28a | 指出送入哪个函数的输入并计算 | 对应关系中绑定位置高亮，结果精确表示 |
| Q28b | 先算内层，再把输出交给外层 | 两种顺序分开显示输入输出链，不交换 $f\circ g$ 与 $g\circ f$ |
| Q28c | 将整体输入替换所有位置，补齐合法限制 | 原输入分母与函数体分母分别定位；化简后仍显示禁取点 |

| Q29b 定值 | 完成对一般 $t$ 的配对式及条件 | 可用示例理解，但以恒等证据确认全范围定值 |
| Q29b 总和 | 配对、计数并处理 $f(1)$ | 项数 201、100 对及单项来源清楚，最终收束到总和 |

- Q29b 的步骤标题采用“代入试算”“验证定值”“配对计数”“计算剩余项”“合计”，不把整条教学流程都命名为代入法；图谱主方法仍是 M9。
- 求值卡以“完整输入 → 对应规则 → 输出”为主，复合计算逐层串联；配对卡将成对项连线或并排分组，剩余项单列。每步只展示当前任务，确认后在原位置补出结果，不用整题对照板或堆叠大段文字。
- 普通代入先明确完整输入；复合函数改为“确定代入顺序”，让学生判断先求哪个内层函数、再把结果交给哪个外层函数。确认后展示符号输入链（如 $0\xrightarrow{f}f(0)\xrightarrow{g}g(f(0))$），不提前算出各层结果；并列函数相加不能画成前后代入关系。
- 每道拆分题有独立题面、来源、课程和学习记录；题内多个目标的作答、草稿、反馈和完成状态分别保存，整页进度只聚合本题目标。用户上传未拆教材整题时仍保留实际小问结构。
- 公式填答比较表达式恒等及合法范围，不把少写 $x\ne0$ 判为完全正确。Q28c 的两个式子分别关联各自范围，不能共用一个限制集合。
- 顺序交互由实际调用依赖生成；不能只按卡片序号假定先后。图谱展示 T4 → M9 → 实际调用的已有技能，步骤记录绑定当前目标；配对不新增方法层级。
- 提供具体误解反馈：“输入是整个 $x-1$”“化简不能补回原来无意义的输入”“这一项只出现一次”；不使用含混的集合／输入输出干扰文案。
- M9 内不插入重复选法卡；未来实际借用已有公共方法且存在判断节点时，再遵循公共选法规则。前端、服务端、AI 回放使用同一版本化答案契约。
- 检查切题、切目标、撤销、刷新、断线续算和切换模式；匿名与登录、不同账号不串记录。一次提示后完成不直接计为独立掌握。
- 纯数学推导行不机械添加中文句号，说明文字正常用标点；不另加第二个展开图谱工具栏，不在学生流中暴露内部字段。
- “完整推导”仅呈现当前步骤的算式、必要条件和结论，不重复讲解代入／换元等概念；这些说明留在读题、选法或答错提示中。定值证明须区分恒等变形、有限域逐点验证与反例，配对求和保留项数和剩余项的实际计算。
- 有理式定值证明展示化简复分式、通分、合并与约分的关键等式，各行须精确等价。配对计数将原和的出现项按互为倒数上下对齐、连线；计算剩余项沿用同一排列，淡化已配对项并圈出剩余项。重复项按出现身份保留，长数列只省略中段；待答图不提前显示对数或剩余项的值。
- “确定定义域”并列呈现两个条件：原始输入表达式本身有意义、该输入属于原函数的定义域。上方显示目标函数，下方以“同时满足”汇合到定义域，作答后仅将问号替换为答案；嵌套调用的限制归入外层输入条件，题设范围及目标式的额外运算限制单独列出，不因约分省略来源。

## 8. 必须完成的回归矩阵

下表为公开开发／自动回归用例，按实际分支组织定向测试，不要求每行另找原图。每项均检查数学结果、必要来源与验证证据；不能只比较最后数字。

| 类别 | 用例／变化 | 必须断言 |
| --- | --- | --- |
| 整体输入 | $f(u)=3u^2-1$，求 $f(x-1)$ | 所有绑定位置替换，平方括号保留；结果 $3x^2-6x+2$ |
| 复合顺序 | Q28 的 $f(g(0))$ 与 $g(f(0))$ | 分别 $-1/4$、1；调用次序和证据不同 |
| 原输入限制 | Q28 的 $g(1/x-1)$；常量 $h(u)=5$ 求 $h(1/x)$ | 前者 $x\ne0,-1$，后者仍 $x\ne0$；不能因化简或常量体丢条件 |
| 原体约分 | $h(u)=(u^2-1)/(u-1)$，求 $h(1)$ 与 $h(t)$ | 前者无定义；后者 $t+1$ 仍要求 $t\ne1$ |
| 显式域 | $f(u)=u^2$ 仅在 $[0,2]$ 定义，求 $f(x-1)$ | 表达式与 $x\in[1,3]$ 同时返回，不能只用自然域 |
| 层内非法 | $g(u)=1/(u+2)$，输入 -2；外层分母为零的复合 | 无定义层和原式位置明确，不生成无穷数值 |
| 二次分母合法性 | $f(u)=u^2$，$g(u)=1/(u-2)$，求 $g(f(x))$ | 返回 $1/(x^2-2)$，排除 $x=\pm\sqrt2$；合法条件求解不能漏掉任一禁取点 |
| 退化与空合法范围 | 常量／一次函数体；常量函数 $f(u)=2$ 与上述 $g$ 复合；函数声明分母为零常量 | 正向替换按实际结构处理；复合无合法输入与无效函数声明分别解释，不生成伪数值 |
| 变量捕获 | 定义变量改名、外层输入同名字母、不同函数相同绑定名 | 只替换绑定位置；参数／索引不改义；函数定义不串用 |
| 定值真假 | Q29 恒等式；$h(u)=u$ 的 $h(x)+h(1/x)$ | 前者合法范围定值 3；后者有有效非常量证据，不直接套配对模板 |
| 规模泛化 | Q29 的上界替换为不同固定正整数 $N$，包括 $N=1$ | 有 $N-1$ 对与单项，和为 $3N-3/2$；不展开固定 101 项白名单 |
| 重复与固定点 | 两次出现 $f(1)$、合法的倒数固定点 -1、额外零散项 | 每个出现项恰计一次；单项不自动翻倍、重复输入不被去重 |
| 非法求和项 | 包含 $f(-1)$ 或输入 $1/0$ 的变式 | 原和无定义；不能删除非法项后给数值 |
| 目标完整性 | Q28a—c 任一目标遗漏；Q29b 定值通过但总和未知；上传 Q28 完整五问 | 独立题只聚合自身实际目标；漏目标不完成，原整题的暂不支持第五问不得隐藏 |
| 原图与身份 | `1/x-1` 与 `1/(x-1)`、嵌套顺序、求和末项及上下标改变 | 原文绑定发现结构差异；不同题意不被公共身份错误合并 |
| 预算边界 | AST、嵌套、展开与项数上限两侧；循环定义 | 准入、执行、验证一致；越界有原因，无递归失控 |
| 证据篡改 | 改值、删禁取点、漏目标、改对数、删剩余项、换目标引用 | 独立验证拒绝，前端正确标签不能替代数学证明 |
| 学习与续算 | 切独立题／目标、草稿、已确认步、子方法返回、重复提交、换号 | 各题、目标与课程版本隔离；重复操作幂等，服务端评分一致 |
