### 1.1 分三批开放

**A 批：Q28(1)—(4)，数值与表达式求值。** 限实数、一元显式函数、固定有理数系数；原函数体为至多二次多项式，或分子至多二次、分母为仿射式的分式。输入允许有理数、仿射式、非零仿射式的倒数加常数，以及至多两层已登记函数的复合。表达式可包含有限项加减与有理系数乘法，具体项数、AST 大小、深度和展开次数在 S0 固定共享预算。

允许的函数体包括常量和系数为零的退化情形；分母为零常量时是无效函数声明，不得作为普通函数求值。显式定义域可为有理端点区间、有限有理点集合或去掉有限个有理点的上述集合；自然定义域由原式决定。题面明确声称的定义域若含原式无意义的点，应报告条件冲突，不能悄悄删点改题。复合产生的二次分母须能精确求出合法范围，不能只支持代表题恰好无实零点的情况。

**B 批：Q28(5)，逆向求输入。** 复用 A 批求值链，在保留原限制后，将指定输出条件等价归约为固定有理系数、至多二次的方程。须覆盖二次、一次、常量与恒等方程，支持精确二次根式解及与原合法范围的交集；不只实现“平方等于零”的特例。若归约超出该范围，如一般四次方程，清楚报告能力缺口，不把高次项擅自忽略。

**C 批：Q29，组合与配对求和。** 复用 M9；新增有限函数值之和及倒数配对 `t ↔ 1/t`。输入项由明确的有限列表、闭区间整数索引及其倒数生成，长度和索引规模受统一预算约束。M10 须证明配对和在实际参与输入上恒定，再给出覆盖全部出现项的配对与计数证据；不能用“求和到 101”的题号／数字分支。

### 1.2 本轮边界

- 求给定输入的输出属于 T4；求所有输入产生的完整输出集合属于 T5。出现 `g(f(x))` 不足以判断目标，必须读题目所求。
- 表达式答案必须同时带合法输入范围；逆向答案必须为全部合法输入集合。不能把两者塞进同一个“数值答案”字段。
- 支持范围按结构定义，代表题的常数、函数名、变量字母和小问编号均不是准入条件。
- 本轮不开放任意超越函数、递归函数定义、一般分段函数、含参方程的参数分类、无限级数或任意配对变换。未能证明定值、覆盖或原式合法性时不得输出已完成。
- 定义域中合法输入不存在时明确处理无效声明或空结果；指定非法数值输入应说明“该输入处无定义”，不能产生 `∞`、`NaN` 或伪造数值。

## 2. 题源与数学金标

### 2.1 Q28：第 86—87 页例 10

共同题干：$f(x)=3x^2-1$，$g(x)=\dfrac1{x+2}$。

| 小问 | 原请求 | 数学金标与必要条件 |
| --- | --- | --- |
| (1) | 求 $f(1)$、$g(1)$ | $f(1)=2$，$g(1)=\frac13$；输入 1 分别合法 |
| (2) | 求 $f(g(0))$、$g(f(0))$ | $g(0)=\frac12$，故 $f(g(0))=-\frac14$；$f(0)=-1$，故 $g(f(0))=1$ |
| (3) | 求 $f(x-1)$、$g(1/x-1)$ | $f(x-1)=3x^2-6x+2$，$x\in\mathbb R$；$g(1/x-1)=\frac{x}{x+1}$，$x\ne0,-1$ |
| (4) | 求 $f(g(x))$ | $\frac3{(x+2)^2}-1$，$x\ne-2$ |
| (5) | 已知 $g(f(x))=1$，求 $x$ | $g(f(x))=\frac1{3x^2+1}$；分母恒正，令其等于 1 得 $3x^2=0$；全部合法解为 $\{0\}$ |

Q28(3) 第二个表达式化简后在 $x=0$ 看似可用，但原输入 `1/x-1` 在该点无意义，必须保留 $x\ne0$。另由交给 $g$ 的输入不等于 $-2$ 得 $x\ne-1$。两个限制来自不同位置，证据和教学反馈不能合并丢失来源。

Q28 五问共享两个函数定义，没有“后问须使用前问答案”的数学依赖。每个目标可从公共定义独立执行；Q28(2) 内层与外层计算的顺序依赖属于同一目标内的调用证据，不能错误地建成跨小问依赖。

Q28(1)—(3) 各含两个请求，应保留原题一个小问下的两个目标，不伪装为原图已有六个新小问。题号只用于编排；依靠稳定函数引用和 `target_ref` 绑定结果。

### 2.2 Q29：第 87 页例 10 变式

共同题干：$f(x)=\dfrac{x+2}{x+1}$。

1. 求 $f(2)+f(\frac12)$：两项分别为 $\frac43$、$\frac53$，结果为 $3$。
2. 判断 $f(x)+f(1/x)$ 是否为定值，并求

$$
f(1)+f(2)+\cdots+f(101)+f(\tfrac12)+f(\tfrac13)+\cdots+f(\tfrac1{101})
$$

合法条件为 $x\ne0,-1$；在此范围上

$$
f(x)+f(1/x)=\frac{x+2}{x+1}+\frac{1+2x}{1+x}=3
$$

总和共 201 项。$n=2,\ldots,101$ 与 $1/n$ 形成 100 对，$f(1)=\frac32$ 只出现一次，因此

$$
S=100\times3+\frac32=\frac{603}{2}
$$

“定值为 3”须附其成立范围，且为整个有效范围的恒等证明，几个数值样本不能替代。定值证明和总和是两个数学产物；只完成其中一个，不能把 Q29(2) 标为完成。

## 4. 题意与结果契约

### 4.1 从原文保留任务，不提前计算

提取、复核、修复共同使用 [graph-stage-one-source-rules.md](../internal/llm-prompts/graph-stage-one-source-rules.md)。表达式目录、schema、原图核对和身份构造同步覆盖新增任务：

- 保留函数名、绑定自变量、原函数体 AST、显式定义域、输入表达式 AST、调用顺序及各自 `source_ref`。原文中的 `f(g(0))` 不在阶段一改写成数字。
- 数值求值继续核对现有 `find_value`；表达式求值须明确“结果仍含自由变量”的语义与合法范围，不能用 `find_range` 装函数表达式。
- 逆向任务明确目标输入变量、原等式及全解要求；Q28(5) 的 1 是题给输出，0 是待推导答案，不可在提取候选中提前写入。
- 定值判断与有限求和分别有目标；拟结果种类包括 `scalar_value`、`expression_with_domain`、`input_solution_set`、`constant_check`、`finite_sum`，名称只是设计，不代表已有 schema 枚举。`constant_check` 明确区分已证明恒定、已证明不恒定和能力未知，只有前两者是已完成的数学判断。
- 共用定义放在祖先作用域，局部条件留在原小问；其他小问给出的条件或求值结果不能自动继承。若将小问独立入题，必须同时保留完整共同定义并登记来源。
- 求和记录输入生成式、上下限、端点、项的出现次数及单列项，不能仅录最终展开文本。无法确定省略号范围或截断原图时报告不确定性。

### 4.2 输入替换与合法性

对函数 $f(u)=F(u)$ 和输入 $a(x)$，合法条件为：$a(x)$ 本身有意义，且其值属于 $D_f$。先保存这些条件和来源，再得到 $F(a(x))$；函数体未使用 $u$ 时也不能忽略前一项。

代入只替换绑定自变量节点，不能做字符串替换。调用 $f(x-1)$ 时所有绑定位置同时替换；函数内绑定变量、外层自由变量、题给参数和求和索引有不同身份。必要的内部改名保持数学等价且可追溯，不能捕获自由变量。

多函数可见上下文以稳定引用及目标作用域传入；不得把 `f` 与 `g` 的定义拼成同一函数，也不得删去真实约束来适配旧的单函数准入器。重复调用形成独立调用位置和证据引用，共享缓存仅能复用同输入、同范围、同版本的已验证产物。

数值输入一旦在某层非法，该调用及依赖目标停止并如实解释。表达式输入则返回完整合法范围；约分、通分或常量化简都不扩大原范围。诸如 $x/x$ 在化简前仍排除 0。

### 4.3 验证与完整性

数值结果以精确有理数／受支持代数数比较；表达式结果在声明合法范围内验证恒等，另外独立重建原调用合法范围。只验证结果式在若干点相等，不能证明表达式答案完整。

逆向从原调用和原等式重建解集，逐个候选验合法性与原等式，并证明没有遗漏。恒等方程返回原合法范围，不能只列几个输入；矛盾方程返回空集，不能误判执行失败。

每个目标都有独立结果类型、完成证据和归属；整题完成要求原题全部请求通过。目标未知或被裁掉不能默认为已完成，部分执行成功须保留明确进度。

## 5. 方法、技能与判断

### 5.1 M9 代入法

拟全局 ID：`method-function-substitution`，登记前查重。它组织完整求值任务，不等同于已有技能 `method-substitution`（换元）。

| 项目 | 契约 |
| --- | --- |
| 输入 | 来源明确的函数定义、指定数值／表达式／复合输入、原范围、目标模式及可见作用域 |
| 前置 | 函数引用可解析、非递归，结构与共享预算通过；参数已固定，目标不含未声明符号 |
| 正向路线 | 明确完整输入 → 按内到外确定合法性 → 替换全部绑定位置 → 有条件化简／计算 → 返回输出与有效范围 |
| 逆向路线 | 展开原复合关系并保留合法范围 → 建等价方程 → 按真实次数求全部候选 → 代回原式筛选 → 返回完整输入集合 |
| 输出 | 数值、表达式及合法范围、逆向全解集，或组合表达式的定值真假与证明；附逐层输入、对应定义、替换位置、条件来源和验证 |
| 子调用 | 按实际需要使用 S3、代数化简、等式变形和二次方程求根；简单数值代入由方法基础步骤完成 |

逆向二次方程的矩阵必须完整：$a\ne0$ 时判别式正／零／负；$a=0,b\ne0$ 时一次解；$a=b=0$ 时恒等或矛盾。分母乘除前必须证明非零，开平方不得漏负根；存在代数根不代表它是合法输入。

若方程有无穷多解，返回已验证的原合法域；若所有代数根被原分母或显式范围排除，返回空集并保留排除原因。根式数值与区间端点的比较采用精确证据，不能用浮点近似决定取舍。

### 5.2 M10 配对求和法

拟全局 ID：`method-function-pair-sum`，登记前查重。首轮配对变换为 $\phi(t)=1/t$，它在非零输入上是对合；配对依据来自函数与项结构，不能预先默认和为 3。

| 阶段 | 输入、产物及必须验证的条件 |
| --- | --- |
| 建立配对恒等式 | 调用 M9 求 $f(t)$、$f(\phi(t))$，保留两项和 $\phi$ 的合法条件；化简证明和为精确常量 $K$ |
| 核查使用范围 | 每个参与项均满足恒等式条件；定值证明只在部分域成立时，不得套给域外项 |
| 建立项对应 | 以“出现项”为单位建立互不重叠的二元对、自配对单项及剩余项；重复输入仍按出现次数计入 |
| 验证计数 | 对合关系、索引映射、上下界和覆盖证明一致；所有原项恰计一次，不能只给一个无依据的对数 |
| 计算剩余项 | 自配对处的单次出现仅计算一次；剩余合法项调用 M9，不能丢弃或自动补上不存在的配对项 |
| 合计与返回 | 对数乘 $K$ 加各剩余项；输出总和、配对恒等式、合法范围及完整覆盖证据 |

首轮覆盖 $t=1$、$t=-1$ 的可能自配对（只在具体函数有定义时使用）、无固定点、多个相同输入、额外零散项、只有剩余项和合法空索引块。非法项如 Q29 的 $f(-1)$ 使原和无定义，不能跳过后继续给总和。

有穷项数较小且满足 M9 预算时，逐项代入相加也可能适用；M10 体现配对结构。配对和不恒定时 M10 不适用，不代表原和无意义；若其他路线未开放则报告方法缺口。未知恒等关系不得伪装成“不恒定”，数学否定需要两个合法输入给出不同输出，或有已验证的非常量证明。

单独的“是否为定值”目标由 M9 完成组合表达式求值，再在完整有效范围上核验恒等或非常量证据：肯定时返回常量及恒等证明，否定时返回有效反例或等价证书。有效范围只有一个输入时按该点实际值判定；范围为空时不能凭空声称一个唯一常量。M10 消费其中已验证的恒定产物组织求和；定值目标得到否定结论可以完成，但不能据此继续套用恒定配对公式。两个目标分别保存状态，跨目标复用时绑定已验证产物和版本。

### 5.3 知识依据、技能复用与方法选择

| 正式节点／条目 | 本型用途 |
| --- | --- |
| `function-concept#definition`、`#elements` | 函数输入输出、完整输入与对应规则，两个条目已登记 |
| `rational-expression#meaning` | 原分母与复合输入分母非零，来源分别保留 |
| `skill-expression-defined` | 提取原输入和原函数体各部分有意义的条件，不负责替代整个 M9 |
| `skill-simplify` | 代入后的展开、通分、约分及配对恒等式，保留有效条件 |
| `skill-equality-transform` | 逆向等式的等价变形，明确乘除条件 |
| `skill-solve-quadratic`、`quadratic-equation` | B 批一般二次求根及依据，复用并核查实际执行契约 |

基本代入、嵌套顺序、配对计数不另建技能。只有实际建立新变量、转换范围及回代关系才调用已有换元技能；不能把 M9 的绑定替换改名成“换元”。

方法判断按目标与结构组织：指定单值／表达式／逆向输入以及组合表达式的定值判断以 M9 进入；具备可证明配对结构的有限和可选 M10，满足预算的直接求和亦可作为 M9 路线。拟公共判断 `rule-function-evaluation-method` 仅在有完整适用性契约时登记，不为每个小问建空判断节点。

M10 借用 M9、未来 M14 借用 M9 时先展示当前子目标；若有适用的公共判断节点，学生再次选法。只有一条已经核验的直接借用路径时用确认，不凭空制造选择题。子方法结束返回父目标；完成一对函数值或一个未配对项不得提前完成总和。

## 8. 必须完成的回归矩阵

下表为公开开发／回归用例。每项均检查数学结果、必要来源与验证证据；不能只比较最后数字。

| 类别 | 用例／变化 | 必须断言 |
| --- | --- | --- |
| 整体输入 | $f(u)=3u^2-1$，求 $f(x-1)$ | 所有绑定位置替换，平方括号保留；结果 $3x^2-6x+2$ |
| 复合顺序 | Q28 的 $f(g(0))$ 与 $g(f(0))$ | 分别 $-1/4$、1；调用次序和证据不同 |
| 原输入限制 | Q28 的 $g(1/x-1)$；常量 $h(u)=5$ 求 $h(1/x)$ | 前者 $x\ne0,-1$，后者仍 $x\ne0$；不能因化简或常量体丢条件 |
| 原体约分 | $h(u)=(u^2-1)/(u-1)$，求 $h(1)$ 与 $h(t)$ | 前者无定义；后者 $t+1$ 仍要求 $t\ne1$ |
| 显式域 | $f(u)=u^2$ 仅在 $[0,2]$ 定义，求 $f(x-1)$ | 表达式与 $x\in[1,3]$ 同时返回，不能只用自然域 |
| 层内非法 | $g(u)=1/(u+2)$，输入 -2；外层分母为零的复合 | 无定义层和原式位置明确，不生成无穷数值 |
| 二次全解 | $f(u)=u^2$，分别解 $f(x)=2,0,-1$ | $\{-\sqrt2,\sqrt2\}$、$\{0\}$、空集；精确验证并不漏负根 |
| 次数退化 | 同一方程族 $ax^2+bx+c=0$，系数取固定有理值覆盖 $a=0$、$b=0$ | 一次单解、恒等全原域、常量矛盾空集均正确，不把固定系数变成含参分类任务 |
| 原域筛根 | $h(u)=(u^2-1)/(u-1)$，解 $h(x)=2$；另限制平方函数在正半轴 | 前者代数候选 1 被排除得空集；后者只保留正根 |
| 恒等与孔洞 | $h(u)=u/u$，解 $h(x)=1$ | 全部解为 $\mathbb R\setminus\{0\}$，不能写全实数或某个样本 |
| 变量捕获 | 定义变量改名、外层输入同名字母、不同函数相同绑定名 | 只替换绑定位置；参数／索引不改义；函数定义不串用 |
| 定值真假 | Q29 恒等式；$h(u)=u$ 的 $h(x)+h(1/x)$ | 前者合法范围定值 3；后者有有效非常量证据，不直接套配对模板 |
| 规模泛化 | Q29 的上界替换为不同固定正整数 $N$，包括 $N=1$ | 有 $N-1$ 对与单项，和为 $3N-3/2$；不展开固定 101 项白名单 |
| 重复与固定点 | 两次出现 $f(1)$、合法的倒数固定点 -1、额外零散项 | 每个出现项恰计一次；单项不自动翻倍、重复输入不被去重 |
| 非法求和项 | 包含 $f(-1)$ 或输入 $1/0$ 的变式 | 原和无定义；不能删除非法项后给数值 |
| 目标完整性 | Q28 第五问失败；Q29 定值通过但总和未知；小问中一个请求遗漏 | 正确保留局部进度，整题不 completed／solved |
| 原图与身份 | `1/x-1` 与 `1/(x-1)`、嵌套顺序、求和末项及上下标改变 | 原文绑定发现结构差异；不同题意不被公共身份错误合并 |
| 预算边界 | AST、嵌套、展开与项数上限两侧；循环定义 | 准入、执行、验证一致；越界有原因，无递归失控 |
| 证据篡改 | 改值、删禁取点、漏逆向根、改对数、删剩余项、换目标引用 | 独立验证拒绝，前端正确标签不能替代数学证明 |
| 学习与续算 | 小问切换、草稿、已确认步、子方法返回、重复提交、换号 | 各目标与课程版本隔离；重复操作幂等，服务端评分一致 |

共享执行模块改动须运行相关 T2、T1、T3 回归；若影响未来 M14 的调用契约，以独立受限有限输入调用测试验证输出可复用，不提前宣称 T5 已实现。
