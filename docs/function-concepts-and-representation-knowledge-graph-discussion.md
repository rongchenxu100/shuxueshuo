### 2.1 K1 函数的概念

| 条目 | 必要知识内容 |
| --- | --- |
| K1.a 定义与记号 | A、B 为非空实数集，按确定的对应关系 f，每个 x∈A 在 B 中都有唯一的 y 与之对应，记作 $f:A\to B$、$y=f(x)$。x 是自变量，f(x) 是对应的函数值。允许多对一，不允许一对多或遗漏输入；常函数也符合此定义。 |
| K1.b 函数的三要素 | **定义域**：允许输入的集合 A；只给解析式且未指定范围时，取使原式有意义的实数集合，实际问题还受情境限制。**对应关系**：确定输入与输出如何对应的规则，不限于解析式。**值域**：实际取到的全部函数值组成的集合 $f(A)=\{f(x)\mid x\in A\}\subseteq B$，不一定等于 B；端点是否包含取决于能否取到。 |
| K1.c 同一函数的判定 | 定义域和对应关系确定后，值域随之确定。两个函数相同，当且仅当定义域相同，且每个输入对应的输出相同；变量字母可以不同。仅定义域和值域相同不足以判定同一函数；表达式化简不改变原定义域限制。 |

一次函数、二次函数和反比例函数的定义域与值域引用各自知识点（见 3.1），不在 K1 重复列项。

### 2.2 K2 区间的概念

| 条目 | 必要知识内容 |
| --- | --- |
| K2.a 有限区间与端点表示 | 设 a<b。闭区间 $[a,b]$、开区间 $(a,b)$、半开半闭区间 $[a,b)$、$(a,b]$ 分别表示 $a\le x\le b$、$a<x<b$、$a\le x<b$、$a<x\le b$。a、b 为端点；包含端点用方括号及数轴实心点，不包含用圆括号及空心点。 |
| K2.b 无界区间与无穷符号 | $[a,+\infty)$、$(a,+\infty)$、$(-\infty,b]$、$(-\infty,b)$ 分别表示 $x\ge a$、$x>a$、$x\le b$、$x<b$；$\mathbb R=(-\infty,+\infty)$。无穷符号不是实数，其一侧只能用圆括号。 |

多段范围的并集和离散集合的表示引用第一章的集合知识 P1、P2。

### 2.3 K3 函数的表示法

| 条目 | 必要知识内容 |
| --- | --- |
| K3.a 解析法 | 用数学表达式及定义域表示函数，便于计算和推导；并非每个给定函数都有已知或简洁的解析式。 |
| K3.b 列表法 | 用表格给出输入与对应输出，便于直接查值。有限定义域可完整列出；无限定义域的有限表格只能提供部分值，不能据此唯一确定其余对应。 |
| K3.c 图像法 | 用图像表示输入输出对应，便于观察变化趋势与性质；示意图读数可能为近似值。图像的定义及作图规则见 K5.a。 |

不同表示描述同一函数时，定义域和对应关系必须一致；表示的含义与转换依据保留在 K3，作图与变换依据保留在 K5。

### 2.4 K4 分段函数

| 条目 | 必要知识内容 |
| --- | --- |
| K4.a 定义与分段表达 | 一个函数在不同输入范围使用不同表达式，用一个大括号合写并注明各段范围。各段须覆盖定义域，分界点归属明确；若范围重叠，对同一输入须给出相同输出。函数值由输入所属段的表达式确定。 |
| K4.b 定义域与值域 | 定义域是各段有效输入集合的并集；值域是各段实际输出集合的并集。每段表达式只在该段规定范围内有效。 |

分段函数的作图规则统一归入 K5.a；具体函数与应用作为关联实例。

### 2.5 K5 函数的图像及其变换

设原函数定义域为 D；以下 a、b 均为正数。

| 条目 | 必要知识内容 |
| --- | --- |
| K5.a 图像与作图基础 | 图像为所有 $(x,f(x))$ 构成的点集，每个 x∈D 对应唯一纵坐标。描点法通过选取代表性输入、列表、描点形成图像；连接须符合函数规则。有限定义域只画离散点；分段图像按各段有效范围在同一坐标系中合并，不跨越无定义点或跳跃连线。端点取到画实心点，未取到画空心点。 |
| K5.b 平移变换 | $y=f(x+a)$ 向左平移 a，$y=f(x-a)$ 向右平移 a；$y=f(x)+b$ 向上平移 b，$y=f(x)-b$ 向下平移 b。水平平移后的定义域分别为 $\{x\mid x+a\in D\}$、$\{x\mid x-a\in D\}$；竖直平移不改变定义域。 |
| K5.c 对称变换 | $y=-f(x)$ 关于 x 轴对称，定义域为 D；$y=f(-x)$ 关于 y 轴对称，$y=-f(-x)$ 关于原点对称，后二者定义域均为 $\{x\mid -x\in D\}$。平移与对称均保留对应端点的取舍。 |
| K5.d 绝对值翻折变换 | $y=\lvert f(x)\rvert$：保留 x 轴上及上方的图像，把下方部分关于 x 轴翻到上方，定义域为 D。$y=f(\lvert x\rvert)$：保留原图中 x≥0 的部分，将右侧部分关于 y 轴翻到左侧，舍去原图的 x<0 部分；定义域为 $\{x\mid\lvert x\rvert\in D\}$，须非空。 |

### 2.6 具体函数的内部条目

| 条目 | 必要知识内容 |
| --- | --- |
| K6.a 定义与分段表达 | 绝对值函数为 $f(x)=\lvert x\rvert$：x<0 时 f(x)=−x，x≥0 时 f(x)=x。绝对值的意义与运算规则引用 P9。 |
| K6.b 定义域与值域 | 自然定义域为 $\mathbb R$，值域为 $[0,+\infty)$。 |
| K6.c 图像 | 图像由两条在原点相接的射线构成，呈 V 形，关于 y 轴对称。 |
| K7.a 定义与分段表达 | $f(x)=\lfloor x\rfloor$ 表示不超过 x 的最大整数，教材记作 [x]；等价地，当 $n\le x<n+1$ 时，$f(x)=n$，其中 $n\in\mathbb Z$。 |
| K7.b 定义域与值域 | 自然定义域为 $\mathbb R$，值域为 $\mathbb Z$。 |
| K7.c 图像 | 图像为阶梯状，在每个 $[n,n+1)$ 上是高度为 n 的水平线段，左端实心、右端空心。 |
| K8.a 定义与表达式 | 反比例函数为 $f(x)=k/x$，k 为非零实常数，等价关系为 xy=k。 |
| K8.b 定义域与值域 | 自然定义域和值域均为 $\mathbb R\setminus\{0\}$。 |
| K8.c 图像 | 图像为双曲线的两支，不与坐标轴相交；k>0 时位于第一、三象限，k<0 时位于第二、四象限。 |

指定定义域时，图像取相应部分，值域由实际输出确定。分段表达与作图的通用规则分别引用 K4、K5；单调性、奇偶性与最值的系统内容在相应章节组织。

### 6.2 层级与统一调用约定

| 对象 | 职责 | 关联与执行边界 |
| --- | --- | --- |
| 知识点 | 定义、性质、定理与数学依据 | 题型可关联知识用于检索；执行时由方法步骤或技能引用具体条目，知识点不是求解入口 |
| 题型 | 描述已知结构与求解目标 | 至少关联一个可选方法；适用性检查后进入方法，不直接选择技能执行 |
| 方法 | 完成其承诺目标的完整路线 | 组织基础步骤、技能或子方法调用，负责输入绑定、条件、分支及完成判定；只调用一个技能的方法也保留 |
| 技能 | 完成有明确输入输出的可复用操作 | 由方法调用；复用现有实现，不因增加方法封装复制技能 |
| 逐题拆解 | 方法在具体题目上的执行记录 | 标明入口、小问目标、实际子调用、中间条件与最终结果；不作为另一种绕过方法的路线 |

**统一入口为“题型 → 方法 → 技能或子方法”。** 方法内部可以包含代入、计数、集合合并等基础步骤；这些步骤无需各建技能。纯基础步骤的方法可以没有独立技能调用，仍须满足相同的方法契约。知识依据在实际步骤处记录，已有技能的依据沿其引用汇总，不维护重复的全量知识清单。

每个方法统一记录以下内容：

| 字段 | 必须明确的内容 |
| --- | --- |
| 输入与目标 | 函数或表达式、变量角色、已知范围、参数及要求返回的结果 |
| 适用条件 | 方法能处理的结构和前提；条件未满足时不能强行执行 |
| 步骤与调用 | 每步输入来自何处，调用哪个技能或子方法，返回结果交给哪一步；按条件调用，不机械执行全部能力 |
| 输出与完成条件 | 结果类型、原条件是否保留、分支是否完整、是否满足原目标；值域须是全部可达输出 |

入口方法与子方法属于同一种 Method 对象。已有方法能完成当前目标时直接复用；只能完成中间目标时由入口方法调用。只调用一个技能的封装只写任务条件、输入绑定和结果核验，不重写技能计算过程。新组合路线同样须先组织为方法，不能以“直接找技能或知识”的例外分支执行。

### 6.3 本节方法候选

以下 M1—M14 为本节方法设计编号，其中 M1 已登记为 `method-domain-intersection`，M6 已登记为 `method-domain-parameter`，其余仍为候选。表格保留各方法完整目标，不是当前程序支持范围；Q15 首批 M1 已完成固定仿射根式／除法等受限结构。第 1 题作为第一道扩题门已通过，扩充固定非负整数幂，并验证零次幂及约分前 $x\ne1$、$x\ne-4$ 的完整保留，继续复用 M1 与 S3。M6 的全实数域输入族支持 $\sqrt P$ 与 $N/\sqrt P$：$P$ 为已准入的含参二次多项式，$N$ 为不额外限制输入的多项式；普通根式与根式分母分别化为非严格、严格恒成立。新增半轴输入族支持 $\sqrt P/\sqrt L$，其中 $L$ 为固定非恒定仿射式、$P$ 为固定至多二次多项式加参数的一次常量偏移，题给域恰为 $\{L>0\}$，再复用分离参数法。左右半轴、二次／一次／常量、顶点位置和参数系数正负均在该契约内维护。Q22、Q04 保留各自既有验收口径，Q12 的浏览器双模式与日常后台更新已完成；Q23b 的数学、教学及真实拍题 API 已通过，浏览器双模式验收通过，日常 8779 后台已更新。具体结构预算、原式准入和验收范围以 [T2 题型设计 §9.6](function-domain-problem-type-design.md#96-q12根式分母与严格恒成立)及 [§9.7](function-domain-problem-type-design.md#97-q23b半轴定义域与分离参数)为准。表中技能使用第 4 节的同一身份；所有调用按实际条件发生，不为入口与子方法用途复制节点。
