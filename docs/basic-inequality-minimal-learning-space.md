## 2. 论域：12 个原子

| id | 技能 | 现有材料 |
|---|---|---|
| `T` | 写出公式与取等 \(a=b\) | 定理卡 |
| `P` | 一正：完整正项且 \(>0\) | CHECK FLOW ①（总览可省略，空间里必须有） |
| `S` | 观察条件整式 \| 目标整式 | ROUTE MAP 核心 |
| `A` | 两个正项入槽，看出定和或定积 | 直接应用 HOW |
| `E` | 三相等：取等与原条件相容 | CHECK FLOW ③、ROUTE 落地 |
| `Sum` | 定和/定积已露出 → 直接应用 | q01、q02 |
| `Arr` | 目标未露出正项时先改写再入槽 | q05、q08、q20、q28 |
| `Sym` | 交换检验，用 \(s,p\) 改写 | 对称法 |
| `Hom` | 次数配成 0，展开找比值定积 | 配齐次式 |
| `Iter` | 用 \(n-k\) 估计轮次并逐轮配对 | 多次应用 |
| `U` | 分母/根号整体换元，同步改写后再观察 | 换元法 |
| `X` | 条件能表出一变量则代入降维 | 条件消元 |

`Arr` 必须从 `Sum` 拆出：q01 不需要整理，q05 需要。若强行 `Arr ≼ Sum`，不会整理会被误判为「不会直接应用」。

第二期再拆：`Hom` → 整体/局部；`q18` 的「先缩放」可升为独立原子。

## 3. 图论：Hasse 前提图

边 \(q \prec q'\) 表示：会 \(q'\) 则必会 \(q\)（surmise）。只保留覆盖边。

```text
T → A ← P
     A → {Sum, Arr, Sym, Hom, Iter, X, E}
S → {Sum, Arr, Sym, Hom, Iter, U, X}
```

约束：

1. **无环。**「换元后再观察」不是 \(U\to S\)。\(S\) 是已掌握技能，换元后是复用，不能画回边。
2. **\(S\) 与 \(T,P\) 不可比。** 未背公式也可练交换检验。
3. **\(U\) 与四条线索不可比。** 如 q22 需要 \(\{S,U,\mathrm{Hom}\text{ 或 }\mathrm{Sum},A,E\}\)，不是「换元 ⊑ 齐次」。

可直接用的图算法：

- 拓扑序 = 合法讲授顺序
- \(\downarrow q\) = 学 \(q\) 的必修前驱闭包
- 外缘 \(F^+(K)\) = 下一步能学的原子（见 §5）

---

## 4. 格论：合法状态 = 向下闭包

设 \(P=(Q,\preceq)\)。学生状态必须是 down-set：

\[
K\subseteq Q\text{ 合法}\iff (q\in K\land q'\preceq q)\Rightarrow q'\in K
\]

全体 down-set \(\mathcal{J}(P)\) 按 \(\subseteq\) 构成有限分配格：

- 交 \(K\wedge L=K\cap L\)：共同仍站得住的部分
- 并 \(K\vee L=K\cup L\)：两条学习路径会合（知识空间对并封闭）
- 覆盖 \(K\prec K\cup\{q\}\)：一次只多会一个原子 → well-graded（learning space）

这一章约几十个合法状态，不是 ALEKS 百万级状态——故称「最小」。

非法例：\(\{\mathrm{Hom}\}\) 缺 \(A,S,T,P\)，禁止出现「会配齐次、不会入槽」。

## 5. 差分补齐

学生当前状态 \(K\in\mathcal{J}(P)\)。外缘：

\[
F^+(K)=\{q\notin K\mid \downarrow q\setminus\{q\}\subseteq K\}
\]

每题绑定最小需求 \(K_p=\downarrow Q_p\)。

| 题 | \(Q_p\)（再自动补前驱） |
|---|---|
| q01, q02 | `Sum, E` |
| q05, q08, q20, q28 | `Arr, E` |
| q03, q04, q14–q16 | `Hom, E` |
| q17 | `Sym, E` |
| q18, q19 | `Sym, U, E`（先缩放/整体再对称） |
| q07, q11, q30–q31 | `Iter, E` |
| q22–q25 | `U, Hom 或 Sum, E` |
| q26 | `U, Sum, E` |
| q27, q29 | `X, Arr 或 Sum, E` |

一次作答后：

```text
缺口 Δ = K_p \ K
可补齐 = Δ ∩ F⁺(K)     ← 只推这个
还不能补 = Δ \ F⁺(K)    ← 先回到更底层前驱
```

提示强度必须进证据：高等级提示后做对，不写入 down-set。

## 6. 落地顺序

1. 写入 `prerequisite` 边表 + `lessonId → Q_p`
2. 学生图只存当前 down-set
3. 判题失败：算 \(\Delta\cap F^+(K)\)，跳到对应方法说明
4. 默认讲授拓扑序：`T,P → A,E → S → Sum → Arr → Hom/Sym → Iter/U → X`
5. 抽查 well-graded：任取合法 \(K\neq Q\)，\(F^+(K)\) 非空

第一期不上概念格、不上 Differential Dataflow。格就是 \(\mathcal{J}(P)\)；差分就是外缘与 \(K_p\) 的交。

## 7. 找对称结构：实质、WHY、与 \(s,p\) 替换

方法卡建议三层，不要把「为什么能换」塞进核心意义或 HOW：

| 层 | 只回答 | 一句话 |
|---|---|---|
| **核心意义** | 对称是什么 | 交换 \(x,y\) 后原式不变 |
| **WHY** | 为什么能用和、积换元 | 无序对 \(\Leftrightarrow\) 一元二次方程两根 \(\Leftrightarrow\) 韦达的和与积 |
| **HOW** | 题上怎么做 | 交换检验 → 令 \(s,p\) 改写 → 验证取等 |

### 7.1 核心意义（识别标准）

> 交换 \(x\leftrightarrow y\) 后取值不变，即 \(f(x,y)=f(y,x)\)，叫做关于 \(x,y\) 对称。

检验时：**目标整式、条件整式各自**交换一次。两处都通过，才进入 WHY / 换元。

核心意义只负责「认出来」，不负责解释 \(s,p\)。

### 7.2 WHY：为什么可以由和与积换元（两步 + 一句收束）

你的两步方向是对的；用语上把「二元一次方程」改为**一元二次方程**（一个未知数、次数为 2）。完整链条如下。

**第一步：对称结构 \(\Rightarrow\) 研究对象是无序对**

- 有序对 \((x,y)\) 与 \((y,x)\) 在 \(x\neq y\) 时是不同对象。
- 若 \(f(x,y)=f(y,x)\)，则 \(f\) 在这两处取值相同，说明 \(f\) **不区分顺序**。
- 因此真正进入 \(f\) 的，不是有名有姓的 \(x\)、\(y\)，而是**无序对** \(\{x,y\}\)（允许 \(x=y\)，即多重集意义下的一对）。

这一步只改「看问题的方式」：从盯两个字母，变成盯「这一对数字」。

**第二步：二元无序对 \(\Leftrightarrow\) 一元二次方程的两根；韦达定理 \(\Leftrightarrow\) 和与积**

任意两个数 \(x,y\)（可相等）都是某个首一二次方程的两根：

\[
(t-x)(t-y)=t^2-(x+y)t+xy=0.
\]

令 \(s=x+y\)，\(p=xy\)，方程就是

\[
t^2-st+p=0.
\]

由**韦达定理**：该方程两根之和为 \(s\)，两根之积为 \(p\)。

于是有等价关系（实数情形加可行域）：

\[
\{x,y\}
\;\Longleftrightarrow\;
\text{方程 }t^2-st+p=0\text{ 的两根}
\;\Longleftrightarrow\;
(s,p)\quad\bigl(\text{实数时 }s^2\ge 4p\bigr).
\]

- 左→右：由一对数字写出和、积，得到方程。  
- 右→左：知道和、积，由韦达还原两根（实数时判别式 \(\Delta=s^2-4p\ge 0\)）。  
所以 \((s,p)\) 不是外加的技巧，而是**无序对的完全坐标**；韦达定理正是「两根」与「和、积」之间的翻译。

**收束（由两步推出换元合法性）**

对称式只依赖无序对；无序对又完全由 \((s,p)\) 确定。因此凡对称的目标/条件，都可以改写成只含 \(s,p\) 的关系，再消元。

中学常用改写（由定义直接验算即可，不必升格讲基本定理）：

| 原式 | 用 \(s,p\) |
|---|---|
| \(x+y\) | \(s\) |
| \(xy\) | \(p\) |
| \(x^2+y^2\) | \(s^2-2p\) |
| \(x^3+y^3\) | \(s^3-3sp\) |
| \(x^2+y^2-xy\) | \(s^2-3p\) |

消元时带上 \(s^2\ge 4p\)（即 \((x-y)^2\ge 0\)）；取等常对应 \(x=y\)（双根）。

### 7.3 两步之外，故意不讲什么

| 不讲 / 后置 | 原因 |
|---|---|
| 「对称多项式基本定理」全称 | 高一不需要；用「只依赖无序对 + 坐标完全」足够支撑换元 |
| 把 WHY 写成「令 \(s,p\)」操作口令 | 那是 HOW，不是理由 |
| 用「二元一次方程」 | 易与方程组混淆；此处是**一元二次** |
| 核心意义里直接写 \(s,p\) | 会把「是什么」和「为什么能换」粘在一起 |

### 7.4 与学习空间原子 `Sym` 的对齐

- `Sym` 的掌握证据应能分开看：会交换检验（核心意义）≠ 会说清为何用 \(s,p\)（WHY）≠ 会在题里改写消元（HOW）。
- 暂时不对称时先整理/缩放（如令 \(u=x/2\)），再重新检验——题绑定用 `Sym` 与 `U` 等组合，不把「整理」塞进 `Sym` 的前提。

### 7.5 一句话

对称 = 研究对象是无序对；二元无序对 = 一元二次方程的两根；韦达 = 两根由和与积完全确定。故可用 \(s,p\) 换元。

## 8. 给中学生怎么讲、可视化怎么做

### 8.1 口播结构（对应三层）

**核心意义（30 秒）**

> 交换 \(x\) 和 \(y\) 以后式子完全一样，就叫对称。目标、条件都要各检一次。

**WHY 第一步（40 秒）**

> 交换后一样，说明式子**分不清谁是 \(x\)、谁是 \(y\)**。我们真正研究的是「这两个数」——数学上叫**无序对** \(\{x,y\}\)，不是排好序的 \((x,y)\)。

**WHY 第二步（60 秒）**

> 两个数 \(x,y\) 一定是某个一元二次方程的两根：\(t^2-(x+y)t+xy=0\)。  
> 韦达定理说：两根之和、两根之积就是方程里那两个系数。  
> 所以给无序对建档，只要两栏：**和** \(s=x+y\)，**积** \(p=xy\)。知道 \(s,p\)，就能还原这一对（实数还要 \(s^2\ge 4p\)）。

**WHY 收束（20 秒）**

> 对称式只看无序对，无序对又完全由 \(s,p\) 决定，所以可以把目标和条件都改成只含 \(s,p\) 的式子。

**HOW（进例题再展开）**

> ① 交换检验 → ② 令 \(s,p\) 改写 → ③ 用 \(s^2\ge 4p\) 消元并验证取等。

禁忌：跳过检验直接令 \(s,p\)；只检目标不检条件；WHY 里开始解整道题。

### 8.3 一题口播示范（练习 8·17）

> **认：** 目标 \(x+y\)、条件 \(x^2+y^2-xy=1\)，交换都不变 → 对称。  
> **为什么能换：** 对称 ⇒ 只研究无序对 \(\{x,y\}\)；这一对是 \(t^2-st+p=0\) 的两根，韦达给出 \(s,p\)。  
> **做：** 条件 \(s^2-3p=1\)，目标就是 \(s\)；用 \(s^2\ge 4p\) 得 \(s\in[-2,2]\)；\(s=\pm 2\) 时 \(x=y\) 取得到。

### 8.4 验收标准

- 能区分三层：对称是什么 / 为何用 \(s,p\) / 题上怎么做  
- WHY 能复述两步：无序对；一元二次两根 + 韦达  
- 不把「令 \(s,p\)」说成定义，而说成对无序对建坐标  
- 做题仍先交换检验，再改写
