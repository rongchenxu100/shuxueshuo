# 工作台 API 接入与测试合同

> 2026-09-11 范围调整：当前首版以[工作台首版设计](workspace-product-design.md)为准，默认已接真实产品服务。本文件保留此前完整工作台方案供后续讨论，其中批量、修订和人工审阅不是当前首版交付要求。

当前任务：将工作台从 Mock 切换到产品真实批量服务。文件名保留以兼容已有链接；
排期以[在线服务开发计划](online-service-development-plan.md#11-实施顺序)为准，
协议和基础设施以[产品服务架构](product-service-architecture.md)为准。

## 1. 当前状态与目标

工作台现有上传/进度接口仍生成模拟数据；Review 已有真实生成与版本重建。
目标是两个入口调用同一后端应用服务。前端不启动 Worker，不实现另一套题意、Solver 或依赖判断。
Mock 留在测试/显式开发模式，不作为生产失败的自动 fallback。

## 2. 首版闭环

- 固定工作空间、无登录；多张完整单题截图上传并返回批次/任务标识。
- 列表逐题展示排队、阶段、成功、失败和取消状态；支持失败题单独重试。
- 页面预览与历史版本，人工通过绑定具体修订/构建。
- 题意 JSON 编辑、正式校验、差异预览、保存、影响预览及点击重建；复用后端既有合同。
- 教学/视觉/CSS 在仓库修改，重建范围由后端决定；不增加单题 HTML/JS 编辑器。
- 每题可进入 Review 查看阶段证据；普通工作台不展示底层 runtime identity/checkpoint。

首版不要求 Tutor、配音、播放时间线或整卷自动切题；已有图形、滑块及移动端可用性继续验证。

## 3. API 与事件

资源合同至少覆盖 Batch、Problem、Revision、Build/Job、Lesson、ReviewDecision。
上传、查询、修订与重建使用 HTTP；产品实时事件使用 WebSocket，迁移期的 Review SSE 共用事件记录。
合同包含版本、stable id、错误码和必要的重试信息，具体路径由产品 API 实现统一登记。

- 提交携带 request_id，重复提交返回同一逻辑结果。
- 任务已接受与任务完成分开显示；不能把队列确认当成生成成功。
- 首次加载/刷新查询快照与事件水位，订阅后补读缺失事件；去重并拒绝旧版本覆盖当前内容。
- 批次订阅复用连接；断线不取消任务，重连后恢复状态而非重发生成。
- 409 表示基础修订或计划已变，需要重新查看差异/影响；不能静默按新范围启动模型。
- 当前有效、过期、缺少证据、历史成功、人工通过分别表示；失败不显示旧页面为新结果。

未来学生会话只提交 session/lesson/step、用户输入及允许的 UI 状态摘要，
服务端构造受限上下文。个人学习状态不进入共享课程 HTML。

## 4. 前端实现与测试边界

组件面向统一数据接口，真实与 Mock 适配共享 decoder/Schema。测试 fixture 覆盖 loading、
success、partial、failed、canceled、stale、reconnect 和 schema incompatibility；不散落临时 JSON。
移除只为模拟流程服务的兼容字段，不能由前端自行创造 Solver 字段或猜测数学结果。

- 合同测试验证真实 API/事件与 fixture 使用相同 decoder。
- 批次并发与部分失败、单题重试、重复命令、事件去重/补读、刷新恢复。
- 修订冲突、失效范围提前、旧任务晚完成、失败后重试和人工通过版本失效。
- 图形状态、公式、键盘操作、移动端、reduce-motion；未来音频单独补充验收。
- 相关前端测试、lint、类型检查、生产构建和真实浏览器端到端链。

完成标准是从实际上传到实际页面与审查的闭环；仅切换 Mock 场景或接口形状一致不能宣称完成。
