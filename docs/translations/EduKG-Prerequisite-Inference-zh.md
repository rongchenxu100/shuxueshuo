## 摘要

教育知识图谱（Educational Knowledge Graph，EduKG）通过组织各类学习实体及其关系，为结构化学习与自适应学习提供支持。先修关系（Prerequisite Relation，PR）在 EduKG 中至关重要，它规定了概念应当按照何种逻辑顺序学习。然而，MOOC 平台 CourseMapper 当前使用的 EduKG 缺少显式的 PR 链接，而人工标注这些关系不仅耗时，也难以保证一致性。为解决这一问题，本文提出一种无需依赖标注数据、可自动推断概念间 PR 的无监督方法。我们基于文档特征、Wikipedia 超链接特征、图特征和文本特征定义了十项准则，并通过投票算法将其组合起来，以稳健地识别教育内容中的 PR。在基准数据集上的实验表明，本方法在保持可扩展性与适应性的同时，取得了高于现有方法的精确率，因而能够为 CourseMapper 中顺序感知的学习提供可靠支持。

**关键词：** 教育知识图谱；MOOC；先修概念识别；关系抽取；知识结构

## 1 引言

教育知识图谱（EduKG）在数字学习环境中承担着组织和表示关键实体及其关系的重要作用，并支持知识发现、概念导航和学习者建模 [1]。在我们的 MOOC 平台 CourseMapper 中，EduKG 为学习者提供学习材料所涵盖主要知识概念的结构化概览，以增进理解和参与度 [2, 3, 1]。然而，CourseMapper 当前 EduKG 结构的一项主要局限，是缺少先修关系（PR）。PR 描述概念之间的依赖：只有先理解某个概念，才能学习另一个概念。这些关系决定了掌握各主题的逻辑顺序，并为个性化学习序列推荐提供支持 [15]。若无显式 PR，学习者可能难以判断应当首先掌握哪些概念，进而妨碍自主学习和自适应推荐系统发挥作用。

既有研究已探索端到端学习方法、基于特征的方法以及用于 PR 抽取的混合方法 [6, 15, 12, 5]。端到端学习方法依赖特定领域的标注数据和静态特征，因此可扩展性有限。基于特征的方法仍得到广泛应用，它们依靠图结构、文本内容或 Wikipedia 数据捕捉概念依赖 [12, 7]。然而，这些方法存在若干局限：它们往往忽略语义信息与结构信息之间的相互作用，也常常只依赖概念顺序；此外，多数基于特征的方法分别评估各项准则，而不是综合不同准则的贡献来有效识别 PR。为克服这些局限，本文提出一种无监督多准则方法，通过投票算法综合文档特征、Wikipedia 超链接特征、图特征和文本特征的贡献，旨在有效抽取 PR，并丰富 CourseMapper 中 EduKG 的结构。

## 2 背景与相关工作

### 2.1 CourseMapper 中 EduKG 的生成

教育知识图谱表示学习情境中的多类实体及其关系，例如概念、教师、课程和机构 [1]。在我们的 MOOC 平台 CourseMapper [2] 中，教师可以上传学习材料（Learning Material，LM），系统随后会自动生成对应的 EduKG。图中包括 LM、幻灯片（Slide，S）、主要概念（Main Concept，MC）、相关概念（Related Concept，RC）、类别（Category，Cat）和学习者（Learner，L）等实体，并通过 `CONTAINS`、`CONSISTS_OF`、`RELATED_TO`、`HAS_CATEGORY`、`HAS_READ`、`UNDERSTOOD`（U）和 `DID_NOT_UNDERSTAND`（DNU）等关系将其连接起来。

系统使用关键词短语抽取算法识别每张幻灯片中的 MC。随后，这些 MC 经由 DBpedia Spotlight 完成扩展，由此加入更多作为 RC 和 Cat 的知识概念。之后，系统依据 EduKG 中的余弦相似度对 RC 和 Cat 进行筛选，仅保留最相关者 [3]。这一结构为学习者提供了 LM 中关键概念的有序视图。通过加入先修关系，还可进一步增强 EduKG：PR 能够对概念间的学习顺序进行建模，并支持自适应学习路径 [15]。目前，CourseMapper 的 EduKG 尚未包含 PR，因而对顺序感知学习的支持仍然有限。

### 2.2 先修关系抽取

PR 描述学习路径中概念彼此依赖的方式。识别 PR 的方法包括端到端学习方法、基于特征的方法和混合方法。端到端学习方法依靠深度学习从大型数据集中检测 PR [6, 19, 17]。基于特征的方法使用人工设计的特征 [15, 12, 7]，例如：捕捉图结构特性的图特征 [12]；利用描述与内容的文本特征 [23, 8]；以及利用超链接、点击流和类别的 Wikipedia 特征 [18, 5, 16]。混合方法则结合端到端学习方法和基于特征的方法 [12, 5]。

许多现有的 PR 端到端推断方法依赖特定领域的标注数据和过于简单的特征，因此难以扩展和适应不同场景。人工标注既耗时，又难以保持一致。多数基于特征的方法彼此独立地考察各项准则，往往忽略语义信息与结构信息的相互作用。为解决这些问题，本文提出一种无监督多准则方法，综合十项分别基于文档、Wikipedia 超链接、图和文本的准则。这些准则通过投票算法整合语义、结构和情境信息；该算法既平衡各准则的贡献，也减轻任一单独准则所带来的噪声。

本方法评估 EduKG 中的全部概念对。这一点对于非结构化内容尤其重要，因为仅凭结构准则可能产生误导。因此，引入利用外部资源与情境信息的额外准则，可以提高 PR 推断的准确性。我们在两个公开数据集上检验了该方法，并取得 \(1.0\) 的精确率，表明本方法具有稳健性、领域无关性，并能够有效抽取 PR。

## 3 方法

为了界定一个概念成为另一概念之先修概念的可能性，我们根据文献回顾制定并采用了一组适配本文场景的准则。这些准则分为文档特征、Wikipedia 超链接特征、图特征、层级特征和文本特征。多准则方法首先使用各项准则分别检查概念对，每项准则提供一种独特视角；随后，通过投票算法聚合各准则的输出，再执行阈值判定，以推断 PR 是否存在。

这些准则应用于 CourseMapper 的 EduKG 中所有概念对，并从两个方向进行考察，以确保识别全面。由于同义概念与自动重定向已在 CourseMapper 平台构建 EduKG 时得到处理，系统只会抽取不存在重复的唯一节点 [3]，故本文不再考察这两类情况。

在介绍模型结构之前，我们先给出三项核心假设：

1. **传递性（Transitivity）** [5, 4]：若 \(A\xrightarrow{\mathrm{PR}}B\)，且 \(B\xrightarrow{\mathrm{PR}}C\)，则 \(A\xrightarrow{\mathrm{PR}}C\)。
2. **非对称性（Asymmetry）** [5, 4]：若 \(B\rightarrow A\)，则 \(A\nrightarrow B\)。
3. **无自连接（No Self-Connection）** [4]：一个概念不能成为其自身的先修概念。

表 1 列出了各项准则的类别、全称、缩写和说明。

| Wikipedia 超链接特征 | 彼此条目中的超链接 | HL-A | \(c_2\) 的条目中提及了指向 \(c_1\) 的超链接 |

### 3.1 先修关系抽取特征

#### 文档特征

这一类别依赖文档结构，获取一篇文章中概念的时间顺序（Temporal Order，TemO）：先引入的概念被视为后续概念的先修概念 [19]。例如，在讨论“聚类”（Clustering）时，“机器学习”（Machine Learning）很可能先于“聚类”出现，因为理解前者是掌握后者的必要条件。若概念 \(c_1\) 的位置 \(P(c_1)\) 先于概念 \(c_2\) 的位置 \(P(c_2)\)，则 \(TemO(c_1,c_2)\) 取值为 \(1\)，否则为 \(0\)：

$$
TemO(c_1,c_2)=
\begin{cases}
1,&\text{若 }P(c_1)<P(c_2)\\
0,&\text{其他情况}
\end{cases}
\tag{1}
$$

TemO 仅适用于 MC，因为它依赖概念在 LM 中的出现顺序；RC 并未在材料中被明确提及，故不纳入此准则。

#### Wikipedia 超链接特征

既有研究通过分析概念对应 Wikipedia 条目的超链接结构，寻找概念之间潜在的 PR [20, 5]。

**彼此条目中的超链接（Hyperlinks on Each Other's Articles，HL-A）。** 此准则考察指向每个概念的超链接是否出现在其他概念相应的 Wikipedia 条目中。例如，若“机器学习”（\(c_2\)）的 Wikipedia 条目中存在指向“人工智能”（Artificial Intelligence，\(c_1\)）的超链接，则表明理解机器学习之前可能需要先理解人工智能，即 \(c_1\) 是 \(c_2\) 的先修概念。该关系形式化如下：

$$
HL\text{-}A(c_1,c_2)=
\begin{cases}
1,&\text{若 }c_1\in H_{c_2}\\
0,&\text{其他情况}
\end{cases}
\tag{2}
$$

其中，\(HL\text{-}A(c_1,c_2)\) 判断指向概念 \(c_1\) 的超链接是否存在于概念 \(c_2\) 的 Wikipedia 条目中：存在时取 \(1\)，否则取 \(0\)。\(H_{c_2}\) 表示概念 \(c_2\) 的 Wikipedia 条目中带有超链接的概念集合。

Wikipedia 条目中的超链接并不总是表示 PR，长条目或出现在条目末尾的超链接尤其如此。例如，若“监督学习”（Supervised Learning）出现在“机器学习”条目的末尾，就可能误导系统推断监督学习是机器学习的先修概念。因此，对于此类特殊情况，还需考虑专门关注条目摘要的准则 [10]。

**彼此摘要中的超链接（Hyperlinks on Each Other's Abstract，HL-Ab）。** 此准则用于判断指向 \(c_1\) 的超链接是否包含在 \(c_2\) 的摘要中。摘要通常给出简要定义；若概念 \(c_2\) 的摘要提到指向概念 \(c_1\) 的超链接，则说明 \(c_1\) 很可能是 \(c_2\) 的先修概念 [10]。例如，若“监督学习”的摘要引用“机器学习”，就意味着应当先理解机器学习，再学习监督学习 [10]。该关系表示为：

$$
HL\text{-}Ab(c_1,c_2)=
\begin{cases}
1,&\text{若 }c_1\in AH_{c_2}\\
0,&\text{其他情况}
\end{cases}
\tag{3}
$$

\(HL\text{-}Ab(c_1,c_2)\) 表示 \(c_1\) 是否为 \(c_2\) 的先修概念。若指向概念 \(c_1\) 的超链接属于 \(AH_{c_2}\)，则取 \(1\)，否则取 \(0\)；其中，\(AH_{c_2}\) 是概念 \(c_2\) 的 Wikipedia 条目摘要中带有超链接的概念集合。

**彼此相关概念摘要中的超链接（Hyperlinks on Each Other's Related Concepts' Abstracts，HL-RCA）。** 受“通过分析相关概念的重要性来推断 PR”这一思想 [9] 以及摘要中超链接作用的启发，我们提出了此项准则。该准则分析每个概念对各自相关概念的摘要。

以“人工智能”和“机器学习”为例：机器学习的一个相关概念“人工神经网络”（Artificial Neural Network），很可能在其 Wikipedia 条目摘要中引用人工智能；相反，人工智能的相关概念“知识表示”（Knowledge Representation），其条目摘要却不会提及指向机器学习的超链接。出现这一模式，是因为相关概念通常具有共同的先修概念。在本例中，人工智能同时是机器学习和人工神经网络的先修概念，如下式所示：

$$
HL\text{-}RCA(c_1,c_2)=
\begin{cases}
1,&\text{若 }c_1\in A_{RC_{c_2}}\\
0,&\text{其他情况}
\end{cases}
\tag{4}
$$

其中，\(A_{RC_{c_2}}\) 是 \(c_2\) 的相关概念之 Wikipedia 条目摘要中带有超链接的概念集合。若指向 \(c_1\) 的超链接存在于 \(A_{RC_{c_2}}\) 中，则 \(HL\text{-}RCA(c_1,c_2)\) 取 \(1\)，否则取 \(0\)。

**引用距离（Reference Distance，RefD）。** RefD 定义为概念对之间的引用距离 [9]。它根据 Wikipedia 条目间的引用链接测量其接近程度，是识别 PR 的良好指标。其基本思想是：对每个概念对，比较“\(c_1\) 的相关概念提及 \(c_2\)”与“\(c_2\) 的相关概念提及 \(c_1\)”之间的不对称性。例如，“数据挖掘”（Data Mining）的大多数相关概念都在各自条目中提及“数据科学”（Data Science），但数据科学的相关概念没有一个在条目中提及数据挖掘。我们对相应公式作如下调整，以适配本文系统：

$$
RefD_{(c_1,c_2)}
=
\frac{\sum_{i=1}^{k}r(R_{c_i},c_2)\,w(R_{c_i},c_1)}
{\sum_{i=1}^{k}w(R_{c_i},c_1)}
-
\frac{\sum_{i=1}^{k}r(R_{c_i},c_1)\,w(R_{c_i},c_2)}
{\sum_{i=1}^{k}w(R_{c_i},c_2)}
\tag{5}
$$

其中，\(C=\{c_1,\ldots,c_k\}\) 是概念空间，\(R_{c_i}\) 是 \(c_i\) 的相关概念集合，\(w(R_{c_i},c_1)\) 是 \(R_{c_i}\) 与 \(c_1\) 之间的余弦相似度，\(r(R_{c_i},c_1)\) 表示 \(c_i\) 的相关概念与 \(c_1\) 之间的关系；此处所谓 \(R_{c_i}\) 指向 \(c_1\)，即判断 \(c_i\) 的相关概念是否包含 \(c_1\)。随后，将 RefD 的结果与阈值比较，以确定是否存在 PR，如下方公式（6）所示：

$$
RefD(c_1,c_2)=
\begin{cases}
1,&\text{若 }-1<RefD(c_1,c_2)<-\theta\\
0,&\text{其他情况}
\end{cases}
\tag{6}
$$

若 RefD 结果位于 \(-1\) 与 \(-\theta\) 之间，则认为 \(c_1\) 是 \(c_2\) 的先修概念。反之，若结果位于 \(\theta\) 与 \(1\) 之间，则认为 \(c_2\) 是 \(c_1\) 的先修概念。结果位于 \(-\theta\) 与 \(\theta\) 之间时，无法推断出先修关系。阈值 \(\theta\) 由实验确定。反向关系定义如下：

$$
RefD(c_2,c_1)=
\begin{cases}
1,&\text{若 }\theta<RefD(c_1,c_2)<1\\
0,&\text{其他情况}
\end{cases}
\tag{7}
$$

**入链与出链之比（Inbound Links and Outbound Links Ratio，IOLR）。** 此准则通过比较一个概念的入链和出链来评估其连通性 [10, 5]。基础概念通常会获得更多入链，而高级概念往往具有更多出链。为减小普遍热门概念所造成的偏差，我们计算入链数与出链数的比值（Inbound-to-Outbound Links，IOL）；IOL 越高，说明概念越基础，因而越可能成为先修概念：

$$
IOL(c_i)=\frac{\sum inboundlinks}{\sum outboundlinks}
\tag{8}
$$

随后，定义比率准则 \(IOLR(c_1,c_2)\) 以确定关系方向：

$$
IOLR(c_1,c_2)=
\begin{cases}
1,&\text{若 }IOL(c_1)>IOL(c_2)\\
0,&\text{其他情况}
\end{cases}
\tag{9}
$$

#### 图特征

此类特征采用 DBpedia 的层级结构，其中 DBpedia 类别表示概念之间的层级关系。

**一个概念是另一概念的类别（One Concept Is a Category of Another Concept，CatCon）。** 类别刻画概念的核心主题，而理解一个概念通常要求掌握由其类别界定的基础要素 [20, 5]。依据 DBpedia 层级，若 \(c_2\) 被归入 \(c_1\) 之下，则可推断 \(c_1\) 是 \(c_2\) 的类别，因而也是 \(c_2\) 的先修概念。为将其形式化，令 \(K_{c_2}\) 表示与 \(c_2\) 关联的类别；\(K_{c_1}\) 的含义与之对应。公式如下：

$$
CatCon(c_1,c_2)=
\begin{cases}
1,&\text{若 }c_1\in K_{c_2}\\
0,&\text{其他情况}
\end{cases}
\tag{10}
$$

\(CatCon(c_1,c_2)\) 表示 \(c_1\) 属于与 \(c_2\) 相关联的类别。换言之，\(c_2\) 被归类在 \(c_1\) 之下。这强烈暗示 \(c_1\) 是 \(c_2\) 的先修概念。

**一个概念是另一概念的直接超类别（One Concept Is the Direct Super-category of Another Concept，SuperCatCon）。** 识别 PR 的另一项有用信号是概念的直接超类别，即 DBpedia 中该概念所属类别的类别 [20]。这遵循传递逻辑：若 \(c_1\)（机器学习）是 \(c_2\)（无监督学习）的类别，且 \(c_2\) 是 \(c_3\)（K-Means）的类别，则 \(c_1\) 是 \(c_3\) 的超类别，进而可推断 \(c_1\) 是 \(c_3\) 的先修概念。令 \(K^{up}_{c_1}\) 表示 \(c_1\) 的直接超类别；若其与 \(c_2\) 的类别相交，则存在 PR：

$$
SuperCat(c_1,c_2)=\left|K^{up}_{c_1}\cap K_{c_2}\right|
\tag{11}
$$

系统还会交换两个概念，以计算反向先修关系 \(SuperCat(c_2,c_1)\) 是否存在。随后，我们比较两者的不对称性，以避免类别相互交织。具体而言，要防止 \(c_2\) 的某些超类别同时也是 \(c_1\) 的类别，致使 \(SuperCat(c_1,c_2)\) 与 \(SuperCat(c_2,c_1)\) 暗示互为先修概念：

$$
SuperCatCon(c_1,c_2)=
\begin{cases}
1,&\text{若 }len(SuperCat(c_1,c_2))>len(SuperCat(c_2,c_1))\\
0,&\text{其他情况}
\end{cases}
\tag{12}
$$

当 \(SuperCatCon(c_1,c_2)=1\) 时，表明 \(c_1\) 有更多超类别同时也是 \(c_2\) 的类别，因而暗示 \(c_1\) 是 \(c_2\) 的先修概念。

#### 层级特征

这一类别捕捉教育内容的结构组织形式，依据概念在层级格式中的位置反映概念关系。该方法适用于所有采用层级结构的教育平台。Thareja 等人使用学术教材的层级结构对概念进阶过程建模，以检测 PR [17]；受其启发，我们在本文场景中采用类似策略，利用 CourseMapper 的课程层级定义 CourseMapper 层级（CourseMapper Hierarchy，CMH）准则，以捕捉课程层级内概念之间的 PR。

CourseMapper 中的课程按层级组织：一门课程包含多个主题，每个主题包含若干频道，而每个频道又包含多份 LM。由于主题、频道和 LM 的排列遵循顺序，这一层级组织可用于推断 PR。具体来说，需要较早访问的频道位于供后续学习的频道之前。通过利用这种结构化进阶过程，我们可以系统地推导同一门课程内不同概念之间的 PR。

$$
ConTop(c_1,c_2)=
\begin{cases}
1,&\text{若 }Top(c_1)>Top(c_2)\\
0,&\text{其他情况}
\end{cases}
\tag{13}
$$

此处，\(Top(c_1)\) 表示 CourseMapper 同一门课程内其学习材料出现 \(c_1\) 的主题或频道。若提及 \(c_1\) 的频道先于提及 \(c_2\) 的频道，则 \(ConTop(c_1,c_2)\) 取值为 \(1\)。在这种情况下，\(c_1\) 成为 \(c_2\) 先修概念的可能性会显著增加。

#### 文本特征

该方法将 BERTopic 与香农熵（Shannon's Entropy）结合，形成 BERTropy，以推断先修连接 [5]。在此语境下，“主题”指给定概念的 Wikipedia 摘要中讨论的题材。例如，“机器学习”条目的摘要可能包含“人工智能”和“统计方法”等主题。

该方法的基本直觉是：高级概念往往更加专门化，因而涵盖的主题更少；一般性概念则横跨更广泛的主题。为实现这一思想，系统使用 BERTopic 从概念 \(c\) 的 Wikipedia 摘要中抽取主题。模型为每个主题分配一个概率，表示该主题在摘要中出现的程度。令 \(P(x)\) 表示 BERTopic 判定主题 \(x\) 出现在概念 \(c\) 摘要中的概率：

$$
P(x)=\text{BERTopic}(x,c)
\tag{14}
$$

给定这些主题概率后，使用香农熵衡量摘要中的主题分布：

$$
EntPro(c)=-\sum_{x}^{X}P(x)\log\frac{1}{P(x)}
\tag{15}
$$

其中，\(X\) 表示所有已识别主题的集合，\(P(x)\) 表示概念 \(c\) 关于主题 \(x\) 的概率。熵值越高，说明概念越一般；熵值越低，则说明概念越高级、越聚焦。系统使用熵规则对所有概念对进行处理，以推断 PR。仅当二者之差超过阈值 \(\theta\) 时，才认为存在 PR。本文通过实验选取阈值，并将其设为 \(\theta=1.33\)；也就是说，当差值位于 \(0\) 至 \(1.33\) 之间时，认为不存在 PR。

$$
BERTropy(c_1,c_2)=
\begin{cases}
1,&\text{若 }EntPro(c_1)-EntPro(c_2)>\theta\\
0,&\text{其他情况}
\end{cases}
\tag{16}
$$

### 3.2 投票算法

将前述准则应用于每个概念对之后，系统使用投票算法确定概念对之间是否存在 PR 及其方向。首先，我们为所有准则赋予相同权重 \(1\)，即同等对待每项准则。这样可以避免推断偏向某一项特征，并确保没有任何一项准则支配最终决策。

随后，构造两个大小均为 10 的二进制数组（独热编码数组）\(A_1\) 和 \(A_2\)，分别对应 \(c_1\rightarrow c_2\) 与 \(c_2\rightarrow c_1\)，用于检查概念对在多大程度上满足预定义准则集。数组中的每个元素对应一项准则：满足准则时取 \(1\)，否则取 \(0\)。因此，只有得到满足的准则会对用于确定 PR 的最终计算产生贡献，未满足的准则不影响结果。

接着，分别对每个数组中的正值求和，以量化概念对在相应方向上得到满足的准则之总贡献。之后，将 \(A_1\) 的总分减去 \(A_2\) 的总分，计算二者之差：

$$
S_{\text{init}}=\sum A_1-\sum A_2
\tag{17}
$$

再对结果进行归一化。归一化是许多应用中的常见做法，也有助于为 PR 推断设定阈值。为此，将最终分数 \(S_{\text{init}}\) 从原始区间 \([-10,10]\) 缩放到标准区间 \([-1,1]\)，以便进行有意义的聚合并支持 PR 推断：

$$
S_{\text{new}}
=2\cdot\left(\frac{S_{\text{init}}-S_{\text{min}}}
{S_{\text{max}}-S_{\text{min}}}\right)-1
\tag{18}
$$

其中，\(S_{\text{new}}\) 是数组 \(A_1\) 和 \(A_2\) 总分之差的归一化结果；\(S_{\text{min}}\) 为最小值 \(-10\)，\(S_{\text{max}}\) 为最大值 \(10\)；\(S_{\text{init}}\) 是概念对在归一化之前的当前分数。

结果归一化后，我们将其划分为三个不同区间，并在正负两侧分别设定阈值 \(\theta\) 和 \(-\theta\)。第一种情况是 \(S_{\text{new}}\)（即两个数组之差）位于 \(-1\) 与 \(-\theta\) 之间，此时判定 \(c_2\) 是 \(c_1\) 的先修概念。若结果位于 \(-\theta\) 与 \(\theta\) 之间，则两个概念之间不存在 PR。最后，若 \(S_{\text{new}}\) 位于 \(\theta\) 与 \(1\) 之间，则判定 \(c_1\) 是 \(c_2\) 的先修概念。

\(\theta=0.28\) 的取值通过一系列实验凭经验确定，旨在找出最适合本文具体应用的参数设置，详见第 4 节。为进一步说明这一过程，表 2 给出了示例：在使用所有准则检查“机器学习”（\(c_1\)）与“监督学习”（\(c_2\)）这一概念对后，我们用两个独热编码数组 \(A_1\) 和 \(A_2\) 表示该概念对在两个方向上满足各项预定义准则的程度。

## 4 实验与结果

为证明所提方法的有效性与优势，我们使用两个公开数据集开展了全面实验和对比分析：AL-CPL 数据集 [18, 11, 10]，以及从生物学课程教材章节中构建的专门数据集 Biology [17]。

### 阈值优化

阈值本质上是一项超参数，用于控制模型判定 PR 时的敏感度。RefD、BERTopic 和所提投票算法的阈值均基于 AL-CPL 数据集，采用相同方法通过实验确定。具体而言，我们分别使用一系列阈值运行各方法，将结果与真实标注数据集进行比较，并计算精确率、准确率、召回率和 F1 分数。

RefD 方法通过分析 Wikipedia 链接结构中概念彼此引用的方式识别 PR。Wang 等人 [18] 最初提出的阈值为 \(\theta=0.04\)。我们在 CourseMapper 平台语境中复现该方法以生成 PR，发现当 \(\theta=0.6\) 时，精确率达到峰值，接近 \(0.9\)。这一结果符合我们的目标，即在尽量减少假阳性的同时可靠地检测 PR。

本文所用阈值高于以往工作，这是因为 EduKG 使用的概念空间具有更强的领域专属性。先前研究在完整的 Wikipedia 概念集合上运行，而本系统将范围限定在从 AL-CPL 抽取的概念及相关概念中，因此形成了更集中、更专门化的语义空间。

类似地，BERTropy 通过分析各概念摘要所涵盖主题的分布，推断概念之间的 PR。我们先计算全部概念的主题覆盖分布，再将 BERTropy 应用于整个概念集合，以确定概念间的 PR。实验发现，当 \(\theta=1.4\) 时，精确率达到峰值，约为 \(0.9\)。这表明较高阈值更为保守，只识别最强的关系；较低阈值虽然能连接更多主题，却可能引入噪声。

对于投票算法，我们通过实验观察到：当 \(\theta=0.28\) 时，精确率达到最大值 \(1.0\)，即在该阈值下，所有正向预测均正确，不存在假阳性。本文优先考虑精确率，因为与捕捉所有可能的 PR 相比，减少假阳性更加重要。错误的先修建议可能对学习路径和课程设计造成负面影响。

### 实验 1：在 AL-CPL 数据集上学习先修关系

为评估所提模型的有效性，我们使用 AL-CPL 数据集中的三个领域开展实验：数据挖掘、物理学和宏观经济学 [18, 10, 11]。该数据集使用三类关系标注概念：\(1\) 表示“先修”，\(-1\) 表示“反向先修”，\(0\) 表示“无关系”。

该数据集可验证除 CMH 以外的全部准则。CMH 需要内容层级，但材料上传到单一频道后，原有层级便会丢失，所有概念也会被视为处在同一层级。因此，层级信息仅用于具备相应结构的 Biology 数据集。我们将 AL-CPL 上传至 CourseMapper，并生成包含主要概念、相关概念和类别的 EduKG。随后，利用这组相关概念推断 CourseMapper 学习材料中各概念对之间存在 PR 的可能性。

#### 单项准则评估

为评估每项准则的贡献，我们在数据挖掘、物理学和宏观经济学三个领域开展实验。精确率方面，在数据挖掘领域，BERTropy 达到 \(1\)，HL-Ab 达到 \(0.84\)，RefD 达到 \(0.84\)，均取得显著效果；在物理学领域，HL-Ab 和 CatCon 均达到 \(1\)，表现良好；在宏观经济学领域，CatCon 以 \(0.86\) 的精确率表现最佳。

召回率方面，IOLR 在数据挖掘、物理学和宏观经济学三个领域分别达到 \(0.83\)、\(0.84\) 和 \(0.91\)，始终优于其他所有准则，能够有效捕捉更广泛的先修关系。相反，SuperCatCon 的精确率和召回率均表现欠佳，说明该准则仍有待改进。

为评估精确率与召回率之间的平衡，我们进一步分析了 F1 分数。IOLR 在数据挖掘、物理学和宏观经济学三个领域分别取得最高的 \(0.67\)、\(0.55\) 和 \(0.59\)，证实其能够有效维持二者之间的权衡。

尽管准确率可能对类别不平衡较为敏感，我们仍将其纳入评估，并从中观察到一些有用趋势。例如，HL-A 在数据挖掘领域取得 \(0.65\) 的较高准确率；CatCon 在物理学和宏观经济学领域分别取得 \(0.70\) 和 \(0.63\) 的较高准确率，但其 F1 分数较低。这说明 CatCon 可能偏向多数类，却不善于识别少数类。

各项准则在不同领域的表现差异，可归因于概念结构和语义清晰度的不同。例如，数据挖掘和物理学数据集往往包含定义明确、层级清晰且技术专属性较强的概念，这与利用结构或语义特征的准则较为契合。相比之下，宏观经济学领域通常更抽象，正式结构也较弱，因此某些方法更难识别清晰的 PR。与既有工作一致，本文更加重视精确率，因为推断所得 PR 的可靠性对下游任务与系统实用价值至关重要。

#### 对比结果与分析

为评估本模型在不依赖标注数据的情况下捕捉 PR 的有效性，我们将其与六种基线方法进行比较：RefD [9]、主动学习（Active Learning）[11]、AdaBoost [22]、WikiCPRL [21]、神经网络（Neural Network）[14] 和语言学驱动策略（Linguistically-Driven Strategy）[13]。如表 4 所示，我们在数据挖掘、物理学和宏观经济学三个领域评估了投票算法。

与现有基线相比，所提投票算法始终取得更高的精确率，但召回率和 F1 分数较低，这反映出该算法专注于仅可靠地抽取最强关系边。例如，在数据挖掘领域，本方法的精确率达到 \(1.0\)；RefD、主动学习和 AdaBoost 的精确率较低，分别为 \(0.51\)、\(0.80\) 和 \(0.85\)，但召回率分别达到 \(0.76\)、\(0.73\) 和 \(0.85\)，F1 分数分别为 \(0.61\)、\(0.67\) 和 \(0.85\)。

类似地，在物理学领域，基于 Bagging 的 AdaBoost 取得 \(0.87\) 的精确率，高于本方法的 \(0.76\)；RefD 和 WikiCPRL 等其他基线的精确率分别为 \(0.49\) 和 \(0.43\)，低于本方法，但召回率较高，分别为 \(0.49\) 和 \(0.90\)。神经网络和语言学驱动策略也呈现相同趋势：在数据挖掘领域，它们凭借更强的召回能力，分别取得 \(0.65\) 和 \(0.81\) 的 F1 分数，均高于本方法的 \(0.42\)。

这一模式表明，尽管基线方法总体上找回了更多链接，本方法却优先保证推断所得 PR 的精确性和可靠性，而这对于构建稳健的学习路径至关重要。在教育场景中，用错误的先修概念误导学习者（假阳性），比遗漏某些先修概念的危害更大。

不过，基线模型的召回率更高。我们认为，这是因为本文在 RefD 和 BERTropy 等准则中选择了以精确率为导向的阈值。这些阈值经过调优，旨在优先保证可靠性而非关系数量，因此推断出的关系更少，却更准确。这一现象也可归因于前述不同领域在概念结构和语义清晰度上的差异。

虽然召回率较低，融合多种基于特征方法的投票算法无需任何标注训练数据，仍然取得了有竞争力的表现。因此，它尤其适合真实场景，因为这类场景的先修关系标注数据往往有限或难以获得。监督模型能够访问标注数据，故其性能通常优于无监督模型；但人工标注成本高、耗时长，且容易出现不一致。多数无监督方法分别评估各项准则，而不是将其整合起来以更有效地识别 PR。本文的无监督多准则方法填补了这一空白：它通过可扩展、灵活的投票算法推断 PR，尤其适用于缺少标注的多样化教育领域。

### 实验 2：在 Biology 数据集上学习先修关系

为了有效评估所提模型检测 PR 的能力，更可靠地评估 TemO 准则，并衡量 CMH 的贡献，我们使用了一个源自 NCERT 生物学课程教材章节的专门数据集 [17]。NCERT 教材可从 https://ncert.nic.in/textbook.php 获取。

实验选择了 NCERT 科学教材中两个概念相关的章节：七年级第 7 章“动物和植物的运输”（Transportation in Animals and Plants）以及十年级第 6 章“生命过程”（Life Processes）。选择这两章是因为它们之间存在自然的层级关系：七年级的基础内容为十年级的高级概念提供支持。

我们将两章内容上传至 CourseMapper 中的同一门课程和同一主题，但分别放入前后相继的两个频道，以保留平台定义的学习层级。我们分别从每章抽取主要概念，再使用 DBpedia 对其扩展以识别相关概念，从而为每章单独生成 EduKG。借助这一结构，我们得以评估所有十项预定义准则检测 PR 的能力。

值得一提的是，添加新的学习材料时，系统只为这份新材料计算 EduKG，而无需重新处理整个 EduKG。原始数据集并无真实标注，因此，我们请领域专家（博士与医学博士）将 186 个概念对人工标注为“先修”或“非先修”。

#### 单项准则评估与对比结果

我们使用精确率、召回率、F1 分数和准确率四项标准指标，在 Biology 数据集上评估每项单独准则（见表 5）。HL-Ab 和 HL-A 的精确率最高，能够在尽量减少假阳性的同时有效识别最可靠的 PR。相比之下，IOLR 和 CMH 的召回率最高，它们以容忍部分假阳性为代价，捕捉到范围更广的依赖关系。

值得注意的是，IOLR 和 CMH 同时取得最高的 F1 分数，说明它们在精确率与召回率之间保持了良好平衡。准确率方面，BERTropy 表现最佳，达到 \(0.75\)；IOLR 和 CMH 紧随其后，进一步表明这些准则能够稳健地区分先修概念对与非先修概念对。

CMH 的成功尤其凸显了结构化教育内容与层级信息在推断 PR 时的价值。该数据集中，材料在各频道间的位置有清晰定义，因此 CMH 能够有效利用这一顺序。相比之下，CatCon 和 SuperCatCon 依赖 DBpedia 的类别层级，TemO 依赖概念在文本中的先后出现，而这两类信息在当前数据集中都不够一致。若加入更多章节，它们的效果可能有所改善。

相比之下，所提投票算法虽然取得了有竞争力的结果，却未超过 CMH 和 IOLR 等表现最佳的单项准则。其精确率和召回率均处于中等水平；各准则独立应用时，投票算法呈现出一定平衡性，但性能仍然有限。投票算法的有效性主要由 CMH 和 IOLR 等强贡献准则支撑。CMH 依赖层级信号，因而取得较高 F1 分数；IOLR 则受益于入链—出链比率，而这两类特征在 Biology 数据集中都得到了尤其良好的体现。

上述发现凸显了整合层级信息的重要性。本文定义的准则分别从 Wikipedia 条目、DBpedia 层级、文本信息、内容顺序和平台层级中推导 PR，因而能够适用于多种教育平台。

## 5 结论与未来工作

教育知识图谱（EduKG）捕捉教育系统中的多类实体及其连接，为学习材料中的关键概念提供结构化视图。先修关系（PR）对于界定学习顺序不可或缺，但 EduKG 中往往缺少这类关系。然而，自动识别 PR 的方法通常依赖特定领域的标注数据和静态特征，因此可扩展性有限。现有基于特征的方法常常忽略语义信息与结构信息之间的相互作用，过度依赖概念顺序，并且分别评估各项准则。

为弥补这些不足，本文提出一种无监督方法：通过投票算法组合十项准则，在不使用标注数据的情况下推断 PR。两个基准数据集上的实验表明，所提方法的精确率高于基线，并能跨领域可靠地抽取 PR。

未来，我们计划使用更多准则扩展 PR 识别框架，还将探索混合方法和基于大语言模型（Large Language Model，LLM）的方法，以更有效地识别 PR。此外，可针对不同领域分别学习自适应阈值，并将其与加权方法结合，以进一步增强 PR 推断的稳健性与准确性。
