## 1. 本型目标与建设顺序

T3 要解决的是：没有给出对应关系 $f$ 的具体解析式，但已经知道它允许接收哪些输入，求新表达式关于外层自变量的定义域。关键是始终分清两个概念（见 §1.1）：**某式的定义域**（外层自变量的取值范围）与 **$f$ 的输入范围**（同一对应关系可接收的输入集合，不随写法改变）。

### 1.1 定义域与 $f$ 的输入范围

讲解与交互统一使用下列用语，避免把「自变量」同时指外层 $x$ 和传给 $f$ 的式子。

| 用语 | 指什么 | 题面例子 |
| --- | --- | --- |
| **定义域** | **永远**指某个已写出表达式／函数，对其**外层自变量**（本批记为 $x$）的全部合法取值 | 「$f(2x-1)$ 的定义域」「$f(x+2)$ 的定义域为 $[-3,2]$」说的都是外层 $x$ 的范围 |
| **$f$ 的输入范围** | 对应关系 $f$ **自身**允许接收的输入集合；同一 $f$ 不论写成 $f(x)$、$f(t)$ 还是 $f(2x-1)$，该集合**始终一致** | Q25 由「$f(x)$ 的定义域为 $[-3,2]$」读出：当自变量就是输入本身时，定义域与输入范围数值相同，故 $f$ 的输入范围为 $[-3,2]$ |
| 完整输入 | 某次调用里实际送进 $f$ 的那个式子，如 $2x-1$、$x+2$ | 必须整体属于 $f$ 的输入范围，不能拆成「把 $x$ 限制在输入范围里」 |

因此：

1. 题面说「$f(u(x))$ 的定义域为 $E$」时，已知的是外层 $x\in E$，**不是**直接把 $E$ 当成 $f$ 的输入范围。
2. 只有在写法恰为 $f(x)$（输入＝自变量）时，才可把「定义域」与「$f$ 的输入范围」读成同一集合；教学上仍先点名两个概念，再说明此刻重合。
3. 机器内部可用 $D_f$ 表示 $f$ 的输入范围；面向学生的卡片、反馈和结论板优先写「$f$ 的输入范围」，需要对照题面「$f(x)$ 的定义域」时再显式对齐，不默认学生把二者当成同一个词。

## 2. 范围及不确定情况

### 2.1 第一批：已知原函数完整定义域

实函数 $f$ 的定义域 $D_f$ 明确、非空，限有理端点的单一区间、半轴、全体实数或单点集合；目标为 $f(ax+b)$，$a,b$ 是固定有理数。允许题面另外限制目标外层变量 $x\in J$，$J$ 使用同一集合范围。实际表达式长度、系数位数及集合复杂度上限在 S0 定稿，准入、求解和验证共用。

正向目标为

$$
D_{f(ax+b)}=\{x\in J\mid ax+b\in D_f\}
$$

未另限范围时 $J=\mathbb R$。对 $a>0$、$a<0$、$a=0$ 全部覆盖：负斜率时交换端点及其开闭归属；常量输入时先检查 $b\in D_f$，成立返回 $J$，不成立返回空集。空结果表达为“原表达式没有合法实数输入”，不制造一个满足高中定义的空定义域函数。题面给出的 $D_f$ 为空属于无效函数声明，不能混同目标合法输入为空。

### 2.2 第二批：从复合形式反推原输入域

题面明确给出 **$f(cx+d)$ 的完整自然定义域恰为 $E$**；外层 $x$ 没有额外限制，$c,d$ 是固定有理数且 $c\ne0$。因为 $x\mapsto cx+d$ 在 $\mathbb R$ 上是一一对应，才可确定

$$
D_f=\{cx+d\mid x\in E\}
$$

随后按第一批求目标 $f(ax+b)$ 的定义域。恢复阶段的 $c\ne0$ 与目标阶段允许的 $a=0$ 是不同前提；不能为方便计算统一拒绝全部常量目标，也不能把反推常量输入强行当作可逆变换。

本批已实现上述恢复路径：描述字段 `known_form` 区分 `identity`／`affine`，保留已知调用自己的变量、完整输入及固定有理系数；目标变量独立绑定。已知侧额外限域仍不准入，不能搬到目标 `input_domain` 规避检查；题面单独给出的目标外层范围 $J$ 沿用第一批支持。

以下语义必须分开：

- “定义域恰为 $E$”是完整集合等式；“在 $E$ 上有意义”只提供合法性下界，不能推出域外均非法。
- 若题设已把外层限制在 $J$，只知道 $J\cap u^{-1}(D_f)=E$，不能把 $u(E)$ 当成全部 $D_f$。
- 非满射 $u$ 通常只确定 $D_f\cap\operatorname{Im}(u)$；例如 $f(x^2)$ 定义域为 $\mathbb R$，只能确定 $[0,+\infty)\subseteq D_f$，负半轴仍未知。
- 常量 $u(x)=d$ 只能判断 $d$ 是否可输入，不能恢复整个 $D_f$。若已知其完整自然定义域是非空真子区间，还应识别题设冲突。

非满射下，某些目标只用到已确定的输入部分，仍可能得到唯一结果；本轮明确不开放这类部分信息推理，提示当前能力范围，不能笼统宣称这些问题数学上无解。

### 2.3 第三批：抽象调用与具体限制合并

已实现目标族 $f(ax+b)/\sqrt{px+q}$ 和 $f(ax+b)/(px+q)$ 的识别、求解与独立验证，系数为固定有理数，包含正负斜率及 $p=0$ 的常量分母分支；目标输入仍允许 $a=0$，已知域来源沿用前两批。保留可能的目标外层范围 $J$。结构简单不等于可忽略零分母、负常量被开方数或空交集。

阶段一的 `target_call` 保留完整目标原式；确定性描述同时保留完整目标 AST／LaTeX、抽象调用输入、具体分母 AST／LaTeX 与位置，不提前拆题或化简。抽象调用和分母必须使用同一目标外层变量，已知调用的哑变量仍独立绑定。

公开输入仍保留既有语义准入：恒零分母、常量负数开平方等无效原式应明确拒绝，不能为返回空集而绕过校验。有效原式的输入条件互斥或与外层范围不相交，才正常返回空的合法输入集合；内部数学探针可以检查无效常量结构无合法输入，但不把它计为公开题目求解通过。

M2 负责 $ax+b\in D_f$；S3 负责具体分母的原式限制。根式分母保留 $px+q\ge0$ 与 $\sqrt{px+q}\ne0$ 两条来源，再验证归约为 $px+q>0$；普通分母保留 $px+q\ne0$。最后取交集，即使其中一条约束对最终集合冗余也保留证据。

本节固定系数域计算不开放多层抽象嵌套、多函数调用、含参内层式、任意非线性内层式或一般分段域；多个含参调用的求参目标独立按 §2.4 准入。不从“$f(t)$ 有定义”推断 $f(t)\ne0$ 或 $f(t)\ge0$：$1/f(u)$、$\sqrt{f(u)}$、$f(u)^0$ 涉及函数值条件，仅知定义域通常信息不足。若另有充分函数值事实，留待扩展契约。

### 2.4 含参扩展：多个调用有共同合法输入

代表题为用户提供教材第85页变式2：若 $f(x)$ 在 $[0,1]$ 上有定义，要使 $f(x+a)+f(x-a)$ 有意义，求 $a$ 的范围。原图只裁取完整题干与 A–D，不包含教材解答，题源为 `function-concepts-parameter-variant02`。

新增目标 `find_abstract_domain_parameter`，保留 `known_call`、`known_domain`、`strength`、完整 `target_call`，显式区分 `variable`、`parameter`，量词为 `exists`。已知调用限恒等形式 $f(t)$，已知输入范围限有理端点的非空有限区间或单点；目标支持同一 $f$ 的多个调用相加、相减或相乘，每个完整输入为 $Ax+Ba+C$，系数为固定有理数。保留原始各调用，禁止用约消丢掉其限制。不支持未知函数值条件、多个参数、非线性或嵌套调用。

题面“在区间上有定义”保留 `meaningful_only`，不能改写成完整定义域。该目标求的是**在题设给定输入范围内，能保证存在一个共同合法 $x$ 的参数**；若给定完整定义域则为精确参数范围。两种语义分别记录 `guaranteed_parameter_range` 与 `exact_parameter_range`，不据前者断言区间外无定义。

求解复用 M2：逐个列输入条件，形成关于 $x$ 的区间；每一下界与每一上界比较，要求交集非空。任一端点开放时对应比较严格；$x$ 系数为零的调用直接形成参数约束。正负系数、常量输入、冗余约束、空集和单点参数集随通用能力实现。独立验证从原目标 AST 重读条件，在参数临界点及各间隔重新求 $x$ 的可行集并给出共同取值见证，不复用执行器的消元结果。

变式2的数学路径为

$$
0\le x+a\le1,\quad 0\le x-a\le1
\Rightarrow [-a,1-a]\cap[a,1+a]\ne\varnothing
\Rightarrow -a\le1+a,\quad a\le1-a
\Rightarrow a\in[-\tfrac12,\tfrac12].
$$

交互按区间结构推荐思路，不按题号指定算法，也不把另一条有效思路判为错误：

- 相对顺序固定、只有一个区间、单点范围、含独立参数限制或多于两个区间：直接列交集非空条件。
- 两个区间各自始终非空、相对顺序随参数变化、没有独立参数限制：优先找两个区间完全错开的情况，求空交集对应的参数，再在全体实数中取补集。本题属于这一类。
- 数学执行同时计算直接解与反向解，并检查两者一致。空交集条件在两个相接端点都包含时用严格不等号；任一端点开放时包含相接情况。存在独立参数限制时，补集结果仍须与其求交，不能直接把全部坏参数外的数都当合法。

本题改为六张局部推导卡：列输入条件 → 分别求允许范围 → 观察公共部分 → 判断两种完全错开的条件 → 求空交集参数范围 → 取补集。先得到 $1-a<a$ 或 $a+1<-a$，再得坏参数集 $(-\infty,-\frac12)\cup(\frac12,+\infty)$，最后取补集。加上读题、认型、选法、边界复核和原题收束，共十一项确认；直接法仍用四张推导卡。

观察卡使用可拖动参数的区间数轴：每个调用一行、公共部分单独高亮，区分重叠一段、共有一点和交集为空。临界值按钮方便观察接触状态，但图只报告当前数值下的状态，不先给最终参数范围。分离卡并列显示 A 在 B 左侧与 B 在 A 左侧两幅示意图，标出真实符号端点，由学生分别选择相应不等式。图上的探索不改变答题进度；每卡完成后才填入右侧结论。未注明选择模式继续按不定项选择，精确匹配标签集合 `[B]`。

$$
-3\le2x-1\le2
\quad\Longleftrightarrow\quad
-1\le x\le\frac32

## 5. 方法、技能与证明职责

### 5.1 原题表达与共享来源规则

当前原题契约保留以下语义：

- 抽象函数身份与实值语义、调用中的绑定外层变量、参数原始 AST 和原文位置。
- 已知域事实的对象：`f` 本身或完整调用 `f(u(x))`；域集合、等式／仅有意义的关系强度、作用域和任何题设外层范围。
- 目标表达式及目标外层范围，不在阶段一写入推导后的 $D_f$、不等式或最终集合。
- 多目标各自的 `target_ref` 与依赖，Q13 保留两个目标；已知值域不会被错当目标或删掉。

提取、复核和修复共用 [graph-stage-one-source-rules.md](../internal/llm-prompts/graph-stage-one-source-rules.md)。提取保留原题的函数名、目标和完整输入关系；内部别名绑定原文，不改公开题面。`f(x+2)` 的定义域指外层 $x$，不是参数 $x+2$ 的范围；这是语义校验和读题交互的共同依据。

公共题目身份包含已知域所归属的对象、内层表达式、端点及目标范围。不能将“$D_f=E$”和“$D_{f(x+2)}=E$”去重成一题。格式归一允许合法空格／TeX 写法，但不得化简原结构或改动证据位置。

Q13 已冻结的字段：`find_abstract_domain` 可带 `known_range`；独立的 `find_abstract_range` 必须带 `known_call`、`known_domain`、`known_range`、`strength`、`target_call`。`known_range` 仅表示已知调用的完整值域，不参与定义域约束。两个目标共享当前作用域的函数身份，外层变量与 `target_ref` 独立；同一已知调用的冲突域／值域拒绝接入，值域变化参与公共题目身份。已知值域需绑定原文来源，不能靠其他函数或兄弟题的区间补齐。提取、复核、修复及公开题面使用同一规则。

拍题学沿用目标标签切换：定义域可独立完成，值域保留并提示“这个目标暂未支持”；完成卡只确认当前目标，不显示整题全部完成。原题没有小问编号时不生成假小问，待 T5 开放后再实现值域目标。

### 5.2 M2 输入、产物与完成条件

面向执行器用 $D_f$ 表示 **$f$ 的输入范围**；面向学生的投影按 §1.1／§6 区分「定义域」与「输入范围」。

| 内容 | 契约 |
| --- | --- |
| 输入 | 来源清楚的抽象域事实（已知对象是 $f$ 还是某个 $f(u(x))$ 的定义域）、调用表达式、外层范围及本批支持的具体限制 |
| 取得／恢复输入范围 | 若已知恰为 $f(x)$ 的定义域，对齐为 $D_f$；否则检查完整自然域与全局仿射覆盖，调用换元并证明 $D_f=u(E)$ |
| 建立限制 | 从目标 AST 提取传入 $f$ 的完整输入 $v(x)$，生成 $v(x)\in D_f$；保留具体分母等原式条件及 $J$ |
| 解与合并 | 不等式技能处理仿射逆像；零系数做成员判断；与具体限制和 $J$ 求交，得到目标式关于外层自变量的定义域 |
| 输出 | 目标定义域、所用 $D_f$（原给或恢复）、每项来源／位置／知识依据、变换证书、交集与端点记录 |
| 完成 | 证明定义域内输入全部合法，并且其外均因至少一项原限制非法；只得到中间 $D_f$ 不算完成目标 |

每条抽象输入条件保留类似 S3 的 `source_ref`、`ast_path`、原 AST、稳定条件身份和依据引用，但注明由 M2 产生；不能伪造 S3 调用记录。相同文本出现在不同位置时保持来源独立。约束求交后，条件清单与解集一一对应，不根据数组位置猜数轴标签。

### 5.4 独立数学验证

验证器直接读冻结原域事实和目标 AST，独立计算支持族的仿射像／逆像及具体限制，并校验集合等式。原域恢复须验证双向：$x\in E\Leftrightarrow u(x)\in D_f$，并证明 $u$ 覆盖全部实数；只有在 $E$ 上试值不够。

正向与混合结果验证 $x\in A\Leftrightarrow[x\in J\land v(x)\in D_f\land C(x)]$，其中 $C$ 保留原式所有具体条件。针对候选端点、开区间及其补集使用精确集合运算和符号证书，不仅核对端点或随机采样。篡改斜率符号、覆盖前提、端点、来源归属或删除分母条件必须被拒绝。

## 6. 学生交互与共同题页

### 6.1 每步一张推导卡

Q25、Q26 共用「求 $f$ 的输入范围 → 列出目标函数的输入条件 → 求目标函数的定义域」三步，随后复核端点。Q25 第一步直接对齐已知域；Q26 第一步由已知复合调用恢复输入范围，不另加一张恢复卡。每张卡只展示本步用到的已知量与本步产物，通过 `⇒` 连接。移除常驻三行对照板，不在每一步重复完整输入、输入范围与最终定义域。

混合题扩为五张局部推导卡：「求 $f$ 的输入范围 → 列出抽象调用的输入条件 → 求抽象调用允许的范围 → 求分母允许的范围 → 取交集，写出定义域」，随后复核边界并完成原题终答。

卡片标题说明正在做什么，左右项的标签明确数学对象。涉及完整目标时统一使用从目标 AST 生成的原式，混合题不能只显示分子；讨论抽象调用时明确标为「抽象调用」。已知式若写成 $f(t)$，仍保留其来源身份，不能把它用作目标标签。避免用“本式”让学生猜当前指哪个函数。

作答前右侧数学内容为空位；答对后以相同结构展示本步完成结果。错误选择停在当前卡，不填结果、不解锁下一步。选项可以列出候选答案，题干示意和完成反馈不得在选择前突出正确答案；已知条件与此前已确认的结果可正常显示。

数轴、端点连线或动画只在相应步骤确有帮助时使用。本轮不新增常驻上下轨、函数值输出区或三维组件。

### 6.3 共同运行时边界

静态专题与拍题流式课程共用运行时、工具栏、集合评分和回放。推导卡使用下列结构，标签、数学内容和补充说明分别传递，前端不解析整段文字来猜对象：

```json
{
  "layout": "derivation",
  "caption": "本步推导",
  "items": [
    {"label": "本步已知", "math": "2x-1\\in[-3,2]"},
    {"label": "目标函数的定义域", "math": null, "note": "请选择后确认"}
  ],
  "connector": "⇒"
}
```

`caption` 使用本步短标题；两项的 `label` 指向具体对象，`math` 是公式字符串或 `null`，可选 `note` 只补充必要说明。作答前的 `stem_board` 右项必须为 `null`；完成后的数学高亮使用同一结构，填入本步答案。完成高亮只在当前步已通过或 AI 回放到该步时展示，不能提前显示。

自己做模式误选不推进，刷新恢复当前步骤，重开练习清空自己做进度。AI 与自己做进度隔离，切换模式不能借用另一模式的完成状态。专题静态课包、拍题流式结果及回放保持同一结构；布局在窄屏可上下排列，但推导方向与标签归属不变。

纯公式行不机械加中文句号。反馈直接说明本步错误，例如「这里送入 $f$ 的是整个 $2x-1$，不是单独的 $x$」。新的视觉投影不修改提取、数学求解、独立验证或评分含义。

| 类别 | 例子／操作 | 必须断言 |
| --- | --- | --- |
| 基本正向 | Q25、Q2 | 分别得到 $[-1,\frac32]$、$[0,1]$，原域未当作答案 |
| 负斜率与端点 | $D_f=(-1,2]$，求 $f(3-2x)$ 的域 | $[\frac12,2)$，闭端点随映射正确交换 |
| 常量目标 | $D_f=[-1,1]$，求 $f(1)$、$f(2)$ 作为外层 $x$ 的常量表达式的合法输入 | 分别为 $\mathbb R$、空集；另限 $J$ 时结果分别为 $J$、空集 |
| 单点和无界 | $D_f=\{1\}$，目标 $f(2x-1)$；$D_f=(0,+\infty)$，目标 $f(-x)$ | 分别 $\{1\}$、$(-\infty,0)$，无穷不可闭合 |
| 额外外层范围 | Q25 另限 $x\in(0,2)$ | $(0,\frac32]$，显式范围来源保留 |
| 正向空交集 | $D_f=[1,2]$，目标 $f(x)$ 且 $x<0$ | 空集；不是执行失败，也不造空域函数对象 |
| 正向范围冲突 | 题设声明 $D_f=\varnothing$；区间端点倒置 | 拒绝无效声明，不“修正”成合法函数 |

| 常量反推 | $D_{f(2)}=\mathbb R$；或声称 $D_{f(2)}=[0,1]$ | 前者不足以恢复全域，后者与完整自然域语义冲突 |
| 仅有意义 | 只给 $f(x+2)$ 在 $[-3,2]$ 有意义 | 不当作完整定义域；不能以此输出唯一完整目标域 |
| 非满射反推 | $D_{f(x^2)}=\mathbb R$ | 不反推 $D_f=[0,+\infty)$；记录本轮推理范围外 |
| 外层受限反推 | $g(x)=f(x+2)$ 且另限 $x\in[0,1]$，已知 $D_g=[0,1]$ | 不能断言 $D_f=[2,3]$ |
| 混合与负斜率 | Q27 恢复样例 | $(1,\frac52]$；抽象条件及两条根式分母来源均在 |
| 常量具体限制 | 分母为 $0$、非零常量；根式分母被开方数为负、零、正 | 零分母、负常量根式或零根式分母在公开准入报告无效原式；有效非零常量分母保留原抽象域及外层范围，不默默省略检查 |
| 冗余分母条件 | $D_f=[1,2]$，求 $f(x)/(x+1)$ 的域 | $[1,2]$，条件清单仍含 $x+1\ne0$ |
| 函数值未知 | 仅给 $D_f$，目标 $1/f(x)$ 或 $\sqrt{f(x)}$ | 不能用域条件替代零点／符号条件，不输出无依据答案 |
| 原图与目标归属 | $f(x)$／$f(x+2)$、$2x-1$／$2-x$、开闭括号、Q13 双目标 | 格式差异可归一；数学差异不被抹平；兄弟目标不串结果 |
| 证据篡改 | 修改恢复域、交换端点、删除具体条件、伪造满射 | 独立验证失败，不能以执行器自报 passed 完成 |
| 逐步推导投影 | 三步的待答卡／完成高亮、错误选择、刷新、AI 切换及窄屏 | 每卡只展示本步两项；待答右项为空，完成后才填；目标函数一致；错答不推进；恢复与两种模式相互隔离 |
