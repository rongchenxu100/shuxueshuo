# FR-T1 B 待定系数法：开发与验收记录

日期：2026-11-01。新增 `method-function-coefficients`（待定系数法求函数解析式）与 `skill-polynomial-coefficient-comparison`（多项式恒等式比较系数），沿用 `rule-function-formula-method`。独立专题现有 11 道题、3 个方法小组；尚未部署。

## 声明范围

- 题面明确给出未知函数为一次或二次函数；关系在实数范围恒成立。设完整一般式并保留最高次项系数非零，不能由右式次数猜函数类型。
- 支持一条主要等式及至多三条附加等式，包括函数复合、差分和初值条件。各式原文、未知函数作用域和来源一起保留，不能为准入删除初值或将未知函数改为已知定义。
- 支持固定有理数、加减乘、非零常数作除数及一次／二次幂；最多两层未知函数调用。展开后原变量次数和系数总次数均不超过二次，单个多项式最多 32 项，AST 总节点最多 256、深度最多 16，有理数分子／分母最多 64 位。
- 解出有限且完整的实系数组合，最多四组；每组必须满足类型与全部原等式。无合法候选、欠定／无限候选及超出预算的系统返回明确的执行诊断，不发布虚构的唯一答案。本批没有开放一般高次或含未知参数的函数方程。
- 保留原题的解析式、指定函数值或 `f(x)` 与常数比较的不等式目标。若多个候选得到不同函数值或解集，返回信息不足及各候选结果，不能任选一个答案。

比较系数技能只把实数恒等式转成系数约束，缺项按零处理，不负责设函数类型、求解或筛选候选。化简、消元、等式回验复用已有公共能力；W10 后续实际调用既有二次方程求根和二次不等式符号能力。独立验证重新绑定原关系、逐一检查候选，并用独立的集合方程求解验证无遗漏，不靠抽样代值证明恒等或完备。

## 学生交互

共用读题、题型判断和预连线选法卡。线索“已知函数类型”连接待定系数法，已完成卡保留选法图。没有添加统一的“先求定义域”关卡。

方法内有六步：按函数类型设一般式 → 把一般式代入题给关系 → 同次幂的系数分别相等 → 求出所有系数 → 把每个结果代回检查 → 回到原题作答。比较系数用左右对照表；系数组合和解析式均完整展示，多个解析式之间标“或”。原题只求值时展示每个候选计算相同目标值；原题求解集时展示已有二次不等式能力的结果。选项、错答反馈、完成卡和 AI 回放由共同教学编译器生成。
