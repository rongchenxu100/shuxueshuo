# 交互步骤卡片设计规范

适用于阶段三引擎驱动的解题步骤卡片（拍题页 `site/lab/search/problem.html` 的流式路线）。新增或修改步骤模板、交互规则、前端卡片渲染时，都按本规范执行。技术实现见 [阶段三步骤交互卡技术方案](stage-three-step-interaction-design.md)；版式参照 `/2/` 恒成立题库（如 q04、q06）。FM-T2／M7 的题型语义见 [利用单调性求最值题型设计](function-monotonicity-extremum-problem-type-design.md)；本节 §9 收纳该路线上已落地的**交互卡 UX 约定**。

## 1. 卡片的两种状态

每个步骤是一张卡片，有两种状态。

| 状态 | 内容 |
|---|---|
| 进行中 | 步骤标题、题干、题干下的题板或题图、作答组件、反馈、确认按钮 |
| 已完成 | 各小问的结论板（及所属完成图）+ 必要的「完整推导」 |

一个交互有多个小问时，仍是一个步骤、一张卡片：

- **进行中**：顶部小问步进条；已答小问折成摘要行；当前小问展示题板／题图与选项。确认后锚点滚到**下一小问标题**（`#gw-part-title`），不要滚回整步大标题。重绘步骤 DOM 时须先**保持当前视口**，再平滑滚到锚点，禁止先闪到步骤顶部再往下滚。
- **已完成**：每个小问的完成图与推导板**成对**出现（图紧挨该问的板），不要把全部完成图堆在整步最上方、再集中堆全部推导板。

## 2. 已完成卡片：结论层 + 数学推导

已完成卡片自上而下：

1. **按小问排列的结论**（推导板；有图则图在该板之前）。
2. **完整推导**（若本步需要）：默认可折叠；放**简洁的数学推导过程**，不是给学生的提示。禁止把多卡嵌套的 `gathered` 再包一层导致乱码。区间结论若以 `[` 开头，拼接换行前须加 `{}`，避免 LaTeX 把 `\\[` 读成换行间距。

### 2.1 完整推导写什么

完整推导是这一步的**数学书写**，读者是已经答完题、回头核对过程的学生或老师。

- **数据来源**：每张卡的 `proof`（多小问按顺序各占一段 `$$…$$`），由 presentation 写入 `formula_explanation`。**禁止**把题干 `question`、提示语或反馈文案塞进 `formula_explanation`。
- **内容**：已知式 → 推出结论所依据的关键数学事实 → 结论，一行一步。例：
  - 二次函数定区间单调：\(f(x)=x^2-mx+5\)；开口向上，对称轴 \(x=\frac m2\)；\(\frac m2\le1\Rightarrow m\in(-\infty,2]\)。
  - 分界点：\(x\to1^-:\ f(x)\to2a-1\)；\(f(1)=1-\frac a2\)；\(2a-1\le1-\frac a2\Rightarrow a\in(-\infty,\frac45]\)。
  - 根式整段非负：\(g\) 严格递减；\(\min g=g(-2)=1-a\)；\(1-a\ge0\Rightarrow a\le1\)。
- **不写**：问句（「应满足什么？」）、操作指令（「拖动」「看看」）、鼓励或纠错话术、与上一行完全相同的重复行；关键依据（对称轴、斜率、转折点 \(k\)、最小值位置）不能省略。
- **形式**：一张卡只有一层 `gathered`；组合题板与结论时先展平再拼接，重复行去掉。文字只用中文短语夹在式子里（`\text{开口向上，对称轴}`），不用英文 `on`。

结论层形式：

| 形式 | 适用 | 数据 |
|---|---|---|
| 结论板 | 一般步骤：一组带标签的公式，可用连接符（→、⇔） | `completion_board`／`highlight`：`caption`、`items[{label, math, note?}]`、`connector?` |
| 合并格子 | 分情况求解后取并集 | `highlight.layout = "merge"` |
| 分情况图 | 分类讨论最值：每种情况一张图 | `completion_graphs` |
| 单张完成图 | 需看图确认的步骤 | `completion_graph`，与该小问结论板成对 |
| 仅结论 | 路线最后的结论步骤 | `highlight.conclusion_only = true` |

规则：

- 有分情况图时，图下只放图题，不额外生成总结句。
- `highlight.result`／板右侧是这一步结论，会出现在下一步承接里。

## 3. 数学推导的写法

- 写数学推导，不复述方法。用 ∵/∴ 链，参照 q06。
- 一句一行；模板里的 `\n` 另起一行。
- 分情况的结论按 ①②③ 或参数条件标注，每种情况一行。
- 求参数范围用方程组／不等式写法；空集写 \(\varnothing\)。
- **函数命名**：有题面名字用题面名；题面未命名时呈现层自行引入不冲突的 \(g/f\) 等别名。学生文案只说「可以设 \(g\) 和 \(f\)」，并写出定义式；不要对学生讲「全称／存在一侧」。禁止用「随便取一侧／配合一侧／左边／右边」顶替函数名。
- **用具体式子，不用方位指代**：题干、题板、反馈、图注里禁止用「左边／右边／左输入／右输入／前者／后者／这一段／那一段」指代数学对象。一律写出题面或当前步骤里的具体表达式／条件（如 \(1-x^{2}\)、\(2x\)、\(x\ge0\)）。与题面写法保持一致（优先 \(1-x^{2}\)，不要擅自改成 \(-x^{2}+1\)）。

## 4. 进行中卡片

### 4.1 题干

- 用一句话问清楚要做什么。
- 题干里已经写出的式子，题板不再重复。
- **已知栏不剧透本题答案**：学生要选的判断／不等式／答案集，不要先写在左侧「已知与当前范围」里。
- **指代词禁令同样适用于题干**：可以说「将 \(1-x^{2}\) 代入该段表达式」，不说「把左边代入」；可以说「\(2x\) 落在常值段」，不说「右输入落在常值段」。

### 4.2 题干下的内容（只选一种）

| 形式 | 适用 | 数据 |
|---|---|---|
| 题板 | 列出已知再作答 | `stem_board` |
| 题图 | 需要看图读增减／值域 | `graph`／`graphs.stem` |
| 上下文 | 默认 | 数学卡 `before` |

### 4.3 选项

- 选项是数学结论本身；空集 \(\varnothing\)，全体实数用统一的 \(\mathbb{R}\) 写法。
- **带足对象上下文**：问的是某个变量／参数的取值时，选项必须点名对象，写成 \(x\in(0,\infty)\)、\(a\ge1\)、\(x=2\)，禁止只抛裸集合 \((0,\infty)\)、\([1,\infty)\)、裸数 \(2\) 或裸 \(\mathbb{R}/\varnothing\)。题干已出现变量名也不算豁免——选项单独读也要能看懂在答谁。
- **禁止裸数值／裸区间当选项**：即使答案是单个数或一个区间，也写成 \(x=\cdots\)／\(x\in\cdots\)（或题设中的求解变量／参数名）；图注与完成态同此要求。
- 干扰项来自真实常见错误；选中后可给针对性反馈。
- **去重**：生成选项后按规范化键合并等价 TeX（如 `\mathbb{R}` 与 `\mathbb R`、`\varnothing` 与 `\emptyset`），禁止出现两个渲染相同的 \(\mathbb{R}\)。实现上由 `_choice` 统一处理。
- 需要学生同时确认「判断」与「参数结果」时，做成**一条选项**（如 \(\text{条件}\Rightarrow\text{参数集}\)），不要拆成已知栏给条件、选项只选集合。
- 选项图（数轴等）只在图能帮助区分时使用；文字已清楚时不加。分情况重复挂数轴时优先删减（见 §9）。

## 5. 分类讨论步骤的组织

以区间最值法为例，参照 q04：

1. **分类讨论最值**：先选分类依据，再判断各情况最值位置。完成卡 = 分情况图 + 完整推导。
2. **求参数范围**：题板列出各情况条件，选最终范围。完成卡 = 合并格子 + 完整推导。

FM-T2／M7 的多分支组织见 §9：标题必须标清分支；多分支求参合并为「每支一卡」，不要无标题的「建立本分支／解本分支」来回六七问。

## 6. 图像

- 图像规格全部由服务端从精确值生成，前端不做数学计算。
- 一组图要么全部画出，要么都不画。
- **配方／顶点式卡**：只保留代数结论，不挂函数图像；读值域／最值卡再给带 ↑／↓ 的示意图。
- **完成态**：各小问的 `completion_graph` 跟在该问推导板旁，不集中堆在步骤顶。
- 空心点表示取不到，实心点表示取到。

## 7. 命名与标题

- 步骤／小问标题要能区分并列情况：斜率分类用（↑）／（↓）／（常值）；读值域与求参用（\(a=0\)）／（\(a\in(0,\infty)\)）等，避免三张同名卡。
- **斜率分类卡**：右格标签固定为参数名（如 \(a\)）；选项写不等式（\(a>0\)）。一次项系数不是裸参数时（如 \(a-2\)），右格仍标 \(a\)，选项写 \(a-2>0\Rightarrow a>2\)。标题用方向区分，勿把答案写进标题；**读值域卡**可在标题标已确定的 \(a\) 范围。
- 情况编号或参数条件在题干、题板、图题、结论层保持一致。

## 8. 待定

- 「各情况的推导」折叠区是否保留（q04 没有这一块）。

## 9. FM-T2／M7 交互卡约定（2026-11-05）

实现入口：`extremum_presentation.py`、`extremum_graphs.py`、`walk.mjs`（`card_group` 拆步、多小问完成态与锚点）。课包经 `build-graph-walk-topic.mjs` 重建，不改单页 HTML。

本节汇总本轮已落地的学生侧约定：大卡切分、不等号化归、动区间端点竞争的压缩板书、参数答案命名与标签写法。题型数学语义仍以 [利用单调性求最值题型设计](function-monotonicity-extremum-problem-type-design.md) 为准。

### 9.1 大卡与小问

编译仍按 `ranges`／`conditions`／`conclude` 相位出交互；学生侧用 `card_group` 拆成**大卡**，同组内才是小问。walk 按组拆步；分组标记、标题和题目／分支范围相同的相邻组（如 conditions 与 conclude 的「求参数」）在显示层合并为一张大卡。底层已发布交互、作答记录和各自的数学证据保持独立不变，后续交互到达时不能改写先前步骤。无分组标记时用裸交互 id，避免 `::_default` 破坏完成态。

| 大卡 | 等号／覆盖（如 A07、B11） | 不等号比较（如 B10、B16） |
|---|---|---|
| 取名（如需） | 题面未命名时单独一张 | 同左 |
| 存在域非空（如需） | — | 单独一张，不要塞进读最值的小问；结论写出参数名（如 \(a\ge1\)，不要裸 \([1,\infty)\)） |
| 化归最值比较 | — | 单独一张：选 \(\max/\min\) 关系 |
| 求一侧值域／最值 | 每侧一张大卡；二次可先「配成顶点式」（无图）；斜率多支时分类标方向、读值域标 \(a\) 范围，末汇总大括号 | 每侧一张大卡。**分段**：逐段读本段最值时已知栏只写**本段** \(f(x)=\cdots\) 与定义域（标题已标第 N 段；不要整段 cases 再挂一行孤立区间，也不用红字描本段）→ 汇总卡再写完整分段并挂全图。**动区间端点竞争**见 §9.4 |
| 求参数 | 讨论覆盖／比较 + 各支求参 + 汇总并集，合成一张大卡 | 同左；多支时每支带本侧本支 \(\max/\min\)，直接代入比较关系求解 |

不等号化归卡：已知用函数名说清「任意一侧取值都要被另一侧压住／盖住」的语义；选项为 \(\max f<\max g\) 等，干扰含方向反了、错用 min／max、误用值域 \(\subseteq\)。不单独强调取得性。等号路径不加此卡。

题面未命名时，在化归／读值域前加「先给两边的式子取名」：只读告知可以设 \(g/f\) 及定义式，按钮「记下了，继续」，不出选项。告知卡用 **lines** 板（不要 derivation 右侧空白「下一步 ?」）。

读最值时：若参数允许域已固定斜率方向（如题设 \(m<0\)），答案必须用模型在该域下的分支最值（\(m+1\)），不能对 \(m+1\) 与 \(3m+1\) 做无约束的符号比较。

不等号求参：不再重问最值比较。单分支为「代入最值，写出参数条件」→「解参数条件」；多分支直接进入各支求参小问（左栏可保留已有关系作承接）；汇总并进同一张「求参数」大卡。

多分支求参小问：

- 已知栏：本支条件 + 两边值域／最值（\(a=0\) 等定点须代入化简，如 \(\{-1\}\)）+ 覆盖／比较关系。
- **不**在已知栏给出覆盖是否成立或具体不等式（由学生选）。
- 选项：\(\text{本支判断}\Rightarrow\text{保留的参数}\)；保留空解支（如 \(a=0\Rightarrow\emptyset\)）。
- **不**挂数轴（避免 3 支 × 2 轴）。

单分支求参：建立卡可挂 g／f 值域数轴各一条；建立卡左侧不空挂未用于本步的环境条件（如仅在「解」步才用的 \(a\in(0,\infty)\)）。

### 9.2 覆盖讨论

- 问法绑函数名：如「\(g\) 取到的每个值，\(f\) 都要能取到」。
- 已知栏用两边值域（或多支汇总），不要复述已读过的 \(g(x)=\)、\(f(x)=\) 与定义域。
- 禁止用单一分支的 \(g\) 值域冒充总述。

### 9.3 板书命名、标签与完整推导

- 已知栏函数式**始终带函数名**：写 \(g(x)=x^2-4x-3\)、顶点式写 \(g(x)=(x-2)^2-7\)；不要只抛裸式。
- 读最值／值域卡：已有 \(f(x)=\cdots\) 时，**不要再重复**一行裸表达式；定义域单独一行即可。分段逐段读时只出本段式，整段 cases 留给汇总。
- 参数答案与选项一律点名参数：\(a\ge1\)、\(a>2+\sqrt7\)，禁止把裸集合 \([1,\infty)\) 当作最终答案文案。
- 推导格标签用「纯文 + 局部 `$…$`」：正确写法是 `$a$ 的取值范围`；**禁止** `a\text{ 的取值范围}` 这类整段塞进 math 标签（前端会显示乱码）。
- 「完整推导」只放简洁数学推导（见 §2.1），来自各卡 `proof`，不放题干与提示；单层 `gathered`，并处理 `[` 开头的区间。
- 学生可见文案不用「像集」；不用「随便取／配合」指代函数。

### 9.4 动区间端点竞争（B10 型）

开口向上、一端随参数移动的闭区间二次函数（如 \(g\) 在 \([1,a]\)）按压缩主线出卡，**不要**再做成「两支各自读最值 → 汇总」：

1. **配成顶点式**（无函数图）：左 \(g(x)=\) 原式与定义域；右 \(g(x)=\) 顶点式。
2. **比较两端**：左写出 \(g(x)=\)、定义域、\(g(1)\)、\(g(a)\)；右选完整差式 \(g(a)-g(1)=(a-3)(a-1)\)（不要只给因式）。示意图为**静态**示意抛物线（固定样本端点，如 \(a=4\)；等端样本如 \(a=3\) 不宜作示意），标 \(1\)／顶点／\(a\)，并画虚线 \(y=g(1)\)；**不做**可拖动 \(a\) 的探索器。
3. **按端点高低分成两类**：左栏**只保留**上一步的差式（不再堆原式、\(g(1)\)、\(g(a)\)）；右栏写全分类，显式带本支最大值，例如
   \[
   \begin{cases}
   g_{\max}=g(1),& a\in[1,3]\\
   g_{\max}=g(a),& a\in(3,\infty)
   \end{cases}
   \]
   不要只写两个 \(a\) 的区间。
4. **求参**：每支一卡，已知带本支 \(\max g\) 与 \(\max f\)，代入 \(\max f<\max g\)（或题面关系）求解；并集收束。

分界由端点差的符号决定（B10 为 \(a=3\)），不能只凭顶点是否在区间内断言最大值必在动端。

### 9.5 指定最值求参（B08／B14／M8）

主线要让学生**明显感到这是恒成立**，再进**已有**子方法的选法与流程；**不要**做成「配方 → 候选点 → 每支四连」，也不用「左／右侧／第 N 段」称谓——一律用该段表达式与定义域说话。

1. **求指定点的函数值**（大卡「确定指定最值」）：板书保留顶点式／对勾原貌；**不挂图**。选项先亮出选用的段式再代入。
2. **写成全域条件**：点明「指定最值 ⇔ 定义域恒成立」；选项仍用 \(\forall\)／\(\exists\)。
3. **逐段进入共享恒成立子问题入口**（`quantified_subproblem`，与定义域求参、分段值域求参合同一致）：「判断转化后的问题」→「选择恒成立问题的解题方法」**plane 选法坐标**（见下图语义：横轴 \(x\) 是否全体实数，纵轴求的是否参数）。
4. **正路**：能分离则 `borrowed_method=method-separation`（B08 两段）；不能分离的二次段借 `method-interval-extremum`；**不含参数**的段（B14 右段一次式）标 `piece_kind=independent`——**跳过** `quantified_subproblem`，只留一步「快速验证本段」（恒成立则对参数无限制／否则无解）。
5. **展开子方法**：含参段 `presentation: expanded`，走子方法**自有**卡片与流程（移项、除数符号、分离、对勾／值域、求参等）。父侧 **不再** 另出「第 N 段：求参」重复答案卡，也不把顶点分类作为进子方法前的必答主线。
6. **汇总**：各段恒成立结果取交；板书用表达式／定义域标注各段答案，不要求最值点唯一。

路径条 `#gw-path` 必须渲染标题里的 `$…$`（`walk.mjs`）；分支后缀优先 \(a\ge0\) 这类关系式，避免裸 `a\in[0,\infty)` 又未渲染。

#### 调用子方法时要注意什么

子方法的意义是**复用它的卡片和流程**，不是在父方法里再发明一套「看起来像」的平行教学。

| 要做 | 不要做 |
| --- | --- |
| 父方法只负责拆出真实、可准入的子问题（关系、定义域、量词、参数、目标） | 在父侧再造「写成恒成立」「选择解法」等 choice，与 plane／子方法步骤重复 |
| 入口统一走 `quantified_subproblem`：判断转化 → plane 选法 | 宿主自绘选法表、或跳过「这是恒成立」直接甩分离代数 |
| `borrowed_method` 指向真正要展开的方法；答对 plane 后 `submethod` + `presentation: expanded` | `fold` 掉学生本应学会的分离／区间步骤，或父侧再解一遍同一参数范围 |
| 子方法返回参数集合后，父侧只做段间取交／回到原题 | 父侧再出「第 N 段：求参」机械答案卡 |
| 标题／问句／`subproblem_context` 用**表达式＋定义域**命名（如对 \(x\le 0\)，\((x-a)^2\ge a^2\)） | 用「左侧／右侧／第 1 段」当学生可见标题 |
| 嵌套子方法继承宿主 `case_path`，使多段重复模板（plane、policy 等）各自可交互 | 清空 `case_path` 导致第二段 plane／步骤被当成 `repeat` 只读 |
| 对勾等含分母的式子：展示可用原式；选法坐标认格时可在内部清掉恒正／恒负分母 | 因选法规则暂认不出格就改回自建 choice，或让第二段选法卡 `compile_error` |
| 分离时若闭端点使除数为 0、但该端点残差恒成立，可放开该端点再借分离 | 强行走分离失败后静默改道且不改学生可见合同 |
