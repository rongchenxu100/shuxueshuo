# FP-T2 根据奇偶性求参：设计与实现方案

更新：2026-11-10。状态：**开发设计，尚未实现本题型、生成练习课程或完成拍题验收。** T1 的域对称与奇偶判定按实际验收合同复用；设计中的接口和范围不能直接视为已经可调用。

本文细化[函数奇偶性建设计划](function-parity-topic-plan.md)中的 T2，承接 [FP-T1 设计](function-parity-problem-type-design.md)，遵循[专题与拍题学共用开发流程](topic-and-photo-learning-development-workflow.md)。含参分类、子方法返回和原题回验参考[单调性求参设计](function-monotonicity-parameter-problem-type-design.md)，具体能力以当前代码合同为准。

本型主线是：**保留原参数限制与原定义域 → 求定义域非空且对称的条件 → 求函数值关系恒成立的条件 → 合并条件 → 验证参数集合必要且充分。** 求出一个可用参数不等于求完；仅端点对称也不等于函数满足奇偶性。

## 1. 身份、范围与完成标准

### 1.1 题型与公共能力

| 项目 | 约定 |
| --- | --- |
| 专题／分组 | `function-parity`／FP-T2 根据奇偶性求参 |
| 候选题型 | `type-parity-parameter` |
| 新增方法 | M2 `method-parity-parameter`，学生名称“奇偶性条件求参法” |
| 技能增量 | 不新增公共技能；扩展 T1 首建的 S1 `skill-domain-symmetry`，复用并扩展比较系数、等式变形、消元及集合运算 |
| 主要知识 | `function-parity#domain`、`#definition`、`#zero`、`#common-functions`；图形引用 `function-parity-graph#symmetry` |
| 原题代表 | FP-A17；FP-A15、FP-A20 的端点求参子任务 |
| 数学结果 | 满足全部要求的参数集合或联合参数条件，附完整分类、域条件、恒等证据和回验 |

知识层继续保持教材的 **3 个节点**，不新建“奇偶性求参知识点”。T2 的端点、系数、有理式与分段是 M2 内部的结构分支，不分别登记一套公共方法。M1「奇偶性定义法」用于固定候选的回验或共用证明内核，不能用已假定的奇偶性反过来证明候选满足要求。

“是奇函数”“是偶函数”均允许零函数；“奇而非偶”“偶而非奇”“既奇又偶”按原文增加或组合性质。“非奇非偶求参”、任意抽象函数方程求参、一般对称轴／中心求参暂不作为本轮开放目标，后两类归入相应方法，不能凭出现参数字母强行路由到 T2。

### 1.2 整题与参数子任务

| 原目标 | 本型负责 | 完成边界 |
| --- | --- | --- |
| A17 求实数 $m$ 的值 | 建立偶性条件，求出全部 $m$ 并回验 | 参数结果就是原题答案 |
| A15 求 $f(m)$ | 由完整域对称求 $m$，检查域有效及已知局部规则相容 | 返回 T3；$m=-4$ 不是原题最终答案 |
| A20 解 $f(x-1)\le f(2x)$ | 由完整域对称求 $b$，返回实例化定义域和已知单调区间 | 返回 T4；$b=1$ 不替代关于 $x$ 的解集 |

A15、A20 不增加原题小问或原目标数量。参数子任务的 `parent_target_ref`、所处理条件及尚需父方法处理的条件分别保存；不得把它们改写成两道原始“求参题”。专题需要直接练端点求参时另编一题，并明确标为新编。

### 1.3 本轮分批开放的结构

下表是实现目标，不是当前能力。一个分支开放后须覆盖其退化、边界和空解情形；其他分支继续保留明确的能力缺口。

| 结构 | 计划范围 | 关键门槛 |
| --- | --- | --- |
| 单参数多项式 | 关于自变量至多四次，系数为单个实参数的至多二次有理系数多项式；原参数限制可参与求交 | 不要求首项非零，除非题目明确指定函数次数；展开后的约束也须在预算内 |
| 含参定义域 | 至多 4 个区间、8 个孤立点或孔洞；有限端点／点坐标为一个参数的仿射式，保留开闭 | 端点排序、重合、区间合并和空域按参数分类，不能只看最外两端 |
| 抽象函数的域子任务 | 只给完整域与奇偶性，或另有受支持的局部多项式规则 | 保留存在性、零点和反射重叠相容性；完整补式、求值和单调推导留给父方法 |
| 固定有限域 | 支持整个有限域上的逐点恒等条件；域规模沿用上述预算 | 不将有限点相等转换成全实数多项式系数相等 |
| 有理式与孔洞 | 分子至多四次；分母为受支持的固定多项式，或参数因子与至多两个 $x-h(p)$ 的乘积，$h$ 为仿射式 | 原分母恒为零的参数单独排除；保留约分前所有孔洞，完整证明剩余域对称 |
| 绝对值与显式分段 | 绝对值内为固定的一次／二次多项式；最多 6 段，分界点固定，各分支属于上述多项式／有理式范围 | 绝对值转为有证据的分段；对镜像分支比较，并单独核对零点、端点和重叠 |
| 受限含参根式 | $\sqrt{\alpha(p)x^2+\beta(p)}$，$\alpha,\beta$ 为有理仿射式；使用自然域或明确声明 $\mathbb R$ | 完整检查非空／全实数有定义条件；奇性需输出恒为零，不能只比较平方 |
| 两参数线性条件 | 固定、已验证的域；最多两个实参数，最终系数／逐点条件为联合仿射等式，附仿射非零限制 | 支持自由参数和无限解族；不宣称支持一般多参数不等式、移动域或非线性曲线求解 |

单参数最终条件允许有理式的分子、分母次数至多 4；所需实临界值必须能完整隔离、精确排序并序列化为有理数或实二次代数数。原分母非零约束另存，不能因条件化简而消失。两参数路线保留联合条件，不投影成两个独立区间后做笛卡尔积。

初始预算建议为：源 AST 至多 256 节点、深度 24，有理数分子／分母至多 128 位；参数切点至多 32 个，形成至多 65 个参数单元；每类的输入细分沿用 T1 的 48 个有限切点、97 个区间／单点单元。参数约束最多 32 条，两参数分支最多 8 组。正规式沿用 T1 次数预算。预算须集中登记，准入、执行、验证和序列化共同读取；中间结果超限返回能力缺口。

本轮不承诺一般含参二次根式、任意移动分段边界、任意 $|x-p|$ 嵌套、多参数非线性系统、指数／对数／三角恒等式。有限候选可以回到已实现的 T1 合同核验，但不能用“某几个候选成功”替代其余参数的完整排除。

## 2. 题源、数学金标与代表课

原题来自[两图归档清单](../internal/senior-high/source-images/function-parity-planning-20261110/manifest.json)中的图 2，第 15、17、20 题。以下以印刷题干为准；手写结果不进入提取事实、生产求解或验证器。

| 来源 | 题意与原目标 | T2 校核结果 | 父目标的最终结果 |
| --- | --- | --- | --- |
| FP-A17 | $f(x)=x^2+(2-m)x+m^2+12$ 为偶函数，求 $m$ | $m=2$；代回为 $x^2+16$，域为 $\mathbb R$ | $2$ |
| FP-A15 | $f$ 是定义在 $[m-5,1-2m]$ 上的奇函数；$x\ge0$ 时 $f(x)=x^2-2x$，求 $f(m)$ | $m=-4$，域 $[-9,9]$，$m$ 属于域，正侧规则在零点给 $0$ | T3：$f(-4)=-f(4)=-8$ |
| FP-A20 | $f$ 是定义在 $[-2b,b+1]$ 上的偶函数，在 $[-2b,0]$ 上递增，解 $f(x-1)\le f(2x)$ | $b=1$，域 $[-2,2]$，题给递增区间为 $[-2,0]$ | T4：$[-1,\frac13]$ |

### 2.1 A17 的完整参数推导

原函数是多项式，对每个实数 $m$ 都在 $\mathbb R$ 上有定义。偶性等价于

$$
f(-x)-f(x)=-2(2-m)x\equiv0,
$$

所以 $2-m=0$，得 $m=2$。常数项 $m^2+12$ 在两边相消，无须令它为零。代回 $f(x)=x^2+16$，在对称非空域 $\mathbb R$ 上满足偶性，充分性成立；任意 $m\ne2$ 都有 $f(-1)-f(1)=-2(2-m)\ne0$，必要性成立。

### 2.2 端点求参及后续义务

A15 的闭区间非空要求 $m-5\le1-2m$。域对称还要求

$$
m-5=-(1-2m),\qquad m=-4.
$$

代回得到非空对称域 $[-9,9]$。局部公式的作用域是 $[0,9]$，不是整个非负半轴；与其反射范围的交集只有零点，且 $0^2-2\cdot0=0$，与奇性相容。T2 可以返回域与参数证据；完整负侧规则和 $f(m)$ 由 T3 继续处理。

A20 由 $-2b=-(b+1)$ 得 $b=1$，回验定义域及题给递增区间均有效。奇偶性与这条单调事实可以同时成立，例如 $f(x)=-|x|$ 在 $[-2,2]$ 上满足两者；这只用于核对题设一致性，**不能把示例函数当作原题唯一解析式**。父方法仍须依据原偶性、单调性和两个输入的范围求解不等式。

新编端点代表题可采用：“$f$ 是定义在 $[a-3,2a]$ 上的偶函数，求 $a$。”由端点配对得 $a=1$，回验为 $[-2,2]$；存在偶函数定义于此域，故参数条件充分。其来源身份须与 A15、A20 分开。

## 4. 题意、结果与子任务合同

### 4.1 保留原目标与性质来源

核查基线的提取 Schema 已有 `find_value` 与 `find_range`，但没有共享奇偶性事实合同。实施时与 T1／T3 共用最小的性质表示，记录函数身份、奇／偶要求、来源和全域作用范围；不按每个题型重复发明字段。下列名称描述编译后拟议语义，不是现有提取字段。

| 语义 | 要求 |
| --- | --- |
| 原目标 | A17 保留求 $m$ 的值；一般参数范围保留 `find_range`；A15 保留 $f(m)$，A20 保留原不等式与求解变量 $x$ |
| 参数与形参 | 显式绑定 `parameter_refs` 与 `variable_ref`，由来源决定角色；不能按字母 $x,a,m$ 猜测 |
| 奇偶性要求 | `odd/even/both/odd_only/even_only`；题给性质是待求参数必须满足的约束，不能作为已经核验的执行证据 |
| 原表达式 | 未约分 AST、每个原分母、分支条件和端点、函数类型声明、局部公式及其范围 |
| 域角色 | 自然域、完整定义域声明、额外限制输入、仅保证某段有意义分别保存；完整域与局部范围不能互换 |
| 原参数限制 | $p>0$、$p\ne0$、参数属于给定集合等直接保留；“二次函数”才导出首项非零，推导仍标来源 |
| 其他条件 | 已知值、局部公式、单调性、额外等式须逐项处理或返回父方法；不悄悄忽略 |

原文只给奇偶性时，模型转录性质，不负责展开恒等式、计算端点方程、比较系数或填写答案。若受控数学记法能承载该事实，优先补一个共享记法及语义；确需 Schema 字段时只补最小属性合同，并同步提取、复核和修复。

题意摘要必须同时展示**原函数／局部规则、题给定义域、奇偶性要求、原参数限制和实际所求**。例如 A17 不能显示成“$f(x)=\cdots$，求 $m$”而漏掉“偶函数”。子任务内得到的参数、定义域与 $f(0)=0$ 均是派生结果，不回填为 OCR 已知条件。

### 4.2 域角色与存在性

没有给定义域时，从原式求自然域。显式声明函数定义于 $D_p$ 时，要求 $D_p$ 非空且原式在其中处处有意义；这允许把公式限制到较小的域，不要求 $D_p$ 等于表达式的最大自然域。若原题明确要求“自然定义域恰为某集合”，才建立相应集合相等子目标。

题目仅保证在 $I_p$ 上有意义，不能将 $I_p$ 当成完整定义域并令两端互为相反数。例如全实数偶函数 $x^2$ 在 $[-1,p]$ 上有意义，只要该区间有效，并不强迫 $p=1$。

参数搜索中某一类使原域为空、分母恒为零或声明域包含非法点，应**排除该参数类并保留理由**，继续处理其余类；不能因某一类无效中止所有求参。全部类都被证明排除时，结果是“无满足条件的参数”；漏读分支、符号不清和能力不足另行诊断，不输出空集。

只有抽象函数及域、奇偶性时，参数要求还包含“存在满足条件的函数”。非空对称域上可构造满足普通奇／偶要求的函数，足以完成纯域题；要求“奇而非偶”还须存在非零的成对输入，域仅为 $\{0\}$ 时不能满足。另有局部规则时须检查反射重叠及零点相容性。未给公式不能猜一条曲线，再用它代替所有允许函数。

### 4.3 参数结果与父任务返回

拟议 `ParityParameterResult` 至少包含：

| 字段 | 内容 |
| --- | --- |
| 身份与版本 | 原 `target_ref`、可选父目标、函数／参数身份、全部来源及依赖版本 |
| `parameter_space` | 原参数约束确定的范围；多参数保存有序变量元组 |
| `cases` | 参数单元、分类依据、覆盖证书及每类的有效函数／域条件 |
| `obligations` | 域非空、原式合法、域对称、所需恒等／非恒等、其他原条件；各自证据和处理状态 |
| `solution` | 一参数精确集合；两参数为有限个分支的联合仿射等式与非零限制，不丢自由参数 |
| `excluded_cases` | 排除原因及对应范围；数学空集也必须有完整覆盖证据 |
| `verification` | 必要性、充分性、全部来源处理与最终验证结果；未知不得充当否定 |
| 子任务返回 | 已处理来源、实例化域／局部规则、仍由父方法负责的条件和继续位置 |

一参数结果可以是空集、一个值、多个离散值、区间并集或全部原参数范围。多个参数构成解族是有效数学答案，不自动归为“信息不足”；若原题另问一个具体值，则由父目标判断该值是否在整个解族上唯一。

A15／A20 的子结果只声明“这些参数条件已验证”。未处理完父目标的其他条件、合法输入和答案前，不生成整题完成事件。后续条件改变时，按依赖使相关子结果与父课程失效，不从学生上一问的输入直接借用参数。

## 5. 数学执行与独立验证

### 5.1 参数分类与原域保留

1. 从原参数限制得到 $P_0$，保存未化简表达式和所有定义条件。需要除以参数或比较参数相关边界时，先记录非零／符号前提。
2. 收集本结构所需的临界条件：端点次序与相等、孔洞重合、参数分母为零、域是否退化、系数归零等。完整求临界根，分开开放区间和临界单点，并与 $P_0$ 求交。
3. 每个参数类分别规范化原域和反射域，比较整个集合。区间合并后再配对，不能固定按原始区间编号匹配；边界归属、孤立点和孔洞全部参与。
4. 有限端点反序且开闭随端点交换，例如 $[L(p),U(p))$ 反射为 $(-U(p),-L(p)]$。单个非退化区间必须两端开闭匹配；闭区间可退化为 $\{0\}$，开区间重合则为空。
5. 参数化根式域可保留为带证书的精确谓词及结构类别，不把含自由参数的边界伪装为固定集合。画图时再选明确的参数值求具体域。

类内选一个参数只用于**已有完整符号不变性证明后的判号或演示**。它不能证明任意参数都满足奇偶性。若归一化或域细分还依赖未处理的参数临界条件，必须继续分类或返回缺口。

### 5.2 在实际域上建立函数值条件

记 $\sigma=1$ 表示偶性，$\sigma=-1$ 表示奇性。域非空、对称且规则合法后，建立

$$
F_p(-x)-\sigma F_p(x)=0\qquad\text{对所有 }x\in D_p.
$$

| 输入域／结构 | 建立参数条件的方法 |
| --- | --- |
| 多项式，域含非退化区间 | 按 $x$ 展开，所有系数分别为零；证明该域在当前参数类确实含区间，不能只以“原来是区间记法”判断 |
| 有限域 | 对域中每个实际输入列精确等式，合并全部条件；这是一整个有限域的全称验证，不是采样 |
| 有理式 | 先证明两边的原分母在当前单元非零，再交叉相乘；系数条件与原域、参数非零条件同时保留 |
| 分段／绝对值 | 对每个非空 $D_i(p)\cap(-D_j(p))$ 比较 $F_j(-x)$ 与 $\sigma F_i(x)$，继续按必要符号点细分 |
| 根式 | 先检查原域和非负根语义；只有两边的符号前提满足时才能使用平方等价，不能把两边平方相同直接当成奇性 |

分段的全部比较单元必须覆盖 $D_p$。属于域的零点和分界点单独验证；分支重叠处须有同值证据。不要求连续，也不能把每一支单独要求为奇／偶代替镜像支配对。

既奇又偶时核验函数在对称域上恒为零；只奇／只偶还要证明它**不恒为零**。非零条件可以由系数非全零、有限域存在非零值或已验证反例给出，并保留参数条件。例如 $px$ 要求奇允许所有 $p$，要求“奇而非偶”才排除 $p=0$。

### 5.3 受限根式与两参数路线

对自然域上的 $F_p(x)=\sqrt{\alpha(p)x^2+\beta(p)}$，被开方数关于 $x$ 为偶式，域配对直接成立；仍须分类检查非空性：$\alpha>0$ 时自然域非空，$\alpha\le0$ 时要求 $\beta\ge0$。偶性在所有这些参数上成立。

该函数值恒非负，若要求奇性，必须在实际域上恒为零。因此自然域下恰需 $\beta=0$ 且 $\alpha\le0$：$\alpha<0$ 时域仅为 $\{0\}$，$\alpha=0$ 时是全实数零函数。若声明域为 $\mathbb R$，则先要求 $\alpha\ge0,\beta\ge0$，奇性进一步要求两者都为零。这些条件需由共享二次式／定义域能力形成证书，不按样例系数写分支。

两参数路线仅处理已生成的联合仿射条件。使用精确线性消元保留秩、自由变量和不相容行；非零限制回代到解族后检查。题目只要求一项性质时不能为“解出唯一数值”额外补另一项。零矩阵且常数项为零返回整个原参数空间；出现不相容行返回空解，均不是执行错误。

例如 $ax^2+bx$ 在 $\mathbb R$ 上为奇函数给 $a=0$、$b\in\mathbb R$；在固定域 $\{-1,1\}$ 上，$ax^2+b$ 为奇函数给 $a+b=0$，不能直接令 $a=b=0$。联合关系必须进入结果、评分与回放合同。

### 5.4 合并与必要充分性

同一参数类中的所有条件取交，不同互斥参数类的结果取并。结果始终是 $P_0$ 的子集；方程根、孔洞重合点、次数退化点与区间端点逐个核对取得性。

完整结果须证明：

- **充分性：** 每个保留类的原域非空、原式合法、域对称，所需恒等式在整个实际域成立，其他原约束也被满足。
- **必要性：** 每个被排除类违反至少一项必要条件；临界值与所有参数类被覆盖，没有遗漏的未决范围。
- **来源完整性：** 每条原题条件都标为已处理、已证明冗余或交回父任务；整题完成不能留有待处理条件。

只在若干参数处调用 T1 得到正确分类，不能证明一个连续参数集合完整。若候选集已由必要条件证明为有限，允许逐候选调用 T1，并用该必要条件的完整解集证明未漏解。

### 5.5 独立验证器

验证器从冻结原题重建参数、形参、域角色与原限制，消费分类和代数证书；不调用最终参数生产器再比较它自己的结果。允许复用底层解析、精确集合和多项式运算，但需独立检查变换、完整根数、参数类覆盖、域反射及每类恒等／反例。

比较系数证书核验所有次数，包括缺项和常数项；有限域证书核验全部输入；有理式证书核验交叉相乘前提；两参数证书核验消元行变换、解族和非零限制。结果为空同样要验证排除覆盖。

必须拒绝：恢复约掉的孔洞、漏退化参数、把 $x$ 当参数替换、把局部范围当完整域、只验一段、漏零点、直接将“无法化简”判为无解、漏原参数限制、把 $a+b=0$ 拆成两个独立范围、绑定其他函数或旧父目标证据。金标只用于测试，不能成为生产验证器的答案来源。

## 8. 必要测试与真实验收

### 8.1 数学覆盖矩阵

除 A17、A15、A20 外，下表均为新编开发／回归材料，不计入原两图的 20 道题，也不作为独立留出。每组按不同证明机制参数化，避免为同一代数步骤堆重复测试。

| 情形 | 样例与预期 | 必须核验 |
| --- | --- | --- |
| 原代表题 | A17：$m=2$；A15 子任务：$m=-4$；A20 子任务：$b=1$ | 最终答案与父目标分开，原性质和域在摘要中完整 |
| 全部参数／排他性质 | $px$ 在 $\mathbb R$ 上要求奇：$p\in\mathbb R$；要求奇而非偶：$p\ne0$；要求偶：$p=0$ | 零函数两种性质都成立 |
| 常数与零点条件 | $f(x)=p$ 要求奇：$p=0$；$x^2+px$ 要求奇：无解 | $f(0)=0$ 不足以证明奇性 |
| 多个参数值 | $(p^2-1)x^2+px$ 要求奇：$p=\pm1$；另给 $p>0$ 时只留 $1$ | 完整根集、原约束求交 |
| 次数退化 | $px^2$ 要求偶：全部实数；明确为二次函数时：$p\ne0$ | 不擅加或遗漏首项非零 |
| 四次展开 | $(x^2-1)^2+px$ 要求偶：$p=0$ | 不按题面字符串或只支持二次 |
| 非空与开闭 | $x^2$ 定义于 $[-p,p]$ 要求偶：$p\ge0$；改成 $(-p,p)$：$p>0$；改成 $[-p,p)$：无解 | 空域、单点和端点配对不同 |
| 域退化改变恒等方式 | $x^2$ 定义于 $[-p,p]$ 要求奇：仅 $p=0$ | 参数临界点的有限域不能套区间系数规则 |
| 有限域 | $px^2+1$，$D=\{-1,1\}$，要求奇：$p=-1$；在 $\mathbb R$ 上则无解 | 全部输入枚举，不能恒等比较整个实轴 |
| 内部孔洞 | $x^2$，$D=[-3,3]\setminus\{1,p\}$，要求偶：$p=-1$ | 不能只验最外端点；$p$ 在原区间外时仍缺少 $1$ 的配对 |
| 区间顺序变化 | $x^2$，$D=[-2,-1]\cup[p,p+1]$，要求偶：$p=1$ | 区间重叠、排序与合并后整体对称 |
| 约分孔洞 | $\frac{x-p}{x-p}$ 要求偶：$p=0$；$\frac{x^2-p^2}{x^2-p^2}$ 要求偶：全部实数 | 单孔／成对孔洞；$p=0$ 的重合点保留 |
| 分母退化 | $\frac{x}{px}$ 要求偶：$p\ne0$；$\frac{px}{x}$ 要求奇：$p=0$ | 分母恒零是无有效函数，分子为零仍保留 $x\ne0$ |
| 固定分母 | $\frac{x^2+px}{x^2+1}$ 要求偶：$p=0$ | 交叉相乘的原非零依据 |
| 绝对值 | $p\lvert x\rvert+x$ 要求奇：$p=0$ | 两侧与零点，不能把绝对值当 $x$ |
| 镜像分段 | $x<0$ 时 $px^2$，$x\ge0$ 时 $x^2$；要求奇：$p=-1$；要求偶：$p=1$ | 每支自身不是奇函数仍可整体为奇；正确配对分支 |
| 零点与不连续 | $x<0$ 时 $-1$，$x=0$ 时 $p$，$x>0$ 时 $1$，要求奇：$p=0$ | 允许跳跃，不漏孤立零点 |
| 根式自然域 | $\sqrt{p-x^2}$ 要求偶：$p\ge0$；要求奇：$p=0$ | $p=0$ 是单点零函数，$p<0$ 为空域 |
| 自然域／声明域 | $\sqrt{x^2+p}$ 自然域上要求偶：全部实数；声明在 $\mathbb R$ 上为偶：$p\ge0$ | 不偷偷删除声明域中的非法输入 |
| 两参数族 | $ax^2+bx$ 在 $\mathbb R$ 上要求奇：$a=0,b\in\mathbb R$；$ax^2+b$ 在 $\{-1,1\}$ 上要求奇：$a+b=0$ | 联合条件、自由变量、有限域适用依据 |
| 局部规则矛盾 | 在 $\mathbb R$ 上为奇，$x\ge0$ 时规则为 $x^2+p$：$p=0$；若仅 $x>0$ 给同式，则奇函数扩展可存在于所有 $p$ | 不补连续性；不将 $>$ 改为 $\ge$；此项使用局部规则相容性子合同，完整补式由 T3 负责 |

范围外输入需有明确诊断：第二个非线性参数、不可完整表达的参数根、移动绝对值边界或未支持根式结构、超预算、未读全的分段。它们不作为“无解”数学答案。若只有部分参数类已解，保存证据供诊断，但不生成声称完整的最终参数课。
