## 实现范围

- **含参定义域：** 单实参数，有理仿射端点，至多 4 个区间、8 个点／孔洞；支持并、交、差，保留开闭。每个原区间必须左端点严格小于右端点；非法区间不能借助并集“救回”，也不能解释成单点。集合运算得到的合法单点与显式有限集另行处理。
- **完整分类：** 包含所有原／反射端点交叉临界值，参数切点最多 32 个。每个参数单元内端点顺序不变，因此输入原子单元的成员关系与反射配对也不变。代表参数只用来选择已证明不变的顺序，不作为抽样猜测。证书保留全部参数单元、开区间和单点成员关系。
- **函数值条件：** 二次以内多项式在有区间的域上检查恒等式；有限域逐点检查，不能误要求全实轴恒等。最终单参数条件至多二次。保留原参数限制、明确的次数、普通／排他奇偶性质。
- **抽象函数与局部规则：** 必须有完整定义域；可以不给公式，或给一条在原域与正／负半轴交集上的局部二次公式。检查反射重叠及零点相容性，判定奇偶扩展是否存在，不补连续性、不伪造唯一全域公式。其他局部范围／多条规则仍返回能力缺口。
- **域角色：** 新增共享事实 `defined_on(f,J)`，编译为 `function_defined_on`。当前在全实数域多项式路线核验独立区间合法性；它不替换 `Dom(f)`，也不改变 T1 的 `domain_role` 枚举。未改 prompt。
- **公共技能与教学：** S1 新增 `solve_domain_symmetry_conditions`。M2 按结构调用 S1 或原比较系数技能；旧 `compare_coefficients` 的次数与全实轴输入限制未放宽。原式和参数端点用源 AST 显示。完成求参后展示原域／反射域配对数轴，并提供不对称示例；孔洞、开闭和孤立点不丢失。
- **父任务：** `borrow_domain_parameter` 返回参数集合、唯一参数下的实例化域、已处理与剩余条件；`verify_borrowed_parameter` 重新绑定父目标及全部选中源事实并验证。A15 返回 $m=-4,D=[-9,9]$；A20 返回参数 $1,D=[-2,2]$。原求值／不等式目标保持待完成，父方法还须处理剩余条件。
