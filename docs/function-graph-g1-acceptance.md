## 1. 学生入口与课程

- 正式本地题页：[B09 · 图像变换法](http://127.0.0.1:8793/topics/function-representations/q09a/)。原 q09 是 FR-T1 的 W09，因此新题使用 q09a。
- [函数的表示法专题](http://127.0.0.1:8793/topics/function-representations/#group-graph)新增“图像变换法”小组，合计 23 道题：原 FR-T1 的 22 道，加 B09。另两个分段题型保持待建设。
- 原题四幅选项图在题面中显示，保留标签、放大和完整原裁图入口。作答时点击选项图片或卡片主体即选择，右上角独立“放大”按钮只查看图片，不改变选择；选中态保留边框与勾选文字。图片尚未加载或绑定不一致时不允许确认。
- 读题、判型、预连线选法之后，三个数学步骤依次为：分步移动图像、总结图像变换、对照原图选图。第一张卡内分为“左右移动”和“上下移动”两小步，每次只判断一个动作。B09 先从 `y=|x|` 右移 1，再从 `y=|x−1|` 上移 1；随后用新顶点总结。合计 3 个数学步骤、4 个作答小步。
- 每次移动的完成图以虚线保留本次移动前的图，以实线和单方向箭头显示本次结果；第二步从已经右移的图出发。零位移的小步自动省略。完成态保留逐步公式、顶点变化和已选原图。自己做与 AI 回放共用同一课程，不手写另一份答案页。

数学路径为 `y=|u|`、`u=x-1`，所以 `(u,v)→(u+1,v+1)`，顶点 `(0,0)→(1,1)`。选图依据只使用原图可复核的特征：

| 原选项 | 标注顶点 | 左右方向 | 核对结论 |
| --- | --- | --- | --- |
| A | `(1,1)` | 左减右增 | 符合 |
| B | `(-1,1)` | 左减右增 | 横坐标不符 |
| C | `(-1,-1)` | 左减右增 | 横、纵坐标都不符 |
| D | `(1,-1)` | 左减右增 | 纵坐标不符 |

不从照片直线角度推断精确斜率，不以“看起来更像”判分。选项重排按稳定 ID 和实际标签绑定，不把数组第一个位置固定当成 A。

## 2. 已开放的执行合同

新增方法 `method-function-graph-transform`、技能 `skill-graph-coordinate-transform`、判断节点 `rule-function-graph-method`，以及目标 `select_function_graph`。`type-function-graph` 激活，但准入继续受下列限制约束：

| 项目 | G1 实现范围 |
| --- | --- |
| 函数 | `|ax+b|+c`，a、b、c 为固定有理数，a≠0 |
| 范围 | 全体实数，或顶点严格位于内部的一个显式区间；区间端点为受支持的精确有理数 |
| 题目目标 | 单选大致图像；选项完整，顶点有标注、两条直线分支及方向均可复核 |
| 显式区间 | 每个选项须提供相应范围，核对端点值及开闭；负 a 的映射反转端点次序和对应开闭 |
| 数学结果 | 精确点映射、基准范围、顶点、逐选项特征差异、唯一匹配选项；独立 verifier 重新核对，不调用求解器冒充核验 |
| 教学图 | 新 `absolute_affine` 类型，由顶点与两个边界生成准确折线路径；SVG 只负责展示，不参与判分 |

a=0、截成单支的范围、模糊图形事实、精确图像等价、多选或多个选项同时匹配均不开放此路线。分段作图在选法图中说明数学上适用、路线尚未展开，不把未实现的技能标成可执行。完整 `piecewise_curve`、二次绝对值、纯示意图和自由手绘评分均不在本批。

## 3. 原照片与身份绑定

提取保留受控图形事实、目标选项与归一化区域；候选经原图复核通过后，服务端检查版本、完整性、作用域、标签和原图／送模图对应，再安装 `question-figures/v1` 清单。原图与每个选项的像素哈希由服务端计算。

数学身份包含已审核图形语义和绑定的选项像素摘要。同文异图不会仅凭题文合并；来源变化、审核版本过期、选项缺失或标签不符会阻止准入。私有原图仍经过 G0 的归属、版本和生命周期校验；公开课包不写入学生照片 URL。

旧 `/image` 仍是送模图，新展示和选图使用 `/figures/{id}`。无可靠分区时保留完整原裁图，但不开放独立选图作答。跨页合并仍未支持。
