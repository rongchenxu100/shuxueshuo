## 1. 开工前已冻结的边界

- G1 只做 `|ax+b|+c`（a≠0）的变换选图。最小 V 形折线服务教学；完整 `piecewise_curve` 和绝对值分段技能执行、教学一起留到 G2。
- B09 逐选项核对顶点、左右方向、轴位置；忽略无比例示意图的像素斜率、长度、颜色。剩余选项自身必须符合证据，不接受“看起来更像”。核对表在设计 §7.1。
- B09-v2 来源涉及图 7、8；按实际题干和 A—D 是否齐全判完整。当前接口仍为单裁图，不支持跨页拼题。
- G2 以 B09-v1 原题 `>`／`≥` 金标冻结和成对回归为准入门；不影响 G1。
- 桌面原题与选项放左栏；右侧知识图谱不得覆盖图片。G0 提供共同面板和滚动后的查看入口；G1 再接依赖选项的步骤卡。
- FR-T2 本轮分段只由绝对值及其变换诱导；一般直接给定的分段函数归 FR-T3。
- G2 引导式构图必须以分段、区间、方向、边界的模型作答完成；不能拿动画结束或手绘截图代替。G4 必须另收未参与开发的纯图像新照片，B09-v3 开发图不算留出。

## 2. 已实现合同与接口

文件合同为 [question-figures/v1](../internal/schemas/question-figures-v1.schema.json)，数据处理在 [figures.py](../server/shuxueshuo_server/search/figures.py)。

| 项目 | 当前行为 |
| --- | --- |
| 高清来源 | 上传流程已保存的 `original.png`，即旋转、裁剪后的原始颜色像素；不是经过灰度化、降采样的送模图片 |
| 无区域清单 | 提供 `original` 整张裁图；保留已有选项排布；不虚构四个分图 |
| 审核区域清单 | 由受信任的题目编制流程写入 `question-figures.json`；没有学生或模型写此文件的接口 |
| 坐标 | 在同一高清来源上用归一化 `[x0,y0,x1,y1]`；转换后必须有像素面积；不混用送模图片坐标 |
| 绑定 | ID 不重复，选项 ID 和标签在对应目标内唯一，`target_ref` 必须属于 `scope_ref`；不接受任意文件路径 |
| 展示身份 | `content_id` 对来源、区域、顺序、作用域及标签整体哈希；修改任一项都更换版本 |
| 私有资源 | 两个新 GET 接口复用账号归属、生命周期校验和读取锁，返回 `Cache-Control: no-store`；跨账号不可读 |
| 静态资源 | 共同组件只允许 `/assets/question-figures/` 下的审核 PNG；不接受私人拍题 URL 或外站 URL |
| 数学身份 | 不修改公共数学身份规则；`figure=unrepresented` 仍拒绝合并和解题；展示哈希不当成数学身份 |

清单文件不含图片 URL。服务端读取时生成同题目的图片 URL，并附带 `content_id` 版本。区域只能引用本次裁图，源哈希或尺寸改变、重复选项绑定、跨作用域绑定均拒绝；旧版本图片请求返回 409。

## 3. `/image` 迁移说明

| 使用者 | 路径与数据 | 失败处理 |
| --- | --- | --- |
| 原送模和诊断 | 继续读取 `question.png`；旧 `/image` 仍返回该文件 | 不改已有送模哈希和识别版本 |
| 新题页 | 拍题状态附带 `figures`；也可单独 GET `/api/search/problems/{id}/figures` | 新清单无效时明确提示，不用旧图盖过失败 |
| 原图与缩略图 | 使用清单内 `original` 的 `/figures/original?version=…` | 资源失效后不能绕过到期、删除或账号边界 |
| 选项图 | 同题的 `/figures/{figure_id}?version=…` | ID 不在清单为 404，旧绑定为 409 |
| 旧记录没有 `original.png` | 明确标记“识别用图（原始裁图未保留）” | 不称其为高清原图；细节不足则重拍 |
| 旧服务未提供新字段 | 状态中既无 `figures` 也无 `figure_error` 时，兼容旧 `/image` | 新资源报错、版本冲突、403 或 410 不触发此回退 |

新前端没有另加一轮清单轮询。状态已经带图清单时直接使用；图片版本没有变化就不重复重建面板。退出登录、删除记录或页面卸载时，销毁图片弹窗、移除图片地址，并清理旧清单。私有清单不写入本地存储或公开课包。

## 4. 学生端显示

共同组件为 [question-figures.mjs](../site/assets/practice/question-figures.mjs)，拍题页与静态课包调用同一实现。

- 拍题页在成功题面中展示图片；识别失败时仍可查看、放大自己的原裁图。只读展示不解锁课程。
- 按目标筛选其选项，保持原数组顺序、稳定 ID 和标签；跨小问不能串图。题给作图区保留在合同中，不当作已知函数曲线展示。
- PC 原题卡进入左学习栏。页面滚动后“查看题图”回到图片并聚焦放大按钮；窄屏存在原图面板时收起会遮图的浮动图谱，仍可通过原入口打开图谱。
- alt、按钮名和图注只使用“题干配图”“选项 A 的原图”等角色和原标签；忽略模型描述与正确选项提示。这是原图访问标签，尚不声称实现数学图形的完整读屏等价描述。
- 放大使用原生弹窗；Tab 可访问关闭按钮，Esc 关闭后焦点返回原按钮。加载失败有明确文字；销毁时清除图源。

## 5. 固定验收样例

| 场景 | 本地证据／结果 | 后续门槛 |
| --- | --- | --- |
| B09 完整题干与 A—D | 从归档图 6 只裁题面与四图；公开预览已人工检查，放大、Esc 与焦点返回已核查 | G1 从真实照片自动生成和复核选项绑定，不能把手工清单当识别成功 |
| 缺选项或缺页 | 前端对 `missing_figure`、`identity.incomplete_choices`、`identity.incomplete_problem` 显示完整题干／全部选项／跨页未支持提示 | G1 实拍缺页必须触发对应诊断，不依据已上传张数判断完整 |
| 页面混有解析 | B09 编制样例明确排除下方教材解法；图片清单拒绝 `solution` role，没有清单时仅保留原裁图 | 尚未实现自动划掉照片中的答案。G1 验收须有含解析页，不能拿解析图补漏选项 |
| 淡色空心点与虚线 | 固定像素单元样例：预处理确实可抹去淡色空心点；新接口逐字节返回原图，局部裁图逐像素一致 | G1 另验真实印刷、倾斜、反光照片的端点和虚线 |
| 同文异图、选项重排 | 更改像素哈希、区域、选项顺序、标签、小问绑定都会改变展示身份；旧图 URL 拒绝 | G1 数学身份需纳入经验证的图形语义，G0 没有放宽公共合并 |
| 账号与资源生命周期 | 匿名、跨账号、旧私有目录均不可读；原图／清单禁止缓存；到期和删除后不可读 | 服务部署后按同合同验证线上权限 |

固定原图和选项由 [构建脚本](../tools/build_function_graph_g0_fixtures.py) 从归档教材生成；未复制私人拍题存储。清单内只有来源与区域，不含答案或排除理由。
