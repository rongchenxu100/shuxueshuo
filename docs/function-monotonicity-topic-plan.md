## 1. 专题身份、分类和范围

专题拟用 ID `function-monotonicity`，入口 `/topics/function-monotonicity/`；对应第三章 `chapter-functions`、3.2 `section-3-2`，以 **3.2.1 单调性与最大（小）值** 为内容范围。既有知识页 `/knowledge/function-monotonicity/` 继续使用原知识身份，专题和知识页属于不同命名空间。

分类以任务为准：B04、B06 虽然求字母的范围，字母只是函数的输入，仍归 T3；B08、B14 给的是最值条件，不能反推函数必定整体单调，归 T2 综合应用。A07、B11 是值域包含，不是仅比较两个最值；归 T2 的“值域与量词综合”小组，执行时仍使用值域任务语义。B15 有函数递推关系，但目标是一个区间端点的最大值，不属于 T5。

### 5.2 T1：判断函数的单调性

独立题型合同、六题金标、交互与验收矩阵见 [FM-T1 题型开发设计](function-monotonicity-problem-type-design.md)。

**M2 为常见具体函数的默认路径，M1 为定义证明路径，M3 负责分段组织。**

1. 求实际定义域，再与题给区间取交。根式分母使用严格大于零，不能机械地全部写成大于等于零。
2. 判别结构：基本二次函数直接用对称轴；根式或倒数拆内外层；和差先核验每一项的方向；绝对值先调用已有按符号分段技能，再交给 M3。
3. M2 的每个复合结论同时绑定内层单调区间、内层范围证据、外层在覆盖该范围的区间上的单调性，不能仅凭“两个方向相同”跳过范围检查。原域已证明非负／严格正等充分条件时，不强制再求完整像集；需要精确像集才能选外层单调支段时，借用原求值域子方法。
4. M3 在每段调用 M2 或 M1，检查分界点归属与跨段次序。允许满足方向的跳跃，不额外要求连续；同向的两个段也不自动合并。
5. 输出原变量上的单调区间，核验端点与最大可延伸范围。图像用于解释，任取数点作图不能代替证明。

M1 的完整步骤为：**任取 $x_1<x_2$ → 写 $f(x_2)-f(x_1)$ → 调用作差比较及化简／因式分解／等式推导 → 利用区间判断严格符号 → 返回增减性**。非严格符号不能直接得到严格单调；具体函数题还需分清是在证明给定区间，还是求全部单调区间。

主要技能：已有 `skill-expression-defined`、`skill-absolute-sign-split`、`method-complete-square`、`skill-simplify`、`skill-factor`；T1 拟新增“复合函数增减性判断”和“跨段单调性检查”，见 §6。M1 收束直接引用单调性定义；函数值比较转输入比较的技能放在 T3 建设。A01、A04 分别验证“局部段不能乱合并”和“定义域断开不能跨零套倒数性质”。

### 5.3 T2：利用单调性求最值及综合应用

详细开发范围、十题金标、方法与技能合同、交互密度及验收矩阵见 [FM-T2 题型开发设计](function-monotonicity-extremum-problem-type-design.md)。该文档为设计状态，尚未实施。

**基础路线 M4：定义域 → 证明／调用单调性 → 找候选端点、转折点或分界点 → 求值比较 → 验证取得性。**

已知严格递增且区间是 $[a,b]$ 时，最小值在 $a$、最大值在 $b$；递减相反。开端点可能只有可接近的界，不能写成取得的最值。分段函数逐段收集候选，再比较整体；A18 必须在 $x=0$ 处保留右段值，不能以两段各自递减推出整体递减。

二次、一次、对勾等已有范围技能继续复用；M4 新增的是“组织单调性证据并据此求最值”的完整教学路径，不复制这些技能的计算或交互。建议在本型补「运算增减性判断」技能：M4 组织整题，基本函数／复合走 M2，和／差／常数倍／倒数走该技能（可由 M2 或 M4 调用）。A14 展示和的递减依据，A16 展示分式分离后的倒数、负常数倍和平移，B10 展示差的递增依据。A16 也可完整调用已有分式求值域方法。

**综合路线 M7：先翻译量词，再求所需的像集／最值。** 令 $F=f(D_1)$、$G=g(D_2)$，两域先检查非空；$x_2$ 可以依赖 $x_1$，不擅自改写量词顺序。

| 原任务 | 可用的等价转化 | 边界要求 |
| --- | --- | --- |
| $\forall x_1\in D_1,\exists x_2\in D_2:f(x_1)=g(x_2)$ | $F\subseteq G$ | 必须是完整像集；$G$ 有空隙时，仅比较两端不够 |
| $\forall x_1\in D_1,\exists x_2\in D_2:f(x_1)\le g(x_2)$ | **两最大值存在时**，$\max F\le\max G$ | 最大值不存在时回到完整范围和可达性，不能套此简式 |
| $\forall x_1\in D_1,\exists x_2\in D_2:f(x_1)<g(x_2)$ | **两最大值存在时**，$\max F<\max G$ | 严格号需保留；无最大值的情况单独处理 |

M7 复用 `skill-quantified-range` 的数学规则，并扩展嵌套量词绑定及集合包含输出；调用各自的求值域子方法后，仍返回父目标求参数。A07 和 B11 的包含方向相反，必须由量词确定，不能固定成一个模板。

**逆向路线 M8：指定点最值 → 带取等点的全域不等式 → 分段调用公共子方法。**

- B08：先确定 $f(0)=a^2$，要求所有 $x\le0$ 的 $(x-a)^2\ge a^2$，且所有 $x>0$ 的 $x+1/x+a\ge a^2$。左段条件与右段条件取交，不附加整体单调。
- B14：先确定 $f(1)=1/2$，要求左段对所有 $x<1$ 不超过 $1/2$；右段递减已经满足。左段按顶点 $a$ 与 $1$ 的相对位置分类，调用区间最值／恒成立方法。
- 学生在进入子问题时判断“这是恒成立还是存在成立问题”，随后直接复用既有恒成立选法卡与完整流程，不另写一套选项或求参卡。

**拓展路线 C1：B15。** 用唯一分解 $x=t+2n$、$t\in(0,2]$、$n\in\mathbb Z$，从递推式证明 $f(x)=2^n t(t-2)$。先证明所有较早区间满足下界，再在第一个可能越界的区间求最早触界点，并确认其后立即存在违规输入。参数目标是前缀 $(-\infty,m]$，不能只求 $f(m)\ge-3$。复用区间最值、二次方程／不等式和量词技能；整数区间分解与递推覆盖证明是尚待实现的能力。

### 5.4 T3：利用单调性解不等式

完整题目台账、复用缺口、交互和分批验收设计见 [FM-T3 题型开发设计](function-monotonicity-inequality-problem-type-design.md)。B02 的增减字样已核定；B06 以教学变式入库，原图范围约定仍不静默改写。

M5 接收比较式 $f(u(x))\mathrel{\square}f(v(x))$，保留原输入表达式和函数对象。

1. 确定两个输入都合法，并落在同一个已有严格单调结论覆盖的区间。
2. 若函数以分段式给出且整体单调尚未证明，完整调用 M3；不能只验证两个输入各自所在的段。
3. 递增保持次序，递减反转次序；将结果交给已有一次／二次不等式子方法。
4. 将所得集合与两个输入条件取交，按原函数验证边界。
5. 若仅有非严格单调或存在常值段，不宣称等价去函数符号；B12 转到分段解不等式方法，按两个输入的分段条件求解并合并。

主要技能：在 T3 首次建设“利用单调性转化不等式”（`skill-monotonicity-order`）；复用已有 `skill-inequality-transform`、`skill-solve-quadratic`、`skill-quadratic-sign`。新技能只把已满足前提的函数值比较转成输入比较，后续解不等式仍调用已有能力；不把定义法的结论收束也塞进同一技能。多个相似题共用一份 M5 教学流程，以区间开闭、方向和输入多项式的绑定变化形成题目。

### 5.5 T4：已知函数单调性求参

独立开发设计见 [FM-T4 已知函数的单调性求参](function-monotonicity-parameter-problem-type-design.md)：覆盖 8 道原题，新增 M6 一个公共方法，不新增公共技能；按二次函数、显式分段、对勾分支和根式定义条件分批建设。既有子方法需补含参条件与验证合同，本设计不代表题型已开放。

M6 的输出必须是**必要且充分**的参数范围：

1. 读清指定区间与严格增减要求；差商／差积条件先等价翻译为单调性，不人为补充 $x_1<x_2$ 作为原题额外条件。
2. 检查整个指定区间上有定义。A13 的被开方数必须处处非负，该要求不能被后续单调条件覆盖。
3. 分析参数导致的退化：二次系数为零时按一次函数；一次斜率为零时常值段不满足严格单调。A11 保留 $a=0$，A06 排除 $a=-2$。
4. 基本二次函数使用对称轴与区间位置的包含关系；复合函数先证明外层在全部内层值上的严格单调性。
5. 分段情形调用 M3，同时返回每段严格性与跨段条件；相邻段的边界值相等可能允许，不能一律用严格号或一律用等号。
6. 合并条件后调用已有不等式方法；对答案端点、退化点和被排除参数类别回验。不能把有限参数采样当作必要充分性证明。

M6 调用已有子方法处理的是实际子问题，例如 A13 的“被开方数在 $(-\infty,-2]$ 恒非负”。现有 `method-domain-parameter` 的“给定完整定义域求参”不等于此处的“指定区间包含于定义域”，不直接冒用目标契约。

### 5.6 T5：证明抽象函数的单调性

独立开发设计见 [FM-T5 证明抽象函数的单调性](function-monotonicity-abstract-proof-problem-type-design.md)。本次采用真实教材题 C01／C02，新增公共方法 0 个、公共技能 0 个；重点扩展任意双点、合法代入与独立证明验证。

复用 M1 的定义证明主流程，增加“函数关系在合法输入下的改写”分支，暂不另建同义的“抽象函数作差法”。输入必须包含函数关系的量词作用域、定义域和符号／大小条件；输出是对任意合法有序双点成立的证明，不是拟合出的函数公式。

完整路径：**任取 $x_1<x_2$ → 构造正差 $h=x_2-x_1$ 或比值 $r=x_2/x_1>1$ → 在合法域内代入函数关系 → 将差表示成已知符号的函数值 → 得到严格大小 → 引用定义收束。**

复用 `skill-equality-transform` 的合法代入与恒等推导、`skill-simplify`、`skill-inequality-transform` 以及 M1／作差比较子方法。新增部分是任意变量、符号条件与作用域证据；不能调用“赋值法求解析式”猜出 $f(x)=kx$ 或 $c\log x$ 来替代证明。

原 P01／P02 新编题建议由以下真实题源替代；方向和条件辨析仍作为验证变式，不计入原题数：

| 题源／验证用途 | 完整条件与目标 | 预期证明与教学目的 |
| --- | --- | --- |
| C01 加法关系 | $f:\mathbb R\to\mathbb R$，对任意实数 $x,y$ 有 $f(x+y)=f(x)+f(y)$；对所有 $t>0$ 有 $f(t)>0$。判断定义域上的单调性 | $f(x_2)-f(x_1)=f(x_2-x_1)>0$；明确“任意两点”与正差 |
| C02 乘法输入关系 | $f:(0,+\infty)\to\mathbb R$，任意正数 $x,y$ 满足 $f(xy)=f(x)+f(y)$；对所有 $t>1$ 有 $f(t)>0$。判断定义域上的单调性 | $x_2/x_1>1$，$f(x_2)-f(x_1)=f(x_2/x_1)>0$；核对除数和关系作用域 |
| 方向变式／条件辨析（验证用） | C01／C02 的全称符号条件改成严格负号；另检查删除符号条件后是否仍能强判严格递增 | 负号变式严格递减；删除符号后不能强判，$f\equiv0$ 是反例。一次赋值或单点正值不能替代整段符号条件 |

第五类保持 `planned`，两道原题的数学、课程与真实拍题验收通过后再开放。题源已完整不等于功能已实现；B15 不计入其完成率。

### 6.1.1 运算增减性判断的范围与题目对应

复合技能处理 $F(g(x))$ 的内外两层；运算技能处理同一个自变量上的 $f(x)\pm g(x)$、常数倍、倒数以及有条件的乘积／商。一个运算技能包含这些内部操作即可，不按加、减、乘、除分别建节点。

既有知识节点 `function-monotonicity-operations` 已有 `shift-scale`、`reciprocal`、`sum-difference`、`product` 等条目，复用其知识身份。尚无对应的公共运算技能合同；已有不等式变形负责具体两点比较中的代数操作，不能把一次不等式取倒数的结果直接标成函数的全区间单调性证明。

| 本批题目 | 实际使用的运算 | 该步骤应得到的结论 |
| --- | --- | --- |
| A14／T2：$\sqrt{1-2x}+2x^2-5x+5$ | 和；先分别判断根式与二次式 | 在共同域 $(-\infty,\frac12]$ 上两项均严格递减，和也严格递减，因此在右端取最小值 $3$ |
| A16／T2：$\frac{2x+1}{x+3}=2-\frac5{x+3}$，$x\in[-2,2]$ | 分式分离后取倒数、乘负常数、加常数 | $x+3>0$ 且递增；倒数递减，乘 $-5$ 后递增，加 $2$ 不改变方向。最大值在 $x=2$，为 $1$ |
| B10／T2 中的 $f(x)=x-\frac1x$，$x\in[-2,-1]$ | 差 | $x$ 递增、$1/x$ 递减，所以差递增；所需最大值为 $f(-1)=0$。此结论只完成父题的一个子目标 |
| A04／T1：$1/\sqrt{x^2-5x-6}$ | 取倒数；与外层 $1/u$ 的复合规则重叠 | 每个合法分量上分母恒正，取倒数反向。T1 原路线已可完成，不强制为了同一反向步骤再调用运算技能 |

复合与运算两种入口使用同一倒数非零、同号及反序证据；同一次变换只展示一个教学步骤。开方本批沿用复合技能，也不在两处重复计算、评分。

首批建议建设和差、常数倍／平移、倒数；若涉及尚未确定符号的参数，先返回需要分类的条件，由父方法组织分支，再在符号已获证明的分支内应用规则。乘积、一般商作为同一技能的后续操作，补独立题源和验收后开放：

| 操作 | 可使用的充分规则与边界 |
| --- | --- |
| 和／差 | 同一区间上“增＋增＝增”“减＋减＝减”“增－减＝增”“减－增＝减”；方向组合不能确定时返回条件不足，而非断言不单调。严格性来自所用规则的前提 |
| 常数倍／平移 | 加常数方向不变，乘正数同向、负数反向；乘零得到常值，同时保留原表达式的定义域限制 |
| 倒数 | 原函数在共同区间恒正或恒负，取倒数反向；不能跨零套用。乘上常数时再判断常数符号 |
| 两个非常数函数的乘积 | 还要检查符号，例如两个恒正递增函数相乘递增；两个恒负递增函数相乘递减。其他组合无现成证明时回到作差比较，不只凭方向套口诀 |
| 两个非常数函数的商 | 先保留分母非零条件，再用取倒数与有条件的乘积规则组合；规则不够时使用分式分离或作差比较。例如在正区间上正的增函数除以正的减函数递增，但两个正的增函数相除不能确定方向 |

本批没有必须依赖“两个非常数函数乘积／商的通用方向规则”的题目。A16 虽然原式是商，既定路线是分式分离，不能据此宣称通用商规则已验收。A10 的右段及 B08 的 $x+1/x$ 则是“一增一减的和”，只靠和的规则不能判断，仍需对勾函数性质、定义法或既有最值方法。

运算技能不是通用单调性求解器。规则无法判断时，由 M2／父方法选择其他适用路线；不能补猜一个方向。后续回归至少包括：共同区间不一致、常数系数正负零、倒数跨零、正／负函数乘积，以及在 $x>0$ 上分子、分母同为正增函数的 $x^2/x$、$x/x^2$、$x/x$ 分别增、减、常值的反例。

### 6.3 题型与判断节点

五个题型身份：`type-function-monotonicity`、`type-monotonicity-extremum`、`type-monotonicity-inequality`、`type-monotonicity-parameter`、`type-monotonicity-abstract-proof`。主图可按五类展示，机器任务仍按实际目标分流：T2 的值域覆盖与最值逆向不能假装成直接求一个数值的最值。

首批只考虑两项公共判断：

- **单调性判定的选法判断**：基本函数／可拆复合／显式分段／需定义证明，允许多条适用路线，选择 M1、M2、M3。
- **单调性比较的前提判断**：两个输入是否有定义、是否在同一已证区间、是否严格单调；决定能否使用 M5 或转分段求解。

已有值域选法 `rule-function-range-method`、区间技能选择 `rule-interval-skill`、恒成立选法 `rule-quadratic-method` 直接复用。简单题无需为了展示图谱额外增加一张选法卡；一条已确定路线可直接进入方法。

## 8. 数学证据与题意处理要求

### 8.1 需要保留的结构

| 结构 | 必须保留的内容 |
| --- | --- |
| 单调性事实 | 函数对象、区间及开闭、方向、严格性、来源是题给还是已证明 |
| 含参分支 | 原式、参数域、退化条件、适用区间、各分支条件的交／并关系 |
| 双点证明 | 任意量词、$x_1<x_2$ 或 $x_1\ne x_2$、输入合法性、每个等式与符号推导的依据 |
| 复合输入 | 外函数身份、完整输入表达式、外层定义域、已知单调区间；求解字母与函数参数角色分开 |
| 量词比较 | $\forall x_1\exists x_2$ 的原顺序、各变量域、关系符号；允许存在变量依赖全称变量 |
| 最值／值域 | 完整集合或上下界、是否取得、原变量取等点、各段来源；不存在最值不能填一个边界数 |
| 指定最值 | 指定点在定义域内、其函数值、全域约束、是否要求唯一；本批题均没有额外唯一性要求 |

## 10. 关键答案校核依据

以下列出最容易受手写答案或方法误用影响的题；其余见逐题表。正式入库仍须从规范题意建立独立验证，不把本节文字直接当成模型输出的自动通过标签。

| 题目 | 校核推导 |
| --- | --- |
| A07 | $f([-2,1])=[-1,3]$，$g([-1,1])=[1-a,1+a]$。前者需覆盖后者，所以 $1-a\ge-1$、$1+a\le3$，与 $a>0$ 合并得 $(0,2]$ |
| A08 | 左段严格减要求 $a>0$；右段在 $x>2$ 减要求 $a\le4$；跨段要求 $1-2a\ge-4+a$。合并为 $(0,5/3]$ |
| A10 | 第一段递增要求 $a<0$。右段对 $1<x_1<x_2$ 有差 $(x_2-x_1)(1+a/(x_1x_2))$；处处正当且仅当 $a\ge-1$。交界要求 $a\le-1-a$，故 $[-1,-1/2]$ |
| A11 | $a=0$ 时 $-2x+3$ 递减；$a<0$ 时对称轴 $1/a<0$，题给区间在递减侧；$a>0$ 时最终递增。故 $a\le0$ |
| A13 | 令 $q(x)=ax^2+2x-5a+5$。整段有定义排除 $a\le0$；递减要求对称轴 $-1/a\ge-2$，即 $a\ge1/2$；此时最小被开方数在 $-2$，为 $1-a\ge0$，所以 $a\le1$ |
| A14 | 定义域 $x\le1/2$。$\sqrt{1-2x}$ 递减，$2x^2-5x+5$ 在该区间也递减，所以最小值是 $f(1/2)=3$ |
| A18 | 左段在 $[-1,0)$ 的值域为 $(2,3]$，右段在 $[0,1]$ 为 $[2,3]$，所以 $\max f=3$。$k>0$ 时 $\max g=g(1)=5-k$，得 $0<k\le2$ |
| B02 | 两输入共同给出 $x\in[0,2/3]$；按减函数读法，$>$ 转成 $x-1<1-3x$，得 $[0,1/2)$；按增函数读法，得 $(1/2,2/3]$。原图字样核定前均作为条件金标 |
| B07／B09② | 两段在分界 $3$ 处衔接为 $9$，整体严格递增。故 $x^2-2x<3x-4$，即 $(x-1)(x-4)<0$，得 $(1,4)$ |
| B08 | 左段以 $x=0$ 为最小点当且仅当 $a\ge0$；右段最小值为 $a+2$，在 $x=1$ 取得。还须 $a^2\le a+2$，得 $a\in[0,2]$ |
| B10 | $f([-2,-1])=[-3/2,0]$，右端实际取得。存在域要求 $a\ge1$；$\max g=\max(-6,a^2-4a-3)$，必须严格大于 $0$，得 $a>2+\sqrt7$ |
| B11 | $f([-1,2])=[-1,3]$。$a>0$ 时 $g$ 的像集为 $[-a-1,2a-1]$，得 $a\ge2$；$a<0$ 时为 $[2a-1,-a-1]$，得 $a\le-4$；$a=0$ 不成立 |
| B12 | 右侧函数值至少为 $1$，故左输入必须 $1-x^2>0$。$x\le0$ 时右侧为 $1$，得到 $(-1,0]$；$x>0$ 时需 $1-x^2>2x$，得到 $(0,\sqrt2-1)$；合并为 $(-1,\sqrt2-1)$ |
| B14 | $f(1)=1/2$。$a<1$ 时左段顶点在域内，需 $a+5/2\le1/2$，得 $a\le-2$；$a\ge1$ 时左段上界在 $x\to1^-$，需 $-(1-a)^2+a+5/2\le1/2$，得 $a\ge(3+\sqrt{13})/2$ |
| B15 | $x=t+2n$ 时 $f(x)=2^n t(t-2)$，$t\in(0,2]$。所有 $n\le1$ 的最小值 $-2^n\ge-2$；在 $(4,6]$ 上 $f(x)=4(x-4)(x-6)$，首次达到 $-3$ 为 $x=9/2$，其后至 $11/2$ 内有值低于 $-3$。故最大 $m$ 为 $9/2$ |
