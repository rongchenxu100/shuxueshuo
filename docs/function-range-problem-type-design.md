## 1. 任务、范围与推进顺序

T5 的目标是得到 **全部实际可达的函数输出集合**。对有效输入集合 $D$ 和函数 $F$，结果必须是

$$
R=F(D)=\{F(x)\mid x\in D\}
$$

必须同时证明：每个合法输入的输出均属于 $R$；$R$ 中每个数都能由某个合法输入取得。只求最大值／最小值、给上下界或画出少量采样点，都不足以完成值域目标。

**所有值域路线都先确定定义域，再在该域上求值域。** 每道题都呈现“确定定义域”步骤；题给域或平凡自然域也要核验并明确展示，可用只读结论减少点击。域未确定、声明冲突或有效输入为空时，不能继续给出非空函数的值域。具体处理见 §4.3。

### 1.2 结构边界

首轮以固定有理系数及精确可表示的代数数端点为计算对象；R0 先明确支持有理端点和无穷端点。R1–R3 开放各自声明的二次族前，必须贯通所需精确代数端点的集合表示、比较、求交、验证和交互：例如 $\sqrt{2-x^2}$、$1/(x^2-2)$ 会产生 $\pm\sqrt2$ 临界点，不能因系数有理就假定端点有理。未通过时只可保留显式受限的开发范围，不算该批广义结构族完成。禁止通过浮点比较决定集合边界。区间上下限、输入数目、AST 深度、幂次与展开规模使用共同预算，不按题号限制。

R0 支持 $a=0$ 的一次式与常数式，单点输入用确切代入处理；空输入集合报告无效／空输入状态，不伪称非空高中函数已经存在。多段有效域由后续批次的集合组织层拆分为合法分量再合并，不把非连通输入交给只接受一个区间的技能。

一般含参值域分类、任意高次有理式、三角／指数／对数值域、一般分段函数、任意抽象函数方程与不完整图像读值均不在本轮开放范围。只给原函数的完整值域而未给子区间信息时，不承诺求任意受限复合函数的完整值域。

## 2. 题源、目标与数学金标

以下为人工推导的设计金标，须在 S1 与原印刷题面逐题核对后冻结。手写答案不作依据；表中结果不能进入生产求解器作为答案白名单。Q3 是代表题，其余为扩题／回归集，不计入留出新题。

### 2.1 Q3：代表题全过程

已知 $f(x)=x^2-2x+2$，$x\in[0,3]$，求值域。

1. 保存原表达式，识别目标是输出集合；先确认原式在题给区间内均有意义，本题定义域为 $[0,3]$，不能因多项式自然域为 $\mathbb R$ 而忽略限制。
2. 配方 $f(x)=(x-1)^2+1$；对称轴 $x=1$ 在有效区间内。
3. 顶点输出 $1$ 在 $x=1$ 取得；两端输出分别是 $f(0)=2$、$f(3)=5$。
4. 全域输出满足 $1\le f(x)\le5$。在 $[1,3]$ 上连续递增并取到两端，覆盖 $[1,5]$。
5. 也可独立验证：任取 $y\in[1,5]$，$x=1+\sqrt{y-1}\in[1,3]$ 且 $f(x)=y$。
6. 输出完整值域 $[1,5]$，保留 $1$、$5$ 的取得位置；$f(0)=2$ 是候选值，不是下界。

课内可用抛物线、顶点和端点辅助展示，但完成依据是已验证的完整范围，不是学生拖动时采到的最大／最小纵坐标。

## 4. 题意表示与完整值域证据

### 4.1 保留原始任务和作用域

R0 已使用 `find_range`：函数像集目标以 `object` 引用原函数，`input_domain` 可表达额外输入范围；原有参数范围目标继续使用 `symbol`。`function_range` 特征保存原函数引用、绑定自变量、原式 AST、域的语义类别及来源。答案沿用集合型 `status=set`，函数像集保留 `object`，参数答案不带该字段；核验和多路线比较检查函数身份，前端分别显示“值域”和“参数范围”。

Q13 已有正式目标 `find_abstract_range`，保留 `known_call`、`known_domain`、`known_range`、`target_call`、`strength=exact` 及其函数身份与来源；`input_domain` 仅在题面另限外层自变量时保留。已知域和值域均归属于 `known_call`，不能把仅保证有意义的 `meaningful_only` 改成完整定义域 `exact`。当前状态是目标可识别、值域求解尚未开放；R4 沿用该契约，补 T5 匹配、M12 的覆盖验证和目标收束，不改写成另一个重复的 `find_range`／`function_image` 目标。具体解析式与抽象已知值域两类任务分别核对契约，不能共用字段名称就视为语义相同。

所有方法统一区分以下域语义，提取、复核、准入和独立验证保持一致：

| 来源语义 | 处理规则 |
| --- | --- |
| 原式自然定义域 $D_{\mathrm{nat}}$ | 从原式保留根式、分母等限制，不能用化简后的表达式扩大它 |
| 完整定义域声明 $D_f=D$ | 先验证 $D\subseteq D_{\mathrm{nat}}$；若包含无定义点，沿用 T4 的定义域冲突语义，不静默删点或缩域。合法声明域可以是真子集，无需等于自然域 |
| 额外求值范围 $E$ | 对合法函数，按题给限制求 $F(D_f\cap E)$；未声明 $D_f$ 时使用自然域。只有题意为额外范围限制或明确要求有效子集时才求交，不能把冲突的完整定义域声明重新解释为限制 |

例如声明 $f(x)=\sqrt{x},D_f=[-1,1]$，或 $f(x)=1/(x-1),D_f=[0,2]$，均应报告条件冲突；不能分别删去负数或点 1 后继续返回值域。若题意明确要求原式在给定范围内的有效输入及输出，则按相应目标求有效子集。域的语义无法从题面确定时保留待核对；当前能力无法证明声明合法性时说明能力缺口，不凭采样通过。空有效输入的处理仍遵循 §1.2。

- 提取保存函数、区间和“求值域”；不提前把任务改成最大值、判别式不等式或求 $x$。
- Q11 的 $f(2x-1)=x^2+2$ 是对实数变量成立的关系，不是定义一个名为 $f(2x-1)$ 的函数，也不能提取成 $f(x)=x^2+2$；教材无另限变量的约定须进入共享来源规则。单参数函数定义无法承载时先补关系协议，不能先行换元后伪装成原题定义。
- Q13 的定义域、已知值域和目标 $f(x+1)$ 各自绑定到正确对象；定义域与值域是两种独立的题给事实，不能由一方推断另一方。已知值域是完整输出断言，不是每个子域都有同样输出。
- Q18 的周期断言绑定 $g$，局部完整值域断言绑定 $f$ 和区间 $[3,4]$；不得改写成 $f$ 周期为 1。
- Q30 按五个原小问保留函数和域的局部作用域；某一问的有限集合或区间不能流入其他问。
- 所有新增语义共同进入提取、复核和修复规则、公共题目身份、原文绑定和冻结依赖；范围不足时保留未知及原因。

### 4.2 值域证明对象

每条完成路线至少保存以下结构化产物，拟字段名在实现时统一登记：

| 产物 | 数学职责 |
| --- | --- |
| `source_function`、`effective_domain` | 来源明确的原函数及全部有效输入；区分自然域、完整定义域声明与额外求值范围，并保留声明合法性核验和限制来源 |
| `image_set` | 精确区间、有限集合或有限并，保留开闭、孔点、离散性 |
| `containment_evidence` | 证明所有合法输入输出都在候选集合内 |
| `attainability_evidence` | 证明集合内任意输出存在合法原像；可为构造、连续单调覆盖、逐个枚举或已验证像集的精确传递 |
| `endpoint_evidence` | 有限边界是否可取及原像；无穷不是可取值；界不取到不代表没有其他原像 |
| `transform_chain` | 换元、分式分离、范围传递、子方法结果与回代的依赖，注明作用域与版本 |

独立验证从冻结原题和条件重新检查上述两个方向；不能仅信任方法产出的 `passed: true`。对于抽象函数，验证的是从题给完整断言到目标范围的逻辑推导，不虚构未知函数解析式。

### 4.3 所有路线的共同前置：确定定义域

每条路线在任何值域推导前完成以下工作，并把核验后的域绑定到当前目标及原式来源：

1. 区分原式自然域、完整定义域声明与额外求值范围，按 §4.1 核验并确定本次全部有效输入。已给定的区间、有限集合和全实数域也不能跳过。
2. 具体函数保留原根式、分母和约分前限制，按需复用 S3／M1；S3 只提条件，条件求解与求交由既有方法／能力完成。抽象函数确认的是目标调用的定义域，如 Q13 先得到 $f(x+1)$ 的输入域 $[0,1]$，不能只展示原函数的 $[1,2]$。
3. 域合法且非空后才计算输出范围。信息不足、契约暂不支持、条件冲突与空输入分别结束，不能凭表达式外观默认 $\mathbb R$。M7 等已给全域函数与目标区间的任务仍明确展示本次求值区间。
4. 子方法接收父方法已验证的域与版本证据；同一原域无需重复推导。M12 换元后还要确定新变量的精确范围，不能拿新变量范围替代原定义域。若另一个目标已求出定义域，只能复用已验证的同版本结果，否则本路线从原题独立求得。

这是每个方法的前置职责，不新增“先求定义域”方法或技能节点。学生侧始终可见域结论，平凡域只读展示，非平凡条件按 §7.1 展开；范围计算、最终验证与交互均使用同一份域证据。

## 5. 七种方法的契约

方法名称沿用章节设计；M3/M4/M5/M7/M12/M13/M14 在本设计中均是待登记方法编号。M13 用于「直接求值域法」，拟用全局 ID `method-direct-range`；M10 继续空置，其余编号不重排。实现时核对全局 ID 唯一性，仅给本批已可执行路线登记机器契约。已有技能按正式身份复用，不按章节复制。

### 5.1 M3 二次函数区间值域法

M3 的核心是求固定至多二次式在已确定输入域上的完整范围，允许再经过本节声明的基本变换得到原目标值域。R0 已登记 `method-quadratic-interval-range`，实现多项式本身在单个非空精确区间／单点上的像集；R1 再扩充 Q5 的二次根式应用，不提前放开任意复合函数。一次与常量退化仍由 M3 完整处理；独立的简单任务在 M13 开放后优先推荐 M13。

先完成 §4.3 的定义域步骤，再判断次数，按需调用配方与 `quadratic_interval_range`；直接绑定技能可完成时不重复计算顶点和端点。输入已是一次式或常量时走对应分支，不强制出现配方、对称轴或顶点步骤。

分支必须覆盖开口正／负、一次正／负斜率、常量；顶点左侧／内部／右侧／端点；有限、半无限和全实数区间；开闭端点和等高端点。常量在任何非空开区间上仍取得该值；端点未包含而同值在域内另有原像时，该输出仍应闭合。

多段域在组织层按分量计算再取并集；单点直接精确代入。每个区间结果由多项式连续性和完整临界点／端点检查保证覆盖，不把整体上下界之间的空缺填平。仅能产生一个最值的子调用不得完成 M3。

#### 5.1.1 方法内的基本范围变换

R1 在 M3 内开放 $c+d\sqrt{U(x)}$，其中 $c,d$ 为固定有理数，$U$ 为已准入至多二次式。先确定原目标定义域，再求该域上 $U$ 的完整像集，最后开平方、比例与平移；不能先算无约束范围再随意裁剪，也不能用求交掩盖声明域冲突。范围变换可复用其他路线提供的已验证完整范围，但不因此扩大 M3 的原式准入族。

对每个非负范围分量传递平方根，之后按 $d>0,d<0,d=0$ 处理比例与平移，保留可达性。$d=0$ 时仍保留原根式有意义要求；原域为空不能返回单点 $\{c\}$。被开方数取到零与只能趋近零须分开，负数范围不送入实数平方根。

输出必须证明基本函数变换覆盖所得集合。Q5 在同一次 M3 执行中完成“定义域 $[-5,-1]$ → 二次式范围 $[0,4]$ → 原函数值域 $[0,2]$”；$[0,4]$ 只是中间结果，不能提前完成原目标。Q30(1) 的推荐入口为 M13，依据基本性质直接求范围，不强加二次分析步骤。

这些是 M3 内的范围变换步骤，Q5 不另插 M13 子调用或一次 M3 自调用，也不新增范围传递技能。M13 组织独立的简单值域目标，和 M3 共享适配的范围变换能力；不因都有开平方步骤就合并两条教学路线。一般平方变换、任意复合基本函数不因本批名称而自动开放。

### 5.2 M12 换元求值域法

首轮输入族包括根式换元、绝对值换元、可逆非恒定仿射输入关系，以及已知完整值域且新输入覆盖原域的情形。前三类还须证明改写后只含新变量、为至多二次多项式，且系数与精确新域属于当前 M3 可完整处理的范围；例如 $x^2+\sqrt{1-x}$ 换元后为四次，不因含仿射根式就准入。已知值域传递另走完整覆盖分支，不要求未知函数有二次解析式。换元技能须返回新变量定义、精确像集、改写后的表达式、回代关系及覆盖证据；M12 组织后续 M3 或已知范围复用。

- 根式换元：$t=\sqrt{ax+b}$，$a\ne0$ 时有 $t\ge0$ 及 $x=(t^2-b)/a$；题给端点映射和不等号方向一起处理。$a=0$ 的常量根式单独归约或报告无有效输入，不套除以 $a$ 的公式。
- 绝对值换元：$t=\lvert ax+b\rvert$，需要证明原目标仅依赖 $t$，并求精确新域；不要求映射单射，但每个新输入必须有合法原像。同一个 $t$ 对应多个原输入时，改写结果必须一致。
- 仿射关系：$f(ax+b)=P(x)$ 在完整实域成立且 $a\ne0$，可恢复 $f(t)=P((t-b)/a)$。$a=0$ 只规定一个输入值，不能推断未知函数全域值域。
- 已知范围复用：先证明 $u(E)=D_f$，才可推出 $(f\circ u)(E)=f(D_f)$；只有 $u(E)\subsetneq D_f$ 时一般仅能给包含关系，不能声称完整值域不变。

Q13 以现有 `find_abstract_range` 进入 M12，可读取已验证、同版本的 T3 定义域目标，或本路线从原题重新求得 $E=[0,1]$ 并记录证明，再验证 $x+1$ 取遍 $[1,2]$。不能直接消费未验证的前问答案；有显式前后问依赖时还须实现失败阻断与重算失效。

### 5.3 M5 分式分离求值域法

本批范围为可验证改写成 $A+B/Q(x)$ 的固定有理式，$Q$ 至多二次，原有效域由原式限制与本批可处理的区间／有限去点集合组成。分式分离必须在原域上证明恒等，不能由化简后的式子重新推断扩大定义域。

先求原域上 $Q$ 的完整像集，确认其中已排除原本不合法的零值，再按正、负分量传递倒数，最后比例与平移；$B$ 的正、负、零分支完整。$Q$ 恒零时无合法输入；$Q$ 常量非零、余数为零时按实际非空原域返回常量输出。

若 $Q$ 的像集跨零，须先按真实有效域获得不含零的分量，不能把跨零区间直接传给单侧倒数函数。有限去点可能不改变像集，也可能留下输出孔点：删除输入 $x_0$ 不等于必删 $F(x_0)$，要检查其他合法原像。分离与范围传递中均保留原分母来源。

对于全实数域上的一次分式，排除渐近值后还须构造其余输出的合法原像；对于 Q7/Q10，完整分母范围与可逆倒数／仿射变换提供全体可达性。只有排除一个输出的论证不能完成方法。

### 5.4 M4 方程有实根法

R3 首轮限定为二次分式 $P(x)/Q(x)$：系数为固定有理数，分子至多二次，**分母恰为二次式，定义域为 $\mathbb R$，且分母已证明在实数全域恒不为零**。在分母首项系数非零的前提下，可用 $\Delta_Q<0$ 核验无实零点，正定与负定分母均可准入。保留原式限制，不因约分或化简而丢失输入条件。

M4 的数学原理是检查合法原像存在性，适用范围可以更广；本轮不把一次分式或常数分母作为 M4 的入口，分别按 M5、M3／M13 等已声明路线处理。分母有实零点或额外受限域时保持能力缺口；后续若扩展，必须补齐域内合法实根的精确判定，不能仅放宽准入。原分母为二次式而整个商为常值时，仍覆盖恒等／矛盾方程分支。

令 $y=F(x)$，等价整理为 $A(y)x^2+B(y)x+C(y)=0$，分支完整覆盖：$A\ne0$ 用 $\Delta\ge0$；$A=0,B\ne0$ 为一次方程；$A=B=0,C=0$ 为恒等方程；$A=B=0,C\ne0$ 无解。每个分支限定在自身条件下求输出集合，再取并集。

Q6 的 $y=2$ 必须保留，不能因使用二次判别式而丢失；Q7 的备选路线在 $y=2$ 变成无解常量方程，不能因为“次数退化”一律纳入。分母全域非零是实根均合法的证明前提，应在验证器中重新核验。

已有 `method-discriminant` 主要完成二次恒成立求参数，不能不检查量词就代替 M4 的“存在合法原像”目标。可复用判别式计算、因式分解、二次判号与等式变形技能；若转成新的子问题，仍须与其方法输入输出匹配。

### 5.5 M14 枚举法

输入为可穷尽列举的非空有限定义域与已准入函数，按稳定输入身份调用 M9，验证每次代入合法，收集全部输出后按精确相等去重。输入数量预算在准入、执行与教学一致，不能静默截断前若干项。

输出为有限集合及输入—输出对应记录。输入重复仅影响记录去重，不重复计值；不同输入有相同输出时允许多对一。声明域冲突与有效子集处理统一遵循 §4.1，不仅在枚举路线检查。

Q30(3) 不调用面向连续区间的线性范围技能，不把 $\{-3,-1,1,3\}$ 写成 $[-3,3]$。基础枚举不是新技能节点，M14 复用 M9 的合法代入和来源证据。

### 5.6 M7 平移关系求值域法

方法依据是目标函数的输入平移与输出平移关系。目标函数不必具有周期性；输出平移量为零时包含周期函数的情形。Q18 由 $g$ 的周期性推出 $f(x+1)=f(x)+1$，因此采用「平移关系求值域法」这一名称。

首轮处理已知 $g(x+p)=g(x)$、$f(x)=a x+g(x)$，$p>0$、$a$ 固定，及一个长度为 $p$ 的完整基础区间值域；目标域须被有限个合法整数平移的完整基础区间**恰好覆盖**，且每段均包含于目标域。原始端点归属作为覆盖条件的一部分。

先推出 $f(x+kp)=f(x)+akp$，再计算各段像集 $R_0+akp$ 并求精确并集。$a$ 正／负／零、平移正／负／零都应覆盖。值域各段只有相交或相邻端点确实连通时才合并；有空缺时保留多个分量。

Q18 中 $p=a=1$，平移 $k=-13,\ldots,6$，输入并集恰为 $[-10,10]$；对应输出并集为 $\bigcup_{k=-13}^{6}[-2+k,5+k]=[-15,11]$。任意输出先来自某段已知完整像集，再通过平移回到目标输入，因此有可达依据。$f$ 自身不以 1 为周期。

目标只有部分基础段时，不用向外取整的完整段替代它；缺少该残段的范围信息就报告无法确定完整值域。也不假设 $g$ 连续或单调。涉及相邻闭段共享端点时，应保持同一输入输出一致；若已知数据与平移关系可证明矛盾，应报条件冲突。

### 5.7 M13 直接求值域法

适用于在准确的定义域上，依据已知基本函数性质和简单范围变换就能求得完整值域的任务。它是完整的求值域入口；基本性质、仿射变换与端点核验仍复用已有知识和能力，不新增技能节点，也不把「表达式看起来简单」作为准入规则。

R1 首批开放固定有理系数的一次式、常量式，以及 $c+d\sqrt{ax+b}$。原有效域须是当前集合能力可精确处理的非空实区间；多段域按合法分量计算再取并集，单点直接代入，任意有限集优先走 M14。绝对值、倒数等其他基本函数的直接路线可按相同原则后续扩展，在各自契约与验收补齐前不开放；现有分式题仍按 M5 等已声明路线建设。

先按 §4.3 确定原定义域。一次式按斜率直接映射输入范围，常量式在非空域上返回单点；根式族依次确定 $ax+b$ 在该域上的准确范围 → 依据平方根的单调性传递非负范围 → 完成比例、平移与端点核验 → 返回原目标完整值域。输入斜率 $a$ 与输出系数 $d$ 的正、负、零分支均需处理；$a=0$ 时核验常量被开方数是否合法，$d=0$ 时仍保留原根式限制。空输入或声明冲突不能因最后输出是常数而绕过。区间开闭、无穷及分量间空缺均精确保留。

Q30(1) 的数学主线为：

$$
D=[0,+\infty)\quad\Longrightarrow\quad\sqrt{x}\in[0,+\infty)\quad\Longrightarrow\quad y\in[-1,+\infty)
$$

除输出不小于 $-1$ 外，还须证明所有 $y\ge-1$ 均可取得：$x=(y+1)^2\in D$ 即为合法原像。对受限域如 $x\in(0,4]$，必须返回 $(-1,1]$，不能直接照搬平方根的全自然域值域。

与 M3 的分工按所需推导确定：Q5 的被开方数是二次式，需要先分析该二次式在合法域上的范围，入口仍为 M3；Q30(1) 直接依据基本性质，入口为 M13。$x+\sqrt{1-x}$ 同时含相关的两部分，不能把各自范围独立相加后声称得到精确值域，仍走 M12。M13 不强制展开配方、顶点、判别式或额外的范围子方法；原定义域按需复用 M1，交互密度仍遵循 §7.1。

### 6.1 适用条件与推荐规则

沿用恒成立题的「结构触发 → 前提核验 → 推荐」模式，建立公共求值域 `method_selection` 判断。T5 初期只开放 M3；R1 增加 M13／M12 后登记实际可执行的分支，后续逐批扩充。规则消费已核验的原定义域，独立检查全部候选，不通过首个命中就排除其他适用方法，也不按题号选择。

| 方法 | 结构触发与本批前提 |
| --- | --- |
| M13 | 一次／常量式或 $c+d\sqrt{ax+b}$；准确输入域、仿射范围、平方根及输出变换均在已验证范围内 |
| M3 | 至多二次多项式，或 §5.1.1 的二次根式应用；能按准确域计算全部区间分量与可达性 |
| M5 | 本批分离后为 $A+B/Q(x)$，$A,B$ 为常数、$Q$ 至多二次；恒等改写、原域上分母范围及倒数分量均可验证 |
| M4 | 原分式分子至多二次、分母恰为二次；原域为全实数且分母无实零点；$P(x)-yQ(x)=0$ 的次数退化与合法实根条件均可判定 |
| M12 | 命中 §5.2 的换元形式且可验证新域、完全改写及 M3 准入；或已知值域传递中可证明新输入覆盖原域 |
| M14 | 非空有限定义域可完整列举，各输入的合法代入均在 M9 支持范围内 |
| M7 | 有可验证的整数平移关系，目标域恰由已知完整范围的输入段覆盖 |

推荐规则在适用条件核验之后执行：有限域优先 M14；符合 M13 直接性质链的任务优先 M13；需要二次范围分析的任务推荐 M3；需换元或平移覆盖时分别推荐 M12、M7。分式能直接分离为常数加常数除以已知范围的中间量时优先 M5；若分离余项仍含变量、尚需额外变换，而 M4 的合法实根条件可直接判定，则优先 M4。两者均可执行时保留备选；其他重叠情形使用固定顺序 M14 → M13 → M3 → M5 → M4 → M12 → M7 作为兜底，推荐依据记录实际触发条件。

例如 Q30(1) 推荐 M13，Q5 推荐 M3，Q7 推荐 M5 并保留 M4。Q6 推荐 M4；分离后可在 $x\ne0$ 时化为 $2+1/(1+x+1/x)$，因而数学上存在 M5 扩展路线，但它需要中间量范围、分段与补回 $x=0$ 的完整处理，不属于 §5.3 首批已声明的常数余项族。在这条通用契约及验收完成前，标明尚未支持，不把数学可行说成不适用，也不因一次分式分离成功就准入。

数学适用性、当前可执行状态与推荐分别维护；无法证明前提时记录未确定／能力缺口，不猜测适用。选法证据保留规范化结构、定义域和各前提结果；模型提取的外观特征不能直接替代程序核验。「含根号」不必然选择 M13，「含二次项」不必然选择 M4。

Q7 可同时适用 M5 与 M4，不为制造唯一答案而把另一方法判错。学生选到适用但未展开的方法，提示当前未展开、允许改选，不完成本步。子方法有适用公共判断节点时让学生再次选择；没有时只读展示已验证的借用依据，不伪造判断节点或为每次调用重复插入确认。子方法展开密度按 §7.1 由父方法决定，完成后返回当前父目标验证原值域。

| --- | --- | --- |

### 7.1 子方法交互密度

遵循共用流程 §5.3.1，数学调用和验证始终完整，学生侧由父方法声明 `fold`（只读结论、证据可展开）、`light`（关键结果或判断）、`full`（完整子方法过程）。不因后台调用子方法就默认展开整套教程，也不省略实际需要的选法判断。

| 父方法中的子任务 | 默认交互 | 升级条件与返回位置 |
| --- | --- | --- |
| 所有路线先确定定义域 | 保留可见步骤；平凡或已给域用 `fold` 展示核验结论，非平凡合法性条件用 `light` | 根式与分母的并列限制、原式孔点等是本步学习重点时展开相关过程；域确认后才进入值域推导 |
| M12／M5 借用 M3 | `light`：展示准确子目标与输入域，判断内层完整范围 | 新域、顶点位置或边界可达性需要专门教学时用 `full`；完成后回到换元或分式范围传递步骤。Q5 的开平方属于本次 M3 内部步骤，不插借还卡 |
| M14 调用 M9 | `light`：一张输入—输出表收集结果，再去重形成有限值域；简单已验证代入可 `fold` | 嵌套输入或代入合法性易混淆时，仅展开该输入的 M9 过程，结束返回同一表行；不对每行重复读题、判型、选法和借还确认 |
| M7 的各段平移与合并 | 先判断平移关系和覆盖，之后重复平移计算用 `fold`，并集关键判断用 `light` | 端点归属或输出空缺是当前难点时展开对应段，返回本次并集目标 |

每张卡只呈现当前步骤所需的对象和变化；表格、数轴或映射图从验证产物生成。未作答的结果留空，确认后填入；展开子方法、刷新或切换学习模式不能泄露尚未确认的后续结果。完整推导保持数学等式和必要条件简洁，方法解释放在提示或选法依据中。

### 7.2 多维判断的分层选法卡

T5 采用一张「依据 → 关键判断 → 方法选择」的分层选法卡，占一个选法步骤。定义域种类、表达式结构、变换条件和合法实根并非两个独立的二元维度，各方法也可能同时适用，因此不继续增加坐标轴或要求学生在多张坐标图之间切换。已有恒成立题的二维平面仍保留；子问题确实只有两个清晰判断维度时继续使用原组件。

```mermaid
flowchart LR
  facts[已确认的定义域与题目条件] --> checks[必要的关键判断]
  checks --> methods[选择本次使用的方法]
  methods --> route[进入适用且已展开的路线]
```

| 卡片区域 | 展示与操作 | 约束 |
| --- | --- | --- |
| 上部：本题依据 | 用少量标签展示已确认的定义域、函数结构或题给关系；题面中高亮当前涉及的分子、分母、根式或关系式 | 已完成的定义域不再出一道相同问题；只展示已验证条件，不把尚待判断的结论先写进标签 |
| 中部：关键判断 | 按当前候选展示有区分度的 1–2 个问题，使用 `choice`、简短填空或公式关系卡；完成后折为一句依据 | 只问本题需要的条件，不遍历七个方法的全部前提；不做完整值域运算。若没有新的关键判断，只读展示依据，保留一次方法选择 |
| 下部：方法选择 | 默认呈现本题相关的少量方法卡，卡内只有方法名及通用操作简介；选一张并确认 | 不为凑选项加入牵强方法；不为限制卡片数隐藏适用备选。自己做模式提交前不显示「推荐／适用／不适用」结论，不自动选中推荐项 |
| 完成态：选择依据 | 展示所选方法、适用条件及推荐理由；其他方法的对比说明按需展开 | 可说明另一条路线更直接，但不能把选择适用备选判错。完整方法×条件对比表仅作回看，不作为初始必答界面 |

学生侧的一次判断只决定展示进度，不改写后台数学事实。后台始终按 §6.1 独立检查各方法；前提回答错误时指出具体冲突位置并停留在本卡，不能据错误答案把某条数学上适用的路线从图谱中删掉。分层呈现允许同时保留多种适用方法，不要求落到唯一方法叶子。

Q7 可采用以下节奏：

1. 已完成定义域步骤，顶栏只读显示 $D=\mathbb R$ 及「分母为二次式、全域非零」；高亮分子与分母。
2. 若本次训练分离条件，问「分离常数后，余项分子是否仍含 $x$？」。正确提交后才显示 $y=2-1/(x^2-x+1)$，作为已确认的选法依据，不提前给出分母范围或最终值域。
3. 展示「分式分离求值域法」「方程有实根法」两张候选卡。已展开时，选 M5 或 M4 均可进入对应路线；完成态说明 M5 的直接分离优势。若 M4 尚未展开，按下述规则停留重选，不判数学错误。

Q6 的余项分子仍含 $x$，可突出反解得到至多二次方程这一依据，推荐 M4；Q30(1) 仅需基本性质，使用简短依据和方法卡，不强行凑两道判断；Q18 以已验证的平移关系和完整区间覆盖作为依据，不展示分母、次数等无关维度。判断问题和卡片布局由结构与证据生成，不按题号拼界面。

评分沿用同一数学契约：必要的前提判断正确且所选方法适用、已展开，才进入对应路线；选中适用但未展开的方法返回 `uncovered`，不计错、不推进、不记掌握；前提未知或能力不足时明确说明缺口，不能判作数学不适用。AI 回放按相同判断顺序展示依据，再选择一条已验证路线。返回、撤销、刷新或切换模式时，关键判断和方法选择属于同一目标／调用上下文；不能借用另一目标的作答，也不能提前显示未提交的推荐结论。

**协议落点（待实现）：** 当前 `graph-method-selection/v1` 强制包含 `plane_axes` 和各分支的 `plane`，不能给 T5 填假坐标通过校验。实施 S2 时冻结带明确展示类型的协议：二维平面和分层卡片各有必需字段，适用性与推荐结果共用；判断节点身份和数学证据不随展示方式复制。卡片的稳定条件 ID、答案、顺序、方法选择及 `uncovered` 语义贯通 schema、编译、前后端评分、静态专题与拍题流式回放。沿用现有方法切换与父子返回契约，本节不表示这些新字段已经实现。
