## 1. 任务、范围与推进顺序

T5 的目标是得到 **全部实际可达的函数输出集合**。对有效输入集合 $D$ 和函数 $F$，结果必须是

$$
R=F(D)=\{F(x)\mid x\in D\}
$$

必须同时证明：每个合法输入的输出均属于 $R$；$R$ 中每个数都能由某个合法输入取得。只求最大值／最小值、给上下界或画出少量采样点，都不足以完成值域目标。

| 项目 | 约定 |
| --- | --- |
| 已登记题型 | `type-function-range`，当前为 `planned`，方法／规则／例题为空 |
| 代表题 | Q3：$x^2-2x+2$ 在 $[0,3]$ 上求值域 |
| 完整题源 | Q3、Q5–8、Q9 值域、Q10、Q11、Q13 值域、Q16–18、Q30 五问，共 17 个值域目标 |
| 跨型目标 | Q9 定义域归 T2；Q13 定义域归 T3；不同目标分别验收，不能互相替代 |
| 不属于本型 | Q24(2) 只求最大面积及取得位置，继续使用已有最值路线，不计作 T5 完整值域题 |

### 1.2 结构边界

首轮以固定有理系数及精确可表示的代数数端点为计算对象；R0 先明确支持有理端点和无穷端点。R1–R3 开放各自声明的二次族前，必须贯通所需精确代数端点的集合表示、比较、求交、验证和交互：例如 $\sqrt{2-x^2}$、$1/(x^2-2)$ 会产生 $\pm\sqrt2$ 临界点，不能因系数有理就假定端点有理。未通过时只可保留显式受限的开发范围，不算该批广义结构族完成。禁止通过浮点比较决定集合边界。区间上下限、输入数目、AST 深度、幂次与展开规模使用共同预算，不按题号限制。

R0 支持 $a=0$ 的一次式与常数式，单点输入用确切代入处理；空输入集合报告无效／空输入状态，不伪称非空高中函数已经存在。多段有效域由后续批次的集合组织层拆分为合法分量再合并，不把非连通输入交给只接受一个区间的技能。

一般含参值域分类、任意高次有理式、三角／指数／对数值域、一般分段函数、任意抽象函数方程与不完整图像读值均不在本轮开放范围。只给原函数的完整值域而未给子区间信息时，不承诺求任意受限复合函数的完整值域。

## 2. 题源、目标与数学金标

以下为人工推导的设计金标，须在 S1 与原印刷题面逐题核对后冻结。手写答案不作依据；表中结果不能进入生产求解器作为答案白名单。Q3 是代表题，其余为扩题／回归集，不计入留出新题。

### 2.1 Q3：代表题全过程

已知 $f(x)=x^2-2x+2$，$x\in[0,3]$，求值域。

1. 保存原表达式和题给输入范围，识别目标是输出集合。
2. 配方 $f(x)=(x-1)^2+1$；对称轴 $x=1$ 在有效区间内。
3. 顶点输出 $1$ 在 $x=1$ 取得；两端输出分别是 $f(0)=2$、$f(3)=5$。
4. 全域输出满足 $1\le f(x)\le5$。在 $[1,3]$ 上连续递增并取到两端，覆盖 $[1,5]$。
5. 也可独立验证：任取 $y\in[1,5]$，$x=1+\sqrt{y-1}\in[1,3]$ 且 $f(x)=y$。
6. 输出完整值域 $[1,5]$，保留 $1$、$5$ 的取得位置；$f(0)=2$ 是候选值，不是下界。

课内可用抛物线、顶点和端点辅助展示，但完成依据是已验证的完整范围，不是学生拖动时采到的最大／最小纵坐标。

## 4. 题意表示与完整值域证据

### 4.1 保留原始任务和作用域

拟沿用或扩充 `find_range` 的函数像集语义，具体字段在 S0/S2 定稿；必须表达原函数引用、绑定自变量、原式 AST、显式输入限制、目标输出及题面来源。若需要新增 `function_image` 类内部目标，标记为新协议并同步所有消费者，不把本文名称直接视为已存在接口。

- 提取保存函数、区间和“求值域”；不提前把任务改成最大值、判别式不等式或求 $x$。
- Q11 的 $f(2x-1)=x^2+2$ 是对实数变量成立的关系，不是定义一个名为 $f(2x-1)$ 的函数，也不能提取成 $f(x)=x^2+2$；教材无另限变量的约定须进入共享来源规则。单参数函数定义无法承载时先补关系协议，不能先行换元后伪装成原题定义。
- Q13 的定义域、已知值域和目标 $f(x+1)$ 各自绑定到正确对象；定义域与值域是两种独立的题给事实，不能由一方推断另一方。已知值域是完整输出断言，不是每个子域都有同样输出。
- Q18 的周期断言绑定 $g$，局部完整值域断言绑定 $f$ 和区间 $[3,4]$；不得改写成 $f$ 周期为 1。
- Q30 按五个原小问保留函数和域的局部作用域；某一问的有限集合或区间不能流入其他问。
- 所有新增语义共同进入提取、复核和修复规则、公共题目身份、原文绑定和冻结依赖；范围不足时保留未知及原因。

### 4.2 值域证明对象

每条完成路线至少保存以下结构化产物，拟字段名在实现时统一登记：

| 产物 | 数学职责 |
| --- | --- |
| `source_function`、`effective_domain` | 来源明确的原函数及全部有效输入；自然限制与显式限制可追溯 |
| `image_set` | 精确区间、有限集合或有限并，保留开闭、孔点、离散性 |
| `containment_evidence` | 证明所有合法输入输出都在候选集合内 |
| `attainability_evidence` | 证明集合内任意输出存在合法原像；可为构造、连续单调覆盖、逐个枚举或已验证像集的精确传递 |
| `endpoint_evidence` | 有限边界是否可取及原像；无穷不是可取值；界不取到不代表没有其他原像 |
| `transform_chain` | 换元、分式分离、范围传递、子方法结果与回代的依赖，注明作用域与版本 |

独立验证从冻结原题和条件重新检查上述两个方向；不能仅信任方法产出的 `passed: true`。对于抽象函数，验证的是从题给完整断言到目标范围的逻辑推导，不虚构未知函数解析式。

## 5. 七种方法的契约

方法名称沿用章节设计；M3/M4/M5/M7/M12/M13/M14 在本设计中均是待登记方法编号。实现时核对全局 ID 唯一性，仅给本批已可执行路线登记机器契约。已有技能按正式身份复用，不按章节复制。

### 5.1 M3 二次函数区间值域法

输入为固定至多二次多项式和一个非空精确区间，输出完整像集及边界可达性。先判断次数，再按需调用配方与 `quadratic_interval_range`；直接绑定技能可完成时不重复计算顶点和端点。

分支必须覆盖开口正／负、一次正／负斜率、常量；顶点左侧／内部／右侧／端点；有限、半无限和全实数区间；开闭端点和等高端点。常量在任何非空开区间上仍取得该值；端点未包含而同值在域内另有原像时，该输出仍应闭合。

多段域在组织层按分量计算再取并集；单点直接精确代入。每个区间结果由多项式连续性和完整临界点／端点检查保证覆盖，不把整体上下界之间的空缺填平。仅能产生一个最值的子调用不得完成 M3。

### 5.2 M13 基本函数范围传递法

首轮只开放 $c+d\sqrt{U(x)}$，其中 $c,d$ 为固定有理数，$U$ 为已准入至多二次式，或由已有验证产物给出完整内层范围。先使用原式条件限定有效域，再求该域上 $U$ 的完整像集，不能先算无约束范围再随意裁剪。

对每个非负范围分量传递平方根，之后按 $d>0,d<0,d=0$ 处理比例与平移，保留可达性。$d=0$ 时仍保留原根式有意义要求；原域为空不能返回单点 $\{c\}$。被开方数取到零与只能趋近零须分开，负数范围不送入实数平方根。

输出必须证明基本函数变换覆盖所得集合。Q5 调用 M3 得 $[0,4]$ 后开平方；Q30(1) 使用平方根的基本完整范围再平移。一般平方变换、任意复合基本函数并不因本批名称而自动开放。

### 5.3 M12 换元求值域法

首轮输入族包括根式换元、绝对值换元、可逆非恒定仿射输入关系，以及已知完整值域且新输入覆盖原域的情形。前三类还须证明改写后只含新变量、为至多二次多项式，且系数与精确新域属于当前 M3 可完整处理的范围；例如 $x^2+\sqrt{1-x}$ 换元后为四次，不因含仿射根式就准入。已知值域传递另走完整覆盖分支，不要求未知函数有二次解析式。换元技能须返回新变量定义、精确像集、改写后的表达式、回代关系及覆盖证据；M12 组织后续 M3 或已知范围复用。

- 根式换元：$t=\sqrt{ax+b}$，$a\ne0$ 时有 $t\ge0$ 及 $x=(t^2-b)/a$；题给端点映射和不等号方向一起处理。$a=0$ 的常量根式单独归约或报告无有效输入，不套除以 $a$ 的公式。
- 绝对值换元：$t=\lvert ax+b\rvert$，需要证明原目标仅依赖 $t$，并求精确新域；不要求映射单射，但每个新输入必须有合法原像。同一个 $t$ 对应多个原输入时，改写结果必须一致。
- 仿射关系：$f(ax+b)=P(x)$ 在完整实域成立且 $a\ne0$，可恢复 $f(t)=P((t-b)/a)$。$a=0$ 只规定一个输入值，不能推断未知函数全域值域。
- 已知范围复用：先证明 $u(E)=D_f$，才可推出 $(f\circ u)(E)=f(D_f)$；只有 $u(E)\subsetneq D_f$ 时一般仅能给包含关系，不能声称完整值域不变。

Q13 可读取已验证、同版本的 T3 定义域目标，或本路线从原题重新求得 $E=[0,1]$ 并记录证明，再验证 $x+1$ 取遍 $[1,2]$。不能直接消费未验证的前问答案；有显式前后问依赖时还须实现失败阻断与重算失效。

### 5.4 M5 分式分离求值域法

本批范围为可验证改写成 $A+B/Q(x)$ 的固定有理式，$Q$ 至多二次，原有效域由原式限制与本批可处理的区间／有限去点集合组成。分式分离必须在原域上证明恒等，不能由化简后的式子重新推断扩大定义域。

先求原域上 $Q$ 的完整像集，确认其中已排除原本不合法的零值，再按正、负分量传递倒数，最后比例与平移；$B$ 的正、负、零分支完整。$Q$ 恒零时无合法输入；$Q$ 常量非零、余数为零时按实际非空原域返回常量输出。

若 $Q$ 的像集跨零，须先按真实有效域获得不含零的分量，不能把跨零区间直接传给单侧倒数函数。有限去点可能不改变像集，也可能留下输出孔点：删除输入 $x_0$ 不等于必删 $F(x_0)$，要检查其他合法原像。分离与范围传递中均保留原分母来源。

对于全实数域上的一次分式，排除渐近值后还须构造其余输出的合法原像；对于 Q7/Q10，完整分母范围与可逆倒数／仿射变换提供全体可达性。只有排除一个输出的论证不能完成方法。

### 5.5 M4 方程有实根法

R3 首轮开放固定实有理系数的至多二次多项式之比，**分母已证明在实数全域恒不为零**，目标为自然定义域上的完整值域。对不满足此前提的分式、额外受限域，保持能力缺口；后续若扩展，必须新增域内合法实根的精确判定，不能仅放宽准入。

令 $y=F(x)$，等价整理为 $A(y)x^2+B(y)x+C(y)=0$，分支完整覆盖：$A\ne0$ 用 $\Delta\ge0$；$A=0,B\ne0$ 为一次方程；$A=B=0,C=0$ 为恒等方程；$A=B=0,C\ne0$ 无解。每个分支限定在自身条件下求输出集合，再取并集。

Q6 的 $y=2$ 必须保留，不能因使用二次判别式而丢失；Q7 的备选路线在 $y=2$ 变成无解常量方程，不能因为“次数退化”一律纳入。分母全域非零是实根均合法的证明前提，应在验证器中重新核验。

已有 `method-discriminant` 主要完成二次恒成立求参数，不能不检查量词就代替 M4 的“存在合法原像”目标。可复用判别式计算、因式分解、二次判号与等式变形技能；若转成新的子问题，仍须与其方法输入输出匹配。

### 5.6 M14 枚举法

输入为可穷尽列举的非空有限定义域与已准入函数，按稳定输入身份调用 M9，验证每次代入合法，收集全部输出后按精确相等去重。输入数量预算在准入、执行与教学一致，不能静默截断前若干项。

输出为有限集合及输入—输出对应记录。输入重复仅影响记录去重，不重复计值；不同输入有相同输出时允许多对一。显式声明的定义域包含无定义点时报告条件冲突，不静默丢点后声称原函数合法；若题意明确要求先求有效子集，应按该目标处理。

Q30(3) 不调用面向连续区间的线性范围技能，不把 $\{-3,-1,1,3\}$ 写成 $[-3,3]$。基础枚举不是新技能节点，M14 复用 M9 的合法代入和来源证据。

### 5.7 M7 整数平移与区间合并法

首轮处理已知 $g(x+p)=g(x)$、$f(x)=a x+g(x)$，$p>0$、$a$ 固定，及一个长度为 $p$ 的完整基础区间值域；目标域须被有限个合法整数平移的完整基础区间**恰好覆盖**，且每段均包含于目标域。原始端点归属作为覆盖条件的一部分。

先推出 $f(x+kp)=f(x)+akp$，再计算各段像集 $R_0+akp$ 并求精确并集。$a$ 正／负／零、平移正／负／零都应覆盖。值域各段只有相交或相邻端点确实连通时才合并；有空缺时保留多个分量。

Q18 中 $p=a=1$，平移 $k=-13,\ldots,6$，输入并集恰为 $[-10,10]$；对应输出并集为 $\bigcup_{k=-13}^{6}[-2+k,5+k]=[-15,11]$。任意输出先来自某段已知完整像集，再通过平移回到目标输入，因此有可达依据。$f$ 自身不以 1 为周期。

目标只有部分基础段时，不用向外取整的完整段替代它；缺少该残段的范围信息就报告无法确定完整值域。也不假设 $g$ 连续或单调。涉及相邻闭段共享端点时，应保持同一输入输出一致；若已知数据与平移关系可证明矛盾，应报条件冲突。

## 9. 回归、留出与数学验证矩阵

| 类别 | 开发／回归样例 | 必须断言 |
| --- | --- | --- |
| 开口与退化 | $x^2,-x^2,2x,-2x,0$ 在开／闭／半无限区间 | 完整范围、常量单点、一次方向，不出现除以零系数 |
| 顶点位置 | 顶点在区间内、外、开端点、闭端点 | 未包含顶点不直接取极值；所有范围内分支有教学路径 |
| 同值多原像 | $x^2$ 在 $[-1,1)$；在 $(-1,1)$ | 分别 $[0,1]$ 与 $[0,1)$，不能按右端开就删掉 1 |
| 非连通域 | $x$ 在 $[-2,-1]\cup[1,2]$ | 保留两段，不以最小最大补成 $[-2,2]$ |
| 删除输入的影响 | $x^2$ 在 $\mathbb R\setminus\{1\}$ 与在 $\mathbb R\setminus\{0\}$ | 分别 $[0,+\infty)$ 与 $(0,+\infty)$；孔点须检查其他原像 |
| 根式原约束 | $0\sqrt{x-1}$；恒负根式；根式刚取零 | 首项虽为零仍要求 $x\ge1$；无效输入不能给伪造范围 |
| 换元覆盖 | Q8 改成不同开闭端点；$t=\lvert x\rvert$ | 精确新域；负根不混入；多对一合法但覆盖不能缺 |
| 换元后的范围 | $x^2+\sqrt{1-x}$ 经 $t=\sqrt{1-x}$ 化为四次；$\sqrt{2-x^2}$ 的代数端点 | 前者不进入首轮 M12 → M3；后者只有精确端点全链路通过才准入，不用近似端点替代 |
| 抽象范围不足 | 已知 $D_f=[1,2]$、$R_f=[0,1/2]$，仅令 $x+1\in[1,3/2]$ | 一般不能确定完整输出；拒绝照搬原值域 |
| 仿射关系退化 | $f(ax+b)=P(x)$ 的 $a=0$ | 不推断全域函数；矛盾关系与信息不足分别处理 |
| 倒数正负与零 | $1/x$ 在正／负半轴；跨零区间；常量分母 | 正确开闭和方向；零不可作倒数；两分量不能填平 |
| 分式约分／零余数 | 原式有可消因子或 $B=0$ | 原域限制仍在；常量范围只在有效非空输入上成立 |
| M4 次数退化 | Q6 的 $y=2$；Q7 的 $y=2$；常值商的恒等／矛盾方程 | 分别纳入、排除；三个退化层次完整，不只检查判别式 |
| 非法实根 | 将 M4 输入改为有分母零点或另限输入域的函数 | 首轮范围外说明缺口；不可把域外实根当合法原像 |
| 有限集 | 不同输入相同输出、重复输入、只有一个输入 | 去重但保存对应；不返回连续区间，预算不截断 |
| 平移关系 | Q18 改平移方向和斜率；目标含残缺基础段 | $g$ 周期不等于 $f$ 周期；只在完整覆盖时套全段值域 |
| 输出并集空缺 | 平移后区间不相交，或相邻两端均不包含连接点 | 保留空缺／缺点，不能机械合并首尾界 |
| 原图与记法 | 普通空格、TeX／ASCII、根号覆盖、分母符号、区间括号 | 等价写法可绑定；改变指数／分母／端点会被拒绝或修复 |
| 伪造与多路线 | 删除可达证据，改原域或输出端点；Q7 两路线 | 独立验证拒绝伪造；比较完整精确集合而非同一个极值 |
| 完成与恢复 | 子方法未完、某个小问未知、旧数学版本恢复 | 不显示整题完成；原目标仍待验；版本变更拒绝旧 checkpoint |

以上案例是公开开发／回归集。每批另冻结至少 2 个不同结构分支的新题，R0 额外冻结开闭、退化、顶点位置组合，R4/R6 各保留信息不足负例；全型留出集至少覆盖七种方法和两道多目标完整题。不得用已知 Q3–Q30 重新命名充当未知题。

留出失败转入故障回归，并补新的留出样本。真实拍题至少覆盖每种新方法首次开放的完整题、原图敏感边界和一题独立留出题；其余完整题源分别记录规范数学、教学、录制回放及真实新调用状态。样本数不是泛化保证，不预写未经测量的成功率。
