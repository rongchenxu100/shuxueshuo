## 3. 本轮代码修复

1. **A03 的等价表示。** 保留精确原式匹配，支持题面 `y=…` 与所求表达式的同一对应关系；允许合法区间在声明/限制角色上的等价标记，但不能裁掉原本非法的输入，也不能吞掉额外约束。
2. **A16、B13、B15 的原文定位。** 支持题面自然语言“在区间 …”以及不带 `$` 的普通数学文本；仅在明确的“定义域为”位置兼容实数集 `R`、粗体 `R`。仍按完整 AST、区间和源文位置核对；增加修改可见公式/区间，或把实数集换成 `Q`、`R+1` 后必须拒绝的反例。
3. **B08 的最值记号。** 遍历 AST 时支持 `min(f(x))` 的空显式下标；只把函数自己的形式自变量作为隐含绑定变量，不能把 `min(f(a))` 或错用参数的下标当作同一个条件。
4. **B15 的受限递推求解。** 从原始恒等式、完整定义域、基准段和全称下界中推导整数分段；基准二次式复用 T1 单调性子方法，最终用独立证书验证所有负向整数块、首次越界位置和边界可取性。单一适用方法使用已有 read/confirm 卡片合同，不伪造第二种选法。
5. **抽象函数声明。** 显式 `Dom(f)=…` 可以声明没有全局解析式的函数；缺少此声明的任意未知函数调用仍不能通过编译。
6. **OCR 题号定位。** 调整真实检测分辨率，并保留四页 OCR 结果、实际检测耗时及全部题号的回归。

递推代码不是通用函数方程求解器。目前支持 $f(x+L)=Kf(x)$、$L>0$、$K>1$，基准区间 $(c,c+L]$ 上为 $A(x-c)(x-c-L)$、$A>0$，整个 $(-\infty,m]$ 满足负下界。系数为受预算限制的有理数，首次失效块索引绝对值不超过 128。对步长、倍率、平移、系数、阈值及负整数块做了变式测试；不满足合同的情况明确拒绝，不套 B15 的答案。
