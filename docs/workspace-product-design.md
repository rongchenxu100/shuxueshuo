# 工作台首版：上传图片生成解析网页

内部工作台默认连接真实产品服务，提供上传单题、生成进度和版本化解析网页。Mock 仅用于显式开发及测试。学生拍题入口及其整页 OCR、登录、额度和历史见[学生拍题设计](student-problem-search-design.md)。

## 入口与三栏职责

本地地址：<http://127.0.0.1:3000/>。默认连接 P2 产品服务，复用 PostgreSQL、RabbitMQ、Worker、API 和受控页面存储，不增加服务或数据库表。

| 区域 | 首版功能 |
| --- | --- |
| 左栏 | 上传新题目、真实题目列表、返回已有题目的生成状态和结果；支持折叠 |
| 中栏（已有有效网页时） | 解析网页主体，占据主要宽度；可新窗口打开，无需发布 |
| 右栏 | 选择图片与预览、上传并生成、接收反馈、九阶段进度及失败说明；没有网页时扩展到列表旁的可用空间 |

无有效网页（包括点击“上传新题目”、生成中或失败）时不渲染中间网页栏或空白占位；生成成功后自动展开中栏，将进度放在右侧。

保留原工作台白色／浅灰底、青绿色操作按钮和可调栏宽。窄屏改为上下排列，解析页保持自身图形及滑块交互。

列表优先显示当前题意修订中的原题文本，包含按顺序排列的小问，最多展示两行并截断；鼠标悬停通过浏览器原生提示展示完整原文。尚未识别时显示图片文件名，不使用产品 UUID 作为学生标题，不调用模型生成摘要。

排队／执行中显示转动图标及真实状态；成功生成且页面有效时显示蓝色未读圆点。点击成功题目才标记已读，自动选中或在处理中点击不会提前消除后来生成的提醒。已读按题目与页面版本保存在当前浏览器，刷新保留，同浏览器标签页同步；重新生成另一个成功页面后再次显示蓝点。该记录不跨浏览器或设备同步，浏览器禁用存储时退化为当前页面内记录。

题目列表每 5 秒及窗口重新获得焦点时更新，保留已加载的分页范围；未选中的题目也会更新运行和完成状态。

## 上传与恢复

- 一次上传一张完整单题图片，PNG/JPEG/WebP，最大20 MiB；后端继续校验实际格式、像素和图片完整性。
- 提交前展示图片；本轮不提供文字新建、手动框选、自动切题或批量上传，多题截图需先在外部裁剪。
- 新文件创建题目并自动提交一次首次构建。相同文件引用已有题目，不自动重建；已有但未生成的题目提供明确的“生成解析”按钮。
- 文件去重出现多个候选时展示已有题目供选择，不猜测归属。
- 浏览器保存请求键、文件名、哈希、批次和已接受响应；网络重试沿用原键。刷新后查询已有上传结果，再继续原首次构建请求。
- 浏览器不持久保存图片二进制。未确认上传成功时，提示重新选择同一文件；已接收的题目和任务始终保留在服务器。
- 所选题目写入 URL 的 `problem` 查询参数，刷新后恢复。任务在后端继续执行，关闭页面不会取消。

## 进度与网页

- HTTP 读取真实构建快照，WebSocket 通知更新；每5秒及窗口重新获得焦点时补充读取权威快照，覆盖断线和页面有效性变化。
- 阶段顺序以构建快照为准，现有九阶段使用可读标题，未知阶段沿用快照标题；不模拟进度或伪造完成百分比。
- 中栏只展示所选构建成功且当前有效的页面。失败、取消或页面失效时隐藏网页栏，在进度区显示明确提示，不用旧页冒充本次成功。
- 页面通过产品授权接口读取，iframe 保持 `sandbox="allow-scripts"`，不写入 `site/`。
- 失败时链接到现有 Review 查看诊断和重试。JSON、检查点、题意修订和阶段重建留在 Review，不展开到首版工作台。

## 暂不接入

真实工作台隐藏网站、专题、发布／发布更新、聊天、Tutor、网页批注、标签编辑、删除、修订及批量管理。后续功能重新讨论，不视为当前待补全的必交功能。

原演示工作台代码保留，只有服务器环境显式设置 `WORKSPACE_MODE=mock` 才启用。真实模式接口出错不回退 Mock。内部工作台的固定身份不适用于学生登录与私有拍题。
