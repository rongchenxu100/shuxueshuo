## 3. 本轮代码修复

- **来源匹配：** 复用通用原文公式定位，支持带／不带 `$` 的数学片段、冒号后的函数主体、教材栏目标题及常见填空线。保持原偏移、完整条件和额外奇偶条件检查，未按题号匹配。
- **题意卡：** 为 T6 补齐原函数关系、奇性、定义域、已知值及所求目标；原式使用源 AST 显示，不提前透露答案。
- **最值表达式适配：** 直接消费已有 `find_range.answer_request` 及 `find_extrema_expression`，独立绑定最大／最小值符号，避免与系数同名时串用。只接管带明确限制域的目标，原来没有限制域的值域题仍走原路线。
- **标量完成合同：** 验证最值存在与对称证书后，只交付所求和的精确标量。执行、handoff 与结果 schema 一致接纳这类结果，普通值域目标仍要求完整集合证据；错误标量、伪造最值证书和原上下文改动均被拒绝。
- **常数声明：** 记法解析接受“$a$ 为常数／实常数”，沿用既有实标量约定；来源和 T6 描述消费该声明，不赋予数值，不删除条件。
- **复核字段校验：** 如果复核称学生题面含“变式”标签，但所指字段中根本没有该标签，判为无效复核并要求重新复核；不会自动确认题意，也不会借此删除数学条件。

题型逻辑在代码中完成；prompt 模板与题型提示未增加。录制入口仅扩展混合 JPG／PNG 题源支持，并记录原文件摘要。
