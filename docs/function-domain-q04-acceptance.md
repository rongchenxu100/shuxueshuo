# 函数的概念 Q04：定义域求参扩题验收

题源为《函数的概念与性质小条（5）》第 4 题，数学内容登记于 [3.1 知识图谱设计](function-concepts-and-representation-knowledge-graph-discussion.md)。本批沿用本地开发流程，不增加迁移或新的课程版本分支。

## 题目与方法复用

函数 $y=\sqrt{mx^2+4mx+3}$ 中 $x$ 的取值范围为 $\mathbb R$，求 $m$ 的取值范围。

公共题目 ID 为 `function-concepts-q04`，入口为 `/topics/function-concepts/q04/`。题型仍为 `type-function-domain`，使用 `method-domain-parameter`，先提取根式非负条件，再化为全称条件，并经 `rule-quadratic-method` 让学生再次选择子方法。数学执行复用 `method-discriminant`，其中参数的二次不等式调用既有 `quadratic-inequality-solve`。不新增题型、方法、技能或判断节点，不按题号匹配求解。

## 必须保留的数学与交互

| 情形 | 数学结果 | 验收重点 |
| --- | --- | --- |
| $m=0$ | 原式为 $\sqrt3$，对所有实数有意义 | 保留参数 $0$；常数分支交互不能沿用 Q22 的排除结论 |
| $m\ne0$ | 需要 $m>0$ 且 $16m^2-12m\le0$ | 二次不等式给出 $[0,\frac34]$，与 $m>0$ 相交得到 $(0,\frac34]$ |
| 合并 | $\{0\}\cup(0,\frac34]=[0,\frac34]$ | 不能遗漏零系数分支；最终两端均闭 |
| 端点 | $m=0$ 时被开方数为 $3$；$m=\frac34$ 时为 $\frac34(x+2)^2$ | 两端均有原式核验证据；允许被开方数为零 |

与 Q22 的主要区别是：Q22 的零系数分支仍有一次项，不能在所有实数上非负；Q04 的二次项与一次项同时消失，变为非负常数。本题还覆盖了关于参数的二次不等式求解。

课程共 14 个作答动作，包含列条件、转成恒成立、子问题选法、判别式内部判断、常数分支保留、参数范围求解、合并和返回原题。题目标题保持“定义域求参 · Q04”，不提前透露零系数分支应保留。
