## 3. 代码问题与修复

| 真实调用暴露的问题 | 修复与防误判约束 |
| --- | --- |
| A03、A06 将 `f(x)±g(x)=…` 提取为普通事实，旧代码只接受目标中的关系或显式全称关系 | `symmetry_value_math.describe` 接受函数自变量上的恒等事实，继续做原文绑定和全范围相容检查；固定点等式仍按点值关系处理，额外参数不自动当作全称变量 |
| A04、A09 的同一局部规则同时出现在目标和事实中，重复绑定导致补全目标失败 | `parity_extension_math.rule_rows` 合并相同规则与相同范围，保留全部来源引用；`bind_local_rules` 将这些引用绑定到同一原文，不生成重复教学规则；不同范围仍分别检查 |
| A15 复核后的局部范围显式含 `∩Dom(f)`，旧代码无法消费 | 只规范化当前函数定义域的冗余交集，再与实际定义域取交；保留原 AST 供来源与证书核验；并集、差集和其他函数域不被改成全实数 |

这些修复适用于同结构的模型提取结果，不按题号或答案分支，没有增加题型专用 prompt。
