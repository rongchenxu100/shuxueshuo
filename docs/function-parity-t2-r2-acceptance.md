## 实际范围

- **四次多项式：** 关于输入至多四次，系数为单实参数的至多二次有理系数式。新增 `compare_quartic_polynomial_coefficients`，原 `compare_polynomial_coefficients` 仍只接受二次以内、全实轴恒等式和 `Equality` 输入。全部参数、多解、无解、零函数、明确声明的次数及排他奇偶性均保留。
- **有理式原域：** 分子、分母正规式关于输入至多四次；保留所有原除法及零次幂的合法性条件。每个分支支持固定分母零点和至多两个仿射移动孔洞，参数因子为零单独分类。约分、分子归零和嵌套除法不能补回孔洞。声明 `Dom(f)` 时逐个原输入单元核验原式有意义；`defined_on(f,J)` 不冒充完整域。
- **固定绝对值／分段：** 绝对值内为固定一次或二次式；显式分段最多六段，固定分界，各段为受支持的多项式／有理式。保留分段范围，镜像输入重新选段，零点、孤立点、开闭和缺失点逐点核验；空分支和重叠分支返回能力缺口。
- **受限根式：** `sqrt(alpha(p)*x^2+beta(p))`，两个系数均为有理仿射式，使用自然域或明确声明的实数集。九种系数符号组合覆盖空域、单点、闭区间、两侧闭射线及实数集；以符号 `±sqrt(-beta/alpha)` 记录端点配对和取到性。要求奇性时利用非负函数值必须恒零的条件，不能只比较平方。声明实数集另要求整个实轴有意义。
- **参数条件：** R2 原参数条件及镜像恒等式化成至多四次的单参数条件，保留参数分母非零限制；实临界值只接收可精确序列化的有理数或实二次代数数。超出次数、位数、参数切点或输入切点预算返回能力缺口，不返回伪造空解。
- **验证：** 重建全部域／镜像单元；独立以原 AST 的合法性和值检查守卫，以逐阶导数恢复恒等式系数，再用完整符号单元验证参数集合。四次多项式用五点插值恢复全部系数。验证不调用生产求解或公共比较能力；修改证书、漏分支、去孔洞或改答案不能发布。

核心模块为 `parity_parameter_original.py`、`parity_parameter_radical.py`；共用既有 M2 执行、题意整理、恢复与最终独立验证，不向 prompt 添加题型说明。本轮没有真实 OCR／模型调用，不能将代码集成当作新照片验收。

## 教学与可视化

板书用源 AST 显示未约分的分式、根式和原分段条件。先检查完整定义域，再比较各段函数值条件，最后与原参数限制求交；普通奇偶性与明确排除零函数的要求分别处理。

核验步骤展示已标注参数的函数／镜像图与 `D`、`-D` 精确数轴，包含可行及可用的不可行实例。曲线仅在已证明合法且连续的输入单元内部采样；孔洞用空心点，有限域只画离散点，不能跨极点连接。镜像实点与原式空点冲突时分成两幅同尺度图；不靠覆盖颜色掩盖域差异。临时浏览器预览检查了四次式、孔洞和分段零点；实际 SVG 与 KaTeX 渲染器也纳入测试。

本批图形是**固定参数实例对照**，不参与答案判断，未作答步骤不显示答案参数图。连续滑块、精确参数输入和交互点探查尚未开放；公共题页、真实账号作答保存及服务恢复仍待统一重建后验收。
