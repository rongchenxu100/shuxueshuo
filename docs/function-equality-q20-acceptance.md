## 1. 题源与数学结论

原题为用户此前上传的第82页例5变式1。原照片已逐字节归档到 [来源目录](../internal/senior-high/source-images/function-concepts-q20/manifest.json)，包含完整原页、正常矩形裁片、实际送模图、坐标及 SHA-256。未遮罩、重绘、拼接或合成图片。原照片右下有印刷解析边缘；提取规则明确排除答案和解析，实际候选没有将其变成题设或正确选项。

| 项 | 两函数 | 可验证依据 | 判定 |
| --- | --- | --- | --- |
| A | f(x)=x；g(x)=(√x)² | 原始定义域分别为 R 与 [0,+∞)，−1 为差集点；化简不能补回非法输入 | 不同 |
| B | f(x)=x²；g(x)=(x+1)² | 两域都是 R；同一个输入0的输出分别为0与1 | 不同 |
| C | f(x)=√(x²)；g(x)=abs(x) | 两域都是 R；负半轴、零点、正半轴构成完整分割，各段分别同为−u、0、u | 相同 |
| D | f(x)=3x²−2x+3；g(t)=3t²−2t+3 | 自变量统一为同一输入u后，全域恒等 | 相同 |

原题“选相同”答案为 C、D。相反极性由逐项关系重新生成 A、B，未判断项不能按错误项处理。

## 2. 实现范围与公共能力

- 比较目标使用 compare_functions；各选项有局部函数作用域，允许显式公共基准引用，保留原始表达式、显式定义域、选择极性和来源。选项不伪造为 children 或 case_path。
- 首批支持实数单自变量、有理系数、至多二次多项式、仿射绝对值、仿射平方的根式、仿射根式的平方，以及有理端点显式区间和单点域。准入、执行和独立验证共用结构边界；范围外返回未支持，不猜真假。
- M8 逐项调用现有 M1 求原始定义域，返回当前选项。八个实际调用都有轨迹；学生侧不投影 M1 逐步卡。
- **学生交互（与课包一致）**：
  - 四项均 `checklist` 自选两边定义域（题干含原式、不预写域答案）；全集实数统一为 \(\mathbb{R}\)。
  - B–D：`equality-evidence` 合并卡第二小问「对应关系是否等价」；A 因域不同跳过该小问。
  - 四项均有单独 `equality_verdict`：「是否相同」。
  - 完成卡结论板：定义域用两边域 + `=`／`≠`；对应关系等价时展示两边原式，不等价时展示「输入 a 时的输出」；收口卡展示两边函数式 +「本项结论」。证明／反例叙述在反馈中。
- 相同需要全域证明；不同保留差集点或经原式验证的反例。完整结果采用独立的 comparison_result，而非伪造参数可行集。
- 原题多选使用标签集合精确等价，独立于步骤 multi 的包含关系评分；非法、重复、多选、漏选均拒绝。空数组可以提交，Q20 中判错。服务端校验所有前置学习步骤，不能靠后台 solved 提前完成原题。
- 新数学模块、共享表达式模块纳入版本指纹；同版本恢复、旧版本拒绝、作用域绑定和跨选项事件均有回归。

主要新增模块为 `notation_function_comparison.py`、`graph_lesson/function_equality.py`、`stage_one/function_equality.py`、`stage_three/equality_runtime.py`、`stage_three/equality_presentation.py` 与前端 `option-workspace.mjs`。共同抽取、复核、修复规则同步更新，未建立单题白名单。

## 3. 两层教学交互

共 **15** 个独立评分决策；表中的“步数”按评分决策计，页面将 B–D 每组前两个小问合并，展示为12步：

| 区块 | 步数 | 内容 |
| --- | --- | --- |
| 入口 | 3 | 读题／认型／选法等 intro |
| A | 2 | 选域清单 → 收口「是否相同」 |
| B | 3 | 选域 + 对应关系（同卡两小问）→ 收口 |
| C | 3 | 同上 |
| D | 3 | 同上 |
| 终答 | 1 | 原题精确多选 |

1. A–D 各有工作区：先完成证据卡，再单独收口。错误停留当前项；完成项仅可只读回看。
2. 四项均通过后才解锁终答。进度芯片只显示 A✓ 等状态；终答初始不勾选，未提交前不自动展示完整结论板。
3. 原题多选正确后显示 CD 与四项中文理由。学生练习与 AI 回放分别保存进度。

A 的公式显示为带括号的 (√x)²，避免与 C 的 √(x²) 混淆。原题 A–D 分行。C、D 的证明先解释共同输入 u（在反馈中）；C 的绝对值规则从实际证明操作透传到公开依据和图谱，其他选项不误挂该依据。
