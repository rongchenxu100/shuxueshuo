# FM-T1 判断函数的单调性：题型开发设计

更新：2026-11-04。状态：**首轮范围已实现；本批 6 道题已生成专题课程并完成真实原图识别。** 具体通过项、输入边界和未覆盖项见 [T1 实施验收](function-monotonicity-t1-acceptance.md)，本设计中的验收矩阵不自动视为全部通过。

本文细化[函数单调性专题计划](function-monotonicity-topic-plan.md)中的 FM-T1，沿用[具体函数定义域](function-domain-problem-type-design.md)、[求函数值域](function-range-problem-type-design.md)和[分段函数](piecewise-function-problem-type-design.md)题型设计的结构。实施遵循[专题与拍题学共用开发流程](topic-and-photo-learning-development-workflow.md)，专题静态课与学生拍题使用同一套题意、方法、验证和教学投影。

本型的核心交付是：**给出有依据、无遗漏的单调区间，并说明每段为什么增或减。** 不能用画出曲线、求出定义域、找到对称轴或证明某个小区间单调，代替原目标完成。以下为设计约定，实际可执行范围以实施验收和执行契约为准。

## 1. 题型身份、方法与首轮范围

候选题型 ID：`type-function-monotonicity`；专题分组：**FM-T1 判断函数的单调性**；知识归属：3.2.1 单调性与最大（小）值。继续复用知识节点 `function-monotonicity`，不把知识节点改成题型节点。

### 1.1 任务边界

| 任务 | 本型处理 | 与其他题型的边界 |
| --- | --- | --- |
| 已知具体解析式，求递增区间、递减区间或全部单调区间 | 本批主任务；输出原自变量上的区间族及证明 | 不改写成求值域或最值 |
| 判断或证明具体函数在给定区间上的增减性 | 同一方法体系的区间证明任务；首轮作为方法子目标和定义法练习 | 证明该区间不自动完成“求全部单调区间” |
| 已知函数单调性，解函数值之间的不等式 | 可调用本型已验证结论，原目标仍属 FM-T3 | 不因出现函数表达式就路由到 T1 |
| 求使函数在给定区间上单调的参数 | FM-T4；调用本型受支持的局部证明能力 | 本型首轮不解自由参数条件 |
| 由抽象函数关系证明单调性 | FM-T5 后续建设 | 本型的具体多项式定义法不等于已支持抽象证明 |

本期使用高中前置知识：单调性定义、一次／二次函数性质、复合性质和绝对值分段；不以导数作为默认路线。所有“增、减”默认指**严格单调**；常值、非减、非增不能偷换成严格结论。

### 1.2 三种方法及职责

方法代号与专题总计划一致，不按本篇重新编号。

| 代号／候选 ID | 学生看到的方法名 | 负责什么 | 不负责什么 |
| --- | --- | --- | --- |
| M1／`method-monotonicity-definition` | 定义法 | 任取有序两点，作差判号，由定义得出指定区间的结论 | 单次局部证明不负责宣告全部区间已经找全；不无条件承接任意函数关系 |
| M2／`method-monotonicity-structure` | 基本函数与复合法 | 基本函数定方向；拆内外层，核对范围，传递增减性，整理区间 | 不把任意和、积的方向按“同增异减”处理；不直接组织跨分段关系 |
| M3／`method-piecewise-monotonicity` | 分段单调性法 | 按符号或原分段条件拆段，调用 M2／M1，核对连接点，整理原函数的单调区间 | 不复制子方法内部计算和教学；不以“各段同向”代替跨段检查 |

选法卡标题只用上表短名；一句话过程说明放方法摘要，不塞进方法名。无复合层时仍可选 M2，卡上说明只走基本函数分支。

M2 是本批常见具体函数的推荐路线，M3 处理 A01 的绝对值，M1 提供定义证明路线。是否适用、是否已实现、是否推荐分别记录；不能为了唯一答案而把其他数学上正确的方法判错。

### 1.3 分批准入

以下 `q(x)`、`P₂(x)` 表示固定有理系数、次数至多二次的多项式，字母系数只是描述数学族，**不是输入中允许任意未定参数**。

| 批次 | 准入结构与题源 | 新增重点 | 范围外 |
| --- | --- | --- | --- |
| R0 基本与单层根式 | `q(x)`、`sqrt(q(x))`；A02 → A03、A12、A15 | M2、准确定义域、二次性质、平方根保序、完整区间协议 | 任意高次、多根式和、任意复合 |
| R1 根式分母 | `1/sqrt(q(x))`；A04 | 严格正域、两层复合、断开区间、孔点和渐近线展示 | 一般有理函数或任意嵌套倒数 |
| R2 绝对值分段 | `P₂(x)+c*abs(r*x+s)`，固定有理数；A01 | M3、既有绝对值分段技能、分界点归属与合并证明 | 多个／嵌套绝对值、任意多段函数；显式分段式另批开放 |
| R3 定义证明备选 | 固定至多二次多项式的显式区间证明任务；A03 和 A01 的单段用于内部证明验证 | M1 → 作差比较子方法；任意两点和严格符号证据 | 根式作差有理化、一般抽象函数关系；这些数学上可用的定义法分支暂不开放 |

R0 的基础探针可先用 A03，代表课仍选 A02。每批完整贯通后再扩大结构；本型收尾至少覆盖全部 6 道原题，并交代 M1 区间证明的实际状态。不要求为了启用 M2 先实现所有 M1 分支。

本轮原自变量区间的端点限定为有理数或无穷；自然域需要的二次实零点须可在这一端点域内精确表示，无实根情形允许。图上函数值可以保留精确根式，不受此输入端点限制。无理输入端点不是数学错误，但在完整表示、比较、图形标签和评分都验收前，不因符号库“算得出”就放行。

允许一个题给区间限制，可为开、闭、半开或无界；自然域计算可以产生两个分量。完整定义域声明与额外考察范围按 §4 区分。首轮不收任意离散定义域、多区间题给限制或不明确的“某处单调”任务。

常数、一次退化，二次判别式正／零／负，顶点在区间内／外／端点均属于所声明数学族的必要分支。R2 中 `c=0` 或 `r=0` 合法退化回基本函数，不除以零，也不保留无意义分段。

数值大小、表达式节点数、展开项数和步骤预算在 S0 对齐既有共享限制，并登记预算内／外相邻用例；不得仅以次数限制替代资源预算，或让提取准入与执行使用不同限制。

### 2.1 代表题 A02：完整解法与对象绑定

1. 从原式提取条件 $-2x^2+x+6\ge0$。因 $-2x^2+x+6=-(2x+3)(x-2)$，得 $D_f=[-\frac32,2]$。
2. 令 $u=q(x)=-2x^2+x+6$，外层为 $y=\sqrt u$。保留原函数 $f$、内层 $q$、中间量 $u$ 三种身份，不能把 $u$ 的范围写成原自变量范围。
3. $q(x)=-2(x-\frac14)^2+\frac{49}{8}$，开口向下，对称轴为 $x=\frac14$。与实际定义域结合，$q$ 在 $[-\frac32,\frac14]$ 上严格递增，在 $[\frac14,2]$ 上严格递减。
4. 已由定义域证明 $q(x)\ge0$；$\sqrt u$ 在 $[0,+\infty)$ 上严格递增。因此上述两个区间上 $f$ 与 $q$ 的方向相同。
5. 两端点 $-\frac32$、$\frac14$ 均合法；经过 $\frac14$ 后方向改变，所求完整递增区间为 $[-\frac32,\frac14]$。

复合步骤需要证明内层所有输出都落在外层的单调区间。此题由 $q(x)\ge0$ 已足够，无需额外要求学生求出 $q$ 的完整值域。若后续结构确实需要精确像集才能选外层单调支段，再完整借用求值域子方法。这是对总计划“核验内层范围”的精化，不是省略复合前提。

### 2.2 A04：两层复合与断开的定义域

$q(x)=x^2-5x-6=(x+1)(x-6)$。被开方数须非负，同时分母不能为零，两条原式来源都保留，合并为 $q(x)>0$。

在 $(-\infty,-1)$ 上，$q$ 严格递减；在 $(6,+\infty)$ 上严格递增。$q\mapsto\sqrt q$ 在正数上保序，$v\mapsto1/v$ 在正数上反序，故原函数左支递增、右支递减。不能拿位于禁取区间内的对称轴 $\frac52$ 直接分割出答案，也不能把 $-1$、$6$ 填进区间。

### 2.3 A01：分段、连接点与完整性

按 $x<0$、$x\ge0$ 去绝对值，得到 $4-(x+1)^2$、$4-(x-1)^2$。两段对称轴分别为 $-1$、$1$；再结合分界点 $0$，原函数依次增、减、增、减。

分段表示中的 $0$ 只归右段；最终单调区间可以在转折点相接。左段虽然不含 $0$，仍需核对原函数 $f(0)=3$ 与左侧边界值相等，才将左侧递减结论延伸为 $[-1,0]$。不能机械复制分段条件的括号，也不能把同一个分界点当成两个不同输入。

## 4. 题意、结果与验证协议

### 4.1 保留原任务与准确域语义

候选主目标 `find_monotonic_intervals` 绑定原函数和方向；候选子目标 `prove_monotonicity_on_interval` 绑定函数、指定区间及需证明的方向。正式名称在 S2 对齐共享记法，不通过 `find_range`、一般参数集合或展示字符串临时承载。

| 输入信息 | 语义要求 |
| --- | --- |
| 函数对象、自变量、原式 AST | 绑定到原文和目标；保留根号覆盖、绝对值、分母及分段条件，不提前去根号、作差或改写成答案 |
| 求增／求减／全部 | 独立目标字段；不能看手写结果推断方向，不能把“求递减区间”录成已知递减 |
| 自然域 | 从原式限制推导，不能先化简再丢掉无定义点 |
| 完整定义域声明 $D_f=D$ | 核验 $D\subseteq D_{\mathrm{nat}}$；声明包含无定义点时报告条件冲突，不默默删点 |
| 额外考察范围 $E$ | 在合法函数的 $D_f\cap E$ 上处理；没有额外条件时使用本函数的完整域 |
| 已知单调区间或待证区间 | 与定义域声明分开；必须先确认输入合法，不能据区间外没有信息就扩大结论 |
| 来源与作用域 | 原题、目标、分支、子问题之间有明确引用；其他题或其他小问的结论不流入本目标 |

“定义域为 $[-1,1]$ 的 $\sqrt x$”是冲突输入；“考察 $\sqrt x$ 在 $[-1,1]$ 内有意义部分的单调性”才可取有效子集。语义不清时保留待核对，不能由执行器替题目补条件。

首轮空有效域、仅有孤立点分别返回 `empty_effective_domain`、`no_nondegenerate_interval` 等明确原因，正式枚举值在 S2 登记。单点上全称命题的真空成立不能使课程宣称“既严格递增又严格递减”。原函数没有合法实数输入、合法函数的考察范围为空、超出能力三种情况分别处理。

### 4.2 单调区间是区间族，不是一个集合答案

以 A01 为例，结果是两个分别成立的增区间 `[(-∞,-1], [0,1]]`，不是声称函数在其并集上递增。更不能将它与“一个断开集合上的全局保序”混为一谈。

| 结果产物（拟） | 最低要求 |
| --- | --- |
| `function_ref`、`target_ref`、`effective_domain` | 精确绑定原对象、目标及域来源，含已验证的声明合法性 |
| `partition` | 由合法域边界、顶点、绝对值分界等形成的完整分析分区，保留常值段、孤立点和分界点归属 |
| `increasing_intervals`、`decreasing_intervals` | 原变量上的有序区间族，精确端点与开闭；不能使用普通集合并归一化后丢失分区语义 |
| `interval_certificates` | 每个区间的方向、严格性、知识依据／子方法、任意两点证明或性质传递证据 |
| `composition_evidence` | 内外层对象、中间变量、内层方向及范围包含证据、外层适用单调区间；所有层使用同一原输入范围 |
| `junction_evidence` | 连接点原函数值、左右边界信息、是否可延伸／合并、不能合并的原因 |
| `coverage_and_maximality` | 全部候选区间已检查；没有遗漏同向部分，也没有能继续延伸却提前截断的结果 |
| `proof_dependencies` | 原题、方法、技能、知识条目和验证版本依赖，区间证明可供后续题型按作用域引用 |

区间族排序可以规范化，重复项可以去重；不能因为两个区间端点数值相接就自动合并。缺点将区间切断；转折点可以同时属于相反方向的两个最大区间。

“求单调区间”统一生成尽可能延伸的规范金标。原题不另限时，可合法加入的转折端点在规范答案中保留。课程说明这是规范填写约定，不能把常见教材省略转折端点的写法一概称为数学错误。

评分另设明确的端点书写策略：本型默认允许省略**已证明可加入的转折端点**，先规范化再比较，并反馈完整写法；自然域边界、题给边界、禁取点不作这种宽容处理。若题目明确要求端点取舍，则以题给要求为准。任意缩小区间不是等价答案；多区间答案须全部给出。该策略进入课程评分合同，前后端及回放一致，不能用普通集合相等替代。

### 4.3 独立验证

验证器从冻结原题和原式重新核对，不信任路线输出的 `passed` 标志，也不通过再调用同一求解函数来充当独立验证。

1. 复核原域、题给范围、分段覆盖及变量绑定。所有结果区间须是有效域内的非退化连通区间。
2. 对每个区间核验严格方向。固定二次式可独立检查两点差的因子符号；复合结果检查每层保序／反序和输出包含关系；分段结果还检查跨段任意输入。
3. 从原式取得本批结构的全部边界／临界点，与输出的完整分区对照；对遗漏区间、错误连接、错误端点或未延伸段拒绝收束。
4. 区间证明任务只收束指定区间；完整求区间任务必须完成覆盖和最大性检查。已证局部结论可以作为中间产物，不标整题完成。
5. 无法证明时区分 `unknown`／能力缺口与已找到反例的错误结论；只证明非严格号不能自动升级严格号。

绘图采样用于显示，数值反例可辅助定位；有限采样通过不能证明全区间单调。篡改一个端点、方向、函数引用、严格性或子方法依赖后，验证应失败。

## 5. 三种方法的执行与教学契约

### 5.1 M2 基本函数与复合法

**输入：** 一个受支持的非分段表达式、原函数身份、已核验的有效域、方向目标。**输出：** 该输入域内完整的方向分区和所求区间族，或明确的范围缺口。

执行顺序：

1. 确定定义域。多项式的 $\mathbb R$ 或合法题给区间只读展示；根式／分母调用既有定义域方法，复用已验证的同对象结果。
2. 识别基本函数或复合层。二次先核对二次项系数是否为零；一次用斜率定方向，常数标为常值。
3. 二次以对称轴拆分，再与每个合法域分量相交；空段丢弃、孤立点保留在域证据中，不能生成零长度增减区间。
4. 复合从内到外逐层传递方向：平方根要求非负输入，倒数要求处于同一不含零的符号侧。每层使用认证范围包含证据。内层常值先核对外层在该值有定义，再返回常值，不套严格增减口诀。
5. 回到原函数和原变量，检查端点与所有分量；按目标方向收束，保存完整分析供验证。

`skill-composite-monotonicity` 只做一次有前提的方向传递，M2 组织完整路线。原域推出 $q\ge0$ 或 $q>0$ 已足够时使用该包含证明；需要精确像集时再借用原求值域方法。外层在所需范围内不单调时不能简单套口诀，须进入已支持的再分段流程，否则报能力缺口。

平方根的零端点是合法点，不因求导不存在而排除；倒数的零点非法。对已合法的非负 $u_1<u_2$，有 $\sqrt{u_1}<\sqrt{u_2}$；对正数 $v_1<v_2$，有 $1/v_1>1/v_2$。这些是本批保序／反序的知识依据。

任意和差、乘积不在 R0–R1 的表达式族内。后续遇到 A14、A16、B10 等运算结构时，M2 可调用“函数运算增减性判断”技能，逐项证明同一区间上的方向和必要符号条件；该技能建议在 T2 建设，不因已有“运算性质”知识页就扩大 T1 首轮准入。

### 5.2 M3 分段单调性法

**输入：** 原表达式及绝对值位置、有效域、目标；R2 限定 §1.3 的单个仿射绝对值。**输出：** 原函数的完整区间族及分段、连接和覆盖证据。

1. 调用 `skill-absolute-sign-split`，得到等价分段表达式和互斥、覆盖原有效域的条件。零点只归一个源分支，原函数在该点的值单独可追溯。
2. 每段建立子目标，传入该段表达式、函数标签、有效区间及原函数来源；默认调用 M2，可在准入范围内选择 M1。
3. 子方法返回该段的增、减、常值分区；不要只看系数正负就把结果标完成。
4. 对相邻候选段核验分界点原值及所有跨段输入的次序；可以加入合法边界点，也可以合并有依据的同向区间。
5. 返回原函数，检查完整性和最大可延伸范围。源分段位置不一定是最终单调区间边界。

跨段技能首轮限定有限个连续多项式分支，使用精确边界值／上下界和取得性。连接条件通过才合并；存在缺点时不合成一个区间。一般不连续分段式的课堂准入留待后续，但技能必须区分“允许有同向跳跃”和“必须连续”，不能写死为两端相等。

例如两个左、右区间各自严格递增，跨段还需证明任意左值小于任意右值。可用左像集上界不大于右像集下界并核对等号是否会由两个不同输入同时取得；若会取得，则严格性不成立。共享的同一个分界输入不是“两个不同输入”。仅比较两个端点代入值、不管开闭与取得性，不足以完成一般跨段证明。

A01 的 $0$ 两侧方向不同，不合并；合成变式 $2x+\lvert x\rvert$ 则应在检查后合并为整个 $\mathbb R$ 上严格递增，不能永远在 $0$ 切开。

### 5.3 M1 定义法

**输入：** 固定至多二次多项式、指定非退化区间、待证方向及来源。**输出：** 带全称量词的两点次序证明；不支持或结论不成立时说明原因。

完整教学沿用“任取 → 作差 → 变形 → 判号 → 定义收束”：

1. 设任意 $x_1,x_2\in I$ 且 $x_1<x_2$，记录任意性和区间约束，不能代入两个样本数后宣称证明。
2. 建立 $f(x_2)-f(x_1)$ 的比较子目标，调用公共 `method-difference-comparison`；其内部复用化简、因式分解、配方和不等式变形。
3. 对 $f(x)=Ax^2+Bx+C$，验证差恒等于 $(x_2-x_1)[A(x_1+x_2)+B]$；结合区间和严格次序判断符号，系数退化时走一次／常数分支。
4. 由差严格正／负返回增／减结论；恒为零返回常值。若区间跨过转折点，不能硬给一个方向。

A03 在 $[0,2]$ 上：$f(x_2)-f(x_1)=(x_2-x_1)(4-x_1-x_2)>0$，因为 $x_1<x_2\le2$ 保证 $x_1+x_2<4$。这也解释了为什么闭端点 $2$ 不破坏严格递增。

当 M1 用作“求全部区间”的完整路线时，先由本数学族的临界点分析生成候选分区，再逐区间执行定义证明，最后统一检查覆盖和最大性。课堂可以先让学生观察图像提出区间猜想，猜想不能当证明前提。只提供 $[0,1]$ 的正号证明，不能收束 A03 的完整答案。

M1 不内置第二份“作差比较”教学。其子方法先补齐受限有序双点合同、图谱返回和验证，再启用本路线；抽象等式代入、根式有理化等分支留在相应后续批次。

“跨段单调性检查”接收已经求出的各段单调区间，检查跨过分界点后是否仍保持同一增减方向、端点能否加入、相邻区间能否合并。它不重新计算各段增减性；M3 负责调用段内方法、组织检查并输出原函数的完整区间族。

### 6.2.1 后续共享技能：函数运算增减性判断

建议新增一个公共技能 `skill-monotonicity-operations`，将和差、取倒数、常数倍、平移以及后续有条件的乘积／商放在同一技能的内部操作中，不为每种运算分别建节点。依据复用 `function-monotonicity-operations`；具体两点比较中的乘除与取倒数，继续复用 `skill-inequality-transform` 的规则和符号检查。

本型 A04 的倒数步骤已可由复合函数技能处理：外层是正数区间上的 $1/u$。未来运算技能也能处理取倒数，但二者共享同一反序与非零依据，同一次运算只生成一份证据和一个教学步骤，不连续讲两遍。

首次完整建设放在 T2：A14 使用和的单调性，A16 使用分式分离后的倒数、负常数倍与平移，B10 使用差的单调性。两个非常数函数直接相乘、相除的规则暂无本批必需题源，不作为 T1 的开工条件。具体题目对应、适用条件及不能直接判断的反例见[总计划 §6.1.1](function-monotonicity-topic-plan.md#611-函数运算增减性判断的范围与题目对应)。

### 6.3 公共选法判断

候选判断节点：`rule-function-monotonicity-method`。输入是原目标、核验后的结构和范围，输出候选适用性及推荐依据；不按 FM-A02 等题号路由。

| 可见线索 | 前提核验 | 推荐／备选 |
| --- | --- | --- |
| 固定一次／二次函数 | 系数、有效区间和退化情形可确定 | M2；R3 后可选 M1 |
| 根式或根式分母可逐层拆解 | 内层属准入族、每层范围与方向可证 | M2；数学上可用但未实现的定义法不判为错误 |
| 单个仿射绝对值产生不同表达式 | 符号分段和分支覆盖可核验 | M3，分支中调用 M2／M1 |
| 题目明确要求用定义证明 | 有任意双点表达式和受支持符号证明 | M1；不能用 M2 跳过题目方法要求 |

学生侧复用已有方法选择组件，线索与方法关系来自公共合同；完成后同一张卡转只读。不是把方法名称和一句理由放到一个临时的新展示框里。

子问题存在正式选法判断时，直接呈现该子方法原有选择卡；没有公共判断的确定性步骤只读说明依据，不人为增加选择题。例如域条件求解按既有定义域流程展开，需要二次不等式子路线时调用原合同，不为出现二次项就额外插一张恒成立选法卡。

### 7.3 图形契约与方向可视化

已知解析式时，**交互态与完成态都提供相应函数图像**。至少支持本型的直线、抛物线、根式曲线、根式分母两支、绝对值分段曲线；使用现有代码图形组件及精确数学产物，不生成图片充当计算图。

- 数据绑定函数对象、变量、有效域、临界点、端点归属及当前证据阶段。内层 $q$ 与原函数 $f$ 的坐标轴、标题和曲线身份始终可辨。
- $\sqrt{q(x)}$ 的原图像不是 $q(x)$ 的抛物线；倒数根式也不能画成普通 $1/q(x)$。只在合法域采样，禁区不连线。
- 合法有限端点显示实心／空心；无穷不是端点。A04 在 $x=-1$、$6$ 附近裁剪显示渐近趋势，不把屏幕边缘误作最大值。
- 同一个坐标系可叠加当前分段与原函数淡线，避免为每条推导重复一张完整大图。窄屏上下排列；按钮和区间选项可作答，不以拖动像素精度评分。
- 给定函数的中性曲线可以帮助观察；未确认的答案方向、正确区间高亮和下一步结论不提前出现。作答后填入当前结论。
- 完成态冻结同一卡片的正确状态，展开可看推导；撤销后回到该步骤实际可见状态，不残留未来答案。

**方向箭头约定（交互卡通用）。** 表达增减性时，优先用可视化箭头：严格递增用向上箭头 ↑，严格递减用向下箭头 ↓；常值段用水平标记，不用增减箭头。箭头绑定具体函数与区间，不得脱离对象只出现孤立符号。文字“增／减”可与箭头并存，但不能只有文字、没有方向图形。选法卡、结论行、数轴分区和完成态回放使用同一套箭头语义。

**复合单调性必须可视化。** 凡进入内外层方向传递（含 A02、A04、A12、A15 及同类变式），交互卡须逐步展示：内层方向箭头 → 外层在合法中间范围内的保序或反序 → 合成后的原函数方向箭头；同时标出中间量身份与范围包含依据。禁止只给出一句“同增异减”结论而无箭头链路。多层复合按层展开，每层确认后再进入下一层。

**加减、倒数、相乘等运算单调性也必须可视化计算逻辑。** 当路线使用和／差、乘常数、倒数、开方等运算性质（含后续放开的和差积，以及 A04 的倒数层）时，卡片须把运算规则画成可跟读的方向演算，而不是只报最终增减：

| 运算 | 可视化最低要求 |
| --- | --- |
| 加／减常数 | 原方向箭头不变；标明平移不改变增减 |
| 乘正常数／负常数 | 同向保留或箭头反转；常数符号与箭头变化同屏对照 |
| 两函数相加／相减 | 各加数（减数）在同一区间上的方向箭头并列，再给出合成规则与结果箭头；缺方向或符号前提时标缺口，不硬套口诀 |
| 相乘 | 各因子方向与必要符号条件分别标出，再合成结果箭头；符号未知时不给出合成箭头 |
| 倒数 | 原方向箭头与“正数上反序”对照，明确反转一次；分母为零的禁区断开 |
| 开方 | 原方向箭头与“非负上保序”对照；零端点可取时保留在合法域 |

运算卡与复合卡可复用同一套 ↑／↓ 组件及现有 `monotonicity-operation-curves`、`composite-monotonicity-curves` 资源，但练习态必须绑定本题函数、区间和已验证前提；知识页演示不能代替作答证据。未作答前不提前点亮正确合成箭头。

### 7.4 父子方法与学习记录

父方法只绑定子目标、输入和返回产物，子方法拥有方法选择、推导、交互和只读完成态。来源提示仅放在进入子方法的第一步；后续用清晰函数标签承接，不在每个标题、图注、答案前重复“本步来自第几段”。

定义域已经核验且函数、作用域、版本相同，子方法直接借用证据；变成另一段或另一输入时重新核对绑定。子方法完成只表示该子目标通过，返回后仍需验证原函数的全部单调区间。

课程记录 T1 → 实际所选方法 → 子方法／技能，不把一次知识提示记为技能掌握。学生选中数学上适用但尚未展开的路线时，不记错、不推进；已实现备选路线与推荐路线具有同等完成资格。

## 9. 回归、留出与验收矩阵

下表均为拟验收用例，不是通过记录。分支测试贯通数学产物、交互题、反馈和回放；范围外用例只检验正确拒绝，不计入已支持能力。

| 类别／样例 | 必须断言 |
| --- | --- |
| 六道原题 | §2 所问方向及完整分析分区均正确；所有结果仍引用原函数 |
| 二次开口正／负：$x^2$、$-x^2$ | 两侧方向相反；转折点可属于两个相反方向的规范区间 |
| 次数退化：$2x$、$-2x$、$0$ | 一次按斜率；常值没有非退化严格增减区间；不计算无意义的 $-B/(2A)$ |
| 顶点位置：$x^2$ 在 $[-2,-1]$、$[-1,1]$、$[0,2]$、$(0,2]$ | 区间内／外／闭端点／开端点分别处理，输出不扩大题给范围 |
| 根式符号分支：$\sqrt{x^2-1}$、$\sqrt{1-x^2}$、$\sqrt{x^2+1}$、$\sqrt{-x^2-1}$、$\sqrt{x^2}$、$\sqrt{-x^2}$ | 分别覆盖两支、有界、全域、空域、重根两侧、仅孤立点；零点合法性、次数与严格性正确 |
| 根式常数退化：$\sqrt4$、$\sqrt0$、$\sqrt{-1}$ | 常值与无实输入分开；不因符号消失而伪造实函数 |
| 根式分母：$1/\sqrt{x^2-1}$、$1/\sqrt{x^2}$、$1/\sqrt{x^2+1}$、$1/\sqrt{1-x^2}$ | 两根排除、重根孔点、全域、有限开区间分支；按方向逐层传递，不跨禁区 |
| 分母常数：$1/\sqrt4$、$1/\sqrt0$ | 常值合法与处处无定义分开；不能除以零 |
| 声明冲突与额外范围 | 明确声明 $\sqrt{x}$ 定义域为 $[-1,1]$ 时拒绝冲突；仅要求有效子集时可求交；同样的数字不代表同样语义 |
| 非最大区间：A03 只答 $[0,1]$ | 局部递增成立，但完整作答尚未完成；反馈“还可延伸”，不谎称局部数学错误 |
| 端点书写：A02 省略转折点 $\frac14$／误删域边界 $-\frac32$ | 按冻结评分策略区分允许的转折端点约定与不完整原域；不能普遍忽略开闭 |
| 区间族：A01 合并成 $(-\infty,1]$、漏写一段 | 拒绝错误连接和遗漏；不能只对所有端点集合做比较 |
| 绝对值连接：$2x+\lvert x\rvert$、$-2x+\lvert x\rvert$、$\lvert x\rvert$ | 前两者分别可合为全域严格增／减，后者不能合成同方向；源分界不固定为答案边界 |
| 绝对值常值段：$x+\lvert x\rvert$ | 左侧常值不标严格增；右侧增区间规范为 $[0,+\infty)$，不能写全域严格增 |
| 绝对值退化及移动零点：$c=0$、$r=0$、$-x^2+2\lvert x-2\rvert$ | 不除零、保留真实次数；分界和对称轴来自表达式，不固定在 $0,\pm1$ |
| 连接技能的正反例 | 同向跳跃可保序；反向跳跃不可合并；缺点不连成区间；上下界相等时核验是否由两个不同输入同时取得。显式分段式首轮仍不对外准入 |
| M1 两点条件 | 去掉“任意”或不同点条件、交换取差顺序却沿用旧符号、仅代入两个点、仅得非严格号，都不能生成原严格全称结论；完整改写后的反向取点证明可规范化核验 |
| M1 覆盖与备选 | 内部核对 A03 的定义证明与性质法得到同一区间族；学生的 A03 求区间课程只开放 M2，M1 留给显式证明任务 |
| 复合前提篡改 | 内层输出不在外层单调支段、内外层身份交换、把开方误作反序时，独立验证拒绝 |
| 范围外：$\sqrt{2-x^2}$、$x^3-x$、$\sqrt{x}+\sqrt{1-x}$、自由参数函数 | 首轮分别因无理端点／未开放结构／参数语义说明缺口；不误报原题识别错，不落入数值采样兜底 |
| 原图／记法 | 根号在分母与分母在根号内不可混淆；绝对值线、正负号、区间开闭、所求方向和隐式乘法准确保留 |
| 图形与评分 | 原图不误画成内层图；断开域不连线；窄屏可作答；图形拖动不是唯一入口；完成态和交互态使用同一图形 |
| 方向箭头与演算可视化 | 区间结论带 ↑／↓；复合卡可见内→外→原函数箭头链；倒数／开方／乘常数等运算卡可见规则与合成箭头；仅有文字口诀无箭头链路不通过；未作答前不点亮正确合成箭头 |
| 父子状态恢复 | 返回父步骤、撤销、刷新、切换自己做／AI 回放不串目标；来源提示只出现一次；子方法结果改变使依赖结论失效 |
| 旧能力隔离 | 定义域、求值域、绝对值作图、分段不等式及无配图拍题保留原语义与选法；静态旧专题不会仅因新增内容被全站版本拦截 |

全部六题和以上公开变式均属于开发／回归集，**不能再称为独立留出**。每批另准备至少两个未参与设计调试的同族变式，覆盖不同分支；R0/R1/R2 至少各有独立真实照片走通，R3 核验同题两种方法的选择、完成与回放。

留出一旦用于修复即转入回归，并补新的留出题。真实模型调用、已录制响应回放、纯数学测试、浏览器验收分开记录；原图归档哈希通过不能算识别通过，课程能打开也不等于学生能完成。
