## 声明范围

- 输入关系为 `f(ax+b)=P(x)`，固定有理系数 `a≠0`，`P` 的次数不超过 2，原关系对全体实数成立。
- 不增加方法或技能节点。换元法现有契约同时支持 A0 根式输入与 A1 仿射输入。
- 保留原始语法后检查：不接受参数系数、变量分母、嵌套函数、附加条件、额外输入区间或未知函数类型约束。不能先约分再丢失原式限制。
- 沿用 128 个 AST 节点、深度 16、系数分子／分母 64 位预算；中间多项式次数上限 4，最终输入一次、右式至多二次。幂仅支持 1、2，以及非零常数底数的 0 次幂。
- `t=ax+b` 的像集为全体实数；反解 `x=(t-b)/a`。独立验证器回代原关系并验证每个实数 t 都有合法原输入。请求全体实数时不报告信息不足。
