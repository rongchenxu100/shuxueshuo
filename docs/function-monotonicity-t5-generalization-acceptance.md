# FM-T5 常见泛化修复与验证

日期：2026-11-10。范围：当前未提交的 T5 实现及本次修复。不代表新照片 OCR／模型提取验收；本轮未调用 OCR 或大模型，未提交、未 push。

## 修复内容

- 函数关系按受限 AST 做等价规范化，支持移项、交换、非零数倍，以及输入差／商形式。拒绝约去未经证明非零的变量因子。
- 完整定义域是必填字段；缺失时返回协议或记号诊断，避免编译时 `KeyError`。
- 原关系、条件变量与证明双点使用独立作用域、新鲜名称；避免原题 `x_1,x_2` 被后续代入捕获。
- 考察区间与完整定义域分开显示；有限区间按准确差／比值范围检查符号条件，保留端点的开闭。
- 检查中性输入处的恒等值，阻止矛盾条件直接生成严格单调结论。
- 指定方向的证明保留题目方向；与推导方向冲突时不伪装成证明完成。
- 拍题页题意整理显示完整定义域、全称关系、符号条件及目标，判断题不提前显示求解方向。
- 新数学模块纳入执行指纹；生成课程和运行恢复能识别数学规则变更。

## 实际支持边界

| 函数关系 | 完整定义域／关系域 | 典型条件与处理 |
| --- | --- | --- |
| $f(u+v)=f(u)+f(v)$ | $\mathbb R$ | 比较函数值与 0；正差或反向负差 |
| $f(uv)=f(u)+f(v)$ | $(0,+\infty)$ | 比较函数值与 0；大于 1 的比或 $(0,1)$ 的反向比 |
| $f(u+v)=f(u)f(v)$ | $\mathbb R$ | 比较函数值与 1；先证明函数值为正，再判断因式化的差 |
| $f(uv)=f(u)f(v)$ | $(0,+\infty)$ | 同上，使用输入比 |

支持目标为完整定义域的非退化连通子区间。函数值的严格比较条件必须覆盖所有构造输入，代码不能用采样代替任意双点证明。

乘法输出族中，`f(t)<1` 单独不足以排除零函数；需要题给正值下界，或等价商式中已经要求函数值分母非零。弱不等号、未覆盖的符号范围、局部关系域、多个函数或额外未处理的事实明确返回未覆盖。没有扩展为任意函数方程证明器。
