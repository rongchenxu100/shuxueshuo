## 1. 题型身份、方法与建设范围

### 1.1 任务边界

沿用公共题型 `type-monotonicity-inequality`，学生名称“利用单调性解不等式”，专题为 `function-monotonicity`。R0 代表课已激活题型并生成课程；R1／R2 仍按分批准入推进。

典型任务为：已知同一函数的单调性，或能够先证明其单调性，求使 $f(u(x))\mathrel{\square}f(v(x))$ 成立的输入范围。核心学习目标是：**两个输入在什么范围内可以比较，递增或递减如何决定比较方向，最后怎样得到完整解集。**

| 情形 | 本型处理方式 | 边界 |
| --- | --- | --- |
| 已知严格单调性 | 检查两个输入，再把函数值比较转为输入比较 | 不要求补出 $f$ 的解析式 |
| 已给具体分段函数 | 先调用分段单调性法；整体严格单调证明通过后使用 M5 | 两段各自递增不等于整体递增 |
| 有常值段或整体单调性不成立 | 使用已有分段解不等式法，按两个输入分别确定分支 | 非严格单调不能直接提供等价转换 |
| 求 $m$、$a$ 等字母的范围 | 按它在原目标中的角色绑定求解变量 | B04、B06 的字母出现在函数输入中，不因此改归 T4 |
| 同题含求值小问 | 保留独立目标，调用 `method-function-evaluation` | B09 第一问完成不代表第二问完成 |

首轮比较关系覆盖 $<,\le,>,\ge$；同一求解变量，输入表达式为固定有理系数的二次以下多项式或常量。单调区间首先支持有理端点与无穷端的区间；计算得到的代数数端点保留精确值。显式分段函数先支持两个有序分支、一次／二次／常值表达式，分界点为有理数。采用直接分段求解时，代入后的比较还须能经已证明的等价变形降到二次以下，否则不在本批准入范围。

函数系数含待求参数、不同函数之间的比较、嵌套多层未知函数、由函数方程证明单调性、仅凭图像估计严格单调性均不在本批准入范围。约分前的分母孔点等未支持结构必须明确拒绝，不能化简后伪装成已支持的多项式。

### 2.2 题源核定与条件金标

**B02：已核定为增函数。** 对照图 3 印刷题意，$f$ 在 $[-1,1]$ 上是增函数。两个输入同在该区间给出 $x\in[0,\frac23]$；保序得 $x-1>1-3x$，即 $x>\frac12$；求交为 $(\frac12,\frac23]$。早期总计划曾误写为减函数；手写答案仅作旁证，不以手写定题设。

**B06：单调区间不是完整定义域。** 原题没有逐字给出 $D_f=(-1,1)$。在“两个输入都处于已知单调区间”的约定下：

$$-1<2a-1<1,\qquad -1<3a-1<1,\qquad 2a-1<3a-1,$$

得到 $0<a<\frac23$。但若允许函数在区间外有定义，例如 $f(t)=t$ 在整个实数域都递增，则原不等式对所有 $a>0$ 成立。因此不能把局部方法的可用范围当成原题的完整解集。

原图题保留“范围约定待确认”。专题已另建教学变式：`function-monotonicity-b06-v1` 在题面显式写出定义域为 $(-1,1)$，reviewer 注明补充条件；不能在 OCR 或规范化中静默修改原印刷题。

分段整体证明不能只记录结论：B03 左段严格递增且值小于 $1$，右段严格递增且值不小于 $1$，跨段严格次序成立。B07/B09 左段为 $9-(t-3)^2$，在 $t<3$ 严格递增且小于 $9$；右段为 $3t$，在 $t\ge3$ 严格递增且不小于 $9$。分界点分别归属原题指定分支。

B09① 的求值为 $f(1)=5$、$f(5)=15$；第二层按输入 $5$ 重新选段，不能继续使用第一次的二次式。

### 2.4 B12：常值段的必要分流

令 $u=1-x^2$、$v=2x$。原函数处处满足 $f(t)\ge1$，且 $f(t)>1$ 当且仅当 $t>0$。所以左侧若不大于 $1$，不等式必不成立；先得到 $u>0$，即 $-1<x<1$。

| 情况 | 原不等式的实际形式 | 本情况解集 |
| --- | --- | --- |
| $-1<x<0$ | $v<0$，故 $(1-x^2)^2+1>1$ | $(-1,0)$ |
| $0\le x<1$ | $u>0,v\ge0$，故 $u^2+1>v^2+1\iff u>v$；再解 $x^2+2x-1<0$ | $[0,\sqrt2-1)$ |
| $u\le0$ | 左侧为 $1$，右侧不小于 $1$ | $\varnothing$ |

合并为 $(-1,\sqrt2-1)$。$x=0$ 满足原式，不能遗漏；两个外端点均使严格关系失败。

若直接去掉 $f$，会得到错误的 $(-1-\sqrt2,-1+\sqrt2)$。例如 $x=-2$ 时，两个输入分别为 $-3,-4$，虽然 $-3>-4$，但 $f(-3)=f(-4)=1$，原不等式不成立。该反例用于说明适用条件，不能取代分支完整性证明。

教学可以先排除 $u\le0$ 以减少重复卡片；执行和验证仍需覆盖 $(u\ge0/u<0)\times(v\ge0/v<0)$ 的全部四种组合。平方比较的化简必须带上非负前提，不能不加条件地把 $u^2>v^2$ 换成 $u>v$。

### 4.2 局部可转换与全题等价分开

记原题允许的自变量集合为 $E$，两个原输入的有意义条件与函数定义域共同给出 $C$。在严格单调区间 $I$ 上可使用的范围为：

$$C_I=C\cap\{x:u(x)\in I\}\cap\{x:v(x)\in I\}.$$

- 当已证明 $C_I=C$，才能用这一单调结论完成整个目标。
- 当 $C_I\ne C$，只得到局部转换。剩余范围有显式定义时继续分类求解；没有足够信息时返回条件不足，不能把剩余范围直接删掉。
- 若完整定义域未给出，先确认原目标是否明确限制到 $I$；B06 正是不能自行补全的情况。
- 只分别知道 $f$ 在两个区间递增，不能跨区间比较函数值；若 M3 证明整体严格次序，则引用其整体证据。

### 4.3 产物与独立验证

| 产物 | 最少内容 |
| --- | --- |
| 范围结果 | 原求解变量、原域、两个调用的合法范围、当前可用范围、覆盖是否完整 |
| 单调性依据 | 题给事实或 M3 证明；函数与区间绑定；严格性；原端点归属 |
| 转换证书 | 原比较、转换后比较、同函数检查、共同区间检查、保序／反序依据、适用范围 |
| 代数子结果 | 原变量上的精确集合、子方法身份、约束与局部验证依据 |
| 最终结果 | 完整解集、各分支覆盖、原题来源、独立验证结论；不完整时明确不输出“全解” |

验证器从原题重新绑定条件，独立检查严格性、作用域、方向和所有分支。抽象函数题使用单调性定理及代数集合验证，不拿自造的 $f(t)=t$ 或 $-t$ 代替任意符合条件的函数。显式分段题对原分支条件与代入式做独立的符号验证，不直接复用 M5 的最终答案作为判据。

集合核验要求无漏解、无增根；有限采样仅作辅助。变更函数、区间开闭、输入顺序、比较符或来源后，旧转换证书必须失效。完整求解流程中“拒绝不适用路线”和“原不等式无解”是不同结果。

## 5. 方法执行设计

### 5.1 M5 单调性解不等式法

| 步骤 | 数学任务 | 调用与返回 |
| --- | --- | --- |
| 1 识别比较对象 | 识别同一函数的两个输入及所求变量，保留原比较符 | 结构检查；不得把 $f(u)$、$g(v)$ 当成同一函数 |
| 2 取得单调性依据 | 使用原题已给性质；必要时求显式分段函数的整体单调性 | 调用 M3，返回严格性、覆盖区间和跨段依据 |
| 3 确定输入条件 | 两个输入都合法，且处于可用的同一严格单调区间 | 输入对应、具体表达式条件及必要的不等式子方法 |
| 4 转换比较关系 | 递增保序，递减反序；严格号和非严格号均保持自身严格程度 | 调用 `skill-monotonicity-order`，返回带前提的等价关系 |
| 5 解代数不等式 | 根据转换结果的实际次数选择计算路径 | 一次由已有不等式技能处理；二次调用 `quadratic-inequality-solve`；常真／常假单独处理 |
| 6 回到原目标 | 与输入条件、题给范围求交，必要时合并分支 | 独立验证完整解集，保留原变量与精确端点 |

步骤先后可按依据依赖合并：例如 B04 的原域为 $\mathbb R$ 且输入均为多项式，域检查完成后只需短承接；不能为凑步骤重复问一次全域。若两个输入完全相同，严格比较为空集，非严格比较为合法域，无须强行运行单调性转换。

### 5.2 M3 的显式分段扩展

1. 从原定义读取各段表达式、域、端点归属；以函数形参构造子问题，不把本题外层 $x$ 直接替换为形参。
2. 每段调用 M2／已支持的单调性子能力，明确常值段。二次分支先整理顶点式，再读所在区间的方向。
3. 调用既有 `skill-piecewise-order-join` 检查跨段次序。边界取值相等可能允许，连续性不是额外前提；方向错误的跳跃则必须拒绝合并。
4. 返回可以整体应用的区间及证明；若只能局部成立，列出局部结果。不能把各段同向箭头拼接成一个未经证明的全域结论。

对 B03/B09 默认完整展示段内和跨段判断，这是应用 M5 的关键依据。B12 的常值段不能返回严格递增；学生得到明确原因后进入分段求解路线。

### 5.3 原分段解不等式法的双输入扩展

设分段域为 $D_i$、表达式为 $p_i(t)$。对每个左右分支组合构造：

$$C_{ij}=C\cap\{x:u(x)\in D_i\}\cap\{x:v(x)\in D_j\},$$

并在该范围内求 $p_i(u(x))\mathrel{\square}p_j(v(x))$；最后对所有 $C_{ij}$ 的结果取并集。原输入的有意义条件始终保留；函数自变量取到分界点时，按原式唯一归属分支。

复用分段绑定、区间求交并、化简、因式分解和具体不等式能力。B12 的非负平方比较可经已有不等式推导或在非负支引用二次函数的严格递增结论，将四次展开降为二次问题；不宣称已有二次方法可解任意四次不等式。未能在已证明前提下降到支持结构时，返回能力缺口。

此扩展由 `method-piecewise-inequality` 承载，不再新增一个 T3 专属方法。B12 可用该方法独立完成；M5 不把“不满足自身前提”记录成一次成功的等价转换。选法层负责分流，课程中的失败尝试只用于解释适用条件。

## 6. 新增技能、知识引用与选法

### 6.1 唯一新增技能：利用单调性转化不等式

**输入：** 同一函数的严格单调证据、两个输入都在同一区间的证据、原函数值比较。

**输出：** 原适用范围内的等价输入比较及依据；它不负责解出 $x$ 的范围，也不负责证明函数单调。

| 函数性质 | 原关系 | 转换后关系 |
| --- | --- | --- |
| 在 $I$ 严格递增 | $f(u)<f(v)$／$f(u)\le f(v)$ | $u<v$／$u\le v$ |
| 在 $I$ 严格递减 | $f(u)<f(v)$／$f(u)\le f(v)$ | $u>v$／$u\ge v$ |
| 在 $I$ 严格递增 | $f(u)>f(v)$／$f(u)\ge f(v)$ | $u>v$／$u\ge v$ |
| 在 $I$ 严格递减 | $f(u)>f(v)$／$f(u)\ge f(v)$ | $u<v$／$u\le v$ |

所有行均要求 $u,v\in I$。只有“非减”或“非增”时拒绝输出这张等价表，不把某个单向蕴含当成等价关系。

例如 B01：输入是“$f$ 在 $(0,+\infty)$ 递增、$2x,x+1>0$、$f(2x)<f(x+1)$”，技能输出 $2x<x+1$；已有代数技能再求 $x<1$，父方法与 $x>0$ 合并。这就是新技能与既有不等式技能的分工。

### 6.2 知识与技能复用

| 既有对象 | 本型用途 |
| --- | --- |
| `function-monotonicity#definition`、`#interval`、`#endpoints` | 严格次序、同一区间与开闭端点 |
| `piecewise-function`、`quadratic-function-properties#monotonicity` | 原分支选择、二次分支的单调性 |
| `interval-notation`、`set-intersection-union` | 输入条件取交、分支结果取并、完整解集表达 |
| `skill-piecewise-order-join` | 跨段单调性检查；属于 M3，不在 T3 重建 |
| `skill-inequality-transform` | 有条件的不等式变形、一次条件与平方比较 |
| `skill-factor`、`skill-solve-quadratic`、`skill-quadratic-sign` | 因式分解、根与区间符号；由原二次子方法组织 |
| `method-complete-square`、`skill-simplify` | 整理二次分支与具体代数式；前者虽以 `method-` 命名，实际为技能 |
| `skill-expression-defined` | 原输入表达式的有意义条件 |

T2 的“运算增减性判断”和 T1 的“复合函数增减性判断”可在后续更复杂函数中借用，本批不为了复用数量而强行加进每题流程。M5 比较的是两个函数值，不是在求复合函数随 $x$ 的增减方向。

### 6.3 给学生看的选法线索

| 题目线索 | 小字说明 | 方法 |
| --- | --- | --- |
| 同一个函数的两个函数值比大小 | 如 $f(2x)<f(x+1)$。先检查两个输入，再利用递增或递减比较它们的大小。 | 单调性解不等式法 |
| 函数分段给出，需要分别代入比较 | 先看两个输入各落在哪一段，再代入对应式子；有常值段时，不能直接去掉 $f$。 | 分段解不等式法 |

具体题只开放已验证可用的路线。B03/B09 的 M5 先借用“分段单调性法”，它不是并列的整题解法；B12 可在适用性判断中解释为何不能直接利用严格单调性。未知函数且未给分段定义时，不显示可点击的分段路线。

## 7. 学生交互、图像与子方法密度

### 7.1 代表课主线

| 代表题 | 学生作答主线 | 卡片要求 |
| --- | --- | --- |
| B01 | 选择方法 → 写出两个输入的合法条件 → 利用递增性比较输入 → 解并合并条件 | 输入范围卡保留 $f$ 的定义域；合法域／解集选项写 $x\in\cdots$，不抛裸区间；转换卡作答态右格留空、由选项给出输入比较，**完成态**写出真实关系（不得残留 `?`） |
| B04 | 选择方法 → 利用递减性转换 → 解二次不等式 → 回到 $m$ 的范围 | 全域检查短承接；二次子方法用实际多项式与求解变量，不回退到抽象公式空讲 |
| B05/B13 | 常量与变量输入合法 → 比较方向 → 得出半开区间 | 完成态可作对照：增减性和原不等号同时变化，得到相同输入条件 |
| B03/B09② | 左段增减（带本段图）→ 右段增减（带本段图）→ 跨段合并（带合图，一次给出整体严格单调）→ 转化比较 → 解二次 | **禁止**先出「核对／先证整体递增」剧透卡；嵌套 M3 用压缩档（去空递减、重复定域、多余配方、R 合法域提问）；单段增减是 M2 子方法，跨段是技能 `skill-piecewise-order-join` |
| B09① | 第一层求值 → 按新输入重新选段 → 第二层求值 | 复用求值教学；与不等式目标的完成状态分开 |
| B12 | 先画整体图像判断是否严格单调 → 按输入分支分类 → 同段严格单调则用单调性转化，跨段／常值段再代入比较 → 合并解集 | 见 §7.4；适用性卡谈严格单调，不先抛「去函数符号」 |

转换卡采用已有“输入—规则—输出”板：左侧给两个原输入及已确认范围，中间给“$f$ 递增 ↑”或“$f$ 递减 ↓”，右侧让学生判断 $u\;?\;v$。完成后显示带前提的等价式，下一步承接该结论。递减时不能把关系反向写成“乘了负数”，应明确依据是函数的反序性质。

合法域与最终解集的选项一律写成求解变量的隶属式（如 $x\in(0,+\infty)$、$a\in(0,\frac23)$、$x=2$），与[交互步骤卡片规范](interactive-step-card-design-spec.md) §4.3「带足对象上下文」一致；题干已问「$x$ 需要满足什么」时，选项仍不可退化成裸 $\varnothing$/$\mathbb{R}$/区间/裸数。题干、图注、反馈禁止用「左边／右边／左输入／右输入」指代，一律写具体表达式（与题面一致，如 $1-x^{2}$、$2x$）。

### 7.2 子方法默认密度

| 子任务 | 默认展示 | 展开条件 |
| --- | --- | --- |
| 两个输入的定义域／区间对应 | 代表课 `full`；同类复习 `light` | 有限域、常量越界、开闭端点必须让学生确认 |
| $\mathbb R$ 上的多项式输入检查 | `fold`，保留结论 | 检查发现额外限制时才展开；不能让学生重复选择“全体实数” |
| 一次不等式计算与求交 | `light`，可与原目标收束合并 | 漏条件、错误端点时展开原有步骤 |
| 二次不等式 | 代表课 `full`，之后可 `light` | 真实调用原二次方法；不复制求根、判号或数轴卡 |
| M3 嵌套在 M5 下 | 压缩：段内增减＋跨段合图；折叠域卡／空递减／段末写区间／M5 prepare／basis | 段内判断走 M2 子方法且**必须带本段单调性图**；跨段走 `skill-piecewise-order-join` 且**必须带合图**；T1 单独求单调区间题仍用全密度 |
| B12 分情况求解 | `full`，每个有效情况一个任务卡 | 常真、常假与空前像可合并为有原因的短结论 |
| B09 求值 | `light` | 重新选段是必要判断，不能直接展示 $15$ 当作已知 |

这些档位只改变展示密度，不省略计算和验证。父步骤说明借用目标，子步骤返回有范围的结果；父步骤不再问一次相同答案。多小问完成图和结论板逐对排列，沿用最新卡片规范。

### 7.3 图像与防泄露

- 抽象函数优先用输入数轴与次序关系板；需要函数趋势示意时显式标“示意”，不指定任意解析式、数值纵坐标或未经题设给出的对称性。
- 不在判断前把 $u,v$ 按正确相对位置排在数轴上。待答关系保留问号，确认后才显示次序箭头或解集着色。
- 显式分段函数沿用 T1 图形：当前讨论区间着色，分界点画竖向分割线，图下标区间，原分支端点按开闭绘制。嵌套在 M5 下时，简单开口已知且顶点不在段内的二次可跳过配方卡，但仍须在段内增减卡上展示图像；跨段合并卡展示合到一起的整体单调性图。
- B12 适用性步先画整体分段图再讨论严格性：水平段与二次段明确区分，帮助学生看见“不同输入可能有同一函数值”；不以几个采样点替代全分支证明。分情况卡继续在同一张 $f$ 图上着色本情况两输入所落的段，再代入对应表达式比较。
- 数轴只有在解释取交、取并或端点时使用。最终作答卡在确认前不涂完整答案集，不给每个机械变形都重复挂图。
- 专题与拍题使用共同教学投影。沿用稳定布局，避免公式渲染、保存状态变化或尺寸观察造成卡片抖动。

### 7.4 B12 分情况交互约定（落地经验）

整体有常值平台时，**不能**把 $f(u)\,?\,f(v)$ 直接改成输入比较；但图仍要先画，段内能用严格单调性时**必须**用。

| 步骤 | 学生看到什么 | 硬性要求 |
| --- | --- | --- |
| 适用性 | 整体分段图；问「是否严格单调」 | 标题／题干谈严格单调，不先抛「去函数符号」 |
| 情况卡标题与条件 | 如「当 $1-x^{2}\ge0$ 且 $2x\ge0$」 | 禁用「第 $n$ 段」；条件板写两条件 $\Rightarrow x\in\cdots$，并补上本步不等式 |
| 同段严格单调 | $f(1-x^{2})>f(2x)\Leftrightarrow 1-x^{2}>2x$，再与范围取交 | 优先单调性转化，不先展开成高次代入式 |
| 跨段／常值段 | 写出代入后的具体比较式 | 题干用 $1-x^{2}$、$2x$ 等式子，禁止「左／右输入」「左边／右边」 |
| 图像标注 | 两输入示意点；一文案正上、一文案正下 | 与题面写法一致（$1-x^{2}$）；视窗包住两点；横轴只留分界刻度，不把示意横坐标打成刻度 |
| 选项与完成态 | $x\in\cdots$／$x=\cdots$ | 与卡片规范 §4.3 一致；禁止裸区间、裸数 |

与 B03 对照：B03 先证整体严格单调再 M5 转化；B12 先否定整体严格单调，再分情况，段内能转化仍转化。

沿用现有课程兼容和构建策略，只重建依赖实际变更的课程；不全量修改 JSON 的 `version`。仅有说明文案变化时不改变评分合同，步骤或答案规则变化时按已有机制升级相关题目。冻结的学习会话不得被新证据覆盖。带配图题处理慢仍作为既有问题记录，不因 T3 发布而宣称已解决。

## 9. 必要验证矩阵与验收口径

本节是后续实现的测试要求；本次文档只做代数校核与引用检查，不运行整站测试。

| 维度 | 必要用例 | 必须挡住的问题 |

必要单元测试按以上数学边界参数化组织，不为文案逐字写重复测试。实现完成后只补相关课程生成／回放检查与代表拍题验收，不反复跑无关全站测试。
