## 2. 代码问题与修复

| 真实调用暴露的问题 | 修复与防误判约束 |
| --- | --- |
| 局部公式和待求不等式作为普通事实提取，目标仅为 `find_range` | 读取实际全称局部规则；仅把原文明确询问、且唯一匹配的关系绑定为目标，保留原 candidate 与来源引用，不补造目标字段 |
| 多小问中，另一问的待求不等式被当成已知条件 | 按原文问句及真实目标归属区分，不能按出现位置丢弃后续条件；额外输入限制仍须消费并与答案取交 |
| 印刷题号直接接函数名，例如 `11. f(x)`，不能绑定函数介绍 | 扩展通用题号前缀识别，不按题号分支 |
| 差商给出单调性，但模型未生成单独的单调性字段 | 复用已有全称异点差商／差积检查；保留原量词、同域和异点前提；存在量词、无异点保护或非严格差商不升级为严格单调性 |
| “实数 a”明确提取为实数范围声明后被拒绝 | 读取现有 `default_domain` 记法，绑定到原文“实数 a”；不将整数声明扩大成实数 |
| 等价的奇偶恒等式被重复列为附加条件，导致补全目标拒绝 | 只识别同一函数、同一输入且与已知奇偶性完全一致的重述；不同函数、不同符号、额外常数不被忽略 |
| 模型写 `x1`、原文写 `x_1`／`x_{1}` 时来源比较失败 | 复用单调性专题已有的下标规范化；不同下标仍不能互相匹配 |
| A05、A11 的后端完成两问，专题登记却只编译第一问 | 内部课程登记改为显式选择两个目标，补全后继续解不等式；测试同时核对全部原目标与最终 `goal_group` 的答案引用 |

这些修复适用于同结构提取结果，没有增加题型专用 prompt，也没有降低模型修复的字段授权检查或提高调用预算。
