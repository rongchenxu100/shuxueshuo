## 声明范围

- 开放 A0 的根式一次输入、A1 的一次输入的配凑路线。右边必须是相应坐标的至多二次多项式；保留前批的自然域、声明域和请求域规则。
- 新增 `f(x-c/x)=h(x)`，其中 c 为固定正有理数。h 是次数在 −2 至 2 之间的有理系数 Laurent 多项式；负一次项系数须为正一次项系数的 −c 倍，负二次项系数须为正二次项系数的 c² 倍。这是同一函数输入产生相同输出的必要约束。
- 原式所有除法仅可排除 x=0，附加禁取点、额外限域、未知参数及超出上述次数的表达式不准入。约分消去的限制仍被检查。沿用 AST 总节点 128、深度 16、系数分子／分母 64 位预算。
- A2 一次分式仍走换元法；本批不把它的配凑法标为错误，只提示该类配凑步骤尚未开放。

恢复时比较多项式系数，得到 `h(x)=H(g(x))`，不求 g 的单值反函数。独立验证重新读取原关系，检查提交的 H 的次数和每个系数、恒等式、源域、确定范围、请求状态及覆盖证书。对于 `g(x)=x-c/x`，任取实数 t，方程 `x²-tx-c=0` 的判别式为 `t²+4c>0`，两根乘积为 `−c≠0`，因此每个实数 t 都有合法的非零原输入。输入虽然非单射，输出由同一个 H 决定。

## 两个独立目标

题源：用户图 4、第 92 页例 5 变式 3。原题为 `f(x−1/x)=x²+1/x²`，求 f(0) 和 f(x)。原图路径和 SHA-256 存于题源记录中；教材解析和手写批注不作为开发指令或自动答案。

1. `find_value` 保留未知函数原关系及目标 `f(0)`。直接取合法原变量 x=1，在原关系中求得 f(0)=2，不读取也不依赖另一目标的解析式。执行复用 `method-function-evaluation`。
2. `find_function_formula` 独立恢复 `f(t)=t²+2，t∈ℝ`，执行 `method-function-matching`。两目标分别有数学步骤、验证结论和完成哈希。
