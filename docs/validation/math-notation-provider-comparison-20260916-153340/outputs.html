# 结果解读与失败原因

本轮当前契约下，DeepSeek 严格通过 6/7（85.7%），Doubao 严格通过 4/7（57.1%）。DeepSeek 整批耗时少约 35.5%；Doubao 总 token 少约 11.4%。全部 14 次语义调用均一次网络尝试完成，以 stop 结束，用量完整，没有重试、追加调用或自动修复。

## 失败原因

| 模型 / 题目 | 本轮失败原因 | 独立离线诊断 |
| --- | --- | --- |
| DeepSeek / K 题 | `angle(BDC)`、`angle(ABD)` 等写法不符合当前三参数 angle 记法，产生两处参数数量错误 | 仅将四个角引用改为三参数形式后仍未通过：图1把 k 比例约束施加在被平分的对角线上；图2缺少 `quadrilateral(A,B,C,D)` 构型，其他条件尚不足以证明其冗余 |
| Doubao / 和平二模 | `M = axis(Γ) ∩ x_axis` 未被当前编译器作为点定义接受，导致 M 绑定失败并连带影响最值和目标 | 诊断副本仅改为 `M ∈ axis(Γ) ∩ x_axis`，即可严格通过，属于交点记法兼容问题 |
| Doubao / 南开一模 | `D = axis(Γ) ∩ x_axis` 同样导致 D 绑定失败 | 诊断副本仅改为 `D ∈ axis(Γ) ∩ x_axis`，即可严格通过，属于交点记法兼容问题 |
| Doubao / K 题 | `O = segment(A,C) ∩ segment(B,D)` 把点与点集直接等同，当前类型校验拒绝 | 仅改为成员关系后仍未通过：图2、(2)、(3) 缺少四边形构型；图1末尾的 `∧ k≥1` 只约束 OR 的第二分支，未覆盖完整定义 |

两家的 K 题本次均保留了 `(1)` 下两图的层次，并在四个子问准确报告图1～4缺失，触发 `extraction.missing_figure`。因此此前的层次与缺图问题在本次返回中已经改善；K 题整体失败来自上述数学表达问题。

诊断副本仅用于定位，未修改原始响应、代码、金标或真实成绩，也未增加模型调用。尤其不能将 Doubao 的两题诊断通过计入本轮通过率。诊断替换及完整差异见 `diagnostic-normalization-only.json`。
