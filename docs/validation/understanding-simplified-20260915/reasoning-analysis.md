# 单次模型输出诊断与金标勘误

本分析基于唯一一次真实调用的实际请求、模型返回、最终可见内容与原图。仅记录可核查的行为归纳，不改写冻结代码、提示词、人工金标或验收结果；未增加模型调用。

## 结论

主要开销出现在关系形式化和输出组织中的重复决策。模型在推理文本前段已经整理了完整题干与四个所求，随后反复考虑层级、对象声明、辅助交点、定义分支以及 JSON 写法，并越界使用几何性质筛选分支。最终还在推理区预写了一份完整 JSON，再生成正式 JSON，耗尽输出预算。

因此，token 上限是截断的直接原因；仅提高上限不会解决未经确认的题设、分支筛选和重复组织问题。不能由本次单样本断言模型普遍不能识图，也不能断言去掉 OCR 就会修复。

## 实测

- 输入 7,601 tokens；completion 16,384 tokens，其中 reasoning 14,399（87.9%）。
- 思考文本 31,349 字符；其中一份完整 JSON 草稿为 6,599 字符，占思考文本 21.1%。这是字符比例，不是 token 或耗时比例。
- 最终业务内容 5,628 字符，在第（3）问 source_text 开头截断；finish_reason=length。
- 实际请求传入 thinking enabled 与 reasoning_effort low。low 在本次请求中没有阻止长推理，不能仅据此认定服务端忽略了参数。

## 已识别的浪费与错误

1. **重复决定树和声明位置。** 多次重新考虑第（1）问应拆成两个顶层节点还是两个子节点，以及 k 放根层还是局部。说明“按字面层级”仍缺少明确示例，模型仍承担了组织策略选择。
2. **定义展开与求解边界反复摇摆。** 模型既讨论保留定义分支，又尝试根据几何性质筛掉分支、推导第一问 k 的具体值。这些推导超出了抽取职责。
3. **辅助点规则不明确。** 为表达长度比，需要引用未命名交点；提示又强调原名和不猜内容，但没有明确允许怎样声明题面隐含对象，导致模型反复选择名称及 role。
4. **OR 的 schema 风格不统一。** 其他 fact 以 kind 分派，OR 却是只有 any_of 的特殊对象。模型在组织草稿后又检查并修改此差别。这里属于接口负担，而非识图难点。
5. **推理区预写完整 JSON，正式内容再次输出。** 额外消耗可观；source_text 还出现根层整题、第（1）问整段、图景局部文本的重复。
6. **来源不确定项未妥善保留。** 原图没有四幅示意图，可见正式输出却使用图形作为依据，加入 parallelogram、interior=true；部分比例方向问题被误填为 ambiguous_reuse，而不是由 OR 本身表达。
7. **题型匹配没有成为主要瓶颈。** 模型正确判断当前四个 family 不适用，正式输出已有 unmatched。等角、角比例、面积比和正切目标本身也能被识别。

## 必须纠正我方金标的一点

上一轮文档将“AECD 的对角线不能自动复用 O”进一步写成了“其交点与 O 是不同身份”，这个结论不成立。

题面给出 E 为 OB 中点、O 为 AC 与 BD 的交点。因此 E、O、B 共线，B、O、D 共线，E、O、D 共线；O 又在 AC 上。对非退化的四边形 AECD，AC 与 ED 的交点就是 O。这个结论不需要假定 ABCD 为平行四边形。

所以：

- 保守抽取暂时引入 X 可以是一种表示选择，但不能因此断言 X≠O。
- 输出 O 本身不能判错；代码应支持基于已知共线关系的身份确认，或在语义比较中接受经过确认的等价表达。
- 当前验证器把同一点参与两组不同 intersection 一律视为 multiple_definitions，会误拒这种正确几何关系。
- “O 也是 AC 与 ED 的交点”与“ED 平分 AC”是不同结论。后者需要额外平分依据，不能因为前者正确就默认成立。
- 当前金标未包含 X≠O 的 fact，但文档和比较/校验政策过于严格，必须纠正。此次实际失败发生在 JSON 解析层，尚未执行该比较，不能把勘误写成此次截断的直接原因。

## 针对性修正方向

在保持整题 IR + 匹配的前提下，优先减少选择，而非继续添加大量解释：

1. 明确题内定义仅做替换与展开，不依据其他题设消去分支、推导数值或作答。
2. 原文只在直接所属节点保存；父节点不复写子节点全部题干。用一个短嵌套示例固定文字层级。
3. 明确允许为题面隐含且表达必需的未命名对象使用局部名字；身份与等价确认交给代码，不让模型设计 role/身份策略。
4. 统一 OR 与其他 fact 的分派风格；用一个短的非本题分支例子演示，不新建本题专用类型。
5. 提示直接生成最终 JSON，不在推理中再排一遍完整 JSON；这只能作为行为约束，不能保证模型遵循。
6. 修正金标中关于交点身份的说明和误拒规则，同时继续保留 □ 和缺图的不确定性。

进一步削减本题不使用的能力 schema、调整预算或思考模式，可以作为后续对照实验；需要独立记录，不能覆盖本次失败或偷偷重复调用获得通过。
