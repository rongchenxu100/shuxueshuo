# 定义展开边界与 OR 统一：离线修复验收

2026-09-15，作者策略 `problem-ir-authoring/v5`。本轮未发起真实模型请求，未切换生产入口。

## 改动

- 定义只做对象/参数代入与基础关系展开。不能利用其他题设排除分支、推导条件或计算所求。
- 修改原有定义 few-shot 为“合邻三角形”：独立记录 ∠BAC=60°，仍保留等长或直角两个分支。组织规则 few-shot 不变。
- OR 与其他 fact 统一：`{"kind":"any_of","branches":[[fact,...],[fact,...]]}`。至少两个非空分支，分支内同时成立，分支间至少一个成立，不要求互斥。操作目录生成 schema、构造器和操作说明。
- 校验器按新字段编译，不把 OR 分支提升为无条件题设。非法字段、引用、量纲和逻辑展开超限仍被拒绝；表达合法不证明条件可满足。
- 本题人工金标后面三幅图恢复定义的四分支，明示的“BD 平分 AC”另列。没有读取新模型输出后修改金标；原始图片、OCR、历史失败审计、生产五题金标均不变。
