但是，对于 ii_solve，selected_curve_point 的 return 有 target_selection？catalog 说 curve_candidate_parameter_solve 的 selected_curve_point 是 call_result_or_answer_or_existing_object，可能返回目标点。如果我们不写 output_targets，代码如何知道这个 return 是 D？answer_from 指定了 step_id 和 return，Goal authority 的 target_ref 是 D，所以代码会验证 selected_curve_point 是否绑定到 D。但 selected_curve_point 可能没有显式绑定到 D，除非 output_targets 指定。catalog 中 selected_curve_point 没有 target_selection 字段。所以可能需要 output_targets 来绑定到 D。规则说“Goal最终答案用`answer_from`选择producer，代码再根据Goal authority验证其对象身份。” 这意味着即使没有 output_targets，代码也会验证 return 是否代表 target_ref。但如何验证？可能 selected_curve_point 返回时，其内部对象身份由 capability 从 target_point 参数确定。我们在 args 中传了 target_point: "D"，所以 selected_curve_point 应该就是 D 对象。因此不需要 output_targets。所以可以省略。

同样，i_vertex 的 args 没有 target，但 quadratic_vertex_point 返回顶点。Goal authority 说 target_ref 是 P，且 P=vertex(Γ)。所以代码知道顶点就是 P。可以省略 output_targets。

iii_solve_b 的 args 中 parameter 是 "b"，返回 parameter_value，所以就是 b。可以省略 output_targets。
