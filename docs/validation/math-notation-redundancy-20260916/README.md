## 两项修复

### 独立线段声明

和平一模返回了 `segment(B,C)`、`segment(O,M)`、`segment(B,N)` 三条独立声明。它们是对象提及，不额外约束题目。编译器现在先检查参数个数、端点绑定及类型，将合法的独立 `segment(...)` 记录为内部对象声明，再从比较条件中移除。

原始响应、规范化候选以及原始内部表示仍保留声明；比较投影的证明记录标明 `standalone_segment_declaration`。只被此类声明提到、未出现在其他条件或目标中的端点也不参与对象别名匹配，避免多余声明阻碍改名等价判断。对象仍保存在原始 IR 中。

这不是删除任意“看起来多余”的字符串。`P∈segment(A,B)`、`AB=3` 等实际关系完整保留；非法参数、未知操作、裸代数表达式及把对象放入逻辑关系仍会报错。本次只对明确的独立线段构造开放此容错，没有猜测线段、直线、射线的含义。

### 坐标轴与零坐标

`P∈x_axis` 规范化为 `y(P)=0`；`P∈y_axis` 规范化为 `x(P)=0`。与坐标分解规则组合后，河西的 `N=(n,0)` 与额外 `N∈x_axis` 只留下同一条零纵坐标条件。

转换也适用于逻辑分支和目标 `at` 内的关系，但不会把分支条件提升为全局条件，也不会删除目标状态。无条件重复关系仅在当前作用域或可见父条件中去重；兄弟小问不能互相提供依据。非零坐标、错误坐标轴和缺少依据的成员关系仍会造成语义差异。

## K 题本轮具体问题

以下均针对 13:56 的新响应，不沿用更早一轮的错误。该响应已经通过数学解析，交集写法已改为 `segment(A,C)∩segment(B,D)={O}`，并保留了定义的两个方向。

### 1. 四处缺图标记全部遗漏

输入明确只包含文字，引用图1～4均未提供。实际输出四个相关节点均没有 `uncertainties`。因此未触发 `extraction.missing_figure`，当前为未阻断的 `candidate_only`。这是一项明确的视觉抽取遗漏，与后面几个比较器问题独立；即便其他差异都可证明等价，本题仍不能按缺图测试成功验收。

### 2. 图1未显式保留四边形 AECD

题面明确“若四边形 AECD 为 k 倍四边形”，金标保存 `quadrilateral(A,E,C,D)`。模型保存了原平行四边形 ABCD、O 的交点关系、E 的中点关系以及定义比例展开，却缺少 AECD 的四边形关系。

这属于题面明确构型的未显式保留。现有代码没有证明该关系可由其他几何条件推出并作为冗余关系省略；仅有 A/E/C/D 四个点名不等于保留了四边形关系。本次的独立线段声明容错不会自动补出该关系。

### 3. 四个末级问的层次与金标不同

```text
金标：root → (1) → 图1、图2；root → (2)、(3)
模型：root → (1)图1、(1)图2、(2)、(3)
```

模型没有丢掉任何一个末级问；金标中 `(1)` 的中间节点也没有额外条件。差异主要是组织方式，不能直接认定为串题。当前比较器按树结构及绑定路径比较，尚未对这种空容器做规范化。

仅在诊断副本中恢复 `(1)` 空容器后，差异能定位到四个末级问的 facts 和 uncertainties；原始根级 children 及全局绑定路径差异消失。没有修改原返回。参见 [k-diagnostics.json](k-diagnostics.json)。

### 4. 模型以比例为 1 表达“平分”

例如模型使用 `cut_ratio(AC,BD)=1`，金标使用 `bisects(BD,AC)`。前者表示交点将 AC 分成的两段等长；后者表示 BD 所在直线经过 AC 中点。注意参数顺序不同是因为两种操作的参数职责不同，并非比例方向读反。

在端点非退化、交点存在且唯一的前提下，这两种写法可表达同一个中点关系；但当前比较器将比例和几何谓词作为不同对象，没有实现这种带前提的转换。图1类似地用 `cut_ratio(AC,ED)=1` 代替 `bisects(ED,AC)`。不能无条件把任意比例为 1 都改成平分，也不应简单认定模型的这种写法错误。

### 5. 图2、（2）、（3）保留完整定义后，又附上明确平分条件

模型在这些问中同时保留“两个方向的完整定义”和 `cut_ratio(AC,BD)=1`；金标则按题面明确的平分方向表达已专门化的定义应用。例如图2的模型结构为：

```text
((AC被平分 ∧ BD上的比为k或1/k)
 ∨ (BD被平分 ∧ AC上的比为k或1/k))
∧ AC被平分
```

金标写“AC被平分，BD上的比为k或1/k”。证明两者等价需要把中点与单位截线比联系起来，再结合 k 的条件处理另一分支；当前的规范化尚不具备这段几何与代数联合蕴含能力。（3）的固定参数 2 也有类似的冗余分支。

这轮模型是在遵守“保留完整分支”，不再是上一轮擅自缩减分支的问题。需要区分抽取组织方式与可证明的语义等价，不能为了匹配金标要求模型先解题。本轮只列出此问题，没有修改 K 题规则来放行。
