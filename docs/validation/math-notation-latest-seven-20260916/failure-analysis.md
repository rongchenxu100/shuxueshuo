# 五道未通过题目的逐项原因

本分析对照选定题图、冻结金标、实际响应、解析报告和比较器实现。没有修改金标、Prompt、解析器或真实验收结果，也没有新模型调用。当前真实结果仍为 2/7。

四道二次函数题均通过 Schema、数学解析与题型匹配，失败分类是 `not_proven_equivalent`，意思是当前比较器没有证明与金标等价，并非已证明模型题意错误。K 题外层 JSON 合法，但数学绑定失败，真实验收尚未进入完整语义比较。

关键复核：河西的 `y_M`、西青的 `y_D` 都是题面已有符号；南开原文明确写了“此时抛物线的解析式和点G的坐标”。因此，不能把这些表达直接归类为模型编造或错误。

| 题目 | 实际触发失败的差异 | 分析归属 |
| --- | --- | --- |
| 和平二模 | M的交点写法；H的直线/线段交点写法 | 具有题目上下文依据的等价表达，比较器未覆盖 |
| 河西一模 | 显式纵坐标 `y_M` 与仅保留横坐标的区别 | 金标简化了原题表达，比较器未处理坐标变量消去 |
| 南开一模 | D的交点写法；曲线目标多一个 `at` | 等价表达缺口，以及题面措辞和目标状态归属的契约问题 |
| 西青一模 | 显式纵坐标 `y_D`；重复声明 `A∈Γ` | 坐标变量与关系蕴含的规范化缺口 |
| K题 | 缺图遗漏、交集操作数类型、局部对象绑定、定义展开 | 确实存在模型遗漏/表达不合约定，同时有绑定器能力缺口 |

## 1. 和平二模

第一处在根节点。模型写：

```text
axis(Γ) ∩ x_axis = {M}
```

金标写：

```text
M ∈ axis(Γ) ∩ x_axis
```

两者都能解析和建立 M。前者还明确交集仅有一个点。在本题中 Γ 的二次项系数为 -1，对称轴是竖直直线，与 x 轴确实只有一个交点，因此这里描述的是同一件事。比较器目前保留等式、单点集及成员关系三种不同结构，没有基于唯一交点条件统一它们。

第二处在（II）。模型写：

```text
line(A,K) ∩ line(E,G) = {H}
```

金标写：

```text
H ∈ segment(A,K) ∩ segment(E,G)
```

原题为“对角线AK和EG相交于点H”。已知 AEKG 是正方形，AK和EG是其两条对角线，其所在直线的交点就是在线段内部的正方形中心。因此，这两种写法在本题上下文中等价；不能脱离正方形条件，在任意题目中把直线和线段互换。

离线定位：只在诊断副本中对齐M的写法，剩余差异只在H；再对齐H，比较通过。未发现其他验收差异。建议补带唯一性及正方形前提的交点规范化，不必让模型重抽这两项。

## 2. 河西一模

唯一差异在（III）。模型写：

```text
M = (b+1/2, y_M)
M ∈ Γ
```

金标写：

```text
M ∈ Γ
x(M) = b+1/2
```

图片原文确实写的是 `M(b+1/2, y_M)`。模型保留纵坐标记号，金标将其简化掉了。这不是模型新增题设，也不是横坐标读错。

代码能正确解析两种表达，但前者会多建立一个 scalar 数学对象 `y_M`。比较器目前只尝试相同数量、相同作用域、相同类型的对象别名映射，不能把命名坐标变量与点的坐标属性对应起来。因此，它看到了不同的对象集合和不同形式的坐标约束。

若 `y_M` 仅用于命名 M 的纵坐标，在其他条件与目标中没有独立用途，消去该坐标记号后，两者约束相同。如果它另有范围条件或本身是所求，就不能直接删除。本次符合可消去的情形。

只在诊断副本中将第一行改成 `x(M)=b+1/2`，比较即通过。`N为动点`、省略默认实数域、省略最值下标均已被正确接受，不是失败原因。

## 3. 南开一模

第一处为 D 的交点表达，与和平二模 M 同类：

```text
模型：axis(Γ) ∩ x_axis = {D}
金标：D ∈ axis(Γ) ∩ x_axis
```

本题明确 `a>0`，对称轴与 x 轴有唯一交点。需要唯一交点规范化，而不是让模型舍弃正确的集合表达。

第二处为（II）②的目标 `at`。两边均保留了：

```text
min(EG+FG) = 5*sqrt(10)/2
```

两边也都要求求曲线方程和 G 的坐标。区别仅是：模型给这两个目标都写了 `EG+FG=min(EG+FG)`，金标只给 G 坐标写了 `at`。

题图原文为：“当EG+FG取得最小值为……时，直接写出此时抛物线的解析式和点G的坐标。”模型将“此时”用于两个并列目标，有明确文字依据。我之前将它简称为“误加最优状态”不够准确。

金标采用的是先前讨论过的内部组织方式：最小值条件用于反求曲线参数，只有G坐标需要标明具体最优位置。因此，这里是忠实于文字的转写与内部目标状态划分之间的差异。曲线参数是否随优化状态变化应由后续绑定/规划处理，不宜让抽取模型承担这个判断。

离线定位：对齐D后只剩这个目标的 `at` 差异；再在诊断副本中去掉曲线目标的 `at`，比较通过。这仅证明差异来源，不证明原模型输出错误，也不是建议自动删除全部 `at`。

上一轮旧响应漏掉最小值语义的问题，本轮已经修正；不能将旧轮错误沿用到这次。

## 4. 西青一模

第一处在（2）。模型写：

```text
D = (b+2, y_D)
D ∈ Γ
```

金标写：

```text
D ∈ Γ
x(D) = b+2
```

原图也明确给出纵坐标记号。和河西一样，这是金标简化后引起的表示差异，需要建立 `y_D` 与 `y(D)` 的对应，而不是认定模型多了一个错误参数。

第二处是模型同时保留：

```text
A ∈ Γ
Γ ∩ x_axis = {A,B}
```

金标只有第二行。由第二行当然可以推出第一行，而图片原文本身也先说“经过点A”，所以这条关系既有题面依据，又是冗余条件。

比较器会去掉完全重复的规范化表达式，但不做集合等式推出成员关系后的去重，因此仍报告额外事实。此处不需要求解抛物线，只需受限的集合/成员关系规范化。

离线定位：对齐D的表达后只剩根节点的冗余成员关系；从诊断副本去掉该关系后比较通过。最值条件、权重2、正半轴范围和所求参数均未触发差异。

## 5. K 倍四边形

这题存在多层问题，不能只修比较器后直接通过。

### 缺图未识别：明确的模型遗漏

输入只给出文字，引用的图1～4均未提供，这是特意保留的测试条件。模型没有任何 `uncertainties`，四处 `missing_figure` 都缺失。

当前 `invalid_candidate` 阻断来自数学非法，不是缺图识别成功。即使下列解析错误都修复，这题仍必须因缺图漏报而失败。无需补图或改动这个测试意图。

### 一个交集类型错误

模型写 `AC ∩ BD = {O}`。按已提供的目录，单字母点名组成的 `AC`、`BD` 在普通表达式中表示长度，长度不能求几何交集，于是报告 `type.intersection`。

明确写成 `segment(A,C) ∩ segment(B,D) = {O}` 可解决这个类型错误。这是学校数学中常见的简写，但不符合本次目录约定；代码没有静默猜它表示长度、线段还是直线。

### 七个连带绑定错误，源自两个作用域

图2和（2）只输出了 `bisects(BD,AC)`、`cut_ratio(...)` 等关系，没有输出题面中的 `quadrilateral(A,B,C,D)`。这些分问的 A/B/C/D 不能从兄弟图1中借用。

当前绑定器可从 `square/parallelogram/quadrilateral` 建立顶点对象，却只把 `bisects/cut_ratio` 的端点当作已存在对象去查找，不能靠操作数类型建立本问端点。因此，在两处缺失声明后，角度、长度和目标也连带报不可见对象，总计七条。

模型遗漏明确的四边形关系是一项问题；绑定器没有充分利用基础记法的参数类型，是另一项工程能力缺口。解决后者不应恢复模型侧 entities，也不能放开兄弟作用域隔离。

离线定位：只明确交集操作数，8条报错降为7条；再仅在诊断副本的图2和（2）各补一条四边形关系，解析报错降为0，但语义仍不通过。

### 图1展开经过了推导，未保留原始定义分支

金标原样保留两种可能：“ED所在直线平分AC”或“AC所在直线平分ED”，每个方向再保留两个截线比方向。

模型直接写了 `O=midpoint(A,C)`、`O∈segment(E,D)` 和 `EO/OD=k ∨ OD/EO=k`，省略另一种平分方向，也未显式保留 `quadrilateral(A,E,C,D)`。

在给定平行四边形及E是OB中点的条件下，O确实是AC中点，E/O/D共线，相关推导有几何依据，不能简单说它凭空编造。但是本轮明确要求定义忠实展开、保留分支、不由抽取模型先做几何推理。当前输出把题面转写和推导混在一起，现有比较器也不会证明这些展开与原定义等价。

### （3）额外引入局部 `k=2`

模型已经将比例展开为 `2` 或 `1/2`，又写了一条 `k=2`。金标没有在本问额外引入k。这不是说数值2错了，而是新增了本问不再使用的参数对象与赋值；当前比较器不消去它，仍产生差异。

此外，图1的 `EO/OD`、`OD/EO` 与金标 `cut_ratio` 形式产生了不同的分母非零义务记录。不能只按文本相似度忽略，需配合几何对象和条件才能比较。

## 处理建议

优先补代码的通用规范化：坐标表达与坐标属性对应；集合等式蕴含成员关系；在可确认唯一交点、正方形对角线等前提下比较交点写法。不要将直线与线段在所有场景下直接视为相同。

南开的 `at` 应先明确容错政策，允许符合题面“此时”的转写，再由代码确定它对目标的实际限制。不要为了贴合金标而要求抽取模型分析动点依赖。

K题继续严格要求识别缺图、保留题内定义应用和分支。可增强绑定器对端点参数的类型识别，但不能靠跨分问借用对象或编造图形来通过。

已通过的和平一模和函数量词题没有这次失败项。当前真实通过率不变；上述分析说明为什么“2/7通过”不能直接解释成“只有2题读懂”。
