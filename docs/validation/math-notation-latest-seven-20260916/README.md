## 验收差异

四道新增二次函数题均通过 Schema、数学解析和题型匹配，未通过当前保守语义比较。不能将这些失败全部视为模型题意错误：

- **和平二模：**M 采用“交集等于单点集”，金标采用“点属于交集”；H 使用两条直线相交，金标使用正方形对角线线段相交。当前比较器没有证明这些写法等价，线段与直线也不直接互换。
- **河西一模：**`M=(b+1/2,y_M)` 代替 `x(M)=b+1/2`，引入纵坐标参数。当前比较器不消去该辅助参数，属于表示与比较能力缺口。
- **南开一模：**D 存在同类交点写法差异；模型给曲线方程和G坐标都标明 `at`，金标仅标G。题面确有“此时抛物线的解析式和点G的坐标”，这是目标状态组织与容错政策差异，不能直接认定模型误加条件。
- **西青一模：**`D=(b+2,y_D)` 代替只指定横坐标；还重复 `A∈Γ`，而已有 `Γ∩x_axis={A,B}`。当前比较器不做辅助坐标消去或集合关系蕴含去重，属于表示与比较能力缺口。
- **K 题：**未输出 `missing_figure`，漏掉有意缺失图1～4的识别；`AC∩BD` 将长度简写用于交集，解析器拒绝。图2和(2)没有显式四边形关系，当前绑定器又不能仅从 `bisects/cut_ratio` 建立全部端点，报告不可见对象。图1对定义作了推导式展开，仍须另行核对。
- **函数量词：**严格语义通过。

K 题当前因非法候选被阻断，不能把这种阻断算作缺图识别成功。其余六题没有误报缺图。本次只测试和统计，未修改解析器、比较器或验收标准，也未把离线修正算成真实通过。所有结果仍是抽取候选，未执行 Solver。
