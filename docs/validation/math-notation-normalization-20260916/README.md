## 实现边界

新模块 `server/shuxueshuo_server/problem_understanding/notation_normalization.py` 在类型与作用域绑定之后处理内部数学对象，不按题号、family 或金标文本分支。

1. **坐标绑定。** `P=(e,t)` 拆为 `x(P)=e`、`y(P)=t`。本作用域内作为坐标名称的标量 `t` 在比较投影中替换为 `y(P)`，其所有条件、目标、后代引用一起替换；原始候选、内部对象及绑定记录保留。若两个点共享变量，保留两点坐标相等的条件。不会从或分支提取无条件绑定，也不会跨兄弟问借用变量。
2. **唯一交点。** 仅在能证实唯一性的情况下，将“交集等于单点集”与“点属于交集”统一。支持坐标轴、已确认非退化二次曲线的对称轴与 x 轴，以及正方形/平行四边形的两条对角线。无显式非零条件的 `a*x^2` 不足以证明非退化。
3. **直线与线段范围。** 对角线前提足以确认交点位于线段内部时才统一；另外复用已有精确坐标交点检查，确认非平行、非退化且交点参数在线段范围内。射线不在此规则内。缺少证据保持不同，不默认互换。
4. **集合蕴含去重。** `Γ∩x_axis={A,B}` 已蕴含 `A∈Γ` 等成员条件，重复条件不再导致失败。反向不成立：仅有几个成员关系不能取代完整交集等式。

每项转换保存规则名、作用域、转换前后表达和使用的前提。编译产物的 `semantic_normalization` 保存完整比较投影；校验报告公开 `coordinate_bindings` 和 `normalization_proofs`。未改动的原始内部表示仍可审计。

复用已有 `equivalence.ProofBudget` 限制规范化工作量，复用 `intersections.Intersections.check` 做精确交点检查，代数部分沿用受限 SymPy 运算。不是把字符串直接交给任意求值器，也没有将旧 fact JSON 契约重新暴露给模型。

## 剩下的两题

**南开：验收口径差异。** 模型将“此时”写到抛物线方程和 G 坐标两个目标上，题面文字确实支持这种转写。金标只给 G 坐标加 `at`。当前比较只剩 `/root/children/1/children/1/goals` 一处差异，不能据此认定模型读错题。本次没有自动删除 `at` 或调整金标。后续应明确目标状态的容错规则，并保留“错误状态仍须拒绝”的反例；不宜让抽取模型分析动点依赖。

**K 题：仍有实质遗漏。** 模型未报告有意缺失的图1～4。`AC∩BD={O}` 将长度简写用于交集，违反类型约定；图2和（2）遗漏四边形声明，当前绑定器不能仅凭 `bisects/cut_ratio` 建立所有局部端点，产生七条连带绑定错误。还存在定义分支经过推导后缩减、额外局部 `k=2` 等差异。当前因非法候选被阻断，**不算缺图识别成功**。详见[此前逐项分析](../math-notation-latest-seven-20260916/failure-analysis.md)。

## 如何避免逐题打补丁

有限的是支持的记法和证明规则，不是题目的数量。一个坐标绑定规则可处理任意合规点名和表达式，一个带前提的对角线规则可处理不同题目的同类关系。但即便记法目录有限，表达式组合仍无限；不能承诺通用等价判断全部完成。

本次补了两层回归并接入现有 `tools/run_solver_tests.py affected`：

- `test_math_notation_normalization.py`：独立于七题的生成矩阵，覆盖改名、顺序、不同参数、父子继承；配套检验缺少前提、兄弟问、或分支、改变线段/射线、错误交点、改变目标 `at`、丢失坐标变量约束、证明预算耗尽等反例。同时验证规范化幂等、比较对称以及原输入不被修改。
- `test_math_notation_recorded.py`：冻结七题实际响应、金标哈希和政策，长期回放。明确断言五题通过及另外两题的具体剩余差异，不把失败夹具改成通过，也不调用模型。

修改抽取模块、模板、Schema、表达目录或相关夹具会自动选中这些测试及旧契约相关回归；测试入口默认禁止 live LLM。现有范围比当前七题更广的 `fast/contract/full` 仍保留这些测试。

今后发现新差异时，应先归为已有规则未覆盖的组合、尚不支持的记法或真实语义差异。增加规则必须同时补可判等变换和不可判等反例，给出前提与证明记录；无法证明的情况保留具体差异，不以字符串相似度放行。
