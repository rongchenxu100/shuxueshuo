## 误判分析与离线修复

**河西（III）**题面说“当 `sqrt(2)*MN+AN` 的最小值为 `21/4` 时，求 `b`”。候选已保留 `min(sqrt(2)*MN+AN)=21/4`，并给求 b 的目标添加：

```json
"at": "sqrt(2)*MN + AN = min(sqrt(2)*MN + AN)"
```

原比较器逐项保留目标的 `at`，因此报告 `not_proven_equivalent`。这不能直接解释为数学错误：既然给定了同一动点范围内可取到的最小值，对每个满足题设的固定参数 b，都可选择一个取到最小值的动点；这样不会改变 b 的答案集合。此前“模型多加错误状态、review 漏检”的结论过强，现撤回。

**西青（2）②**相同：已保留 `min(2*DM+AM)=5+5*sqrt(3)`，求 b 的目标上的 `at: "2*DM+AM=min(2*DM+AM)"` 同样不改变 b 的答案集合；review confirmed 不能据此判为漏检。

西青（1）另有代码缺口：模型定义 `V=vertex(Γ)` 后求 V 的坐标，金标直接求 `vertex(Γ)`。二者是合法别名。已基于本次原始响应离线增加**显式顶点别名规范化**：只用无条件、当前作用域的定义替换引用，继承给子问；保留附加条件和 `at`，不跨兄弟问、不把 OR/量词分支提升成公共定义，也不推导顶点坐标。等号左右反写的点类型识别同步补齐。

新增通用规则 `parameter_goal_extremum_witness`，只作用于编译后的比较投影，原始候选和其 `at` 保持原样。首版要求：目标是祖先曲线定义中的参数；路径端点由参数确定，只有一个可识别的轴上自由坐标；当前问无条件保留同一表达式的有限 min/max 值；显式优化变量提示一致；`at` 只表达同一最值的取到状态。数值最值事实按 min/max 的“可取到”含义提供存在性前提，不把下确界当最小值，不计算最优点或解 b。

每次归约记录参数、动点坐标和依赖前提。求动点坐标、依赖动点的答案形式、错误优化变量、不同表达式、额外 at 条件、OR/量词中的最值、跨问或父问的最值不能凭本规则归约；题设范围和最值事实仍严格比较。复杂依赖不在本证书范围内时继续报告未证明等价，不自动忽略 at。

七题原始响应在当前代码下离线复验 **7/7（六题严格等价、一题按既定政策接受）**。**冻结成绩仍保留为 5/7，金标、政策、图片和全部原始响应未改写，没有请求模型重跑。**
