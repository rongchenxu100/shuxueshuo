## 提示词与示例

- 按题面编号组织 children，编号内的独立图景继续分 children。
- 原文仅保存在直接所属节点；父节点无独立原文时填 []，不复写子问全文。
- 对象与参数在所属图景声明；仅题面明确共用时放父层。定义中的参数字母相同不代表各图景共享一个对象。
- 表达必需的未命名交点允许取未占用的局部名字，声明 point 并填写 intersection；不同图景可以重复使用同一名字。
- role 缩减为原文明示的 fixed/moving，其他情况省略；移除模型侧 given/constructed 选项。
- 保留“等邻三角形”定义示例，新增独立组织示例。两个示例均经过生成的 schema 与真实解析器校验，未使用 k 倍四边形作为示例。

## 代码修复

已有词法机制继续按层级分配内部 ID：本层声明覆盖父层，未声明向父层查找，不访问兄弟节点。新增回归证明不同图景中同名参数和辅助点隔离；允许交点名 Z1 等普通局部标识，不需要模型前缀 ID。

语义比较先校验原始对象，再在同层类型/role 相符的名字间尝试有界配对，解决多个辅助点同时改名和改变声明顺序时的贪心误配。只有完整编译语义一致才接受，仍比较全部条件、目标、分支和定义域义务；不会合并多个实体。最多检查 256 个候选配对，256 个 scope，4,096 次组织搜索，超预算保留不通过结果。

移除“同一点参与不同 intersection 就必然冲突”的误拒规则：多条线可以共点。允许该结构不等于证明其与原图一致，也未新增通用几何定理求证或自动身份合并器。此前关于 AECD 的交点必然不同于 O 的文字已勘误；人工金标保留局部 X，但不声明 X≠O，不为通过实验重写其数学条件。
