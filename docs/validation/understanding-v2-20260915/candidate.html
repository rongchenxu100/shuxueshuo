定义与问题

definition 若四边形的一条对角线被另一条对角线平分，且另一条对角线被交点分成的两条线段长度之比为k（k≥1），则称该四边形为“k倍四边形”。 (definition.text)

（1）图 1

condition 如图1，在□ABCD中，对角线AC与BD交于点O，点E为OB中点。 (q1.fig1.given)

text □ABCD 的符号形状无法可靠确定。 (q1.fig1.symbol)

condition 四边形AECD为k倍四边形。 (q1.fig1.instance)

requirement 求k的值。 (q1.fig1.goal)

（1）图 2

condition 如图2，在k倍四边形ABCD中，对角线AC被BD平分。 (q1.fig2.given)

requirement 求S△ACD/S△ACB，用含k的代数式表示。 (q1.fig2.goal)

（2）图 3

condition 如图3，四边形ABCD为k倍四边形，其对角线BD平分对角线AC。 (q2.given)

condition ∠BDC=2∠ABD。 (q2.angle)

condition BD=4CD。 (q2.length)

requirement 求k的值。 (q2.goal)

（3）图 4

condition 如图4，已知定点A、B，点D为平面内一点，连接A、B、C、D构成四边形ABCD。 (q3.points)

condition AB⊥BM。 (q3.perpendicular)

condition 点C为射线BM上一动点。 (q3.ray)

condition BD平分AC。 (q3.bisect)

condition ∠BAC=∠DAC。 (q3.angle)

condition 四边形ABCD为2倍四边形。 (q3.instance)

requirement 求tan∠ACD的值。 (q3.goal)
