# FP-T1 判断函数的奇偶性：设计与实现方案

本文细化[函数奇偶性建设计划](function-parity-topic-plan.md)中的 T1，参照[函数单调性 T1 设计](function-monotonicity-problem-type-design.md)，遵循[专题与拍题学共用开发流程](topic-and-photo-learning-development-workflow.md)。专题课与学生拍题共用题意、数学执行、独立验证和教学投影。

本型的核心是：**保留原定义域 → 检查相反输入能否配对 → 计算 $f(-x)$ → 分别核验奇性、偶性 → 收束四类结论。** 运算和复合可以缩短证明，但不能省略定义域或把未知判成错误。

## 1. 身份、范围与完成标准

### 1.1 题型及任务边界

| 项目 | 约定 |
| --- | --- |
| 专题／分组 | `function-parity`／FP-T1 判断函数的奇偶性 |
| 候选题型 | `type-function-parity` |
| 候选方法 | `method-parity-definition`，学生名称“奇偶性定义法”，别名“定义法”（单调性已有同名“定义法”，不单独使用该名称） |
| 首建技能 | `skill-domain-symmetry`，学生名称“检查定义域的对称性”；名称不写死“关于原点”，T2 含参、T5 一般中心沿用 |
| 主要知识 | `function-parity#domain`、`#definition`、`#zero`；图形引用 `function-parity-graph#symmetry`、`#paired-values` |
| 代表题 | FP-A01.1、FP-A01.2，一道原题的两个独立作答目标 |
| 输出 | 奇函数、偶函数、既奇又偶、非奇非偶；附原域、两项性质各自的证明／反例 |

知识层保持教材对应的 **3 个节点**：函数的奇偶性、奇偶函数的图像特征、函数图像的对称性。T1 不新增知识节点，不把代入、零点检查、收束答案各拆成新技能。

本型处理“给出具体函数，判断其奇偶性”，包括逐个判断和从原题选项中选择满足指定性质的函数。以下任务另行路由：

- 已知奇／偶，要求参数：FP-T2。
- 已知奇／偶及一侧公式，补另一侧公式：FP-T3；不能把缺失的一侧自动补成奇函数后再证明它为奇函数。
- 利用已知奇／偶解不等式：FP-T4。
- 一般对称轴、对称中心或“某函数加常数为奇函数”：FP-T5／T6。
- 只有一幅不完整的示意图、只有几个函数值或任意抽象函数关系：不据此完成本型的全域判定。

### 1.2 本轮承诺的结构范围

以下是**实现目标**。准入依据是 AST、域结构及证明能力，不是题号、照片、系数白名单或答案。

| 子范围 | 本型收尾要求 | 边界 |
| --- | --- | --- |
| 固定多项式 | 有理系数，至多四次；含零函数、非零常数、展开前等价写法 | 含未确定参数转 T2；不将偶数次项外观当成证明 |
| 固定有理式 | 约分前分子、分母至多四次；保留每一处原分母禁取值 | 所需实临界点须能由完整根计数证明为有理数，或由有理系数一次／二次因子精确获得；一般高次代数根暂不开放 |
| 绝对值 | 一次／二次多项式的绝对值、与至多四次多项式的有界和差积；按符号区间处理 | 不是直接复用旧比较器的“二次多项式加一个绝对值”门槛；扩展见 §3、§5 |
| 根式 | 二次多项式平方根及其有界乘除、常数倍；$\sqrt{Q(x)^2}$，$\deg Q\le2$；原域可能为区间、区间并集或有限集 | 平方后还须检查符号；一般嵌套根式、不同根式任意相加的全域消元暂不开放 |
| 根式特殊路径 | 有限定义域逐点验证；反射后根式完全一致时使用可验证的结构等式 | 如 $\sqrt{1-x^2}+\sqrt{x^2-1}$ 无需实现一般根式和的消元 |
| 有限分段 | 至多 6 个显式分支，分支式属于上述范围；条件能转为受支持的固定区间／有限点集 | 需验证覆盖、重叠、边界归属；不以默认“先出现的分支优先”消解冲突 |
| 运算与显式复合 | 原式可在预算内进入上述结构；相反输入的变换、原域限制全部保留 | 不承接仅给抽象外函数／内函数性质、未给完整式子的通用关系证明 |
| 原题选择 | 单选、多选、未注明选项模式；选择“奇”“偶”“既奇又偶”“非奇非偶” | 原题“是奇函数”的性质包含既奇又偶；不能误用四选一的排他标签评分 |

定义域支持非空的有限区间并集、有限点集及删去有限点的组合。输入的有限端点／点为有理数，或可精确比较的实二次代数数；无穷端点始终开。首轮预算拟定为：显式集合至多 8 个区间、16 个孤立点／删点，分段至多 6 段；合并全部反射边界和符号临界点后至多 48 个有限切点、97 个开放区间／单点单元。

源 AST 每个函数至多 256 节点、深度 24；有理数分子／分母至多 128 位。恒等式内部有理正规式次数至多 24、平方式次数至多 48，沿用现有比较器预算。这些预算要集中登记并由提取后准入、执行、验证共同读取；中间表达式超过预算也停止，不能只检查原式。

不要求先实现任意超越函数、一般高次无理根或任意分段嵌套。指数、对数、三角函数和未给完整规则的抽象函数留作后续范围，返回具体能力缺口。常见二次无理端点如 $\pm\sqrt2$ 属本轮扩展目标，不能在“支持二次根式”的声明中隐去这一缺口。

### 1.3 按证据分层准入

1. 能完整确定原域且证明不对称，便可判非奇非偶，不必先支持该表达式的恒等化简。
2. 原域对称且为有限集，允许枚举**整个域**，不要求区间上的正规式能力。
3. 原域对称且含区间，进入受支持的全域恒等证明；确切反例可否定一项性质，但找不到反例不等于恒等成立。
4. 表达式超出声明范围时，不因偶然几个采样值一致而放开；只允许已经完整验证的域反例等通用路径。

A01 两个小问通过只算代表题贯通。本型收尾还须完成四类结论、非对称域、约分孔洞、有限域、根式、分段和原题选择的边界覆盖，并明确尚未开放的结构。

## 2. 题源、数学金标与代表课

来源为[奇偶性两图归档清单](../internal/senior-high/source-images/function-parity-planning-20261110/manifest.json)的图 1 第 1 题。手写“奇／偶”和批改符号不参与题意提取，也不作为生产求解证据。

| 源目标 | 印刷题意 | 原域 | 独立校核结果 |
| --- | --- | --- | --- |
| FP-A01.1 | 判断 $f(x)=\dfrac{x}{x^2+1}$ 的奇偶性 | $\mathbb R$，因为 $x^2+1>0$ | 奇函数；$f(-x)=-f(x)$，且 $f(1)=\frac12\ne0$，不是偶函数 |
| FP-A01.2 | 判断 $f(x)=\lvert x\rvert+x^2$ 的奇偶性 | $\mathbb R$ | 偶函数；$\lvert-x\rvert=\lvert x\rvert$、$(-x)^2=x^2$，且 $f(1)=2\ne0$，不是奇函数 |

两个小问可以复用显示名 $f$，编译后的函数身份必须局部隔离。专题若拆成两张题卡，仍记录同一原题及各自 `target_ref`，不得改称两道原始题；公开 `qXX` 在纳题时再分配。

代表题完整推导：

$$
\text{A01.1：}\quad D=\mathbb R=-D,\qquad
f(-x)=\frac{-x}{(-x)^2+1}=-\frac{x}{x^2+1}=-f(x).
$$

$$
\text{A01.2：}\quad D=\mathbb R=-D,\qquad
f(-x)=\lvert-x\rvert+(-x)^2=\lvert x\rvert+x^2=f(x).
$$

每题内部都要完成另一项性质的排除；教学可以合并为结论旁的一句依据，不强迫学生重复一套相同计算。非零证据来自原式的精确求值，不来自“题目看起来不是零函数”。

## 4. 题意、结果与路由契约

本节字段为拟议合同，实施时同时更新 Schema、记法编译、规范化、题目身份和版本依赖，不能只加一个执行器分支。

### 4.1 提取边界

拟新增 `determine_function_parity` 目标。提取只记录题给信息：

| 字段／语义 | 要求 |
| --- | --- |
| 函数及目标 | 引用当前作用域中的函数定义；保留函数名、形参和原问法，不预填奇／偶答案 |
| 原始定义 | 使用既有函数／分段表示，保存未约分的 AST、原分支条件和来源；不新增第二种表达式语言 |
| 域及域角色 | 没有给域时从原式求自然域；给出完整定义域为 `declared`；明确限制输入为 `restriction` |
| 原题选项 | 每项保存局部函数、标签、原文及域；`selection_mode` 为 `none/single/multiple/unspecified`，来自题面 |
| 所问性质 | 逐个分类或选择某性质；原题“是奇函数”与“只是奇函数”分别规范化，不能猜排他性 |
| 完整性／不确定项 | 沿用现有来源完整性和复核协议；缺分支、端点不清、式子识别冲突不当成数学上的非奇非偶 |

题意摘要至少显示**函数原式、题给定义域（如有）、“判断奇偶性”目标**。分段条件不能在摘要中丢失；约分式只作为后续等价计算，不覆盖“原题”。

明确声明 $D$ 为完整定义域时，必须满足 $D\subseteq D_{\mathrm{natural}}$；若包含原式无定义点，返回题设冲突，不能默默删去。明确限制输入 $x\in I$ 时，实际域为 $I\cap D_{\mathrm{natural}}$。对 $f(x)=x^2/x$，“定义域为 $[-1,1]$”与“只考虑 $[-1,1]$ 中有意义的输入”不是同一个合同。

### 4.2 编译后绑定

每个目标保存 `target_ref`、候选题意版本、局部 `function_ref`、原 AST／分支及其 `source_ref`、域角色与域来源。新生成的 $f(-x)$ 标记为派生对象，记录 `substitution: x -> -x`、源函数身份和推导版本；不得登记为 OCR 题给事实。

- 判断目标不含“假定奇／偶”的前提。题面确实同时给出同一函数的性质时，按完整任务保留并检查一致性；不忽略可见事实直接套本型。
- 阶段一只解析与描述结构，阶段二按目标识别本型，阶段三产生数学结论。
- 原式、域角色、开闭、孔洞、分支归属、选择性质和目标改变，都进入规范题目身份；仅更名形参可进行保留来源的等价规范化。
- 多小问只继承祖先公共条件，不读兄弟小问的 $f$ 定义或答案。选择题各选项也隔离同名函数。

### 4.3 结果不是单个布尔值

拟议 `ParityResult`：

| 字段 | 内容 |
| --- | --- |
| 绑定与版本 | `target_ref`、`function_ref`、原始来源、执行／证明合同版本 |
| `domain` | 原合法域、非空证据、原式限制、域来源 |
| `domain_symmetry` | 反射域、`proved/refuted/unresolved`、集合等式证据或未配对点 |
| `odd`、`even` | 各为 `proved/refuted/unresolved`，分别附完整恒等证据或确切反例 |
| `classification` | 仅在足够证据验证通过后为 `odd_only/even_only/both/neither` |
| 运行状态 | `verified`、`unresolved` 或有效题意／数学输入错误；映射到现有服务状态，不混入四类答案 |

| 奇性 | 偶性 | 排他分类／显示文案 |
| --- | --- | --- |
| 已证明 | 已否定 | `odd_only`／奇函数 |
| 已否定 | 已证明 | `even_only`／偶函数 |
| 已证明 | 已证明 | `both`／既奇又偶 |
| 已否定 | 已否定 | `neither`／非奇非偶 |

域不对称时，两项性质都因必要前提不成立而被否定，引用同一域反例；无需在缺失点上计算 $f$。若一项已证明、另一项仍未知，保留部分证据但不完成四类判定。空域、题意缺失、题设冲突、预算超限和验证失败各有诊断，不作为“非奇非偶”选项。

## 5. 数学执行与独立验证

### 5.1 保留原域并反射

先执行／借用定义域子方法。所有根式非负、原分母非零、分支有效条件都参与求域。$0/(x-1)$ 和 $0\sqrt{x}$ 仍保留原限制，不能因化简为零而变成全实数域。

反射技能首建固定中心 $a=0$；接口预留固定中心参数，T2 含参和 T5 一般中心的能力暂不登记为已支持。计算

$$
-D=\{-x:x\in D\},\qquad [a,b)\longmapsto(-b,-a].
$$

区间端点反序且开闭随原端点交换；孤立点、孔洞、无穷一并处理。反射两次必须恢复原集合。比较规范集合的对称差，不只比较最左、最右端点。不相等时给 $t\in D$ 且 $-t\notin D$；若搜索先得到反方向的差集点，应取反后规范为该方向。

空域在反射之前结束为无有效实函数。$\{0\}$ 是非空域，必须继续；此时仅 $f(0)=0$ 为既奇又偶，非零值为偶函数。

### 5.2 反射整个函数规则

对原函数形参作结构替换，得到 $g(x)=f(-x)$，其实际域应为 $-D$。替换涵盖分子、分母、幂、绝对值、根式和分支条件，保留“整体取负”的节点及运算优先级。

奇性比较 $g(x)$ 与 $-f(x)$，偶性比较 $g(x)$ 与 $f(x)$。只有在 $D=-D$ 已获验证后，才比较整个 $D$ 上的规则。

此步由代入法 `method-function-evaluation` 完成显式公式代入，**不调用“已知奇偶性”的反射结论来证明待判奇偶性**。总计划 S2 `skill-function-symmetry-transform` 用于已知／已证关系的应用，留到相应题型首建；T1 不为一次 $x\mapsto-x$ 再注册同义技能。

### 5.3 共用恒等比较内核

从现有函数相等模块抽出受控的“对应规则比较＋证书核验”接口，拟记为 `compare_on_domain`／`verify_on_domain`：

1. 接收两个保留来源的表达式、原域证书和比较单元；验证该单元包含于两个式子的合法域，不能信任调用者传入的裸集合。
2. 原相同函数判定仍先证明两函数的完整域相同，再调用该接口；奇偶性父方法先完成反射和域对称，两者共用恒等逻辑。
3. 有理式比较使用受预算约束的精确正规式；乘分母前保留非零依据。不得在化简后的表达式上重算原域。
4. 绝对值按**完整**符号切点细分，根式保留非负根语义；$\sqrt{Q^2}=\lvert Q\rvert$，不是无条件等于 $Q$。
5. 根式平方比较同时验证原式符号，拒绝“平方相同，所以值相同”。有限域逐点时使用精确代数值。
6. 增加保留定义域的反射规范化：有理常数、形参、和差积商、幂及受支持函数调用的同构节点可逐步核验相等。反射后完全相同的根式和可沿这条路径证明，无需伪称支持任意根式和消元。
7. 精确试点只用于找反例。未知正规式、无法完成符号证明或预算用尽返回 `unresolved`。

在有限非空域上枚举所有元素是全称证明；在含区间的域上抽取有限点不是。多项式在一个非退化区间恒等可用系数证明，但在有限域上必须按实际点判断，不能用整条实轴上的系数规则排除“既奇又偶”。

当一项恒等已证明、且存在确切非零点，可直接给另一项反例。例如偶性及 $f(t)\ne0$ 给出 $f(-t)=f(t)\ne-f(t)$。反例中的值仍从原式／原分支核验；这只缩短计算和教学，不把两项性质合成互斥的真假开关。

### 5.4 分段函数的公共细分

设原分支有效域为 $D_i$，表达式为 $F_i$。对每一对原／反射分支构造

$$
C_{ij}=D_i\cap(-D_j).
$$

在非空 $C_{ij}$ 内比较 $F_j(-x)$ 与 $F_i(x)$、$-F_i(x)$。继续按绝对值／根式的必要切点细分；所有单元的并必须等于原 $D$。

- $0$、分段端点及其相反点单独核对，只要属于域就不能漏掉。
- 未声明完整域时，未覆盖位置不自动补值；声明完整域时，遗漏位置属于题设／提取待核查问题。
- 重叠分支在重叠域上应给同一输出。能证明不一致则是无效函数定义；无法证明一致则暂停，不默认取第一支。
- 不要求连续。左右极限不等并不自动排除奇函数；原点的实际值、两侧配对关系才是证据。
- 若分支从原图漏读，先按源文完整性处理，不能把漏读造成的域不对称显示成正确答案。

### 5.5 验证器责任

验证从冻结的原候选题意重建绑定和前提；不得调用最终判定生产器，再比对它自己的结论。可以复用确定性的解析、集合和精确代数运算，但域覆盖、替换、单元恒等／反例均由证书消费端逐项检查。

必须拒绝以下篡改：恢复约掉的孔洞、改开闭、只提交部分分区、把 $f(-x)$ 绑定到另一函数、漏一个分支端点、只验平方不验符号、用非法／浮点反例、把“未知”改成“否定”、更改分类但不改两项性质、复用其他 `target_ref` 或旧版本证据。

全称证明至少包含域覆盖和每个非空单元的依据；否定证据必须能在原式与原域上直接核验。金标只服务测试，不进入生产求解或验证器。

### 7.1 代表题的最短有效流程

| 环节 | 学生看到／完成的事 | 反馈及完成态 |
| --- | --- | --- |
| 判断定义域 | 原式及域卡；A01.1 核对 $x^2+1$ 是否可能为零 | 保留 $D=\mathbb R$ 和一句依据，不重复展开多项式常识 |

### 7.2 数轴与图像合同

- 数轴绑定实际域，清楚画出多个区间、空实端点和孔洞；有限域只画点。显示 $a$ 与 $-a$ 的准确数值／符号，不能只用颜色暗示。
- 曲线来自原函数及合法域。缺失点不连线；有限域不画连续曲线；分段跳跃不补线。无穷、画布截断和渐近趋势不冒充定义域端点。
- 配对点使用 $(a,f(a))$、$(-a,f(-a))$；奇性确认后标原点中心对称，偶性确认后标 $y$ 轴对称，零函数可同时显示两种关系。
- 作答前可以展示中性原图供观察，但正确关系、对称高亮和未来答案不提前显示；图像只能辅助观察，全域结论来自符号／集合证据。
- 原式的 $f(-x)$ 计算同时展示在图旁，学生能知道“反射输入”和“输出取负”是两个不同操作。不得将 $f(-x)$ 的曲线当成未经说明的原函数。
- 复用知识页的配色和配对组件，新增参数化课程资源；不复制固定示例并修改几处标签。SVG／代码绘图足够，不生成位图充当数学图。
- 活跃态、答对态、已完成态、后退和 AI 回放消费同一份图形与显隐状态。数学排版完成后稳定布局；滑块移动只更新图层与数值，不重建整张卡片造成抖动。
- 窄屏上下排列，精确公式和集合另有文本；拖动仅辅助理解，不以拖动到某个像素位置评分。键盘和点击均可完成关键作答。

定义域子方法使用既有 fold／light／full 密度：简单域折叠，非平凡域首题按需展开，始终实际执行并验证。同一函数、域角色、目标和版本的域证据可借用；新反射函数不能仅凭显示名相同借用。

## 9. 必要测试、留出与真实验收

### 9.1 数学覆盖矩阵

除 A01 两问外，下表是**新编回归样例**，不计入两页 20 道原题，也不冒充独立留出。系数、记法及输入名变式使用参数化测试覆盖，不复制题号分支。

| 情形 | 样例与金标 | 所防止的错误 |
| --- | --- | --- |
| 代表正例 | A01.1 奇；A01.2 偶 | 只见 $x$／$x^2$ 就猜性质；只证明一项 |
| 零与常数 | $0$ 在 $\mathbb R$ 上既奇又偶；$3$ 在 $\mathbb R$ 上仅偶 | 将两项性质硬做互斥 |
| 有零点但非奇 | $x^2+x$ 在 $\mathbb R$ 上非奇非偶；$x=\pm1$ 可核验两项失败 | 由 $f(0)=0$ 推奇性 |
| 四次项 | $x^4-2x^2$ 仅偶；$x^3-2x$ 仅奇 | 只支持代表题的二次式；只按字符串识别次数 |
| 开闭不对称 | $x^2$，$D=[-2,2)$，非奇非偶，$-2$ 未配对 | 只比较端点数值 |
| 原式孔洞 | $\dfrac{2x^2+2x}{x+1}$ 非奇非偶；$\dfrac{x^3}{x}$ 在 $\mathbb R\setminus\{0\}$ 仅偶 | 约分恢复原来无定义的点 |
| 对称两支 | $\dfrac{3x}{1-x^2}$ 仅奇；$\dfrac{x}{\sqrt{x^2-1}}$ 在 $(-\infty,-1)\cup(1,\infty)$ 仅奇 | 强行要求定义域连通或含零 |
| 零式也有域 | $0/(x-1)$、$0\sqrt{x}$ 均非奇非偶 | 先化成零再忘原域 |
| 单点域 | $f(x)=x+1$，$D=\{0\}$，仅偶；$f(x)=x$，同域既奇又偶 | 空域与单点域混同 |
| 离散根式域 | $\sqrt{1-x^2}+\sqrt{x^2-1}$：$D=\{-1,1\}$，既奇又偶 | 误判无定义／将离散点连成曲线 |
| 有限域系数 | $x^2-1$，$D=\{-1,1\}$，既奇又偶；同式在 $\mathbb R$ 上仅偶 | 在有限域套全实数系数规则 |
| 显式并集 | $f(x)=x$，$D=[-3,-1]\cup[1,3]$ 仅奇；改为 $[-3,-1]\cup[1,3)$ 则非奇非偶 | 漏内部端点、靠最小最大值判对称 |
| 二次无理端点 | $\sqrt{2-x^2}$ 在 $[-\sqrt2,\sqrt2]$ 仅偶；$\lvert x^2-2\rvert$ 在 $\mathbb R$ 上仅偶 | 二次根式只支持有理根；浮点端点合并 |
| 根式符号 | $\sqrt{x^2}=\lvert x\rvert$ 仅偶；$x\sqrt{x^2+1}$ 仅奇 | 平方相等忽略正负；根式分母漏零点 |
| 分段零点 | $x<0$ 时 $-x^2$，$x\ge0$ 时 $x^2$，仅奇；将 $f(0)$ 单独改为 $1$ 则非奇非偶 | 只比左右开区间、不检查零点 |
| 分段镜像 | $x<0$ 时 $x^2-x$，$x\ge0$ 时 $x^2+x$，仅偶 | 不反射分支条件；取错公式 |
| 非连续奇函数 | $x<0$ 时 $-1$、$x=0$ 时 $0$、$x>0$ 时 $1$，仅奇 | 额外要求连续性 |
| 运算退化 | $x-x$ 既奇又偶；$x\lvert x\rvert$ 仅奇 | 运算规则漏零函数、整体符号错误 |
| 显式复合 | $(x+1)^2$ 非奇非偶；$1/(x^2+1)$ 仅偶 | “外偶内任意必偶”；复合不检查完整输入 |
| 平方前的原式限制 | $\bigl(\sqrt{x}/\sqrt{x}\bigr)^2$ 的域为 $(0,\infty)$，非奇非偶 | 平方／约分后的常数式掩盖原域 |
| 无效／冲突 | $\sqrt{-x^2-1}$ 无有效实函数；$x^2/x$ 声明域含 $0$ 为冲突 | 空域真空恒等、静默改题 |
| 分支不完整／重叠 | 完整域声明下漏零点；重叠区间给不同输出 | 自动补值、依赖分支顺序 |

还须有超预算、未知根式恒等及不支持函数的诊断测试。数学未知不等于非奇非偶；结构超限也不能触发无限次修复或生成虚假最终课。

### 9.2 只做必要的单元与定向集成

### 9.3 新题留出与拍题验收

实施前固定开发、回归和留出角色。独立留出至少覆盖原域不对称、零函数／有限域、非平凡分段、根式或复合四种机制；来源和金标另存，不进入开发调试或 few-shot。已公开的 A01 和本表例题只能作开发／回归，不能换几个系数就称新的结构留出。

两条入口都需验收：

1. **专题构建**：人工核定题意 → 同一阶段三执行和独立验证 → 共享课程产物 → 题目／方法导航及学习记录。
2. **真实拍题**：上传原图 → 实际 OCR → 选中第 1 题及两小问 → 模型提取 → 原图复核／必要修复 → 目标路由 → 数学执行验证 → 两问课程 → 作答、刷新、继续学习。

原图验收后再用未参与调试的新照片验证代表之外的开放结构。真实 OCR、模型提取／复核、数学执行、课程生成、浏览器作答与恢复分别记结果；录制回放只算回归，不能替代新照片完整调用，也不能只看生成 HTML 就写“上传流程通过”。

记录源图摘要、目标、工作流／合同／课程版本、调用记录与逐层结果；凭据不入库。一次故障应保留原始失败证据和修复后记录。新增事实或恢复原域后必须重跑受影响数学和课程，不保留旧分类。
