判别式法 · 图解

核心对全体实数恒成立，就看整条抛物线与横轴的位置，用开口方向和判别式 Δ 表示出来。

判断两个前提都满足，才用判别式法

读题信号 · 第 02 题 已知不等式 kx2+2kx−(k+2)<0 恒成立，求实数 k 的取值范围。
  • 没写 x 的范围：x 取全体实数
  • x2 的系数是 k：可能为 0，要先单独讨论
  1. 1x 的取值范围：全体实数题目没写范围，或写“对任意实数 x”
  2. 2x2 的系数：确定非零含参数、可能为零时，先讨论系数为 0 的情形，再用判别式
  • 不满足x 只在某个区间上→
  • Δ < 0不相交 ✓
  • Δ = 0相切，允许取等时 ✓
  • Δ > 0穿过横轴 ✗

开口向上时，要 f(x)≥0 恒成立，图像不能到横轴下方

  • 恒 ≥ 0开口向上+Δ ≤ 0
  • 恒 ≤ 0开口向下+Δ ≤ 0

不等号不带等号（>、<）时，只取 Δ < 0

  1. 1定开口系数可能为 0 先讨论，再看开口方向
  2. 2位置化成 Δ不相交 Δ < 0，允许相切 Δ ≤ 0
  3. 3解范围，查边界边界值代回原不等式检验

区间最值法（分类讨论） · 图解

核心x 只在某个区间上取值，就只看这一段图像：最高点小于 0，整段都小于 0。

判断一个前提满足，就能用区间最值法

读题信号 · 第 04 题 当 1≤x≤2 时，不等式 x2+mx+4<0 恒成立，求实数 m 的取值范围。
  • 只要求 1 ≤ x ≤ 2：只看区间上的那一段图像
  • 判别式管的是整条图像，这里用不上
  1. 1x 的取值范围：某个区间如“当 1 ≤ x ≤ 2 时”“∀x < 0”；开口方向不是前提，它决定最值在哪里取到
  • 不满足x 取全体实数→
  • 也可以参数容易单独移到一边→

第 04 题，m = −5.5 时：区间外有正有负不要紧，区间内最高点 f(1) < 0

  • 恒 < 0区间上的最大值 < 0
  • 恒 > 0区间上的最小值 > 0

最值在顶点还是端点，看对称轴与区间的位置

  1. 1转化为最值条件< 0 比最高点，> 0 比最低点
  2. 2分类讨论最值对称轴与区间比较，分情况写最值
  3. 3合并，查边界情况内取交集，情况间取并集

03

分离参数法 · 图解

核心把参数单独放到一边，问题就变成水平线 y = 参数 与函数 h(x) 比高低。

判断两个前提都满足，才用分离参数法

读题信号 · 第 06 题 “∀x<0,x2+ax+2≥0”为真命题，求实数 a 的取值范围。
  • 参数只出现在 ax 中：移项后除以 x，就能把 a 单独放到一边
  • x < 0：除数符号确定，除以负数时不等号变向
  1. 1参数能单独放到一边已经分离，或移项后可以分离
  2. 2要除的式子，符号确定不需要除，或需要除但符号确定；符号不定就不能直接除
  • 不满足除数符号不定（如第 02 题的 x2 + 2x − 1）→

第 06 题，h(x) = −x − 2/x（x < 0）：a ≤ h(x) 恒成立 ⇔ a ≤ 2√2

  • 参数 ≤ h(x)→比 h(x) 的最小值
  • 参数 ≥ h(x)→比 h(x) 的最大值

除以负数，不等号要变向

  1. 1分离参数看除数符号，定不等号方向
  2. 2转化为最值条件≤ 比最小值，≥ 比最大值
  3. 3求最值，查边界用图像、单调性或基本不等式

04

更换主元法 · 图解

核心对哪个字母恒成立，就把它当自变量（主元）；另一个字母当常数，常常变成一次函数，只看两端。

判断两个前提都满足，才用更换主元法

读题信号 · 第 08 题 已知函数 y=mx2−mx−6+m，若对于 1≤m≤3，y < 0 恒成立，求实数 x 的取值范围。
  • 给出范围的是 m，要求的是 x：把 m 当作主元
  • y = (x2 − x + 1)m − 6：关于 m 是一次函数
  1. 1恒成立针对的是给出范围的字母它不是要求范围的那个字母，就把它当作主元
  2. 2固定另一个字母后，关于主元是一次形式可退化为常数；最值都在区间端点取到
  • 不满足恒成立针对的就是 x→

第 08 题：x = 0 时 f(m) = m − 6，两端都在横轴下方；x = 2 时 f(m) = 3m − 6，右端跑到上方

  • 斜率恒正／恒负→最值在确定的一端
  • 斜率符号不定→两端都要看

一次函数在区间上恒 < 0 ⇔ 两个端点值都 < 0

  1. 1定主元，整理写成 f(主元) = (…)·主元 + (…)
  2. 2看斜率定端点恒正、恒负看一端，不定看两端
  3. 3解不等式，查边界解关于原来字母的不等式
