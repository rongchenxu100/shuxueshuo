# Q27：取倒数、换元、分离后再换回

入口 `/1/q27/`，归入首页“分式分离法求最值”（第 06 组），排在 Q26 后面。题目：若 x>0，求函数 y=(2x+1)/(x²+1) 的最大值（最大值 (√5+1)/2，x=(√5-1)/2）。

只提供“取倒数后分式分离”路线。7 步：

1. 转化目标（choice）：求 1/y 的最小值。干扰项“求 1/y 的最大值”方向反了；“求分母 x²+1 的最小值”忽略了分子也在变。
2. 换元（substitution）：在 1/y=(x²+1)/(2x+1) 中点选分母 2x+1，记为 t，得 x=(t-1)/2、t>1、1/y=(1/4)·(t²-2t+5)/t。干扰项是分母里的 x，选中后预览显示只是改名。
3. 分式分离（fill）：在 (t²-2t+5)/t ≟ t+□+○·(1/t) 中填 -2、5。候选 ±2、±5；确认错误组合后，页面把所填式子乘回 t，比较一次项与常数项；完成后得 1/y=(1/4)(t-2+5/t)。
4. 观察和积结构：t 与 5/t 积为 5，定积求和，系数 1/4 和常数 -2 留在外面。
5. 应用基本不等式：t+5/t≥2√5，所以 1/y≥(√5-1)/2。
6. 验证取等：t=5/t 且 t>1，得 t=√5，x=(√5-1)/2。
7. 换回 y（choice）：(√5+1)/2。干扰项 (√5-1)/2 是 1/y 的最小值、忘了换回；2√5-2 漏了系数 1/4 也没换回。完成卡给出最大值与取到时的 x。
