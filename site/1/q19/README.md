# Q19：消参、分式分离、凑配表达式

入口 `/1/q19/`，分组“消参法求最值”，排在 Q18 后。题目：a>0、b>0、9a+b=ab，求 a+4b 的最小值（49）。

只提供“消参法”路线，固定消 b。6 步，与 Q16 相同：

1. 消参（choice）：选 b=9a/(a-1)。干扰项 9a/(a+1)、(a-1)/(9a) 各有整理核对预览。完成后系统补出 a>1，目标化为 a+36a/(a-1)。

3. 凑配表达式（choice）：选 (a-1)+36/(a-1)+37。未凑配时预览说明积不固定，常数未调整时预览说明不等价。
4. 观察和积结构：a-1 与 36/(a-1) 积为 36，定积求和，常数 37 不参与。
5. 应用基本不等式：两项和≥12，a+4b≥49。
6. 验证取等：a=7 满足 a>1，b=21/2，代回原条件成立。
