# Q10：配齐次式

入口 `/1/q10/`。题目：x,y>0，x+5y=1，求 5/x+4/y 的最小值。

只提供“配齐次式”路线，不显示教材编号。5 步：

1. 识别齐次结构：目标负一次，条件表达式正一次。
2. 配齐次式：选择整个式子，乘入 x+5y；系统展开为 25+25y/x+4x/y。
3. 观察和积结构：两个比值项正且积为 100，定积求和。
4. 应用基本不等式：两项和≥20，加回常数后原式≥45。
5. 验证取等：25y/x=4x/y，系统得 x=1/3、y=2/15 并验证原条件。

HTML 保存展示与本地答案；教师数据在 `server/shuxueshuo_server/tutor_demo/lessons/q10.json`。无题目专属 JS、计算板或 Prompt 特例。

公共 homogeneity 组件使用两个有序次数槽位。rewrite 使用两个独立候选域，分别为作用范围和乘数；每个作用范围的预览在 HTML 模板中声明，公共组件支持后续局部配式。仅对一项乘定值保持值但整体不齐次；整体乘 x+y 不保持值。
