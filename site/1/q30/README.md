# Q30：构造对称或消元求最小值

入口 `/1/q30/`，归入首页“找对称结构和积换元”（第 07 组），排在 Q29 后面；第 07 组提示注明本题也可以消元后分式分离，第 04 组提示反向提到本题。题目：已知 a>0，b>0，且 2ab=a+2b+3，求 a+2b 的最小值（6，a=3、b=3/2 时取到）。

两条路线，开头选择。

“找对称结构，和积换元”，7 步：

1. 识别对称结构（symmetry）：交换 a、b 后条件与目标都改变（2ab 不变，但 a+2b 变成 b+2a）。
2. 构造对称（choice）：x=a、y=2b，条件化为 xy=x+y+3，目标为 x+y。干扰项 x=2a、y=b 与 x=2a、y=2b 换元后条件仍不对称。
3. 和积换元（substitution，定义形态）：s=x+y，p=xy；x,y>0，目标 a+2b=s。
4. 改写条件（choice）：p=s+3，干扰项 p=s-3、2p=s+3。
5. 选不等式（choice）：x,y 为正数，p≤s²/4 与 s≥2√p 都算对；干扰项 p≥s²/4。完成后得 s²-4s-12≥0。
6. 解不等式（choice）：s≥6。干扰项“s≤-2 或 s≥6”没用 s>0 舍去负的一支，-2≤s≤6 解集方向反了。
7. 验证取等（equality）：x=y，代入 x²=2x+3 得 x=3，即 a=3、b=3/2。

“消元后分式分离”，5 步：

1. 消元定范围（choice）：画板给出 2b=(a+3)/(a-1)，a>1 正确；干扰项 a>0（照抄题目条件）、a≠1（只看分母）。
2. 分式分离（fill）：a+(a+3)/(a-1) ≟ (a-1)+□·1/(a-1)+○，候选 1–4，答案 4、2；错误组合展示两边都乘 a-1 后与 a²+3 的核对。
3. 观察和积结构（structure）：a-1 与 4/(a-1) 定积求和，常数 2 最后再加。
4. 应用基本不等式（amgm）：(a-1)+4/(a-1)≥4，a+2b≥6。
5. 验证取等（equality）：a-1=4/(a-1)，a=3，b=3/2。
