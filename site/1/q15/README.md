# Q15：先拆项，再只给负一次的一组乘入定值 1

入口 `/1/q15/`。题目：a>0、b>0、a+b=1，求 (b+1)/a+(a+1)/b 的最小值。

只提供“配齐次式”路线，思路与 Q13 一致。5 步：

1. 识别齐次结构：系统先拆项，原式=(b/a+a/b)+(1/a+1/b)。学生判断第一组零次、第二组负一次、条件表达式 a+b 正一次；完成后说明目标不是齐次式，只需给第二组乘条件表达式。
2. 配齐次式：选第二组，乘入 a+b，得 (1/a+1/b)(a+b)=2+b/a+a/b，原式=2+2b/a+2a/b。整个式子或第一组乘 a+b 会让第一组变成一次，提交后给出反馈。
3. 观察和积结构：2b/a 与 2a/b 积为 4，定积求和。
4. 应用基本不等式：两项和≥4，原式≥6。
5. 验证取等：2b/a=2a/b，正数下 a=b，结合 a+b=1 得 a=b=1/2。
