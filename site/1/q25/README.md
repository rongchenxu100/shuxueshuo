# Q25：换元分离的同型巩固

入口 `/1/q25/`，归入首页“分式分离法求最值”（第 06 组），排在 Q24 后面。题目：当 x>-1 时，求函数 y=(x²+3x+6)/(x+1) 的最小值（最小值 5，x=1）。

只提供“分式分离法”路线。5 步：

1. 换元（substitution）：点选分母 x+1，记为 t，得 x=t-1、t>0，分子化为 t²+t+4。干扰项是分母里的 x，选中后预览显示分母仍是 t+1，只是改名。
2. 分式分离（fill）：在 (t²+t+4)/t ≟ t+□+○·(1/t) 中填 1、4。候选 1、3、4、6，其中 3、6 是原分子的系数；确认错误组合后，页面把所填式子乘回 t，比较一次项与常数项；完成后得 y=t+1+4/t。
3. 观察和积结构：t 与 4/t 积为 4，定积求和，常数 1 不参与。
4. 应用基本不等式：t+4/t≥4，所以 y≥5。
5. 验证取等：t=4/t 且 t>0，得 t=2，回代 x=1，满足 x>-1。完成卡给出最小值 5 与取到时的 x。
