# Q23：逐项分式分离

入口 `/1/q23/`，首页新分组“分式分离法求最值”（第 06 组）的第一题。题目：x>0，求 y=(x²-x+4)/x 的最小值及此时 x 的值（最小值 3，x=2）。

只提供“分式分离法”路线。4 步：

1. 分式分离（fill）：在 (x²-x+4)/x ≟ x+□+○·(1/x) 中填 -1、4。确认错误组合后，页面把所填式子乘回 x，比较一次项与常数项；完成后得 y=x-1+4/x。
2. 观察和积结构：x 与 4/x 积为 4，定积求和，常数 -1 不参与。
3. 应用基本不等式：x+4/x≥4，所以 y≥3。
4. 验证取等：x=4/x 且 x>0，得 x=2。完成卡同时给出最小值 3 与 x=2。
