# Q01 交互练习

入口：[index.html](index.html)。在仓库根目录启动静态服务：

```sh
python3 -m http.server 8765 --bind 127.0.0.1 --directory site
```

访问 `http://127.0.0.1:8765/1/q01/`。页面无需构建、外部字体或 CDN；点选练习不依赖后台。需要对话时，本地启动 8766 后台，方式见 [后台说明](../../../server/shuxueshuo_server/tutor_demo/README.md)。也可直接通过该后台的 `/1/q01/` 同源访问。部署时静态页由 Nginx 提供，API 已接入现有 8000 后台，不需另开 demo 服务。

演示路径：

**基本不等式**

1. 选择“直接应用基本不等式”，在圈框中分别选择 m、n；保持条件为和、目标为积，确认结构。
2. 在基本不等式模板中重新选择 m、n，确认代入后显示定和替换和上界推导。
3. 在固定等号两侧重新选择 m、n，确认后显示取等验证和最大值。

**条件消元法**

1. 选择“条件消元法”，选择 `n = 2 − m` 或 `m = 2 − n`。系统代入目标式并展开，同时得到剩余变量的范围 `(0, 2)`。
2. 选择“配方”或“利用二次函数的顶点”。系统完成计算，得到上界 1 和候选取值 `m = n = 1`。
3. 判断候选取值是否满足正数、定和条件；确认后展示代回验证与最大值。最后简短对照基本不等式路线。

入口仅展示两条可完整练习的路径：直接应用基本不等式、条件消元法。其他思路可通过底部对话讨论，不额外展示方法选项；Q01 暂不提供计算板。

选择方案期间可直接切换路线；学习中或完成后可通过对话请求尝试另一条路线，旧尝试折叠保留，新尝试从首节点开始。重新练习清空本地 Context，下次对话才创建新后台会话。

方框与圆圈的 m/n 顺序可交换；同形状自动同步。结构箭头交换和、积的位置。两个槽位重复或结构反向时给出局部提示，不跳步。页面顶部可重新体验，刷新也从第一步开始。

每个问题（选方案、判断结构、基本不等式、取等条件）在前台无操作 10 秒后，温和突出提示按钮并出现一次“需要一点提示吗？”，不显示倒计时。点击、键盘操作和输入会重新计时并收起邀请；输入框聚焦时暂停，隐藏标签页时暂停。邀请或主动求助后，同一问题不再重复邀请；重新体验会重置。提示不自动展开，也不代替学生作答。

底部对话框始终可见。点选、填写、校验、反馈和推进在浏览器本地执行，不调用 API。文字或主动提示才连接 DeepSeek：批量同步尚未确认的页面操作，后台重新校验后结合教师 JSON 和 Context 回应。对话失败可继续点选，重试保留新增进度；若迟到回复切换了路径而产生冲突，保留本地进度并提示重新练习。

本题内容、推导与图形在 `index.html` 的模板中；`practice-config` 保存本地组件配置和答案。公共 `components.js` 实现组件，`context.js` 处理本地规则与记录，`runtime.js` 处理页面流程和按需对话，不再有专用 `q01.js`。后端 `lessons/q01.json` 是老师的教学说明，不负责渲染页面。两份配置通过路径、节点、版本及一致性测试对齐。

正式页面为 `/1/q01/`，旧 `/demo/q01.html` 保留跳转。公共资源位于 `site/assets/practice/`。无需构建或调用 Solver；刷新会重开练习，尚不持久保存进度。部署时需同时发布本页、公共资源与支持批量同步的后台代码。

设计依据：[静态课程与一对一老师的职责](../../../docs/interactive-lesson-shared-runtime-design.md)。
