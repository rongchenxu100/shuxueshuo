# Q02：平方与倒数平方的和

入口 `/1/q02/`，题干来自截图：求 `x² + 1/x²` 的最小值。在实数范围内讨论，定义域 `x≠0`；不要求 `x>0`。最小值为 2，在 `x=±1` 时取得。

## 路径与学生输入

| 路径 | 节点 | 学生提供 | 系统补充 |
| --- | --- | --- | --- |
| 直接法 | 观察结构 | 两项 x²、1/x²；定积求和 | 两项为正且积为 1 |
| 直接法 | 应用基本不等式 | 将两项放入 AM-GM 组件 | 化简得到下界 2 |
| 直接法 | 验证取等 | x²=1/x² | 求出 x=±1，验证最小值 |
| 配方 | 选择平方结构 | (x−1/x)² | 展开、整理、由平方非负得到下界 2 |
| 配方 | 验证取等 | x=1/x | 求出 x=±1，验证最小值 |

配方选择后即展示作者预写的展开式。和的平方也是成立的恒等变形，但仅利用平方非负得到的下界 −2 无法取到；保留预览并引导尝试差的平方，不判恒等式错误，不通过本预设节点。不提供自由计算板。
