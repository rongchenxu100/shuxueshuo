# Q13：只给第一项乘入定值 1

入口 `/1/q13/`。题目：a>0、b>0、2a+b=1，求 1/a+a/b 的最小值。

只提供“配齐次式”路线。5 步：

1. 识别齐次结构：第一项 1/a 负一次、第二项 a/b 零次、条件表达式 2a+b 正一次。三格次数，不显示相乘后的次数；完成后说明目标不是齐次式，只需给第一项乘条件表达式。
2. 配齐次式：选第一项，乘入 2a+b（相当于把分子的 1 换成 2a+b），得 2+b/a+a/b。整个式子乘 2a+b 会让第二项变成一次，提交后给出反馈。
3. 观察和积结构：b/a 与 a/b 积为 1，定积求和。
4. 应用基本不等式：两项和≥2，原式≥4。
5. 验证取等：b/a=a/b，正数下 a=b，结合 2a+b=1 得 a=b=1/3。
