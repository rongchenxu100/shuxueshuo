# Q21：双换元与待定系数

入口 `/1/q21/`，分组“换元求最值”，排在 Q12 后。题目：a>0、b>0、1/(4a+b)+1/(a+2b)=3，求 5a+3b 的最小值（4/3）。

只提供“换元法”路线。7 步：

1. 双换元（substitution）：在条件中点选 4a+b 与 a+2b，记为 x、y。只换一个时预览显示另一个分母仍含 a、b。完成后条件化为 1/x+1/y=3，x>0、y>0。
2. 用新元表示目标（fill）：在 5a+3b ≟ □·(4a+b)+○·(a+2b) 中填 1、1。确认错误组合后，页面展开所填式子，比较 a、b 的系数；完成后得 5a+3b=x+y。
3. 识别齐次结构：目标 x+y 为正一次，条件表达式 1/x+1/y 为负一次（与 Q12 方向相反）。
4. 配齐次式：给整个式子乘 (1/3)(1/x+1/y)=1，展开得 2/3+(1/3)(y/x+x/y)。全部 9 种范围与乘数组合接入计算展示，错误组合分别说明是否保持值、是否配成零次。
5. 观察和积结构：y/x 与 x/y 积为 1，定积求和。
6. 应用基本不等式：两项和≥2，5a+3b≥4/3。
7. 验证取等：x=y=2/3，回代 a=2/21、b=2/7 均为正。完成态说明 x、y 还需满足 2x>y、4y>x，取等点满足。
