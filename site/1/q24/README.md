# Q24：先换元再逐项分式分离

入口 `/1/q24/`，归入首页“分式分离法求最值”（第 06 组），排在 Q23 后面。题目：若函数 f(x)=(x²-2x+4)/(x-2)（x>2）在 x=a 处取最小值，求 a 的值（a=4，最小值 6）。

只提供“分式分离法”路线。5 步：

1. 换元（substitution）：点选分母 x-2，记为 t，得 x=t+2、t>0，分子化为 t²+2t+4。干扰项是分母里的 x，选中后预览显示分母仍是 t-2，只是改名。
2. 分式分离（fill）：在 (t²+2t+4)/t ≟ t+□+○·(1/t) 中填 2、4。确认错误组合后，页面把所填式子乘回 t，比较一次项与常数项；完成后得 f(x)=t+2+4/t。
3. 观察和积结构：t 与 4/t 积为 4，定积求和，常数 2 不参与。
4. 应用基本不等式：t+4/t≥4，所以 f(x)≥6。
5. 验证取等：t=4/t 且 t>0，得 t=2，回代 x=4。完成卡给出 a=4，并说明最小值 f(4)=6 不是所求的 a。
