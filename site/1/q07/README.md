# Q07：负根式中的定和求积

入口：`/1/q07/`。章节分类：常规配凑法求最值。

原题：已知 −3<x<0，求 y=x√(9−x²) 的最小值。
答案：−9/2，在 x=−3√2/2 时取到。

## 交互与教学要求

单路径 `matching`，复用公共组件，无题目专属 JS、无计算板。

1. **凑配表达式**（choice）：选择 −√[x²(9−x²)]；核对 √(x²)=|x|=−x，不能丢负号或根号。完成态以箭头展示转化，根号内正项使用蓝框、橙圈。
2. **观察结构**（structure）：选择 x²、9−x²，判断定和求积。先求乘积上界是原题的中间目标，原式仍求最小值。
3. **应用基本不等式**（amgm）：填写两个正项；系统代入和为 9，得到 √[x²(9−x²)]≤9/2。左右两侧均使用圈框。
4. **代回原式**（choice）：取负后得到 y≥−9/2；方向写反或漏掉负号不得通过。
5. **验证取等**（equality）：只需给 x²=9−x²。系统解方程、按开区间筛选负根，验证下界可达。
