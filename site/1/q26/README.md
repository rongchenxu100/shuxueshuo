# Q26：取倒数后逐项分离

入口 `/1/q26/`，归入首页“分式分离法求最值”（第 06 组），排在 Q25 后面。题目：若 x>0，求函数 y=2x/(x²+4) 的最大值（最大值 1/2，x=2）。

只提供“取倒数后分式分离”路线。5 步：

1. 转化目标（choice）：求 1/y 的最小值。干扰项“求 1/y 的最大值”方向反了；“求分母 x²+4 的最小值”忽略了分子 2x 也在变。完成后系统写出 x>0 ⇒ y>0、1/y=(x²+4)/(2x)。
2. 分式分离（fill）：在 (x²+4)/(2x) ≟ □·x+○·(1/x) 中填 1/2、2。候选 1/2、1、2、4；确认错误组合后，页面把所填式子乘回 2x，比较二次项与常数项；完成后得 1/y=x/2+2/x。
3. 观察和积结构：x/2 与 2/x 积为 1，定积求和。
4. 应用基本不等式：x/2+2/x≥2，即 1/y≥2，又 y>0，所以 y≤1/2。
5. 验证取等：x/2=2/x 且 x>0，得 x=2。完成卡给出最大值 1/2 与取到时的 x。
