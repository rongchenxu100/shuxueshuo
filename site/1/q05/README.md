# Q05：指数项的定积求和

入口：`/1/q05/`，归入基本不等式章节的「直接法求最值」。

原题：设 a、b 为实数，a+b=3，求 2^a+2^b 的最小值。
答案：4√2，在 a=b=3/2 时取到。

## 三个教学节点

| 节点 | 学生关键输入 | 系统补充 |
| --- | --- | --- |
| 观察结构 | 2^a、2^b；定积求和 | 指数项始终为正，乘积为 2^(a+b)=8 |
| 应用基本不等式 | 两个指数项与不等式的对应 | 化简下界为 4√2 |
| 验证取等 | 2^a=2^b；对话也接受 a=b | 联立 a+b=3 得 a=b=3/2 并验证可达 |

第一步提供 a、b、2^a、2^b 四个候选；后两步仅提供两个指数项。
选 a、b 并观察定和本身成立，但尚未联系到目标；a、b 不一定为正。
需要为正的是 2^a 和 2^b，不是指数 a、b。教师 JSON 明确区分这两点，避免把正确观察简单判错。
