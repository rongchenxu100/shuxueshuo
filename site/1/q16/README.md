# Q16：消参后分式分离，再凑配定积

入口 `/1/q16/`，分组“消参法求最值”。题目：x>0、y>0、x+2y+xy-7=0，求 x+y 的最小值。

只提供“消参法”路线。6 步：

1. 消参（choice）：选 x=(7-2y)/(y+1)。干扰项漏掉一次项 x、移项未变号，各有整理核对预览。完成后系统补出 x>0 ⇒ 0<y<7/2。
2. 分式分离（fill）：在 7-2y=□·(y+1)+○ 中填 -2、9，系统逐项除以分母，得 x+y=y+9/(y+1)-2。
3. 凑配表达式（choice）：选 (y+1)+9/(y+1)-3。未凑配时预览说明积不固定，常数未调整时预览说明不等价。
4. 观察和积结构：y+1 与 9/(y+1) 积为 9，定积求和。
5. 应用基本不等式：两项和≥6，x+y≥3。
6. 验证取等：(y+1)²=9，y=2 在范围内，x=1。
