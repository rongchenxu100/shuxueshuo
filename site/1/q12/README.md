# Q12：两个分母同时换元

入口 `/1/q12/`。题目：正数 m,n 满足 2m+n=6，求 1/(2m+1)+1/(n+1) 的最小值。

只提供“换元法”路线。6 步：

1. 换元：在目标式里点选两个分母 2m+1、n+1；两个都选才正确，得 x+y=8、x>1、y>1、1/x+1/y。只选一个时对照表如实展示另一个分母仍含原变量。
2. 识别齐次结构：目标负一次，条件表达式 x+y 正一次。
3. 配齐次式：选择整个式子，乘入 (x+y)/8；系统展开为 1/4+(1/8)(y/x+x/y)。
4. 观察和积结构：两个比值项正且积为 1，定积求和。
5. 应用基本不等式：两项和≥2，原式≥1/2。
6. 验证取等：y/x=x/y，系统得 x=y=4（均>1），即 m=3/2、n=3。

这是点选换元第一次使用两个新变量：`names` 为 x、y，只有两个分母可点，三种组合（只换左、只换右、都换）各有对照表模板。新变量按被选对象在式中的位置命名，所以只换 n+1 时它记为 x。
