# Q03 · 定积求和中的系数项

入口：`/1/q03/`，归类为「直接法求最值」。

题目：已知 x>0、y>0、xy=4，求 x+2y 的最小值。
答案：4√2，在 x=2√2、y=√2 时取到。

本页仅提供「直接应用基本不等式」完整路径，不新增专用 JS、计算板或 Prompt。

| 节点 | 学生的关键输入 | 组件候选 |
| --- | --- | --- |
| 观察结构 | 定积求和，两项为 x、2y | structure；x、y、2y |
| 应用基本不等式 | 将 x、2y 对应到公式，或表达等价关系 | amgm；x、2y |
| 验证取等 | x=2y（顺序可反转） | equality；x、y、2y |

第一步问题为「这两项是定和求积，还是定积求和？」。遗漏系数、和积方向错误、重复项或取等时误填 x=y 均不能推进；修正后可以继续。系统负责化简下界、联立原条件求出取值和验证，不额外要求学生填写 x、y。
