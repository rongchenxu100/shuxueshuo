# Q06：配凑固定积

入口 `/1/q06/`，章节分类「常规配凑法求最值」。
原题：实数 x>1，求 2x+2/(x-1) 的最小值。
答案为 6，在 x=2 时取到。

## 教学步骤

1. 凑配表达式：选择 2(x-1)+2/(x-1)+2。三个选项均有展开预览；遗漏补回的常数 2 或误写为 −2 不能通过。完成后只核对等价改写，保留常数 2；正性与固定积的依据在下一步展示。
2. 观察结构：圈框选择 2(x-1)、2/(x-1)，切换为定积求和。确认后展示两项为正、乘积为 4；只改写正确不能跳过这一判断。
3. 应用基本不等式：圈框填写 2(x-1)、2/(x-1)。系统化简两项和的下界为 4，再加回常数 2，得到原式不小于 6。
4. 验证取等：填写两项相等。系统解 (x-1)^2=1，由 x>1 筛出 x=2 并验证。

教师 JSON 同时接受 t=x-1>0 的等价改写和等价取等方程。直接对原两项应用基本不等式是成立的，但乘积 4x/(x-1) 不固定，不能直接确定本题最小值；对话应认可成立部分，再指出尚未解决的目标，不直接判为非法操作。
