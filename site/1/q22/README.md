# Q22：双换元后用待定系数改写条件

入口 `/1/q22/`，分组“换元求最值”，排在 Q21 后。题目：x>y>0、4x+3y=1，求 1/(2x-y)+2/(x+2y) 的最小值（9）。

只提供“换元法”路线。7 步：

1. 双换元（substitution）：在目标中点选 2x-y 与 x+2y，记为 a、b。只换一个时预览显示另一个分母仍含 x、y。完成后系统补出 a=x+(x-y)>0、b>0，目标化为 1/a+2/b。
2. 用新元表示条件（fill）：在 4x+3y ≟ □·(2x-y)+○·(x+2y) 中填 1、2。确认错误组合后，页面展开所填式子，比较 x、y 的系数；完成后条件化为 a+2b=1。
3. 识别齐次结构：目标 1/a+2/b 为负一次，条件表达式 a+2b 为正一次。
4. 配齐次式：给整个式子乘 a+2b（等于 1），展开得 5+2b/a+2a/b。全部 9 种范围与乘数组合均展示实际展开；未达目标时分开说明等值性与齐次次数，改选清除旧结果。
5. 观察和积结构：2b/a 与 2a/b 积为 4，定积求和，常数 5 不参与。
6. 应用基本不等式：两项和≥4，原式≥9。
7. 验证取等：a=b=1/3，回代 x=1/5、y=1/15，满足 x>y>0。完成态说明 a、b 还需满足 3a>b、2b>a，取等点满足。
