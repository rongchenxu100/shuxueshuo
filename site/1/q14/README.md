# Q14：直接乘 1，或先换元再配齐次

入口 `/1/q14/`。题目：x>0、y>0、1/x+4y=1，求 x+1/y 的最小值（最小值 9，x=3、y=1/6）。

按 x、y 看，目标与条件表达式都不是齐次式，所以提供两条路径，学生先选。

**直接乘 1**（排在前面，4 步）：

1. 整体乘 1：给整个式子乘 1/x+4y，展开为 5+4xy+1/(xy)；x 与 1/x、1/y 与 4y 相乘为常数。只乘一项、乘 1/x+y 或乘 1 都会给出反馈。
2. 观察和积结构：4xy 与 1/(xy) 积为 4，定积求和。
3. 应用基本不等式：原式≥9。
4. 验证取等：xy=1/2，结合条件得 x=3、y=1/6。

**先换元再配齐次**（6 步）：

1. 换元：点选 1/y 设为 t，得 1/x+4/t=1、t>0、目标 x+t。点 x 或 1/y 里的 y 只是改名。
2. 识别齐次结构：目标 +1，条件表达式 −1，相乘 0 次。
3. 配齐次式：整个式子乘 1/x+4/t，得 5+4x/t+t/x。
4. 观察和积结构：两项积为 4。
5. 应用基本不等式：原式≥9。
6. 验证取等：t=2x，得 x=3、t=6，回到 y=1/6。
