# Q28：对称结构与和积换元求范围

入口 `/1/q28/`，首页新分组“找对称结构和积换元”（第 07 组）的第一题。题目：若实数 x,y 满足 x²+y²-xy=1，求 x+y 的取值范围（[-2,2]）。首页第 07 组提示注明 Q08 的第二条路径也是这种做法，第 02 组提示反向提到第 07 组；Q08 本身未改。

只提供“找对称结构，和积换元”路线。6 步：

1. 识别对称结构（symmetry）：条件 x²+y²-xy 与目标 x+y 交换 x、y 后都不变。
2. 和积换元（substitution，定义形态）：s=x+y，p=xy；x,y 为实数，s、p 暂无符号限制。
3. 改写条件（choice）：s²-3p=1。干扰项 s²-2p=1 漏了 -xy；s²-p=1 是 x²+y²+xy。完成后得 p=(s²-1)/3。
4. 选不等式（choice）：p≤s²/4，由 (x-y)²≥0 得到，对任意实数成立。干扰项 s≥2√p 对非负数成立（允许零），但不适用于整个实数定义域（x=y=-1 为反例，p<0 时 √p 无实数意义）；p≥s²/4 方向反了。完成后代入得 s²≤4。
5. 解出范围（choice）：-2≤s≤2。干扰项只有上界、默认正数的 0<s≤2、解成 s²≥4 的 s≤-2 或 s≥2。
6. 验证端点（equality）：x=y（候选含 -y），得 x=y=±1，端点 ±2 都能取到；系统用判别式 s²-4p=(4-s²)/3≥0 说明中间值也都能取到。
