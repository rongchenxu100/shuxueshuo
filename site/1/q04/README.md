# Q04 · 负数条件下的基本不等式

入口：`/1/q04/`，归类为「直接法求最值」。

原题：已知 x<0，则 x+4/x−4 有（ ）。
A. 最大值0；B. 最小值0；C. 最大值−8；D. 最小值−8。

答案：C；最大值 −8，在 x=−2 时取得。

| 节点 | 学生的关键输入 | 组件 |
| --- | --- | --- |
| 整理表达式 | 原式是正项 −x、−4/x 的和的相反数，再减4 | choice；三个等价改写候选，选择后展开核对 |
| 应用基本不等式 | 两正项的和≥4 | amgm；候选 x、4/x、−x、−4/x，只有后两项标为正 |
| 回到原式 | 取负反向，再减4，原式≤−8 | choice；≤−8 / ≥−8 |
| 验证取等 | −x=−4/x | equality；系统解方程，用 x<0 筛出 −2 |

接受等价文本 x=4/x 作为取等条件；不把 x=2 作为满足原题的取值。不把只猜 C 当成表达了当前步骤的关键信息。学生提出 t=−x>0 的等价换元也可讨论；不提供重复路径或计算板。
