# Q18：配因式后整体消参

入口 `/1/q18/`，分组“消参法求最值”，排在 Q17 后。题目：正数 a、b 满足 2ab+2a+b=3，求 1/(2a+1)+1/b 的最小值（5/4）。

只提供“消参法”路线。5 步：

1. 配因式（单格 fill）：在 (2a+1)(b+1)=□ 中填 4。未确认使用问号等号；四种错答均展示展开所得4与实际填写的比较。提问保留计算，改选清除，重新确认才重算展示。
2. 消参（choice）：选 1/(2a+1)=(b+1)/4。干扰项 4/(b+1)、(b+1)/3 各有整理核对预览。完成后系统补出 0<b<3，目标式拆成 b/4+1/b+1/4，并说明为何保留 b。
3. 观察和积结构：b/4 与 1/b 积为 1/4，定积求和，常数 1/4 不参与。
4. 应用基本不等式：b/4+1/b≥1，原式≥5/4。
5. 验证取等：b=2 在 (0,3) 内，a=1/6，代回原条件成立。
