# Q11：换元

入口 `/1/q11/`。题目：a>0，b>0，a+b=2，求 2/(a+1)+4/b 的最小值。

只提供“换元法”路线。6 步：

1. 换元：在目标式里点选 a+1（或其中的 a），系统用对照表展示条件、范围、目标的改写；正确为 t=a+1，得 t+b=3、t>1、2/t+4/b。
2. 识别齐次结构：目标负一次，条件表达式 t+b 正一次。
3. 配齐次式：选择整个式子，乘入 (t+b)/3；系统展开为 2+(1/3)(2b/t+4t/b)。
4. 观察和积结构：两个比值项正且积为 8，定积求和。
5. 应用基本不等式：两项和≥4√2，原式≥2+4√2/3。
6. 验证取等：2b/t=4t/b，系统得 t=3√2−3（>1，在换元后的范围内），即 a=3√2−4、b=6−3√2。
