# Q29：先构造对称，再和积换元求范围

入口 `/1/q29/`，归入首页“找对称结构和积换元”（第 07 组），排在 Q28 后面。题目：若实数 x,y 满足 x²+4y²-2xy=1，求 x/2+y 的取值范围（[-1,1]）。

只提供“找对称结构，和积换元”路线。7 步：

1. 识别对称结构（symmetry）：交换 x、y 后条件与目标都改变，原式不对称。
2. 构造对称（choice）：a=x、b=2y，条件化为 a²+b²-ab=1，目标为 (a+b)/2。干扰项 b=4y（(4y)²=16y²）与 a=2x、b=y 换元后仍不对称。
3. 和积换元（substitution，定义形态）：s=a+b，p=ab；目标 x/2+y=s/2。
4. 改写条件（choice）：s²-3p=1，干扰项同 Q28。
5. 选不等式（choice）：p≤s²/4，干扰项同 Q28；完成后得 -2≤s≤2。
6. 解出范围（choice）：-1≤x/2+y≤1。干扰项 -2≤x/2+y≤2 忘了除以 2，另有只写上界、默认正数。
7. 验证端点（equality）：a=b（候选含 -b），即 x=2y，得 (1,1/2) 取 1、(-1,-1/2) 取 -1；系统用判别式说明中间值也都能取到。
