# Q20：消参后先判断两项为正

入口 `/1/q20/`，分组“消参法求最值”，排在 Q19 后。题目：m>2、n>1、3m+3n=mn+7，求 m+2n 的最小值（13）。

只提供“消参法”路线，固定消 m。7 步：

1. 消参（choice）：选 m=(3n-7)/(n-3)。干扰项 (3n+7)/(n-3)、(3n-7)/(3-n) 各有代回核对预览。完成后系统补出 n≠3，目标化为 (3n-7)/(n-3)+2n。
2. 分式分离（fill）：在 3n-7 ≟ □·(n-3)+○ 中填 3、2。确认错误组合后，页面展开所填式子，比较 n 的系数与常数项；完成后得 m+2n=2n+2/(n-3)+3。
3. 凑配表达式（choice）：选 2(n-3)+2/(n-3)+9。未凑配时预览说明积不固定，常数未调整时预览说明不等价。
4. 判断两项为正（choice，本题重点）：n>1 不能保证 n-3>0，要由 m>2 推出 n>3。放在凑配之后，学生已看到要判断的两项。完成后反向核对 n>3 时 m=3+2/(n-3)>3>2。
5. 观察和积结构：2(n-3) 与 2/(n-3) 积为 4，定积求和，常数 9 不参与。
6. 应用基本不等式：两项和≥4，m+2n≥13。
7. 验证取等：n=4 满足 n>3，m=5，代回原条件成立。
