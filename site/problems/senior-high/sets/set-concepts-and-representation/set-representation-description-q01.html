试用自然语言叙述下列集合所包含的元素：
（1）{x∈ℝ| x<4}；（2）{y∈ℝ| y<4}；（3）{y∈ℕ| y<4}；
（4）{x| y=x2+1}；（5）{y| y=x2+1}；（6）{(x,y)| y=x2+1}。答案：（1）小于4的全体实数；（2）小于4的全体实数；（3）小于4的自然数；（4）全体实数；（5）大于等于1的全体实数；（6）抛物线y=x^2+1上的所有点
解题要点

先看竖线左侧的代表元素，再读右侧共同特征。

  1. x、y 或 (x,y) 分别表示横坐标、纵坐标或点，不能只看条件式。
