# Q01 交互与对话演示

入口：[q01.html](q01.html)。在仓库根目录启动静态服务：

```sh
python3 -m http.server 8765 --bind 127.0.0.1 --directory site
```

访问 `http://127.0.0.1:8765/demo/q01.html`。页面无需构建、外部字体或 CDN；会话和对话依赖后台。本地同时启动 8766 后台，方式见 [后台说明](../../server/shuxueshuo_server/tutor_demo/README.md)。也可直接通过该后台的 `/demo/q01.html` 同源访问。部署时静态页由 Nginx 提供，API 已接入现有 8000 后台，不需另开 demo 服务。

演示路径：

**基本不等式**

1. 选择“直接应用基本不等式”，在圈框中分别选择 m、n；保持条件为和、目标为积，确认结构。
2. 在基本不等式模板中重新选择 m、n，确认代入后显示定和替换和上界推导。
3. 在固定等号两侧重新选择 m、n，确认后显示取等验证和最大值。

**条件消元法**

1. 选择“条件消元法”，选择 `n = 2 − m` 或 `m = 2 − n`。系统代入目标式并展开，同时得到剩余变量的范围 `(0, 2)`。
2. 选择“配方”或“利用二次函数的顶点”。系统完成计算，得到上界 1 和候选取值 `m = n = 1`。
3. 判断候选取值是否满足正数、定和条件；确认后展示代回验证与最大值。最后简短对照基本不等式路线。

入口依次展示五种方法：直接应用基本不等式、条件消元法、换元法、配齐次式、找对称结构。基本不等式和条件消元提供完整路线；另三种展示适用结构和本题不优先采用的原因，不判为数学错误。“找对称结构”按和积换元解释：本题已直接给出和与积，换元没有进一步简化，仍需建立和积不等关系。

选择方案期间可直接切换路线；学习中或完成后可通过对话请求尝试另一条路线，旧尝试折叠保留，新尝试从首节点开始。重新体验创建全新会话。

方框与圆圈的 m/n 顺序可交换；同形状自动同步。结构箭头交换和、积的位置。两个槽位重复或结构反向时给出局部提示，不跳步。页面顶部可重新体验，刷新也从第一步开始。

每个问题（选方案、判断结构、基本不等式、取等条件）在前台无操作 10 秒后，温和突出提示按钮并出现一次“需要一点提示吗？”，不显示倒计时。点击、键盘操作和输入会重新计时并收起邀请；输入框聚焦时暂停，隐藏标签页时暂停。邀请或主动求助后，同一问题不再重复邀请；重新体验会重置。提示不自动展开，也不代替学生作答。

底部对话框始终可见。点选由后台规则处理，文字和主动提示由 DeepSeek 理解；两者更新同一会话状态。完成节点的对话默认折叠，数学结果与推导由本题预设组件展示，不调用 Solver。教学路径和判定契约来自后台 JSON 文件，前端仍是 Q01 专用展示适配器。
